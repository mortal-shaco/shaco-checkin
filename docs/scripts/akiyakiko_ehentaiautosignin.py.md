## 脚本功能

- 按原计划每六小时第 1 分钟访问 E-Hentai 新闻页，核验每日黎明签到奖励或明确的今日已领取提示。
- 识别 Random Encounter 并提示人工处理或等待结束；不自动进入战斗，待处理时返回非零退出码。
- 保留 E_COOKIE、E_PROXY、E_USER_AGENT 参数；支持完整 Cookie 中包含等号的值与逐行多账号。
- 默认 TLS 三次重试后回退 TLS 1.2 三次，验证服务器证书，限制请求超时和响应大小，禁止凭据重定向。
- 识别 Cookie 续期和过期提示数量，保留全部原始字段，只合并上游允许的六类字段；显式开启后使用私密缓存兼容旧版本凭据读取。
- 显示官方明确返回的当前登录用户名，隐藏凭据、手机号及原始响应；不输出代理地址或完整请求头。
- 完全断网预演、时间轴阶段日志、账号与子任务统计、恰好一行 TASK_SUMMARY 结构化输出及失败闭合退出码。
- 所有结局均生成脱敏通知总结，依全局开关和脚本名单调用青龙通知；预演仅本地演示，通知不可用不改变业务结果。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `E_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://e-hentai.org 后打开开发者工具的网络面板，访问 news.php，从该请求的请求头中复制完整 Cookie；至少包含 ipb_member_id 与 ipb_pass_hash。不要复制 Cookie: 前缀。请勿把凭据发给他人。
- 填写格式：每个非空行填写一个账号的完整 Cookie；账号内字段用分号分隔，字段仅按首个等号拆分，后续等号、& 和 @ 原样保留。显式启用私密缓存时可兼容从缓存读取，但首次配置及预演仍应填写本变量。

### 可选参数

### `E_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：按部署环境需要，从自己的代理服务取得地址；不填则直连且不读取系统代理。
- 填写格式：单行 HTTP 或 HTTPS 代理地址，可含该代理自己的认证信息；不会输出地址。不支持其他代理协议。

### `E_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：可从浏览器开发者工具中同一请求的 User-Agent 请求头复制；不填使用上游默认浏览器标识。
- 填写格式：单行可打印 ASCII 文本，不得包含凭据。

### `E_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网预演时设为 1；正式运行不设置或设为 0。
- 填写格式：1/0、true/false、yes/no、on/off；预演仅校验配置并生成本地通知预演，不验证真实登录或签到。

### `E_COOKIE_CACHE`

- 必填：否
- 敏感：否
- 获取或设置：确需跨运行保存服务器续期 Cookie 时主动设为 1，默认 0。
- 填写格式：1/0、true/false、yes/no、on/off；预演始终不读写缓存，正式运行仅保存业务核验通过的账号更新。

### `E_COOKIE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：启用缓存时可指定自己可写的私密文件路径；默认脚本旁的 ehentai_cookie.txt。使用旧缓存前先确保文件仅当前用户可读写（权限 600）。
- 填写格式：本地文件路径；每行一个账号，与 E_COOKIE 顺序一致；拒绝符号链接，原子写入并设置权限 600。环境变量优先，修改账号顺序后需重新配置。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式列出需要通知的脚本；本任务没有内置默认名单。
- 填写格式：支持 catalogId、AkiyaKiko_EhentaiAutoSignIn/autosignin.py、autosignin.py、当前文件名及文件名通配符；逗号、分号或空白分隔，* 匹配全部，空值不选中任何脚本。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块不在标准目录时填写该模块所在的可信目录；不需要克隆其他项目。
- 填写格式：本地目录，包含 notify.py 或 sendNotify.js；也会尝试导入 notify.send 并查找 /ql/data/scripts 和 /ql/scripts；模块缺失仅告警。

## 多账号

E_COOKIE 每个非空行是一个独立账号；同一账号配套 Cookie 字段放在同一行，以分号分隔，每字段仅按首个等号拆分。禁止使用 & 或 @ 分隔账号。逐账号独立执行，任一账号配置、网络、业务核验失败或出现待处理随机事件时整体非零退出。

## 副作用与风险

- 正式运行访问新闻页可能领取每日奖励、刷新会话或触发随机事件。
- 仅显式设置 E_COOKIE_CACHE=1 时将通过业务核验的续期 Cookie 写入本地私密缓存，不修改环境变量。
- 正式运行且通知启用时通过部署环境的青龙通知模块向已配置的渠道发送脱敏总结。
