# 大海资源站每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/dahai.js`
- 青龙命令：`node scripts/dahai.js`
- 建议 Cron：`0 30 11 * * *`
- 发布哈希：`2a17e92f9b12ad6fb8e917c88d90667ee59ef5f6fabdadcd621325c1709ce27b`
- 许可证：`MIT`

## 脚本功能

- 每天 11:30 使用登录 Cookie 签到
- 显示连续签到天数
- 显示官方返回的非敏感昵称、用户名、显示名称或公开 UID
- 明确识别签到成功与今日已签到，其他错误失败退出
- 多账号独立执行及汇总
- 完全断网预演、阶段日志和结构化汇总
- 通过青龙通知模块发送脱敏总结，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `DAHAI_COOKIE_LIST`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://vip.lzzcc.cn 后，在浏览器开发者工具网络面板打开本站请求，复制请求头 Cookie 完整值；失效后重新登录获取。
- 填写格式：每个非空行一个账号的完整 Cookie，保留分号和等号，不使用 & 或 @ 分隔账号。

### 可选参数

### `DAHAI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置，1 开启完全断网预演。
- 填写格式：1、true、yes、on 开启预演，其他值执行正式签到。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 sendNotify.js 所在目录，默认检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地通知模块目录路径。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
