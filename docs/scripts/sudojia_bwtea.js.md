# 霸王茶姬每日签到与积分提醒

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_bwtea.js`
- 青龙命令：`node scripts/sudojia_bwtea.js`
- 建议 Cron：`22 11 * * *`
- 发布哈希：`6c7a37e9d10e71acbf0f22997db91262260bfb5b30c0da79c90b0b1c0fe7baec`
- 许可证：`GPL-3.0`

## 脚本功能

- 登录状态校验及官方昵称显示
- 查询新版签到状态及连续签到天数，未签到时执行签到并复核状态
- 查询当前积分及即将到期的积分和日期
- 逐行多账号隔离执行与失败非零退出
- 完全断网预演、脱敏青龙通知及时间轴和结构化统计

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BW_TEA_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在本人微信霸王茶姬小程序登录时抓包，找到 https://webapi2.qmai.cn/web/seller/oauth/flash-sale-login 响应中的 token 和 user.id；失效后重新登录获取。不要分享抓包内容。
- 填写格式：每个非空行填写 token#id，仅首个 # 分隔配套凭据，后续内容原样保留；不使用 & 或 @ 分隔账号。

### 可选参数

### `BW_TEA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置为 1 可断网预演。
- 填写格式：1 为预演，其他值为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启。
- 填写格式：0、false、no、off 关闭，其余开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；未设置则查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地通知模块目录；业务运行不依赖该目录。

## 参数获取方法

## 多账号

每个非空行一个账号，按首个 # 分割 token 与 user.id；各账号独立处理，任一失败整体非零退出。
