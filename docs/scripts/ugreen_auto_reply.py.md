# 绿联社区自动回复

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ugreen_auto_reply.py`
- 青龙命令：`python3 scripts/ugreen_auto_reply.py`
- 建议 Cron：`2 10 * * *`
- 发布哈希：`f083d3c155500a0646099f861ffb046ad593406050777ce2b93ccf0eba7a5f2f`
- 许可证：`MIT`

## 脚本功能

- 使用 Cookie 登录绿联社区 club.ugnas.com
- 从功能讨论、玩法攻略、用户互助三个板块抓取帖子列表
- 提取 formhash 后对随机帖子提交回复
- 公开回复文案优先使用一言，失败或 dry-run 时回退本地语料
- 支持 UGREEN_COOKIE 每行一个账号的多账号独立处理，任一账号失败时整体非零退出
- 提供完全断网预演、时间轴脱敏日志、账号与任务统计及单行 TASK_SUMMARY
- 按青龙全局开关发送脱敏通知，通知故障不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `UGREEN_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：打开 https://club.ugnas.com/ 并登录绿联社区，按 F12 打开开发者工具，在请求头中复制 Cookie，填入青龙环境变量。多个账号时每行一个 Cookie。
- 填写格式：每行一个完整浏览器 Cookie 字符串；账号之间只用换行分隔，不要用 &、@ 或其他符号分隔账号。

### 可选参数

### `UGREEN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要在完全断网条件下检查配置与流程时设置。
- 填写格式：设为 1、true、yes 或 on 启用预演。

### `UGREEN_REPLY_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：控制每个账号本轮回复的帖子数量。不填写时默认 3，避免上游默认连发 20 帖的高副作用。
- 填写格式：1 至 20 的整数。

### `UGREEN_ACTION_DELAY_SEC`

- 必填：否
- 敏感：否
- 获取或设置：两次回复之间的等待秒数。不填写时默认 2 秒；已移除上游 30–600 秒随机长等待。
- 填写格式：0 至 60 之间的秒数。

### `UGREEN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置单次 HTTPS 超时；不填写时为 30 秒。
- 填写格式：5 至 120 之间的秒数。

### `UGREEN_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可选。覆盖一言失败或 dry-run 时使用的本地回退文案；不填写则从内置语料随机选取。
- 填写格式：不超过 280 字的纯文本。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 QINGLONG_NOTIFY=auto 时填写要通知的脚本选择器。
- 填写格式：可用逗号、分号、空白或换行分隔；支持 a941733da99ecdb7、candidate.py、ugreen_auto_reply.py、通配符或 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙 notify.py 不在默认位置时，填写其所在目录。
- 填写格式：包含 notify.py 的本地目录路径。

## 多账号

每个账号的 Cookie 单独占一行；逐账号独立执行自动回复，任一账号失败时进程整体返回非零退出码。
