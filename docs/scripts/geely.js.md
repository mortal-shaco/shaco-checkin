- 脚本路径：`scripts/geely.js`

- 许可证：`MIT`

## 脚本功能

- 每日风控签到（MD5 签名请求头 X-Data-Sign）
- 查询当月累计/连续签到天数
- 查询成长体系能量体总量
- 可选读取 App Store 最新版本号并用于请求头
- 多账号逐行处理、断网预演、时间轴日志与单行 TASK_SUMMARY
- 青龙脱敏通知；通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `GEELY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人设备抓包吉利汽车 APP（host=app.geely.com）请求头中的 token 与 deviceSN/devicesn；每个非空行写入一个账号。不要提交或分享真实凭据。
- 填写格式：每行一个账号：token|devicesn（仅在首个竖线处拆分）；或单行 JSON {"token":"...","devicesn":"..."}。不使用 & 或 @ 分隔账号。

### 可选参数

### `geely_val`

- 必填：否
- 敏感：是
- 获取或设置：上游旧版变量名；仅当未设置 GEELY_ACCOUNTS 时作为兼容输入读取，获取方式与 GEELY_ACCOUNTS 相同。
- 填写格式：与 GEELY_ACCOUNTS 相同：每行 token|devicesn 或 JSON 对象。

### `GEELY_APP_VERSION`

- 必填：否
- 敏感：否
- 获取或设置：可选。需要固定客户端版本号时自行填写；未设置时正式运行会尝试查询 App Store，失败则使用 3.25.0。
- 填写格式：形如 3.25.0 的版本字符串

### `GEELY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演排查时设为 1；正式签到勿开启。
- 填写格式：1/true/yes/on 启用断网预演；0/false/no/off 或不设置表示正式运行

### `GEELY_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：网络较慢时可自行调大超时；默认 15000 毫秒。
- 填写格式：1000 至 60000 的整数毫秒

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选。设置后仅对列表中的脚本启用通知；空值表示全部关闭。
- 填写格式：逗号/分号/空白/换行分隔的 catalog-id、文件名或 glob；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙 notify.py / sendNotify.js 所在目录；容器内部一般无需设置。
- 填写格式：绝对路径目录

## 多账号

每个非空行一个账号；同一账号的 token 与 devicesn 写在同一行（token|devicesn 或 JSON）。任一账号失败则进程以非零退出码结束。
