# 今日校园信息收集

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/dailycp.py`
- 青龙命令：`python3 scripts/dailycp.py`
- 建议 Cron：`57 8 * * *`
- 发布哈希：`ee6ca1ea34be670014674a08418c1f1502bf2a6e0d4cf74324d5f393f792b593`
- 许可证：`MIT`

## 脚本功能

- 按学校全名解析今日校园租户与登录地址
- 支持 campusphere IAP 与 AuthServer 登录
- 查询并自动填写提交待处理信息收集任务
- 可选确认待办通知（默认关闭）
- 基于本地 formdb 模板复用历史填报内容
- 多账号逐行独立处理与失败汇总
- 完全断网预演、时间轴日志与单行 TASK_SUMMARY
- 青龙脱敏通知及全局通知开关

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `DAILYCP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人学校在今日校园入驻的学号与登录密码；学校名称须与今日校园租户列表中的全名一致；定位地址填写学校要求的详细位置文本。切勿写入公开仓库或日志。
- 填写格式：每个非空行一个账号：学校全名|学号|密码|定位地址；仅按前三个 | 分割，地址中后续 | 保留；支持空行与 # 注释；不要用 & 或 @ 分隔账号

### 可选参数

### `DAILYCP_SCHOOL`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名；仅当 DAILYCP_ACCOUNTS 为空时与 USERNAME/PASSWORD/ADDRESS 成对使用
- 填写格式：今日校园租户列表中的学校全名

### `DAILYCP_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名；仅当规范变量为空时与学校、密码、地址一起使用
- 填写格式：学号或统一身份认证用户名

### `DAILYCP_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名；仅当规范变量为空时与学校、学号、地址一起使用
- 填写格式：对应学号的登录密码明文

### `DAILYCP_ADDRESS`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名中的定位地址；仅当规范变量为空时使用
- 填写格式：提交信息收集时使用的详细定位文本，例如 中国某省某市某区某路

### `DAILYCP_FORMDB`

- 必填：否
- 敏感：否
- 获取或设置：真实执行必填：指向已按发送者用户名命名的本地 JSON 表单模板目录。首次缺模板时脚本会写入空白稿，需手工填好后再跑。断网预演可不填。
- 填写格式：本地目录绝对或相对路径，例如 /ql/data/dailycp-formdb

### `DAILYCP_CONFIRM_NOTICE`

- 必填：否
- 敏感：否
- 获取或设置：需要同时确认待办通知时设为 1；上游默认未启用，本维护版默认关闭以保持原行为
- 填写格式：1/true/yes/on 启用；默认关闭

### `DAILYCP_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自定义单次 HTTPS 请求超时秒数
- 填写格式：5 到 60 的数字秒，默认 20

### `DAILYCP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演、只校验配置时手动设置为 1
- 填写格式：1/true/yes/on 启用预演；默认实际执行

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本白名单启用通知时设置；空值表示全部禁用
- 填写格式：catalog-id、脚本路径、文件名或 glob，可用逗号/分号/空白/换行分隔；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认路径时，设为 notify.py 或 sendNotify.js 所在目录
- 填写格式：本地目录绝对路径

## 多账号

DAILYCP_ACCOUNTS 中每个非空行是一个独立账号；格式为学校全名|学号|密码|定位地址（仅按前三个 | 分割）；逐账号解析租户、登录、提交信息收集（可选确认通知），任一账号失败时进程整体非零退出

## 副作用与风险

- 实际执行时登录今日校园并建立内存会话
- 实际执行时提交信息收集表单，改变当日填报状态
- 启用 DAILYCP_CONFIRM_NOTICE 时确认待办通知
- 缺少本地模板时会向 DAILYCP_FORMDB 写入空白 JSON 草稿
- 启用青龙通知时会向已配置渠道发送脱敏任务汇总
