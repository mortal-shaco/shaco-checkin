# 网易云游戏自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/wyycg.py`
- 青龙命令：`python3 scripts/wyycg.py`
- 建议 Cron：`47 1 * * *`
- 发布哈希：`aa3dce562c711a85fcaae625ea5a3f217bafe265e6a8ccefa9716cb657547f8c`
- 许可证：`Apache-2.0`

## 脚本功能

- 验证网易云游戏 Authorization 凭据并读取账户配置
- 每日签到并对业务结果进行明确成功判定，未知响应按失败处理
- 显示官方返回的非敏感昵称、用户名、显示名称或公开 UID
- 多账号逐行处理与独立失败统计
- 兼容旧凭据变量及原主脚本的位置参数输入
- 青龙统一通知与原主脚本的 Telegram、ServerChan、QQ、PushPlus 可选推送
- 完全断网预演、时间轴日志、账号统计及单行结构化总结
- 校验网易云游戏账号凭据
- 执行每日签到并核验业务成功标志
- 显示官方响应中的昵称、用户名、显示名称或公开 UID
- 按换行处理多账号并隔离失败
- 兼容原 wyycg_cookies 凭据变量及可选 PPKEY 推送
- 完全断网预演、分阶段脱敏日志和结构化汇总
- 所有运行结果均尝试青龙通知，支持全局关闭并保留业务退出码
- 每日网易云游戏签到，保留每天 08:20 的计划和原请求路径、POST 方法及请求头格式。
- 换行多账号及原 authorization 字段配置兼容，各账号独立处理。
- 标准库实现 HTTPS 请求，设置超时、响应大小上限并拒绝跳转。
- 仅接受明确签到成功或已签到文字；空响应、未知业务结果和错误均失败闭合。
- 官方返回安全的昵称、用户名、显示名或公开 UID 时显示原值，不输出凭据及原始响应。
- 完全断网预演，通知仅模拟；实际模式在成功、部分失败、失败和配置错误后尝试青龙通知。
- 时间轴日志、阶段耗时、账号与任务统计，以及恰好一条 TASK_SUMMARY JSON 记录。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WYYCG_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录网易云游戏网页 https://cg.163.com，在浏览器开发者工具网络面板查看 n.cg.163.com 的账户配置或签到请求，复制 Authorization 请求头完整值。不要填写 Cookie 请求头，也不要公开凭据。
- 填写格式：每个非空行一个账号的完整 Authorization 值；保留凭据内部字符，不使用 #、&、@ 分隔账号。

### 可选参数

### `wyycg_cookies`

- 必填：否
- 敏感：是
- 获取或设置：兼容关联来源的旧环境变量；获取方式与 WYYCG_ACCOUNTS 相同。仅在规范变量为空时读取；也兼容第一个位置参数。
- 填写格式：每个非空行一个账号；原来的 # 账号分隔符已统一改为换行。 此共享旧变量仅接受明确 success/ok=true 或 code/statusCode=0/200，不根据模糊文本判成功。

### `WYYCG_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 开启完全断网预演；不访问业务接口或通知渠道。
- 填写格式：1 开启；0、false、no、off 或空值关闭，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙 notify.py 所在目录；也会尝试导入 notify 及标准青龙脚本目录。通知组件缺失不影响业务退出码。
- 填写格式：本机通知目录的绝对路径；业务运行不依赖此目录。

### `WYYCG_TELEGRAM_ID`

- 必填：否
- 敏感：是
- 获取或设置：从 Telegram 获取消息接收者标识；兼容第二个位置参数。
- 填写格式：与 WYYCG_TELEGRAM_TOKEN 同时设置才启用额外推送。

### `WYYCG_TELEGRAM_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从 Telegram BotFather 获取机器人令牌；兼容第三个位置参数。
- 填写格式：机器人令牌完整值，仅用于 Telegram 推送。

### `WYYCG_SERVERCHAN_KEY`

- 必填：否
- 敏感：是
- 获取或设置：从 ServerChan 账户的发送密钥页面获取；兼容第四个位置参数。
- 填写格式：发送密钥完整值；选填。

### `WYYCG_QQ_KEY`

- 必填：否
- 敏感：是
- 获取或设置：从原来源使用的 push.xuthus.cc 服务获取；服务是否仍可用未经联网核验；兼容第五个位置参数。
- 填写格式：发送密钥完整值；选填。

### `WYYCG_PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从原来源使用的 PushPlus 服务账户获取令牌；旧域名已采用 HTTPS，服务是否可用未经联网核验；兼容第六个位置参数。
- 填写格式：发送令牌完整值；选填。

### `CG163_ACCOUNTS`

- 必填：否
- 敏感：是
- 获取或设置：登录 https://cg.163.com/，打开浏览器开发者工具的网络面板，查看 n.cg.163.com 的 client-settings/@current 或 sign-today 请求，复制请求头 Authorization 的完整值；不是整个 Cookie。凭据过期后重新登录并获取。
- 填写格式：每个非空行填写一个账号的完整 Authorization 值，保留可能存在的认证前缀；不使用 #、& 或 @ 分隔账号。

### `PPKEY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从 PushPlus 官网登录后的个人中心获取推送令牌；不设置时仅尝试青龙通知。
- 填写格式：单个推送令牌；采用 HTTPS 请求体传输，不写入 URL。

### `CG163_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 启用完全断网预演，正式运行时移除或设为 0。
- 填写格式：1、true、yes、on 启用，其他值关闭，默认关闭。

### `GAME163_AUTHORIZATION`

- 必填：否
- 敏感：是
- 获取或设置：登录本人网易云游戏网页 https://cg.163.com/，打开浏览器开发者工具网络面板，从发往 n.cg.163.com 的已认证请求复制完整 Authorization 请求头值；过期后重新登录获取，不要公开凭据。
- 填写格式：每个非空行一个账号的完整 Authorization 值，保留前缀和内部字符，不使用 & 或 @ 分隔账号。

### `GAME163`

- 必填：否
- 敏感：是
- 获取或设置：旧配置兼容入口，凭据获取方式同 GAME163_AUTHORIZATION；规范变量非空时优先使用规范变量。
- 填写格式：每行一个完整凭据，或原 GAME163 账号配置的 JSON 数组，每项为含 authorization 字符串的对象；不再依赖私有配置文件。

### `GAME163_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置，用于完全断网的参数和流程预演。
- 填写格式：1、true、yes、on 开启，默认 0；预演不代表业务签到成功，通知仅模拟投递。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号；规范变量优先，其次旧变量，再次第一个位置参数。逐个独立处理，任一账号失败时整体非零退出。 兼容 CG163_ACCOUNTS、GAME163_AUTHORIZATION、GAME163 旧 JSON 数组及共享 wyycg_cookies；按变量来源分别校验业务结果。旧两份任务的每日 01:34 与 01:21 Cron 可改为调用本规范脚本。

## 副作用与风险

- 执行每日签到，可能领取云游戏时长
- 真实执行时通过已配置的通知渠道发送脱敏任务总结
- 每日签到可能增加账号签到天数及奖励
- 向青龙通知渠道发送脱敏任务摘要
- 配置 PPKEY 后向 PushPlus 发送脱敏任务摘要
- 实际模式向网易云游戏提交每日签到，可能获得服务端签到奖励。
- 通知开启且实际模式下，通过青龙通知模块发送脱敏任务总结。
