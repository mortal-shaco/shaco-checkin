## 脚本功能

- 按原每日 07:32 计划获取 UTF-8 URL 列表并向百度推送本站 URL
- 支持多站点独立执行及显式重复推送次数，统计接受条数、成功次数、失败次数与剩余配额
- 保留 data_url、submit_url、times 字段和 BAIDU 数组兼容输入
- 完全断网参数预演、请求超时、响应大小限制、禁止重定向、本站 URL 检查和明确业务成功判定
- 脱敏时间轴日志、账号及任务统计、单行 TASK_SUMMARY 结构化总结和青龙通知；通知失败不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BAIDU_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录百度搜索资源平台验证站点，在普通收录的 API 提交页面获取含 site 和 token 的接口地址，使用 HTTPS。自行提供公开可读取的 UTF-8 URL 列表，每行一条本站 URL。
- 填写格式：每个非空行为一个 JSON 对象，data_url 为 HTTPS 列表地址，submit_url 为 https://data.zz.baidu.com/urls?site=已验证站点地址&token=站点令牌。times 可选整数 1 至 100，默认 1。

### 可选参数

### `BAIDU`

- 必填：否
- 敏感：是
- 获取或设置：旧配置兼容输入，优先迁移到 BAIDU_ACCOUNTS；使用百度站点 API 提交页面的令牌与自己的列表地址。
- 填写格式：非空 JSON 数组，元素字段与 BAIDU_ACCOUNTS 相同，仅在规范变量为空时读取。

### `BAIDU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 进行断网预演。
- 填写格式：1 开启；0、false、no、off 或空值关闭。预演不调用任何网络或外部通知模块。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启。
- 填写格式：0、false、no、off 或空值关闭，其他非空值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录；也查找可导入的 notify 模块及青龙标准脚本目录。
- 填写格式：本地目录路径，仅用于可选通知，业务 HTTP 不依赖本地文件。

## 多账号

每个非空行一个账号 JSON 对象，将该账号的列表地址与含令牌的接口地址放在同一对象中。逐账号独立执行，任一失败整体非零退出；兼容旧 BAIDU 数组，不使用 & 或 @ 分隔账号。
