# 科研通 AbleSci 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/worker.js`
- 青龙命令：`node scripts/worker.js`
- 建议 Cron：`9 8 * * *`
- 发布哈希：`e37805da91387bb8b35f156234bcc8bfd27ac877d9475c91de06b401fbb22bb2`
- 许可证：`MIT`

## 脚本功能

- 使用科研通登录 Cookie 调用官方签到接口，识别签到成功与今日已签到。
- 展示接口返回的积分奖励、当前积分、连续签到天数，以及昵称/用户名/公开 UID 等非敏感身份（若返回）。
- 支持每行一个 Cookie 多账号；兼容上游 COOKIE 变量名；账号失败隔离并汇总退出状态。
- 可选自定义 User-Agent 与请求超时。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验 Cookie 格式、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ABLESCI_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：使用本人浏览器登录 https://www.ablesci.com 后，打开开发者工具网络面板，复制对本站请求的完整 Cookie 请求头（通常含 _identity-frontend 等会话字段）。勿填写他人 Cookie 或日志中的敏感信息。
- 填写格式：每个非空行一个账号的完整 Cookie 字符串。不使用 & 或 @ 分隔账号。行内保留 Cookie 原文，不做字段拆分。

### 可选参数

### `COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：上游 Cloudflare Worker 兼容变量；仅当未设置 ABLESCI_COOKIE 时作为备用输入，获取方式与 ABLESCI_COOKIE 相同。
- 填写格式：与 ABLESCI_COOKIE 相同：每行一个 Cookie。正式配置请优先使用 ABLESCI_COOKIE。

### `ABLESCI_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：需要自定义浏览器标识时手动设置；一般可留空。
- 填写格式：完整 User-Agent 字符串；缺省使用内置桌面 Chrome UA。

### `ABLESCI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不访问科研通、不签到、不投递真实通知。

### `ABLESCI_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：1000 至 60000 的整数毫秒；缺省或非法值使用 15000。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 ac5bf2222e757d4e、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

ABLESCI_COOKIE（或兼容 COOKIE）每个非空行一个账号的完整 Cookie。账号逐个独立签到与统计，任一账号失败则整体非零退出，其余账号继续执行。

- 正式运行时向科研通提交每日签到，可能增加账号积分或连续签到天数。
