# 阿里云盘签到与奖励领取

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/autosignin.js`
- 青龙命令：`node scripts/autosignin.js`
- 建议 Cron：`0 9 * * *`
- 发布哈希：`c9f9cb1e7cf025514b245d555ac63849d2617eb3d29b473f92cf61f6b2a4a72b`
- 许可证：`MIT`

## 脚本功能

- 刷新并验证登录令牌，显示官方返回的非凭据账号身份。
- 每天 9 点执行签到并显示当月累计签到天数。
- 领取当天已完成的每日签到奖励和每日任务奖励，展示领取结果；未完成及已结束奖励明确跳过。
- 保留维护候选的业务状态及结构核验；未知奖励结构、状态和类型按失败处理。
- 逐行多账号及旧变量兼容，账号独立执行，任一失败整体非零退出。
- 完全断网预演、请求超时、响应大小限制、脱敏时间轴日志、每账号及任务统计和唯一 TASK_SUMMARY 汇总。
- 所有运行结果生成脱敏通知总结；正式运行使用青龙 sendNotify.js 投递，预演仅生成不联网投递。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ALIYUN_REFRESH_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录自己的阿里云盘网页版，在浏览器开发者工具的应用（Application）→本地存储（Local Storage）中查找登录信息里的 refresh_token，仅复制该字段值并保存到青龙环境变量。失效后重新登录获取，不要复制完整登录对象。
- 填写格式：每个非空行一个刷新令牌；空行忽略，不使用 & 或 @ 分隔账号。

### 可选参数

### `refreshToken`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容输入，获取方式与 ALIYUN_REFRESH_TOKEN 相同，仅在规范变量未设置时使用。
- 填写格式：每个非空行一个刷新令牌，旧版 & 分隔格式需改为换行。

### `ALIYUN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网验证时设置为 1；正式运行设为 0 或不设置。
- 填写格式：1 为断网预演，不调用业务接口及外部通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启；可设置关闭值。
- 填写格式：默认 1；0、false、no、off 关闭，不区分大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已配置的青龙 sendNotify.js 所在目录；默认依次查找 /ql/data/scripts、/ql/scripts。
- 填写格式：本机目录路径；模块不可用或失败不改变业务退出码。

## 多账号

每个非空行一个账号的刷新令牌，规范变量优先于旧变量。账号独立执行；账号或奖励失败继续处理其他账号及奖励，但整体非零退出。
