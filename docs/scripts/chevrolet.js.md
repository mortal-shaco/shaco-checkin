## 脚本功能

- 雪佛兰 APP 每日签到，保留上游接口、POST 方法及 cpctoken 请求头参数。
- 每行一个账号，兼容上游 xflCookie，独立处理并汇总账号结果。
- 完全断网预演，检查参数及执行流程，不把预演标为业务签到成功。
- 请求超时及响应大小限制，严格检查 HTTP 状态和明确业务成功标记。
- 显示官方返回的非秘密昵称、用户名、显示名称或公开 UID，同时抑制凭据、手机号和原始响应。
- 脱敏时间轴日志、账号及任务统计、单行 TASK_SUMMARY 汇总。
- 通过青龙 sendNotify.js 通知成功、部分失败、失败、配置错误及预演结果，通知异常不改变业务退出码；断网预演中通知网络被禁止。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CHEVROLET_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人授权设备上使用抓包工具查看雪佛兰 APP 签到请求 https://ctwx.sgmlink.com/api/check/submit 的 cpctoken 请求头，复制值；仅在本地青龙环境变量中保存，不分享抓包或凭据。
- 填写格式：每个非空行填写一个账号的 cpctoken 原始值，不含请求头名称；不使用 &、@ 或其他字符分隔账号。

### 可选参数

### `xflCookie`

- 必填：否
- 敏感：是
- 获取或设置：上游旧参数，获取方式同 CHEVROLET_ACCOUNTS；未设置规范变量时自动兼容。
- 填写格式：每个非空行填写一个 cpctoken；规范变量即使为空也优先，不回退旧变量。

### `CHEVROLET_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要离线检查时手动设置。
- 填写格式：1 表示断网预演，其他值表示实际签到。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙已有通知渠道配置；需要关闭通知时手动设置本开关。
- 填写格式：默认 1；0、false、no、off（不区分大小写）关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：通常无需设置；自定义安装时填写本地青龙 sendNotify.js 所在目录。
- 填写格式：本地目录路径；同时自动查找 /ql/data/scripts 和 /ql/scripts。

## 多账号

每个非空行代表一个账号，按顺序独立签到；行首尾空白去除，行内所有字符保留。任一账号失败整体非零退出，其他账号继续执行。
