# iamtxt 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/iamtxtsignin.py`
- 青龙命令：`python3 scripts/iamtxtsignin.py`
- 建议 Cron：`21 10 * * *`
- 发布哈希：`ede4262ae30d63937e20fa8a6d49ca3e62eec2f5e6cd4687a8555cc8131641e1`
- 许可证：`GPL-3.0`

## 脚本功能

- 通过 Cookie 执行 iamtxt 每日签到，保留原接口、POST 方法及 userid=0 表单参数。
- 识别官方成功和今天已签到响应，未知响应、网络故障及无效配置失败退出。
- 支持逐行多账号及旧 COOKIE 参数，独立执行并聚合退出码。
- 完全断网预演，检查配置、生成脱敏结果及通知摘要，不验证登录或签到。
- 输出带时间戳的编号阶段、每账号及最终统计和单行 TASK_SUMMARY JSON。
- 支持青龙通知及可选 SENDKEY 微信推送，按开关及选择器发送脱敏统计，通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `IAMTXT_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://www.iamtxt.com/ 后，打开浏览器开发者工具的网络面板，查看本站已登录请求，复制请求头 Cookie 完整值，不含 Cookie: 前缀。仅存入青龙私有环境变量。
- 填写格式：每个非空行一个账号的完整 Cookie，行内分号、&、@ 等字符保留，不用这些字符分隔账号。

### 可选参数

### `COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游变量，获取方式同 IAMTXT_COOKIE；建议迁移到 IAMTXT_COOKIE。
- 填写格式：IAMTXT_COOKIE 为空时读取，每个非空行一个完整 Cookie。

### `IAMTXT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网预演设为 1，正式运行设为 0 或不设置。
- 填写格式：1/true/yes/on 开启；0/false/no/off 关闭。

### `SENDKEY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从 Server酱官方控制台获取自己的推送密钥，兼容原微信推送；不设置不影响签到。
- 填写格式：单个密钥，兼容 sctp 数字 t 前缀及传统密钥；仅发送脱敏统计。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，设置后替换默认通知列表；auto 模式按选择器匹配本脚本。
- 填写格式：逗号、分号或空白分隔，支持目录编号 e1245908d22b3902、脚本相对路径、文件名和文件名通配符；* 匹配全部，空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，青龙通知模块不在默认位置时填写可信的 notify.py 或 sendNotify.js 所在目录。
- 填写格式：本地目录；也支持导入 notify.send 及 /ql/data/scripts、/ql/scripts 默认目录。通知不可用不影响业务退出码。

## 多账号

IAMTXT_COOKIE 每个非空行一个完整账号 Cookie，兼容 COOKIE；逐个独立执行，不以 & 或 @ 分隔，任一账号失败则整体非零退出。
