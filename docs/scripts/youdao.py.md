# 有道云笔记每日空间奖励

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/youdao.py`
- 青龙命令：`python3 scripts/youdao.py`
- 建议 Cron：`55 0 * * *`
- 发布哈希：`15903aa6f22a3142f994f573106b7bac7e9198615bf4f2a03515d0a29ed8602e`
- 许可证：`MIT`

## 脚本功能

- 刷新登录会话，保留已有 Cookie 并接收服务端更新。
- 每日同步空间奖励，验证 rewardSpace 字段。
- 每日签到，验证 space 字段。
- 连续领取三次广告空间奖励，分别验证 space 字段。
- 显示官方返回的非敏感昵称、用户名、显示名称或公开 UID，不从 Cookie 提取身份。
- 多账号独立处理，统计已确认奖励、阶段耗时及账号结果，输出单行结构化任务总结。
- 完全断网预演及青龙脱敏通知，通知失败不改变业务退出码。
- 通过 YOUDAO_AD_REWARDS=0 显式关闭三次广告奖励；默认仍执行原有三次请求。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `YOUDAO_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://note.youdao.com 后打开开发者工具网络面板，复制发往 note.youdao.com 已登录请求的完整 Cookie 请求头，不含 Cookie: 前缀。必须包含 YNOTE_PERS；过期后重新登录获取，勿公开凭据。
- 填写格式：每个非空行一个账号；Cookie 字段用分号分隔，字段仅按第一个等号拆分，保留值中的后续等号。

### 可选参数

### `YOUDAO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 进行完全断网预演，通知仅模拟，不验证真实登录；默认 0。
- 填写格式：1 启用；0、false、no、off 关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙通知模块所在目录。未设置时自动发现青龙标准目录。
- 填写格式：本地目录路径。

### `YOUDAO_AD_REWARDS`

- 必填：否
- 敏感：否
- 获取或设置：自行设置；默认 1 保留三次广告空间奖励，设为 0 关闭该动作，签到和同步仍执行。
- 填写格式：1 或 0，也支持 true/false、yes/no、on/off。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号；同一账号的 Cookie 字段以分号连接，字段仅按首个等号拆分。独立处理账号，任一账号失败则整体非零退出。
