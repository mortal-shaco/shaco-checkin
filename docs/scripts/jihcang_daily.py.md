# ikuuu 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/jihcang_daily.py`
- 青龙命令：`python3 scripts/jihcang_daily.py`
- 建议 Cron：`45 9 * * *`
- 发布哈希：`ca50ca72616f055b1914a68f64c30cdde7c01837fc1a213d33c4693b15f2f929`
- 许可证：`MIT`

## 脚本功能

- 使用本人邮箱密码登录并保留每账号独立会话
- 每日签到与明确已签到结果识别；登录和签到均检查业务标志，未知响应失败闭合
- 每行一个账号，多账号独立处理及整体失败退出码
- 兼容原 config.json 的账号、登录及签到地址、代理、超时、浏览器标识与可选推送设置
- 保留默认直连和可选 HTTP/HTTPS 代理，保护代理凭据
- 保留 Server酱优先、PushPlus 次之的旧通知选择，改为 HTTPS 和有超时请求
- 输出脱敏的连接、代理、TLS、HTTP 和响应格式错误诊断及排查提示
- 显示官方返回的非敏感昵称、用户名、显示名或公开 UID
- 完全断网预演、分阶段计时日志、账号与任务统计及单行结构化汇总
- 按全局通知开关和脚本名单发送青龙脱敏摘要，推送失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `IKUUU_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人 ikuuu 官方站点注册或登录时使用的邮箱和密码；在青龙环境变量中粘贴，每行一个账号。不要将真实值写入订阅脚本或日志。旧 config.json 的 accounts 数组仅作兼容输入。
- 填写格式：每行 邮箱|密码，只在第一个 | 处分隔，密码后续的 | 原样保留；不使用 & 或 @ 分隔账号。

### 可选参数

### `IKUUU_LOGIN_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选；从本人核实的官方站点登录请求获取。未联网验证默认域名是否仍有效。默认 https://ikuuu.de/auth/login；覆盖旧 urls.login。
- 填写格式：同签到接口同源的 HTTPS 地址，禁止查询参数、片段、用户信息及非标准端口。

### `IKUUU_CHECKIN_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选；从本人核实的官方站点签到请求获取。默认 https://ikuuu.de/user/checkin；覆盖旧 urls.checkin。
- 填写格式：同登录接口同源的 HTTPS 地址，禁止查询参数、片段、用户信息及非标准端口。

### `IKUUU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 启用断网预演；不访问业务接口及通知服务。
- 填写格式：1、true、yes、on 启用；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式下配置需要推送的脚本名单；本脚本无默认入选。支持目录 ID、scripts 相对路径、文件名或文件名通配符。设置为空禁用全部名单推送。
- 填写格式：逗号、分号、空格或换行分隔；* 选择全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 notify.py 或 sendNotify.js 所在目录；也自动寻找脚本目录、Python 搜索路径和标准青龙脚本目录。缺失或推送失败不改变业务退出码。
- 填写格式：本地目录路径，仅通知适配使用，业务请求不依赖此目录。

## 多账号

每个非空行一个账号，邮箱与密码只在第一个 | 处分隔。账号独立会话，单个账号失败仍继续其他账号，任一账号失败整体非零退出；旧 accounts 数组继续兼容。
