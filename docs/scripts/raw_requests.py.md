# 一亩三分地每日签到答题

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/raw_requests.py`
- 青龙命令：`python3 scripts/raw_requests.py`
- 建议 Cron：`51 8 * * *`
- 发布哈希：`30cd47212a9ed35f2c766368018e76220d1623beb78e9cb0a9d51bcb3cf6e6ed`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用 Cookie 登录一亩三分地并保持会话（推荐，兼容强制微信扫码账号）
- 可选用户名密码登录 auth.1point3acres.com（需 2captcha 解 reCAPTCHA）
- 检测今日签到状态并在未签到时提交每日签到
- 签到 todaysay 优先使用一言文案，失败或预演时回退本地文案
- 拉取每日一题并用内置题库匹配后提交答案
- 支持按开关分别启停签到与答题
- 支持多账号换行配置、断网预演、时间轴日志与青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `YM3D_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://www.1point3acres.com 后，打开开发者工具 → Network，选中 bbs/ 请求，复制请求头中的 Cookie 整段。强制微信扫码登录的账号请使用此方式。多账号时每行一个 Cookie。
- 填写格式：每行一个完整 Cookie 字符串（可含分号分隔的多个键值）；账号之间只用换行分隔

### `YM3D_CAPTCHA_KEY`

- 必填：是
- 敏感：是
- 获取或设置：注册 https://2captcha.com 并充值后，在个人中心复制 API Key。签到与答题需 Turnstile；密码登录额外需要 reCAPTCHA。
- 填写格式：2captcha API Key 字符串

### 可选参数

### `YM3D_ACCOUNT`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容项。未配置 YM3D_COOKIE 时可用论坛用户名与密码；多数账号已要求微信扫码，优先 Cookie。真实登录还需 YM3D_CAPTCHA_KEY 解 reCAPTCHA。
- 填写格式：每行一个账号：用户名&密码（仅按第一个 & 分割）

### `YM3D_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时设置为 1。
- 填写格式：1/true/yes/on 启用；其它或未设置则真实执行

### `YM3D_ENABLE_CHECKIN`

- 必填：否
- 敏感：否
- 获取或设置：控制是否执行每日签到；默认开启。
- 填写格式：1/true/yes/on 或 0/false/no/off；默认 1

### `YM3D_ENABLE_QUESTION`

- 必填：否
- 敏感：否
- 获取或设置：控制是否执行每日答题；默认开启。
- 填写格式：1/true/yes/on 或 0/false/no/off；默认 1

### `YM3D_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可选。一言不可用或断网预演时，用作签到 todaysay 的本地回退文案。
- 填写格式：不超过 280 字的纯文本

### `YM3D_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选。单次 HTTP 超时秒数。
- 填写格式：整数秒，范围约 5–120，默认 20

### `YM3D_UA`

- 必填：否
- 敏感：否
- 获取或设置：可选。自定义浏览器 User-Agent。
- 填写格式：完整 User-Agent 字符串

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选。设置后仅列表内脚本发送通知；空值表示全部禁用。
- 填写格式：catalog-id、文件名或 *，可用逗号/分号/空白分隔

## 多账号
