## 脚本功能

- 每日签到并显示签到奖励容量
- 查询今日签到状态、奖励和签到进度
- 查询会员类型、到期时间、总容量、已用容量及使用百分比
- 可选查询抽奖余额
- 显示接口提供的公开昵称、用户名、显示名称或 UID
- 逐行多账号及旧凭据变量兼容
- 可选 TLS 邮箱通知与青龙脱敏通知
- 完全断网预演、分阶段日志及结构化业务汇总

### 必选参数

### `QUARK_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录本人夸克手机客户端，使用本人授权的 HTTPS 抓包查看 drive-m.quark.cn 的 /1/clouddrive/capacity/growth/info 或 /sign 请求查询参数。获取同一账号的 kps、sign、vcode，分别 URL 解码一次后填写；失效后重新获取，禁止分享凭据。 优先读取此变量，未设置时兼容完整的三个旧变量。
