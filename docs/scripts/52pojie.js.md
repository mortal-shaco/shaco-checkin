# 吾爱破解每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/52pojie.js`
- 青龙命令：`node scripts/52pojie.js`
- 建议 Cron：`8 0 * * *`
- 发布哈希：`591bdea8bdcb0bbc14cf41f135994b63d55fe570f40f767614526f95572577e1`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每日 9 点吾爱破解签到，保留上游地址、PUT 方法和浏览器请求头。
- 判断签到成功、已签到、登录失效、HTTP 异常和未知响应，失败闭合。
- 支持 UTF-8 和 GBK 系列网页编码，逐行多账号 Cookie 和旧变量别名。
- 显示官方当前登录用户名，抑制凭据与原始响应。
- 完全断网预演、总超时、响应大小限制、阶段日志、账号统计和单行 TASK_SUMMARY。
- 青龙脱敏总结通知、可选 Bark 推送及全局通知开关。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `POJIE_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.52pojie.cn/home.php，打开开发者工具网络面板并刷新，复制该站请求头的完整 Cookie，保存到青龙环境变量；失效后重新登录获取，不公开分享。
- 填写格式：每个非空行一个账号的完整 Cookie，包含非空站点前缀_auth 字段；保留同一行所有分号分隔字段，不用 & 或 @ 分隔账号。

### 可选参数

### `CookieWA`

- 必填：否
- 敏感：是
- 获取或设置：旧版 CookieWA 的兼容输入，获取方式与 POJIE_COOKIE 相同；规范变量优先。
- 填写格式：每个非空行一个完整 Cookie。

### `POJIE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：完全断网预演时设置为 1。
- 填写格式：1、true、yes 或 on 启用，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；默认检查 /ql/data/scripts 和 /ql/scripts，通知缺失或失败不改变业务退出码。
- 填写格式：本地通知模块目录，仅用于可选通知。

### `BARK_KEY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从 Bark 应用复制个人推送密钥，仅用于脱敏总结通知。
- 填写格式：一个 Bark 推送密钥。

### `barkKey`

- 必填：否
- 敏感：是
- 获取或设置：旧版 barkKey 的兼容输入，BARK_KEY 优先。
- 填写格式：一个 Bark 推送密钥。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
