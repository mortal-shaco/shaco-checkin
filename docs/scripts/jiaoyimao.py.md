# 交易猫签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/jiaoyimao.py`
- 青龙命令：`python3 scripts/jiaoyimao.py`
- 建议 Cron：`35 6 * * *`
- 发布哈希：`0fe2f3c8bea6116f7ae74a41e632fda6fd3ced2321375fde1ac2022b5dd68815`
- 许可证：`Apache-2.0`

## 脚本功能

- 每天 06:35 执行交易猫每日签到，保留上游接口与明确成功字段。
- 查询并显示剩余积分，查询失败使该账号及整体任务失败。
- 逐行多账号独立执行，兼容原单账号 Cookie 变量；显示官方返回的非敏感公开身份。
- 提供完全离线预演、分账号分阶段脱敏日志、唯一单行 TASK_SUMMARY 汇总与青龙通知选择。
- 网络请求设置超时和响应大小限制，禁止凭据随重定向转发。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JIAOYIMAO_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人已登录的交易猫客户端或网页调试工具中查看积分中心网络请求，复制同一账号同一会话发往 m.jiaoyimao.com/api2/account/integration/ 的完整 Cookie 和 x-csrf-token 请求头。缺少有效值时重新登录获取，不要猜测或使用上游写死的值。
- 填写格式：每个非空行一个账号：x-csrf-token 请求头值、一个制表符、完整 Cookie 请求头值。仅按首个制表符分割，Cookie 内的 & 和 @ 不用于分隔账号。

### 可选参数

### `JIAOYIMAO_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：兼容原单账号变量，从本人积分中心请求复制完整 Cookie，须同时提供同会话的 JIAOYIMAO_CSRF_TOKEN。不能与组合变量混用，多账号请迁移到组合变量。
- 填写格式：单行完整 Cookie 请求头值。

### `JIAOYIMAO_CSRF_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧单账号兼容输入，从与 JIAOYIMAO_COOKIE 相同会话的积分中心请求复制 x-csrf-token；组合变量已含此字段时不要设置。
- 填写格式：单行请求头值。

### `JIAOYIMAO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线测试时设置为 1，正式执行设为 0 或不设置。
- 填写格式：1、true、yes、on 开启；0、false、no、off 关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式下配置通知名单，支持本脚本 catalogId、jiaoyimao.py、实际文件名、scripts/ 下对应路径或文件名通配符。未设置时默认不通知，空值禁用全部，星号选择全部。
- 填写格式：逗号、分号或空白分隔的选择器。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写本机青龙 notify.py 或 sendNotify.js 所在目录；也会尝试导入 notify 和两个青龙标准脚本目录，无需私有仓库。
- 填写格式：本机通知模块目录路径。

## 多账号

每个非空行一个账号，使用 JIAOYIMAO_ACCOUNTS 将同账号 CSRF 与 Cookie 通过首个制表符合并。账号独立执行，任意账号失败整体非零退出。旧变量仅兼容单账号，不与组合变量混用。
