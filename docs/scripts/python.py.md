# 佛山职院企微学工签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/python.py`
- 青龙命令：`python3 scripts/python.py`
- 建议 Cron：`*/5 7-22 * * *`
- 发布哈希：`f0c72bc59c532f9d10de07090bfea551b6623a5c4de46b59ce03aec5af6a3e32`
- 许可证：`GPL-3.0`

## 脚本功能

- 拉取佛山职院学工系统待签到任务列表
- 按 QD 与 QDTimeText 判断签到窗口与是否已签
- 提交 GPS 坐标签到并按 errcode==0 判定成功
- 经纬度小数末两位随机抖动（保留上游定位偏移）
- 换行多账号与 FVTI_TOKEN 兼容别名
- 请求超时、断网预演、脱敏时间轴日志与单行 TASK_SUMMARY
- 青龙通知开关、脚本选择与 Python/JavaScript 通知发现链

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FVTI_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在企业微信打开学工 OAuth（appid=wxf4d2e5e90c26ff0e，redirect 至 zhxg.fvti.edu.cn/code），从跳转页或抓包结果中复制 Authorization Bearer Token；再用地图取签到点纬度与经度。Token 通常约 24 小时有效，过期需重新获取。不要发给他人或写入公开仓库。
- 填写格式：每个非空行一个账号：BearerToken|纬度|经度|备注(可选)。也兼容上游 Redis CSV 多字段行（取第 1/6/7 字段为 Token/纬度/经度）。不使用 &、@ 分隔账号。

### 可选参数

### `FVTI_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名；未设置 FVTI_ACCOUNTS 时使用。单账号可只填 Token，并配合 FVTI_LAT / FVTI_LNG；也可使用与 FVTI_ACCOUNTS 相同的多行格式。
- 填写格式：与 FVTI_ACCOUNTS 相同，或纯 Token（需同时配置经纬度变量）。

### `FVTI_LAT`

- 必填：否
- 敏感：否
- 获取或设置：账号行未写纬度时的默认纬度；须与 FVTI_LNG 同时配置。
- 填写格式：纬度数字，范围 -90 到 90；提交时会按上游逻辑抖动小数末两位。

### `FVTI_LNG`

- 必填：否
- 敏感：否
- 获取或设置：账号行未写经度时的默认经度；须与 FVTI_LAT 同时配置。
- 填写格式：经度数字，范围 -180 到 180；提交时会按上游逻辑抖动小数末两位。

### `FVTI_FORCE_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：默认按接口返回的 QDTimeText 窗口判断；仅在确认需要忽略时间窗时开启。
- 填写格式：1/true/yes/on 强制尝试未签任务；默认关闭。

### `FVTI_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况自行调整单次 HTTP 请求超时；不填使用默认 15 秒。
- 填写格式：5 到 120 之间的数字秒，默认 15。

### `FVTI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在测试环境自行开启；正式执行时删除或设为 0。
- 填写格式：1/true/yes/on 开启完全断网预演；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式下需要替换默认通知名单时自行设置。
- 填写格式：逗号、分号或空白分隔；可匹配 catalogId、脚本路径、文件名或通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录。
- 填写格式：目录路径；失败后继续尝试 /ql/data/scripts 与 /ql/scripts；通知失败不改变业务退出码。
