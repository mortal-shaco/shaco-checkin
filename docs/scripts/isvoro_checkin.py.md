# ISVORO 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/isvoro_checkin.py`
- 青龙命令：`python3 scripts/isvoro_checkin.py`
- 建议 Cron：`6 10 * * *`
- 发布哈希：`e676a03855eb4a5b4f055d085d67a14777378ef148df22da8f956f7cd8227a8b`
- 许可证：`MIT`

## 脚本功能

- 每日签到并复查服务端 checked_in，已签到时避免重复提交
- 查询连续签到天数、本次奖励、积分余额及累计积分
- 只读查询遇到 401 时单次刷新并重试，写请求不自动重放
- 显示官方返回的非秘密昵称、用户名或公开 UID
- 每行一个账号独立执行，失败闭合并输出逐阶段日志和脱敏统计
- 兼容合集停用标识及 __DAILY_ALL_RESULT__= 输出
- 完全断网预演、TASK_SUMMARY 汇总及可配置青龙系统通知
- 显式启用后精确匹配并合并回写已验证的新 Cookie

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ISVORO_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://isvoro.com/checkin，打开开发者工具的网络面板，刷新并选择 /api/v1/auth/me 请求，复制请求头 Cookie 完整值。每个账号分别登录获取。
- 填写格式：每个非空行一个完整 Cookie，必须同时含 pmt_access、pmt_refresh、pmt_csrf。字段以分号分隔，仅在首个等号拆分，不用 & 或 @ 分账号。

### 可选参数

### `ISVORO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网验证时设置为 1，正式执行时删除或设为 0。
- 填写格式：1/true/yes/on 开启，其余关闭。

### `ISVORO_WRITEBACK`

- 必填：否
- 敏感：否
- 获取或设置：需要将刷新后的 Cookie 保存到青龙面板时显式设为 1，默认关闭。
- 填写格式：1/true/yes/on 开启，开启时必须同时配置 CLIENT_ID 和 CLIENT_SECRET；按原始多账号完整变量值精确匹配并一次回写。

### `CLIENT_ID`

- 必填：否
- 敏感：是
- 获取或设置：仅启用回写时必填。青龙系统设置的应用设置中创建应用并授予环境变量权限，复制应用编号。
- 填写格式：与 CLIENT_SECRET 配套使用，为所有账号共用的面板应用凭据。

### `CLIENT_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：仅启用回写时必填。从同一青龙应用复制应用密钥。
- 填写格式：与 CLIENT_ID 配套使用，不填入账号 Cookie 行。

### `DAILY_ALL_CHILD`

- 必填：否
- 敏感：否
- 获取或设置：原合集调用时设置为 1，独立运行无需设置。
- 填写格式：1 输出兼容的 __DAILY_ALL_RESULT__= 汇总，同时遵守全局通知开关。

### `DAILY_ALL_DISABLED`

- 必填：否
- 敏感：否
- 获取或设置：需要显式停用该任务时填写 isvoro 或 isvoro_checkin。
- 填写格式：兼容原合集，以逗号、分号、竖线、& 或换行分隔停用标识，这些分隔符不用于账号。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要自动通知时将 isvoro_checkin.py 或 1459eae4ec890c40 加入列表。显式设置的列表替换默认选择，空列表关闭全部。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符，* 选择全部。未提供默认名单时 auto 不发送。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定已有青龙 notify.py 或 sendNotify.js 所在目录，也会发现标准青龙通知模块。
- 填写格式：本地目录路径。断网预演只生成摘要，不执行通知模块。

## 多账号

每个非空行一个账号的完整 Cookie，保留字段值中的等号；账号独立执行，任一账号失败整体非零退出，回写时保留其他账号行。
