## 脚本功能

- 使用石之家 Cookie 与匹配的 User-Agent 完成每日签到
- 默认领取当月可领签到奖励，可按开关跳过
- 可选检查角色房屋拆除倒计时
- 可选点赞、评论与活跃印记；默认关闭以避免不安全副作用
- 开启评论时优先使用一言 HTTPS 文案并保留署名，失败回退本地文案
- 读取并展示接口返回的非敏感角色名或公开身份
- 支持每行一个账号，Cookie 与 User-Agent 合并配置
- 完全断网预演、超时、业务成功校验、时间轴日志与单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FF14_RS_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录石之家官网后，在开发者工具网络面板中复制已登录请求的 Cookie 中 ff14risingstones=编码值，并复制与登录时一致的 User-Agent。每行一个账号，写成 Cookie|User-Agent；不要把凭据发给他人。
- 填写格式：每个非空行一个账号。格式为 Cookie|User-Agent，仅在首个竖线处拆分，后续 User-Agent 原文保留。Cookie 可为完整 Cookie 头或 ff14risingstones=...；不使用 & 或 @ 分隔账号。

### 可选参数

### `FF14_RS_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名。未设置 FF14_RS_ACCOUNT 时，与 FF14_RS_USER_AGENT 按行一一配对使用。
- 填写格式：每个非空行一个 Cookie；行数必须与 FF14_RS_USER_AGENT 相同。

### `FF14_RS_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：兼容别名。未设置 FF14_RS_ACCOUNT 时，填写与获取 Cookie 时相同的浏览器 User-Agent，并与 Cookie 按行配对。
- 填写格式：每个非空行一个完整 User-Agent 字符串。

### `INPUT_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：上游风格兼容别名；仅在未设置 FF14_RS_ACCOUNT / FF14_RS_COOKIE 时，与 INPUT_USER_AGENT 按行配对。
- 填写格式：每个非空行一个 Cookie。

### `INPUT_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：上游风格兼容别名；与 INPUT_COOKIE 按行配对。
- 填写格式：每个非空行一个 User-Agent。

### `FF14_RS_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：一般无需修改；仅当官方 API 域名变更且确认安全时调整。
- 填写格式：HTTPS 根地址，默认 https://apiff14risingstones.web.sdo.com；仅允许石之家官方域名。

### `FF14_RS_GET_SIGN_REWARD`

- 必填：否
- 敏感：否
- 获取或设置：与上游默认一致，需要关闭自动领奖时设为 0。
- 填写格式：1/true/yes/on 领取当月可领签到奖励；0/false/no/off 跳过。默认 1。

### `FF14_RS_CHECK_HOUSE`

- 必填：否
- 敏感：否
- 获取或设置：需要在签到后检查角色房屋拆除倒计时时开启。
- 填写格式：1 开启；0 关闭。默认 0。发现倒计时时该账号记为失败。

### `FF14_RS_DO_LIKE`

- 必填：否
- 敏感：否
- 获取或设置：上游正式入口已注释点赞；仅在确认需要时手动开启。
- 填写格式：1 开启对指定帖子点赞；0 关闭。默认 0。

### `FF14_RS_DO_COMMENT`

- 必填：否
- 敏感：否
- 获取或设置：上游正式入口已注释评论；仅在确认需要时手动开启。开启后正式运行优先请求一言生成脱敏评论文案。
- 填写格式：1 开启评论；0 关闭。默认 0。

### `FF14_RS_DO_SEAL`

- 必填：否
- 敏感：否
- 获取或设置：需要提交活跃印记时开启；上游正式入口默认未启用。
- 填写格式：1 开启；0 关闭。默认 0。

### `FF14_RS_LIKE_POST_ID`

- 必填：否
- 敏感：否
- 获取或设置：开启点赞时填写目标根帖子 ID。
- 填写格式：正整数，默认 8。

### `FF14_RS_COMMENT_POST_ID`

- 必填：否
- 敏感：否
- 获取或设置：开启评论时填写目标根帖子 ID。
- 填写格式：正整数，默认 8。

### `FF14_RS_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：开启评论且一言不可用时的本地回退文案；也可在断网预演中使用。
- 填写格式：不超过 280 字的纯文本；留空则使用内置短句。

### `FF14_RS_IMPERSONATE`

- 必填：否
- 敏感：否
- 获取或设置：curl_cffi 浏览器指纹配置；通常保持默认即可。
- 填写格式：例如 chrome124；默认 chrome124。

### `FF14_RS_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次请求超时。
- 填写格式：5 到 120 的秒数，默认 30。

### `FF14_RS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试配置时自行开启；正式执行删除或设为 0。
- 填写格式：1/true/yes/on 完全断网预演；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式下需要替换默认通知名单时自行设置。
- 填写格式：逗号、分号或空白分隔；可匹配 catalogId、脚本路径、文件名或通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录。
- 填写格式：目录路径；失败后继续尝试 /ql/data/scripts 与 /ql/scripts；通知失败不改变业务退出码。
