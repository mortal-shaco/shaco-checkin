## 脚本功能

- 使用 Cookie 或 Authorization 执行 Leaflow 每日签到，支持同账号组合凭据及上游 token_data 结构
- 识别隐藏字段和 CSRF 后提交既有签到表单；识别成功、今日已完成、登录失效和失败，并在必要时回读首页核验
- 返回当日奖励并排除历史奖励区域
- 保留每行多账号、有限重试、请求超时及可选随机执行窗口，任一账号失败则非零退出
- 支持完全断网预演和脱敏配置校验，不调用签到、通知模块或文本供应商
- 保留原维护版参数及兼容别名、机器输出和 34 18 * * * 定时配置
- 官方页面返回安全的昵称、用户名、显示名称或公开 UID 时原样显示，不输出凭据、手机号或设备标识
- 发现青龙通知模块，支持全局开关和脚本选择器；成功、失败、部分失败和配置错误均生成脱敏汇总，预演只生成本地通知摘要，通知不可用时保留业务退出码
- 打印阶段时间轴、账号和子任务统计、完成时间、最终状态，保留 START、ACCOUNT、SUMMARY 并仅追加一条 TASK_SUMMARY JSON
- 限制跨源重定向及响应大小，保留独立标准库 HTTP 实现，无私有仓库或安装引导依赖

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LEAFLOW_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在本人浏览器登录 https://checkin.leaflow.net，打开开发者工具的网络面板，刷新并选中签到站点请求，复制 Cookie 或 Authorization 请求头的完整值；同一账号的配套凭据置于同一行 JSON，不使用抓取他人凭据或自动下载工具。
- 填写格式：每个非空行一个账号：完整 Cookie 请求头，或 JSON 对象（cookie 字符串及 authorization 字符串，可只提供一个）。也接受 cookies 名值对象及上游 token_data 对象；headers 对象仅接受 Authorization。Cookie 按分号解析且仅在第一个等号处分割，值内的等号、&、@ 保留；账号只用换行分隔。

### 可选参数

### `LEAFLOW_ACCOUNTS`

- 必填：否
- 敏感：是
- 获取或设置：可选结构化账号兼容输入，获取方法同 LEAFLOW_COOKIE；仅在未设置 LEAFLOW_COOKIE 时读取。
- 填写格式：与 LEAFLOW_COOKIE 相同，每行一个账号

### `LEAFLOW_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游 Cookie 提取工具的输入名，获取方法同 LEAFLOW_COOKIE；仅在前两个变量均未设置时读取。
- 填写格式：与 LEAFLOW_COOKIE 相同，每行一个账号

### `LEAFLOW_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时手动设置为 1，正式运行删除或设置为 0。
- 填写格式：1 启用完全断网预演；不调用任何通知模块，不读取凭据配置文件

### `LEAFLOW_BASE`

- 必填：否
- 敏感：否
- 获取或设置：一般无需设置，默认 https://checkin.leaflow.net；仅在确认服务迁移且信任新站点时设置。
- 填写格式：不含路径、查询、片段或内嵌凭据的 HTTPS 源地址

### `LEAFLOW_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选手动设置，默认 20。
- 填写格式：1 至 120 的整数，单位秒

### `LEAFLOW_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：可选手动设置，默认 3。
- 填写格式：1 至 5 的整数，表示每账号最多尝试次数

### `LEAFLOW_RETRY_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：可选手动设置，默认 3。
- 填写格式：0 至 60 的整数，单位秒

### `LEAFLOW_MAX_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：可选手动设置，默认 0。
- 填写格式：0 至 3600 的整数，单位秒，为各账号随机窗口

### `LEAFFLOW_BASE`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游变量名，仅在未设置 LEAFLOW_BASE 时读取。

### `TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游参数，仅在未设置 LEAFLOW_TIMEOUT 时读取。
- 填写格式：1 至 120 的整数，单位秒

### `RETRY_TIMES`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游参数，仅在未设置 LEAFLOW_RETRIES 时读取。
- 填写格式：1 至 5 的整数

### `RETRY_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游参数，仅在未设置 LEAFLOW_RETRY_DELAY 时读取。
- 填写格式：0 至 60 的整数，单位秒

### `RANDOM_SIGNIN`

- 敏感：否

### `DEBUG_MODE`

- 必填：否
