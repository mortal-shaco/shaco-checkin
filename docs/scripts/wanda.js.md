# 万达电影签到与能量查询

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/wanda.js`
- 青龙命令：`node scripts/wanda.js`
- 建议 Cron：`52 1 * * *`
- 发布哈希：`2d517fa83b3ba301a2a9befe18b27030ea4d2b31c2110d617fa3f271e1597989`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每日签到，保留每日 00:10 计划和上游签名规则
- 查询累计能量与剩余能量
- 显式开启后在能量至少 50 时执行一次签到抽奖
- 独立开关控制答题活动报名、电影答案获取与提交，以及最多两次可选抽奖
- 每行一个账号，兼容旧会话变量名
- 完全断网预演、超时和大小限制、业务成功检查与账号失败隔离
- 显示官方非敏感身份并抑制凭据和原始响应
- 时间轴日志、阶段和账号统计、单行结构化汇总与青龙脱敏通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WANDA_MI`

- 必填：是
- 敏感：是
- 获取或设置：登录万达电影并进入签到页，从本人万达请求头 MX-API 的 JSON 中提取 _mi_ 字段。上游捕获域名 user-api-prd-mx.wandafilm.com，入口 https://act-m.wandacinemas.com/2005/17621a8caacc4d190dadd/ 可能过期，以客户端实际请求为准。只填写字段值，不公开分享。
- 填写格式：每个非空行一个完整 _mi_，不使用 & 或 @ 分隔账号

### 可选参数

### `senku_wanda_mi_`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游同名存储键的环境输入，从本人请求获取；不读取 box.dat；WANDA_MI 非空时优先。
- 填写格式：每行一个 _mi_

### `WANDA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设为 1。
- 填写格式：0 或 1，默认 0；1 时不请求业务接口或通知渠道

### `WANDA_SIGN_CODE`

- 必填：否
- 敏感：否
- 获取或设置：从本人签到请求正文 activityCode 获取当前编号，旧活动可能过期。
- 填写格式：数字，默认 134146532

### `WANDA_LOTTERY`

- 必填：否
- 敏感：否
- 获取或设置：确认愿意消耗签到能量后开启。
- 填写格式：0 或 1，默认 0；1 时余额达到 50 才抽奖一次

### `WANDA_QUESTION`

- 必填：否
- 敏感：否
- 获取或设置：答题活动开放时自行开启，保持上游默认关闭。
- 填写格式：0 或 1，默认 0；开启后报名、获取电影答案并提交

### `WANDA_QUESTION_CODE`

- 必填：否
- 敏感：否
- 获取或设置：从本人答题活动请求 activityCode 获取编号。
- 填写格式：数字，默认 15884027；与签到活动独立

### `WANDA_QUESTION_DRAWS`

- 必填：否
- 敏感：否
- 获取或设置：确认答题活动抽奖规则后自行配置。
- 填写格式：0、1 或 2，默认 0；非零须开启答题，不超过官方返回的剩余次数

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式中设置通知选择列表，本任务没有默认选中条目。
- 填写格式：逗号、分号或空白分隔；支持 8e3a583eb2a0dc24、wanda/wanda.js、wanda.js、实际文件名及 * 通配；空值不通知

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指向青龙已有 sendNotify.js 所在目录；也查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径；通知异常不改变业务退出码

## 多账号

每个非空行一个账号的完整 _mi_；逐账号独立执行，任一账号失败则整体非零退出，其他账号继续。

## 副作用与风险

- 提交每日签到，可能获得能量
- 仅显式启用签到抽奖时消耗能量并产生奖励记录
- 仅显式开启答题时报名并提交答案，可能获得抽奖机会
- 仅显式开启答题抽奖时消耗抽奖机会并产生奖励记录
- 真实运行且选中通知时通过青龙既有渠道发送脱敏汇总
