- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/astrbot_plugin_kuro.py`
- 青龙命令：`python3 scripts/astrbot_plugin_kuro.py`
- 建议 Cron：`31 7 * * *`

- 许可证：`MIT`

## 脚本功能

- 鸣潮、战双游戏每日签到；主备角色接口查询；显示官方角色名称与签到记录奖励。
- 库街区社区签到与重复签到识别。
- 查询官方账号身份及库洛币余额；官方非敏感昵称、用户名和公开 UID 按返回值展示。
- 显式开启的论坛每日任务：浏览3篇、点赞5篇与分享登记。
- 每行一个账号、独立执行、超时和严格业务判定、脱敏时间轴日志及单行结构化汇总。
- 每日07:30青龙调度，支持手动执行、按任务开关、完全离线预演与青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KURO_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://www.kurobbs.com，打开开发者工具的 Application → Cookies，复制 user_token 的值。设备字段可从本人发往 api.kurobbs.com 的请求头 devCode、distinct_id 获取。仅在青龙私密环境变量中填写，不粘贴整个 Cookie。
- 填写格式：每个非空行一个账号；支持原始 token，或含 token、可选 devcode、distinct_id 的单行 JSON 对象；不使用 &、@ 分隔账号。未填设备字段沿用上游固定登录设备值。

### 可选参数

### `KURO_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号输入，获取方法同 KURO_ACCOUNTS；仅在未设置 KURO_ACCOUNTS 时读取。
- 填写格式：单个 token；推荐迁移到 KURO_ACCOUNTS。

### `KURO_ENABLE_WUWA`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置；默认开启鸣潮签到。
- 填写格式：1 开启，0 关闭；兼容 true/false、yes/no、on/off。

### `KURO_ENABLE_PGR`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置；默认开启战双签到。
- 填写格式：1 开启，0 关闭；兼容 true/false、yes/no、on/off。

### `KURO_ENABLE_FORUM_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置；默认开启社区签到。
- 填写格式：1 开启，0 关闭；兼容 true/false、yes/no、on/off。

### `KURO_ENABLE_FORUM_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置；默认关闭；开启后浏览3篇帖子、点赞5篇帖子并登记分享，会产生公开互动。
- 填写格式：1 开启，0 关闭；兼容 true/false、yes/no、on/off。

### `KURO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地验证或青龙预演时设为 1；不访问任何网络，也不调用通知渠道，只生成脱敏通知摘要。
- 填写格式：1 完全离线，0 正式运行；默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：设置要通知的脚本选择器；设置后替代默认名单。当前脚本默认列入通知任务。
- 填写格式：支持目录编号、scripts/文件名、文件名、文件名通配符；逗号、分号或空白分隔；* 全选；空值全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙通知模块所在目录；未设置时尝试 import notify、/ql/data/scripts 和 /ql/scripts。
- 填写格式：包含 notify.py 或 sendNotify.js 的本机目录。

## 多账号

每个非空行一个账号；同一账号的 token 与设备信息放在同一个 JSON 对象中，也支持每行只填 token。各账号独立执行，任一账号失败则整体非零退出。
