# 欣都龙城每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_mallcoo.js`
- 青龙命令：`node scripts/sudojia_mallcoo.js`
- 建议 Cron：`9 1 * * *`
- 发布哈希：`698a0d85a0b901be8957a4adaa6b795232ec45651b1f5809b5e72a592f689b5d`
- 许可证：`GPL-3.0`

## 脚本功能

- 查询并显示账号昵称
- 每日签到，识别今日已签到并复核新签到状态
- 查询当前积分余额
- 查询连续签到天数
- 查询过期积分提示
- 多账号逐行配置与独立失败处理
- 完全断网预演、脱敏日志及结构化汇总
- 通过青龙发送脱敏通知，通知失败不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MALLCOO_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录欣都龙城微信小程序，抓取 https://m.mallcoo.cn 请求，在请求正文 Header.Token 中获取当前账号令牌；过期后重新登录抓取。
- 填写格式：每个非空行一个完整 Token，不使用 & 或 @ 分隔账号。

### 可选参数

### `MALLCOO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 开启完全断网预演，默认正式执行。
- 填写格式：1 开启，其他值关闭

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：手动设置，默认开启青龙通知。预演时仅记录通知摘要，不发送网络通知。
- 填写格式：0、false、no、off 关闭，其他值开启

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 sendNotify.js 所在目录；未设置时查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地通知模块目录

## 多账号

每个非空行一个账号，账号独立处理；任一账号失败时整体非零退出。
