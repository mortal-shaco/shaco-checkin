## 脚本功能

- 支持 Cookie 与邮箱密码两种登录方式及逐行混合多账号。
- 需要验证码时使用本地 ddddocr，最多三次识别验证；连续两次登录失败停止该账号。
- 兼容原 Cookie 缓存格式，检查缓存身份、按需重新登录并安全更新缓存。
- 支持手动镜像锁定、七个内置镜像轮换、当次成功镜像优先；内置镜像耗尽后通过无凭据 HTTP 读取发布页中的已知镜像链接。
- 执行每日签到，识别今日已签到，读取连续天数、等级、积分奖励和累计天数。
- 站点返回可辨认的昵称时显示该身份，抑制凭据、手机号和原始响应。
- 支持显式代理、严格 TLS 校验、同域 HTTPS 重定向限制、请求超时和响应大小限制。
- 保留通知及仅失败通知选项，支持青龙全局开关、脚本选择清单和 notify.py 自动发现。
- 完全断网预演不访问站点、不读取或写入缓存、不调用通知网络，校验格式并准备脱敏通知摘要。
- 输出分账号编号阶段与耗时、子任务统计、最终状态及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SIJISHE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在司机社使用本人注册邮箱和密码；或登录后在浏览器开发者工具的网络面板，复制站内请求的完整 Cookie 请求头值。请勿分享或写入公开文件。
- 填写格式：每个非空行一个账号；邮箱&密码仅在首个 & 处分割，后续密码原样保留；也可直接填 Cookie，各行可混用。禁止用 & 或 @ 分隔多个账号。

### 可选参数

### `SIJISHE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地验证时手动设置为 1，默认关闭。
- 填写格式：1、true、yes、on 表示启用完全断网预演。

### `SIJISHE_HOST`

- 必填：否
- 敏感：否
- 获取或设置：通过上游发布页 https://47447.net/ 人工核实本人使用的司机社镜像。
- 填写格式：裸域名，不含协议、路径和端口；留空按内置列表尝试。

### `SIJISHE_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：从本人可信的代理配置中取得，可省略直连。
- 填写格式：HTTP 或 HTTPS 代理地址，可能包含认证信息，禁止公开。

### `SIJISHE_CACHE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：可选设置本人私有目录中的缓存文件路径；默认脚本同目录 xsijishe_cookie.json。
- 填写格式：本地文件路径；兼容原 accounts 映射格式，文件权限 0600，原子写入并加锁，不接受符号链接。

### `SIJISHE_DEBUG`

- 必填：否
- 敏感：否
- 获取或设置：兼容原变量，可选手动设置；完整脱敏阶段日志始终开启。
- 填写格式：布尔值；不输出响应、签名、验证码或代理信息。

### `SIJISHE_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：兼容原脚本通知开关，默认 true。
- 填写格式：true 或 false；全局显式通知开关及通知清单优先。

### `SIJISHE_NOTIFY_ONLY_FAIL`

- 必填：否
- 敏感：否
- 获取或设置：兼容原脚本成功静默选项，默认 false。
- 填写格式：true 时仅失败通知；全局显式启用优先，预演始终准备摘要。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选设置需要通知的脚本选择清单；设置后替换本脚本默认通知选择。
- 填写格式：逗号、分号或空白分隔，可用目录相对路径、文件名、文件名通配符、目录编号 43434889ab5f9361 或 *；空值全部禁用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙已配置 notify.py 时可指定其所在目录；也会搜索 Python 导入路径和 /ql/data/scripts、/ql/scripts。
- 填写格式：本地目录；通知器为可选青龙集成，缺失或失败保持业务退出码。

## 副作用与风险

- 正式运行提交邮箱密码登录与按需验证码验证，可能创建登录会话并影响站点登录风控计数。
- 正式运行执行司机社签到并可能获得站内积分或车票奖励。
- 邮箱密码模式在本地创建缓存锁、更新或删除失效 Cookie 缓存，收紧缓存权限。
- 通知启用且青龙通知器可用时发送脱敏任务结果。
