# 安慕希每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_amx.js`
- 青龙命令：`node scripts/sudojia_amx.js`
- 建议 Cron：`25 0 * * *`
- 发布哈希：`f20aaeea7f456877a1c4435b64f6c987fbbc582ae6eecc8b67abed9a316e0325`
- 许可证：`GPL-3.0`

## 脚本功能

- 查询账号信息并显示接口返回的昵称，不输出手机号
- 查询今日签到状态，已签到则跳过重复签到
- 未签到时执行每日签到，并再次查询签到状态核验结果，显示可用的奖励积分
- 查询当前积分
- 按非空行支持多账号，逐账号统计，失败时非零退出
- 完全断网预演、阶段日志和单行 TASK_SUMMARY 结构化汇总
- 通过青龙 sendNotify.js 发送脱敏总结；支持全局开关、通知超时和失败隔离

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AMX_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录安慕希微信小程序，在本人授权的抓包环境中查找发往 msmarket.msx.digitalyili.com 的请求，复制请求头 access-token 的完整值。失效后重新登录获取。请勿复制整个请求头或分享凭据。
- 填写格式：每个非空行一个完整 Token；不使用 & 或 @ 分隔账号，行内字符保持不变，首尾空白忽略。

### 可选参数

### `AMX_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 启用完全断网预演。
- 填写格式：1 为预演；其他值为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关，默认启用。
- 填写格式：0、false、no、off 禁用，忽略大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：设置已有青龙 sendNotify.js 所在目录；否则自动查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机目录路径，不下载或安装通知模块。

## 多账号

每个非空行一个账号的 access-token，按行独立处理；任一账号失败时整体非零退出。
