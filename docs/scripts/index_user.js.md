# 微博超话自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/index_user.js`
- 青龙命令：`node scripts/index_user.js`
- 建议 Cron：`5 11 * * *`
- 发布哈希：`97e5d05b80a4895bdf1543db0b6dd599321f919779abb47a5bf749de21ecbada`
- 许可证：`MIT`

## 脚本功能

- 分页读取当前登录账号关注的全部超话，并校验业务响应与分页字段。
- 按上游接口逐项串行签到，保留 100000 成功与 382004 已签到判定，兼容字符串和数字业务码。
- 支持多账号独立执行、单项失败继续及失败时非零退出。
- 保留自动签到开关，关闭后只读列表；以终端日志和青龙通知替代浏览器气泡设置。
- 响应提供非敏感昵称时显示官方原值；缺失时使用账号序号。
- 提供完全断网预演、分阶段时间轴、账号统计及单行 TASK_SUMMARY 结构化总结。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WB_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://weibo.com/ 后，打开开发者工具的网络面板，选择本人已登录的微博同站请求，复制请求头 Cookie 的值；仅保存到青龙私密环境变量。过期后重新登录获取。
- 填写格式：每个非空行是一份完整 Cookie，键值对用分号分隔；不含 Cookie: 前缀，不使用 & 或 @ 分隔账号，保留值内的等号。

### 可选参数

### `WB_AUTO_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置；默认开启，仅会对已关注超话签到。关闭时只获取超话列表。
- 填写格式：1 开启，0 关闭；兼容 true/false、yes/no、on/off。

### `WB_INTERVAL_MS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中按需要设置；沿用上游至少 500 毫秒串行间隔。
- 填写格式：500 至 60000 的整数，默认 500，单位毫秒。

### `WB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地或青龙验证时设为 1；使用模拟超话，不验证登录状态。
- 填写格式：1 断网预演，0 正式执行；预演不请求微博、不写入状态、不真实发送通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙设置通知脚本选择器；可用本脚本文件名、脚本相对路径、catalogId 或 *；未配置时本脚本不在默认名单。
- 填写格式：用逗号、分号、空白或换行分隔；支持 * 通配符；空值关闭全部；QINGLONG_NOTIFY=0 始终关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在青龙通知模块位于自定义位置时，填写包含 sendNotify.js 的目录；否则自动查找 /ql/data/scripts 与 /ql/scripts。
- 填写格式：可选本地目录，只用于通知；缺失或投递失败不改变业务退出码。

### `QL_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通常自动设置，仅用于计算通知选择器的脚本相对路径；无需手动配置。
- 填写格式：青龙安装根目录；未设置时相对 /ql/data/scripts 计算。

## 多账号

WB_COOKIE 每个非空行一个独立账号；完整 Cookie 属于同一账号，不拆开配套字段。顺序处理所有账号及其超话，单个账号或超话失败继续处理其余项，任一失败整体非零退出。
