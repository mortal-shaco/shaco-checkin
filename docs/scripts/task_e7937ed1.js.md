# 王者营地每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_e7937ed1.js`
- 青龙命令：`node scripts/task_e7937ed1.js`
- 建议 Cron：`59 15 8 * * *`
- 发布哈希：`1a7bc073180a23dab7d8383bdcdb8251ea52bc7115c915ad0cf733e824d2291e`
- 许可证：`GPL-3.0`

## 脚本功能

- 按原定时执行王者营地每日签到，保留抓包认证请求头和完整请求体。
- 使用规范合并账号变量，兼容原请求头与请求体变量以及原注释中的请求体别名。
- 支持多账号独立运行、失败非零退出、超时和响应大小限制、显式业务码校验。
- 完全断网预演校验账号配置，不将预演成功标记为真实签到成功。
- 展示官方返回的非敏感昵称、用户名、显示名或公开身份，输出脱敏阶段日志、账号统计及单行 TASK_SUMMARY。
- 通过青龙通知模块发送脱敏摘要，支持全局开关与脚本选择；离线预演仅展示摘要，通知异常保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WZYD_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人已授权设备登录王者营地，抓取手动每日签到发往 https://kohcamp.qq.com/operation/action/signin 的 POST 请求。将认证请求头与完整请求体分别写入 headers、body。配套字段必须来自同一账号同一请求。签名或会话失效后重新抓取；脚本不生成签名，不输出抓包内容。
- 填写格式：每个非空行一个 JSON 对象，包含 headers 和 body 两个对象；headers 原样保留抓包认证字段 appid、openid、msdkEncodeParam、sig、userId、timestamp、source、encode、algorithm、version；body 保留 cSystem、h5Get、roleId 及原请求其他字段。

### 可选参数

### `WZYD_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧版请求头变量；来源同 WZYD_ACCOUNTS 的 headers。未设置规范变量时，与 WZYD_BODY 或 WZYY_BODY 配套读取。
- 填写格式：每行一个请求头 JSON 对象，与请求体变量逐行对应；仅为历史兼容保留分号分隔。规范变量优先。

### `WZYD_BODY`

- 必填：否
- 敏感：是
- 获取或设置：从同一签到请求提取完整 JSON 请求体；兼容旧版，与 WZYD_TOKEN 配套。
- 填写格式：每行一个请求体 JSON 对象，包含 cSystem、h5Get、roleId，保留其余字段；数量、顺序与请求头一致。历史分号分隔仍兼容。

### `WZYY_BODY`

- 必填：否
- 敏感：是
- 获取或设置：兼容原注释中的旧拼写，内容与 WZYD_BODY 相同；后者存在时优先。
- 填写格式：与 WZYD_BODY 相同。

### `WZYD_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设为 1，正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 启用；离线检查不会签到、请求公告或发送网络通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙设置需通知的脚本选择器；设置后替换默认选择，本脚本未指定默认名单，auto 默认不发送。
- 填写格式：逗号、分号或空白分隔，支持目录 ID、脚本相对路径、文件名及文件名通配符；本脚本可选 e7937ed1d56e881d、王者营地.js、candidate.js；* 为全部，空值关闭自动选择。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；否则查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径；不下载通知依赖；缺失时记录通知不可用并保留业务退出码。

## 多账号

WZYD_ACCOUNTS 每个非空行一个完整账号 JSON，同一账号请求头与请求体合并；不使用 & 或 @ 分隔。兼容旧变量逐行配对及历史分号格式。账号独立执行，任一账号配置或签到失败则整体非零退出。
