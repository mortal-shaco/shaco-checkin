## 脚本功能

- 按默认账号逐行顺序访问新闻页，明确黎明与奖励（含 Hath）或已领取提示才成功；HTTP 200 本身不视为成功
- 默认 TLS 三次请求后 TLS 1.2 三次回退，校验证书，单次超时 30 秒，最多读取 2 MiB，禁止携带凭据重定向，不使用系统代理
- Random Encounter 仅提示人工处理或等待并非零退出；保留逐账号隔离与部分失败汇总
- E_COOKIE 环境变量优先，首等号拆分，保留所有原字段与值中的等号、&、@；按非空行多账号
- E_COOKIE_CACHE 默认关闭，显式开启后可读取私密缓存；仅业务成功或今日已完成且白名单字段变化时原子写入权限 600；不修改环境变量
- 只合并 ipb_member_id、ipb_pass_hash、sk、hath_perks、nw、event 六类续期字段，保留其他原字段；服务撤销会话时失败且不保存该账号更新
- 保留 Cookie 到期时间提醒，官方当前登录身份脱敏展示，隐藏凭据、手机号和原始响应
- E_DRY_RUN=1 完全断网，不读取或写入凭据文件，不加载通知模块，仅校验配置并生成通知摘要
- 保留阶段耗时、逐账号和子任务统计，所有结局恰好一行 TASK_SUMMARY，通知失败不改变业务退出码
- 保留青龙 Python 通知和可选 Node.js 通知，支持当前及归档脚本选择标识，默认按原名单策略，不新增计划任务

## 环境变量与参数

先配置必选参数再运行；条目注明的兼容变量可以替代规范变量。缺少任一必选参数及其全部兼容变量时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `E_COOKIE`

- 必填：是（也可设置 `E_COOKIE_FILE`）
- 敏感：是
- 获取或设置：在自己有权使用的浏览器登录 E-Hentai，从 news.php 请求头复制完整 Cookie，至少包含 ipb_member_id 和 ipb_pass_hash。不要公开分享。
- 填写格式：每个非空行一个账号；分号分隔字段，仅按首个等号拆分，保留后续等号、&、@及全部原字段。拒绝重复字段、空值、非法字段名、非可打印 ASCII 和 Cookie: 前缀。正式运行显式启用缓存且变量为空时才读取缓存，预演必须提供此变量。

### 可选参数

### `E_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从自己有权使用的 HTTP 或 HTTPS 代理服务获取；默认直连，不读取系统代理。
- 填写格式：单行有效 HTTP/HTTPS 代理地址，可含代理认证信息；禁止空主机、端口 0、查询、片段及非根路径；默认直连，不读取系统代理。

### `E_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：可选，从浏览器 news.php 请求头复制 User-Agent；不设置时沿用上游浏览器标识。
- 填写格式：单行可打印 ASCII 浏览器标识，不得包含凭据；空值使用原默认标识。

### `E_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1；正式运行不设置或设为 0。
- 填写格式：1、true、yes、on 启用完全断网预演，其他值正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式列出需要通知的脚本；未配置名单时默认不推送。
- 填写格式：逗号、分号或空白分隔，支持当前及归档 catalogId、规范路径、归档路径、两者源路径、文件名与通配符；* 全部选中，未配置或空值均不推送。匹配区分大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 notify.py 或 sendNotify.js 所在目录；默认尝试导入 notify 及青龙标准脚本目录。无需此目录即可执行业务。
- 填写格式：本机通知模块目录路径；通知失败保持业务退出码。

### `E_COOKIE_CACHE`

- 必填：否
- 敏感：否
- 获取或设置：确需跨运行保存服务器续期 Cookie 时主动设为 1，默认 0。
- 填写格式：1/0、true/false、yes/no、on/off；预演始终不读写缓存，正式运行仅保存业务核验通过的账号更新。

### `E_COOKIE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：启用缓存时可指定自己可写的私密文件路径；默认脚本旁的 ehentai_cookie.txt。使用旧缓存前先确保文件仅当前用户可读写（权限 600）。
- 填写格式：仅 E_COOKIE_CACHE 显式开启后生效；默认规范脚本旁 ehentai_cookie.txt。每行一个账号，与环境变量顺序一致。读取仅接受当前用户所有、无组及其他用户权限的普通文件，建议权限 600；拒绝符号链接及超过 131072 字符的内容。原子写入权限 600，环境变量始终优先，账号增删或重排后重新配置。

## 副作用与风险

- 正式访问新闻页可能领取每日签到奖励、刷新会话或触发服务端随机事件

- 正式运行通知启用且匹配时调用部署环境的青龙通知模块
