# E-Hentai 自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/autosignin.py`
- 青龙命令：`python3 scripts/autosignin.py`
- 建议 Cron：`42 */6 * * *`
- 发布哈希：`569b66c641f158b675499ed0ddf8152e510816155af2a9308e838257607c1c95`
- 许可证：`MIT`

## 脚本功能

- 访问 E-Hentai 新闻页完成签到，并核验事件区明确奖励或今日已完成提示
- 识别随机遭遇，提示手动处理或等待结束；未确认签到时非零退出
- 保留默认 TLS 三次请求及 TLS 1.2 三次回退，设置超时、响应大小限制与证书校验
- 兼容 E_COOKIE、E_PROXY、E_USER_AGENT，多账号按非空行独立运行
- 解析服务端 Cookie 到期时间并提醒更新，不输出或写回 Cookie 值
- 显示官方返回的公开账号身份；其他响应内容保持脱敏
- 完全断网预演、时间轴阶段日志、账号统计、任务统计和单行 TASK_SUMMARY 汇总
- 正式运行通过青龙通知模块发送脱敏汇总，通知不可用不改变业务退出码；预演生成摘要并禁止外部投递

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `E_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 E-Hentai，打开开发者工具的网络面板，访问 https://e-hentai.org/news.php，复制该请求的完整 Cookie 请求头值。至少包含 ipb_member_id 与 ipb_pass_hash；Cookie 失效或服务提示更新时重新获取。不要公开分享。
- 填写格式：每个非空行一个账号的完整 Cookie；字段用分号分隔，每个字段只按第一个等号拆分，后续等号保留。不要使用 & 或 @ 分隔账号。

### 可选参数

### `E_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从自己有权使用的 HTTP 或 HTTPS 代理服务获取；默认直连，不读取系统代理。
- 填写格式：HTTP 或 HTTPS 代理地址，所有账号共用；可包含代理认证信息但不会输出。

### `E_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：可选，从浏览器 news.php 请求头复制 User-Agent；不设置时沿用上游浏览器标识。
- 填写格式：单行浏览器标识，禁止换行和空字符。

### `E_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1；正式运行不设置或设为 0。
- 填写格式：1、true、yes、on 启用完全断网预演，其他值正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 notify.py 或 sendNotify.js 所在目录；默认尝试导入 notify 及青龙标准脚本目录。无需此目录即可执行业务。
- 填写格式：本机通知模块目录路径；通知失败保持业务退出码。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

E_COOKIE 每个非空行一个账号；同一行保留该账号所有 Cookie 字段。账号独立处理，任一账号失败时整体非零退出。
