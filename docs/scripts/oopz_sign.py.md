# Oopz每日签到与星辉任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/oopz_sign.py`
- 青龙命令：`python3 scripts/oopz_sign.py`
- 建议 Cron：`25 9 * * *`
- 发布哈希：`7eec997ce46299eefe873d56ee77677f2964ca66765df483f0c22e5917c89e58`
- 许可证：`MIT`

## 脚本功能

- 使用 Oopz Web 端签名算法完成每日星辉签到，并核对连续签到天数。
- 一站式完成社区星辉任务：浏览、点赞、评论、分享、发布笔记并尝试领取奖励。
- 评论与发布正文优先使用一言随机文本并按策略署名，失败或断网预演回落本地短句；发布配图优先必应每日一图。
- 支持 token|uid 会话，或手机号|密码自动登录并在失效时重登；展示官方返回的昵称或公开 uid。
- 支持逐行多账号、动作开关、完全断网预演、超时控制、时间轴日志与单行 TASK_SUMMARY。
- 通过青龙 notify.py 或 sendNotify.js 发送脱敏任务汇总，遵守全局开关与脚本清单。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `OOPZ_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 Oopz App 或 https://web.oopz.cn 使用本人账号。推荐密码登录行：用手机号与登录密码；或从已登录客户端/抓包取得 token 与 uid。勿把真实凭据写入仓库、日志或示例。
- 填写格式：每个非空行一个账号。token|uid，或 11 位手机号|密码；仅在首个竖线处分割，后续字符完整保留。

### 可选参数

### `OOPZ_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写登录后的 oopz-signature/token；仅当 OOPZ_ACCOUNTS 为空且同时提供 OOPZ_UID 时生效。
- 填写格式：单个 token 字符串。

### `OOPZ_UID`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名：填写公开用户 uid；仅当 OOPZ_ACCOUNTS 为空且同时提供 OOPZ_TOKEN 时生效。
- 填写格式：单个 uid 字符串。

### `OOPZ_PHONE`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写注册手机号；仅当 OOPZ_ACCOUNTS 为空且同时提供 OOPZ_PASSWORD 时生效。
- 填写格式：11 位数字手机号。

### `OOPZ_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写登录密码；仅当 OOPZ_ACCOUNTS 为空且同时提供 OOPZ_PHONE 时生效。密码会按客户端 RSA-OAEP 加密后提交，脚本不落盘。
- 填写格式：单个密码字符串。

### `OOPZ_ACTIONS`

- 必填：否
- 敏感：否
- 获取或设置：可选：选择本轮执行的动作；默认与上游定时任务一致为签到加全部每日星辉任务。
- 填写格式：逗号、分号或空白分隔：sign、tasks；默认 sign,tasks。

### `OOPZ_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可选：评论或发布在一言不可用或断网预演时使用的本地正文；不设置则使用内置短句。
- 填写格式：不超过 280 字的公开文本；不会发送给一言接口。

### `OOPZ_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置单次 HTTPS 请求超时；默认 25 秒。
- 填写格式：数字秒，范围 5 到 120。

### `OOPZ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：用于首次配置检查与完全断网预演；不代表真实业务成功。
- 填写格式：1、true、yes 或 on 启用；不访问业务接口、一言与必应。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行选择需要推送的脚本；设置后替代默认通知清单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；支持 2d0eeee40adf7820、scripts/oopz_sign.py；* 选择全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：指定已安装青龙通知模块所在目录，否则依次发现可导入的 notify、/ql/data/scripts、/ql/scripts。
- 填写格式：目录路径，包含 notify.py 或 sendNotify.js。

## 副作用与风险

- 正式执行时提交每日签到，可能增加星辉与连续签到天数。
- 启用 tasks 时会浏览、点赞、评论、分享社区内容，并可能发布一篇笔记、上传配图与领取任务奖励。
- 密码登录账号会向官方登录接口提交加密后的密码以换取会话；脚本不把凭据写入本地文件。
- 通知启用且助手可用时发送脱敏任务汇总；无网络预演不投递外部通知，也不请求一言或必应。
