# 加密货币 INR 报价监控

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/cryptocurrency.py`
- 青龙命令：`python3 scripts/cryptocurrency.py`
- 建议 Cron：`*/5 * * * *`
- 发布哈希：`712f310059dd525a0814119e806f6fe278f38d8a33cc942a104ae441bffeb89e`
- 许可证：`MIT`

## 脚本功能

- 查询并展示 BTC、BCH、LTC、DASH、DGB、ZEC 六种币的 INR 报价，沿用上游 Coinome 页面及价格排列约定。
- 选择单币种与目标价，严格高于当前阈值时提醒，同次运行自动提高阈值。
- 保留旧版命令行轮询间隔参数，使用环境变量替代交互，支持有限次数连续采样。
- 青龙定时运行及汇总通知，含成功、失败、配置错误和断网预演结果；预演仅模拟通知。
- 完全断网预演、带阶段耗时的中文日志和单行 TASK_SUMMARY 结构化统计。
- 仅在 HTTP 200、HTML 响应和六项有限正数价格校验通过后判定行情采样成功。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CRYPTO_CURRENCY`

- 必填：是
- 敏感：否
- 获取或设置：自行选择要监控的币种，替代原脚本交互选择。
- 填写格式：BTC、BCH、LTC、DASH、DGB、ZEC 之一，忽略大小写

### `CRYPTO_TARGET_INR`

- 必填：是
- 敏感：否
- 获取或设置：自行设置希望收到上涨提醒的 INR 价格，替代原脚本交互输入。
- 填写格式：有限正数，每次启动重置为此值

### 可选参数

### `CRYPTO_SAMPLES`

- 必填：否
- 敏感：否
- 获取或设置：自行设置单次任务采样次数，默认 1。
- 填写格式：1 至 120 的整数，同次运行保留上涨后的新阈值

### `CRYPTO_REFRESH_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：自行设置采样间隔，默认 60 秒；旧版单个命令行整数参数仍可使用且优先。
- 填写格式：1 至 3600 的整数，仅多次采样时等待，预演不等待

### `CRYPTO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时设置为 1，固定样例不代表真实行情。
- 填写格式：1、true、yes、on 开启，默认关闭

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行指定需要通知的脚本列表，未设置时默认选中本任务。
- 填写格式：英文逗号、分号或空白分隔目录编号、脚本路径、文件名或通配符；空值关闭全部；* 选择全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写已有青龙 notify.py 所在目录，亦自动查找可导入模块及青龙标准目录。
- 填写格式：本地目录路径，可选；通知失败保持业务退出码
