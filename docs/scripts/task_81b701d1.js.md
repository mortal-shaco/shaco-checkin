## 脚本功能

- 使用 HayFrp 用户名密码登录官方 API，并展示官方返回或配置中的用户名身份。
- 登录后携带 csrf/token 执行每日签到领取流量，识别签到成功与今日已签到。
- 支持每行一个账号及可选备注前缀，账号失败隔离并汇总退出状态。
- 可选自定义 API 根地址；默认 https://api.hayfrp.com。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验账号格式与 API 地址协议、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HAYFRP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人 HayFrp 控制台账号密码（https://console.hayfrp.com 可登录验证的同一组凭据）。勿填写他人账号或日志中的敏感信息。
- 填写格式：每个非空行一个账号，格式「用户名,密码」，只在第一个逗号处拆分（密码可含逗号）。可选备注前缀「备注|用户名,密码」，只在首个竖线处拆分。不使用 & 或 @ 分隔账号。

### 可选参数

### `HAYFRP_API_URL`

- 必填：否
- 敏感：否
- 获取或设置：一般无需修改；仅当官方更换 API 根地址时手动设置。
- 填写格式：完整 HTTP(S) API 根地址，默认 https://api.hayfrp.com；脚本会向 {根地址}/user 发起 POST。

### `HAYFRP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不访问 HayFrp、不签到、不投递真实通知。

### `HAYFRP_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：1000 至 60000 的整数毫秒；缺省或非法值使用 20000。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 81b701d12d5b39f2、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

HAYFRP_ACCOUNTS 每个非空行一个账号；可选备注仅按第一个竖线分割，用户名与密码仅按第一个逗号分割。账号逐个独立登录、签到与统计，任一账号失败则整体非零退出，其余账号继续执行。
