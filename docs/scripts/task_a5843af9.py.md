## 脚本功能

- 独立会话访问站点，通过邮箱密码登录并明确校验登录结果。
- 每日签到，明确验证业务返回 ret=1；未确认成功时失败退出，不自动重试。
- 兼容 editXY 主题，展示等级、到期时间及剩余流量；主题无字段时明确跳过。
- 展示官方返回的昵称、用户名、显示名称或公开 UID，隐藏凭据及手机号。
- 支持多站点多账号逐行配置及账号隔离，任一账号失败整体非零退出。
- 保留 Server酱、酷推、Qmsg、Telegram、Pushplus 五种可选通知渠道，支持青龙通知及全局开关、名单。
- 提供断网预演、时间轴日志、逐账号统计和单行结构化汇总。
- 保留云函数入口 main_handler(event, context)，返回业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SSPANEL_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：从所使用的 SSPanel 站点登录页获取 HTTPS 地址，使用自己注册的登录邮箱和密码；密码从密码管理器获取。不支持验证码或双因素认证。
- 填写格式：每个非空行：HTTPS站点|邮箱|密码，仅分割前两个竖线，密码中的后续竖线原样保留；行首尾空白去除。账号之间只用换行。

### 可选参数

### `SSPANEL_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设为 1，正式执行时删除或设为 0。
- 填写格式：1/true/yes/on 为完全断网预演，仅校验参数，不投递通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写希望接收通知的脚本标识，设置后替换默认选择。
- 填写格式：逗号、分号或空白分隔；支持目录编号 a5843af909a36789、脚本相对路径、文件名及通配符；* 为全部，空值为全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写现有 notify.py 或 sendNotify.js 所在目录，亦自动查找标准青龙路径和可导入的 notify 模块。
- 填写格式：本地目录，不下载或安装通知模块。

### `SendKey`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Server酱账号的发送密钥页取得。
- 填写格式：单个密钥，受通知总开关和名单控制。

### `ktkey`

- 必填：否
- 敏感：是
- 获取或设置：可选：从酷推管理页面取得发送密钥。
- 填写格式：单个密钥，受通知总开关和名单控制。

### `QmsgKey`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Qmsg 管理页面取得消息密钥。
- 填写格式：单个密钥，受通知总开关和名单控制。

### `tele_bot_token`

- 必填：否
- 敏感：是
- 获取或设置：可选：通过 Telegram 的 BotFather 创建机器人并取得令牌。
- 填写格式：机器人令牌，需同时配置 tele_user_id。

### `tele_user_id`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Telegram 机器人的会话更新中取得自己的会话编号。
- 填写格式：与 tele_bot_token 配套的会话编号，仅用于通知。

### `tele_api_url`

- 必填：否
- 敏感：否
- 获取或设置：可选：默认官方 https://api.telegram.org；代理须自行管理并使用 HTTPS。
- 填写格式：无内嵌凭据的 HTTPS 地址，仅用于 Telegram 通知。

### `push_token`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Pushplus 账号的令牌页面取得。
- 填写格式：单个推送令牌，受通知总开关和名单控制。
