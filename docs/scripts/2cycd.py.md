# 2cycd 论坛自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/2cycd.py`
- 青龙命令：`python3 scripts/2cycd.py`
- 建议 Cron：`0 0 * * *`
- 发布哈希：`25b8017bb313cc0226008cc36a8141e3beffd0aa6de9d33731441593a5b20a40`
- 许可证：`MIT`

## 脚本功能

- 按每日计划为 2cycd 论坛账号执行签到并领取贡献
- 支持每行一个 Cookie 的多账号独立处理，并在任一账号失败时整体返回非零退出码
- 签到前从一言 HTTPS 接口获取公开文字并按作者、来源格式署名，所有规定故障均回退到本地文字
- 保留原有最多三次尝试的默认行为，并允许在安全范围内调整超时和尝试次数
- 提供完全断网的预演模式、分阶段脱敏日志、逐账号统计及单行结构化任务汇总
- 按青龙全局开关和脚本选择列表发送脱敏通知，通知故障不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CYCD_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.2cycd.com/，打开开发者工具的网络面板并刷新页面，从发往 2cycd.com 的 home.php 或 plugin.php 请求头中复制完整 Cookie 值。每个账号单独占一行。
- 填写格式：每行一个账号的完整 Cookie 请求头值；Cookie 内部可保留分号、& 和 @，不得用它们分隔账号。

### 可选参数

### `cycd_cookie`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，获取方式与 CYCD_COOKIE 相同；新配置应优先使用 CYCD_COOKIE。
- 填写格式：每行一个账号的完整 Cookie 请求头值。

### `CYCD_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要在完全断网条件下检查配置和流程时设置。
- 填写格式：设为 1、true、yes 或 on 启用预演。

### `CYCD_FALLBACK_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：自行填写一言接口失败时使用的本地签到文字；不填写则使用脚本内置文字。
- 填写格式：去除首尾空白后为 1 至 280 个字符。

### `CYCD_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置单次请求超时；不填写时为 10 秒。
- 填写格式：1 至 60 之间的秒数。

### `CYCD_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：按需要设置每个账号的最多请求尝试次数；不填写时为 3 次。
- 填写格式：1 至 5 之间的整数。

### `CYCD_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：通常无需设置；仅在 2cycd 官方站点迁移到新的 HTTPS 子域名时填写。
- 填写格式：属于 2cycd.com、不含账号、密码、查询参数或片段的 HTTPS 地址。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 QINGLONG_NOTIFY=auto 时填写要通知的脚本选择器。
- 填写格式：可用逗号、分号、空白或换行分隔；支持 00e71cec355af1fb、candidate.py、output/candidate.py、通配符或 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙 notify.py 不在默认位置时，填写其所在目录。
- 填写格式：包含 notify.py 的本地目录路径。
