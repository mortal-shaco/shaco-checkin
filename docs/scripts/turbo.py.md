## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TURBOVIEW_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://web.vtpro.xyz 注册或登录 ViewTurbo 账号，使用注册邮箱与登录密码。不要把凭据写入公开仓库或聊天。兼容上游时也可改用 USER1/PASS1、USER2/PASS2… 成对填写（仅当本变量未设置时生效）。
- 填写格式：每个非空行一个账号，格式 邮箱|密码；仅在第一个竖线处分割，密码中后续竖线保留。不要用 & 或 @ 分隔账号

### 可选参数

### `TURBOVIEW_DOMAIN`

- 必填：否
- 敏感：否
- 获取或设置：仅当官方 API 根地址变更时覆盖；默认 https://api.viewturbo.com
- 填写格式：https:// 开头的 API 根地址，不含业务路径

### `TURBOVIEW_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：网络较慢时可适当增大单次请求超时
- 填写格式：5..60 整数或小数秒，默认 15

### `TURBOVIEW_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时手动设置为 1
- 填写格式：1/true/yes/on 启用；0/false/no/off 关闭

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本白名单启用通知时设置；空值表示全部禁用
- 填写格式：catalog-id、脚本路径、文件名或 glob，可用逗号/分号/空白/换行分隔；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认路径时，设为 notify.py 或 sendNotify.js 所在目录
- 填写格式：本地目录绝对路径
