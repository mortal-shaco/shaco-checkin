# 菜鸟图库图币签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/cainiao.py`
- 青龙命令：`python3 scripts/cainiao.py`
- 建议 Cron：`27 10 * * *`
- 发布哈希：`c782f1704e40e6ae932f2bd2f412252d4017116c405d1bb90a06c337aad2b8cb`
- 许可证：`MIT`

## 脚本功能

- 使用登录 Cookie 执行菜鸟图库每日图币签到，保留上游 HTTPS GET 接口和请求头。
- 核验明确的签到成功或今日已签到消息，未知业务码、页面、消息与接口异常均按失败处理。
- 支持每行一个账号、可选本地账号标签及官方非敏感身份展示。
- 支持原有可选 PushPlus 通知及青龙通知选择列表和全局开关，发送脱敏汇总。
- 支持完全断网预演、逐阶段时间轴、账号及任务统计、单行 TASK_SUMMARY 结构化结果和云函数 main_handler 入口。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CAINIAO_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：使用自己的账号登录 https://www.sucai999.com，在浏览器开发者工具的网络面板查看本站已登录请求的请求头，复制完整 Cookie 值。失效后重新登录获取，不要分享凭据。
- 填写格式：每个非空行对应一个账号的完整 Cookie 值，不含 Cookie: 前缀。保留分号、等号和其他字符，不以 & 或 @ 分隔账号。

### 可选参数

### `CAINIAO_ACCOUNT_NAMES`

- 必填：否
- 敏感：否
- 获取或设置：可自行设置本地账号标签；也会显示官方响应中提供的非敏感昵称、用户名、显示名称或公开 UID。
- 填写格式：可选，每行一个标签，按行号与账号对应，不要使用手机号或凭据作为标签。

### `CAINIAO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设置为 1 启用完全断网预演。
- 填写格式：1、true、yes、on 启用，默认 0。预演不执行签到和通知。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可从 PushPlus 官方个人中心获取自己的推送令牌；通知启用时可追加 HTTPS 汇总推送。
- 填写格式：可选单个令牌，仅发送脱敏任务汇总，不向 PushPlus 发送 Cookie。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置通知脚本选择列表。
- 填写格式：使用逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符，* 匹配全部，空值在 auto 模式下关闭全部。本任务可用 1abfc0b939e55837 或 cainiao.py。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如青龙通知模块位于自定义目录，可指定该目录；否则自动查找可导入的 notify 模块及青龙标准路径。
- 填写格式：可选本机目录，包含 notify.py 或 sendNotify.js；模块不可用时保留业务退出码。
