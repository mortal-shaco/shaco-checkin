# CC98 WebVPN 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/webvpn_fixed_api.py`
- 青龙命令：`python3 scripts/webvpn_fixed_api.py`
- 建议 Cron：`12 8 * * *`
- 发布哈希：`abbb84f1b03a6d02e54e5acbe0eee4cebcc5f5b8924c9666486cf79ca23af290`
- 许可证：`MIT`

## 脚本功能

- 使用浙大 WebVPN 账号登录网关并建立会话
- 经固定 WebVPN 路径获取 CC98 OAuth Token 并提交每日签到
- 区分签到成功、今日已签到与业务失败，展示财富值奖励与连续签到天数
- 展示 CC98 用户名作为公开账号身份，方便核对
- 支持每行一个 CC98 账号的多账号独立处理，共用同一 WebVPN 凭据，任一账号失败时非零退出
- 支持完全断网预演、请求超时、时间轴日志、脱敏通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CC98_WEBVPN`

- 必填：是
- 敏感：是
- 获取或设置：使用浙江大学 WebVPN（https://webvpn.zju.edu.cn）可登录的统一身份账号与明文密码。仅写入青龙环境变量，不要分享或提交到公开仓库。
- 填写格式：用户名|密码；仅在第一个竖线处分割，密码中后续竖线保留

### `CC98_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用 CC98 论坛（https://www.cc98.org）可登录的用户名与明文密码。每个非空行一个账号；不要把凭据发给他人或写入公开仓库。
- 填写格式：每个非空行一个账号：用户名|密码；仅在第一个竖线处分割。空行和以 # 开头的注释行忽略

### 可选参数

### `WEBVPN_USER`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容别名：当 CC98_WEBVPN 为空时，与 WEBVPN_PASS 同时提供即可。优先使用 CC98_WEBVPN。
- 填写格式：WebVPN 用户名明文

### `WEBVPN_PASS`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容别名：当 CC98_WEBVPN 为空时，与 WEBVPN_USER 同时提供即可。优先使用 CC98_WEBVPN。
- 填写格式：WebVPN 密码明文

### `CC98_ACCOUNT_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：可选兼容别名：当 CC98_ACCOUNTS 为空时，与 CC98_USER_N/CC98_PASS_N 组合使用。优先使用 CC98_ACCOUNTS。
- 填写格式：正整数，表示兼容模式下的账号个数

### `CC98_TOKEN_PATH`

- 必填：否
- 敏感：否
- 获取或设置：仅在上游默认固定路径失效时覆盖；留空使用内置 CC98 Token 的 WebVPN 路径。
- 填写格式：以 / 开头的 WebVPN 路径

### `CC98_SIGN_PATH`

- 必填：否
- 敏感：否
- 获取或设置：仅在上游默认固定路径失效时覆盖；留空使用内置 CC98 签到的 WebVPN 路径。
- 填写格式：以 / 开头的 WebVPN 路径

### `CC98_CONNECT_TIMEOUT_SEC`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置连接侧超时参考值；与请求超时一并取较大值用于 urllib。留空默认 5 秒。
- 填写格式：2 至 60 之间的秒数

### `CC98_REQUEST_TIMEOUT_SEC`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置读超时参考值；与连接超时一并取较大值用于 urllib。留空默认 15 秒。
- 填写格式：5 至 120 之间的秒数

### `CC98_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用；预演不访问 WebVPN/CC98 接口，也不声明真实签到成功。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启完全断网预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试导入 notify 和青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径

## 多账号

CC98_ACCOUNTS 中每个非空行代表一个 CC98 账号，格式为用户名|密码；仅在第一个竖线处分割。所有账号共用同一 CC98_WEBVPN 网关凭据。脚本逐账号独立处理，任一账号失败时进程非零退出。
