# 顾家家居签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_kukahome.js`
- 青龙命令：`node scripts/sudojia_kukahome.js`
- 建议 Cron：`9 2 * * *`
- 发布哈希：`dff6bd437c0ba864d340b25eb01b49535cddc58e879964a9236434a926f34aa3`
- 许可证：`GPL-3.0`

## 脚本功能

- 读取并显示官方返回的账号昵称，不输出手机号或原始响应
- 每日签到并校验业务状态与积分结果
- 查询连续签到天数与当前积分
- 逐行多账号独立执行及失败非零退出
- 完全断网预演、分阶段日志及单行结构化任务总结
- 青龙脱敏通知，通知异常不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `GU_HOME_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录顾家会员微信小程序，在本人授权的抓包环境中查看 https://mc.kukahome.com 请求头，取得同一账号的 AccessToken 和 X-Customer。凭据过期后重新登录获取。
- 填写格式：每行 AccessToken#X-Customer，仅在首个 # 处分割，后续字符原样保留；不使用 & 或 @ 分隔账号。

### `GU_HOME_APP_SECRET`

- 必填：是
- 敏感：是
- 获取或设置：从获授权的顾家应用 appid=667516 签名配置或合法取得的本任务上游脚本 appSecret 常量取得。所有账号共用应用签名参数，不是账号令牌；维护版不内置该值。断网预演无需此项。
- 填写格式：应用签名密钥原文。

### 可选参数

### `GU_HOME_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：青龙环境变量中设置。
- 填写格式：1 为完全断网预演，其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙 sendNotify.js 所在目录；未设置时依次查找 /ql/data/scripts、/ql/scripts。
- 填写格式：本地通知模块目录路径；不可用时记录通知失败并保留业务退出码。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行对应一个账号，按首个 # 分割同账号的两个请求头；各账号独立处理，任一账号失败则整体非零退出。
