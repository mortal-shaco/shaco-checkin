## 脚本功能

- 使用喜马拉雅账号 Cookie 执行每日签到
- 支持换行分隔的多账号独立执行与汇总
- 支持可选的同账号 X-Xuid-Fp 请求参数
- 提供完全断网的预演模式
- 按青龙通知策略发送脱敏结果摘要
- 输出带时间戳的阶段日志、账号统计和单行 TASK_SUMMARY JSON

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XMLY_LIST`

- 必填：是
- 敏感：是
- 获取或设置：登录喜马拉雅网页或 App，在本人设备的开发者工具或抓包工具中找到发往 ximalaya.com 的本人请求，复制完整 Cookie；若该账号请求还包含 X-Xuid-Fp，可一并填写。请勿向他人分享这些值。
- 填写格式：每行一个账号，填写 Cookie；可选在该行首个制表符后填写同账号的 X-Xuid-Fp，即 Cookie<TAB>X-Xuid-Fp。账号之间只能使用换行分隔。

### 可选参数

### `XMLY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时设置为 1；预演不会调用签到接口或通知脚本。
- 填写格式：1 表示启用，未设置或其他值表示关闭。

### `XMLY_TIMEOUT_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置单次签到请求超时秒数；通常无需设置。
- 填写格式：3 至 60 的数字，默认 12。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写需要发送通知的脚本选择器；可用本任务 catalogId、脚本文件名、相对路径或星号通配符。
- 填写格式：多个选择器用逗号、分号、空白或换行分隔；* 表示所有脚本，显式空值表示全部禁用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在标准目录时，填写包含 sendNotify.js 或 notify.py 的目录。
- 填写格式：青龙容器内的绝对目录路径。

## 多账号

XMLY_LIST 中每个非空行是一个独立账号；脚本逐个执行并汇总，任何账号失败都会使进程以非零状态退出。Cookie 与同账号可选 X-Xuid-Fp 仅在该行首个制表符处分隔，不使用 & 或 @ 分隔账号。
