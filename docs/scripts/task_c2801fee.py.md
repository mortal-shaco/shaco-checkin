# 掘金签到与可选抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_c2801fee.py`
- 青龙命令：`python3 scripts/task_c2801fee.py`
- 建议 Cron：`40 10 * * *`
- 发布哈希：`7db818d41a12265bb195f787e7f8ab19c5b09ac1e3a034272090669a7f95eb0f`
- 许可证：`MIT`

## 脚本功能

- 每天执行掘金签到，以整数业务码 err_no=0 确认成功；未知业务码或响应异常均失败退出。
- 显式开启后在签到成功后执行一次抽奖；默认关闭可能消耗积分的抽奖操作。
- 兼容 JJ_COOKIE 和可选 SERVER_KEY；支持逐行多账号及独立失败隔离。
- 完全断网预演参数及执行计划，预演不会验证业务成功，也不会调用通知网络。
- 通过青龙通知助手发送脱敏结果，并兼容可选 Server 酱通知；通知失败保留业务退出码。
- 输出时间轴、阶段耗时、账号及任务统计和唯一 TASK_SUMMARY；显示官方返回的非敏感昵称或公开用户编号。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JJ_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录掘金，在开发者工具的网络面板选择发往 api.juejin.cn 的已登录请求，复制请求头 Cookie 的完整值，不包含 Cookie: 前缀。请只在青龙私有环境变量中保存，不提交到仓库。
- 填写格式：每个非空行一个账号完整 Cookie；不按 &、@、分号或等号拆分账号，行内分号和等号原样保留。

### 可选参数

### `JJ_LOTTERY`

- 必填：否
- 敏感：否
- 获取或设置：默认关闭；接受抽奖可能消耗积分后，手动设置为 1。签到成功后才会抽奖一次，不自动重试。
- 填写格式：0 或 1，默认 0

### `JJ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设为 1。完全禁止网络调用，通知只生成脱敏预览，不验证账号或业务成功。
- 填写格式：0 或 1，默认 0

### `SERVER_KEY`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容原参数；从自己的 Server 酱控制台获取 SendKey，留空即关闭此额外通知。仅发送脱敏统计，不再转发原始接口响应。
- 填写格式：单个 SendKey；字母、数字、下划线或连字符

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选通知脚本选择器；设置后替代默认选择。可填写目录编号 c2801fee6b1b75bf、脚本相对路径、文件名或文件名通配符；* 选择全部，空值禁用全部。
- 填写格式：逗号、分号或空白分隔的选择器

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 notify.py 或 sendNotify.js 所在目录；优先尝试导入 notify.send，再查指定目录、/ql/data/scripts、/ql/scripts。任务业务本身不依赖通知模块。
- 填写格式：本机通知模块所在目录路径
