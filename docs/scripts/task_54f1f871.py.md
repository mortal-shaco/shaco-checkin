## 脚本功能

- 支持绝区零、原神、崩坏：星穹铁道、崩坏3和未定事件簿的 HoYoLAB 签到；仅执行明确选择的游戏。
- 查询今日签到状态、累计天数、漏签天数，以及接口实际返回的奖励名称和数量。
- 兼容只读 config.json 账号配置、每账号游戏选择、--accounts 和 --games 筛选；新增 --info-only 只读查询。
- 支持逐行多账号，账号与游戏失败隔离；失败闭合，签到后重新查询官方状态验证。
- 保留显式配置的 Discord 通知和用户提及，新增青龙通知选择器、脱敏总结及断网预演。
- 输出官方返回的非敏感身份、分阶段耗时、账号统计和单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HOYOLAB_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录 HoYoLAB 官网，在浏览器开发者工具的网络面板打开本人签到请求，复制请求头中的完整 Cookie；仅保存在青龙私密环境变量中。兼容已有 config.json 的 accounts[].cookie，使用该兼容方式时可不设置此变量。
- 填写格式：每个非空行一个账号的完整 Cookie，保留其中分号及等号；不用 & 或 @ 分隔账号。

### 可选参数

### `HOYOLAB_GAMES`

- 必填：否
- 敏感：否
- 获取或设置：根据本人已开通的游戏手动选择；也可通过 --games 或原 config.json 的 accounts[].games 指定，不自动开启任何游戏。
- 填写格式：以空格或逗号分隔的 zzz、gi、hsr、hi3、tot；环境变量覆盖配置文件，命令行优先。

### `HOYOLAB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地预演时设为 1；预演禁止所有 HTTP 请求、Discord 和青龙通知实际发送。
- 填写格式：1、true、yes、on 开启，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写允许通知的脚本选择器；设置后替换默认名单，空值关闭全部。
- 填写格式：以逗号、分号或空白分隔目录编号、scripts/相对路径、文件名或文件名通配符；* 表示全部。目录编号为 54f1f8710298d67d。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙通知模块所在目录；否则尝试导入 notify 并查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：包含 notify.py 或 sendNotify.js 的目录；仅通知适配可选使用青龙模块，不是业务依赖。

## 多账号

HOYOLAB_ACCOUNTS 每个非空行一个完整 Cookie，各账号独立执行；游戏通过 HOYOLAB_GAMES 统一选择，也兼容原 config.json 每账号 games。--accounts 按从零开始的索引筛选，--games 覆盖游戏。任一账号配置、查询、签到或复核失败时整体非零退出。
