# 图虫每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_tuchong.js`
- 青龙命令：`node scripts/sudojia_tuchong.js`
- 建议 Cron：`38 5 * * *`
- 发布哈希：`cdc3e24cb80e5424179994733a38c773a31e05e91eb357a0d54e1fd47d32e270`
- 许可证：`GPL-3.0`

## 脚本功能

- 手机号密码登录，沿用上游 AES-128-ECB 手机号加密与请求头。
- 查询并展示官方昵称及公开 UID。
- 每日签到获取积分。
- 查询当前积分与等级。
- 每行一个账号，账号独立处理，任一失败整体非零退出。
- 完全断网预演与配置格式校验。
- 限时请求、响应大小限制、业务结果校验和脱敏日志。
- 正式运行通过青龙发送脱敏通知；通知失败不改变业务退出码；断网预演仅生成本地通知摘要。
- 带时间戳的分阶段结果、每账号及总体统计，输出唯一单行 TASK_SUMMARY。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TUC_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在图虫 APP 注册并绑定手机号，在账号设置中设置或重设登录密码；使用本人账号的手机号和密码，无需抓包。
- 填写格式：每个非空行一个账号：手机号#密码。仅在第一个 # 分割，其后密码原样保留，包括 #、&、@；不支持用 & 或 @ 分隔账号。

### 可选参数

### `TUC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 开启完全断网预演。
- 填写格式：1 为预演；其他值或未设置为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启；预演只展示本地通知摘要，不加载发送模块。
- 填写格式：0、false、no、off 关闭，大小写不敏感；默认 1。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写已有青龙 sendNotify.js 所在目录；未设置时依次查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径，仅用于可选通知集成；业务请求无外部文件依赖。

## 多账号

每个非空行一个账号，仅以第一个 # 分割手机号和密码；账号顺序执行，相互隔离，任一账号失败时整体非零退出。

## 副作用与风险

- 正式运行登录会建立服务端会话。
- 正式运行每日签到会改变签到状态并可能增加积分。
- 正式运行在启用通知且青龙模块可用时向已配置通知渠道发送脱敏摘要。
