# 掘金每日签到与可选免费抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/juejin.js`
- 青龙命令：`node scripts/juejin.js`
- 建议 Cron：`42 10 * * *`
- 发布哈希：`9cb3dd9561e9da906f97967c4dedbabeb477ca620850ea67856f8c0527583058`
- 许可证：`MIT`

## 脚本功能

- 每日签到，严格检查 HTTP 状态与业务码
- 查询免费抽奖次数，无免费次数时正常跳过
- 显式授权后仅免费次数为正时抽奖一次
- 兼容原单账号变量和云函数 main 导出，新增逐行多账号独立执行
- 完全断网演练、请求超时、响应大小限制、失败非零退出
- 显示接口提供的非秘密账号身份，输出阶段日志、账号统计和唯一 TASK_SUMMARY 汇总
- 按全局开关和脚本名单发送青龙脱敏通知，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JUEJIN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录掘金网页版，在开发者工具网络面板查看 api.juejin.cn 请求；从查询参数取得 aid，从请求 Cookie 取得 sessionid 值，不要粘贴整条 Cookie。
- 填写格式：每个非空行一个账号，格式为 aid|sessionid，仅按第一个 | 拆分；aid 为数字，sessionid 不含分号、空白或控制字符。

### 可选参数

### `juejin_aid`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游单账号变量，从掘金请求查询参数取得。仅未设置 JUEJIN_ACCOUNTS 时使用，必须配合 juejin_sessionid。
- 填写格式：数字应用标识

### `juejin_sessionid`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游单账号变量，从登录后的掘金请求 Cookie 取得 sessionid 值。仅未设置 JUEJIN_ACCOUNTS 时使用，必须配合 juejin_aid。
- 填写格式：单账号会话值，不含字段名

### `JUEJIN_FREE_LOTTERY`

- 必填：否
- 敏感：否
- 获取或设置：自行设置以显式授权抽奖；仅免费次数查询成功且为正时抽一次。查询与抽奖非原子操作，避免其他任务并发抽奖。
- 填写格式：1 开启；默认 0 关闭

### `JUEJIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置；仅验证配置和演练三个阶段，不发送业务请求或实际通知。
- 填写格式：1 开启；默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行设置通知名单，替换默认选择；可用目录编号 012f027cd2f3c11b、脚本路径、文件名或文件名通配符。
- 填写格式：逗号、分号或空白分隔；* 全选；空值关闭全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 sendNotify.js 的目录；未配置时查找 /ql/data/scripts 与 /ql/scripts。仅用于通知，不是业务依赖。
- 填写格式：本地目录路径
