## 脚本功能

- 多站点多账号每日签到，兼容会话 Cookie、系统访问令牌及配套密码续期；认证失败可在本次进程内重新登录，不回写配置。
- 读取官方用户名、昵称、显示名称和公开 UID，按返回值显示可公开身份，抑制凭据和手机号。
- 遇到接口明确要求 PoW 时按来源协议获取挑战、有限时计算并提交，不输出挑战或 nonce。
- 读取当月签到天数、累计额度、今日签到状态及本次签到奖励和日期，可通过任务开关选择签到或查询。
- 兼容可选 HTTPS 云端配置读取与本地账号回退，隔离云端认证、禁止认证重定向及云端通知覆盖。
- 断网预演、超时及响应体上限、逐账号失败隔离、脱敏时间轴日志、单行结构化汇总及青龙通知策略。
- 只有 HTTP 200 且 success 为布尔真才确认接口业务成功；已签到消息还须通过月度记录 checked_in_today 为真确认。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NEWAPI_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录各自 NewAPI 站点；开发者工具 Application → Cookies 复制 session 值，或在个人设置生成系统访问令牌。user_id 从本人 /api/user/self 的 data.id 或请求头 new-api-user 获取，不能根据用户名猜测。密码续期可填写本人登录用户名及密码；cf_clearance 从本站 Cookie 获取，可能绑定出口与 User-Agent。无需提交凭据或依赖其他仓库文件。
- 填写格式：每个非空行一个 JSON 对象：url 为 HTTPS 站点根地址；session、access_token 至少一个，或同时填写 login_username 与 login_password。可选 user_id、cf_clearance、name。兼容旧 JSON 数组及每行 URL#SESSION、URL#SESSION#ACCESS_TOKEN；含 # 的凭据请使用 JSON，禁止逗号、&、@ 分隔账号。session 填 Cookie 值而非整个 Cookie 头，access_token 保留个人设置要求的原始格式。

### 可选参数

### `NEWAPI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置，预演不发送业务、云配置或通知请求。
- 填写格式：1 启用断网预演；默认正式运行。

### `NEWAPI_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需要在青龙环境变量中选择任务；默认同时执行签到及月度统计。
- 填写格式：checkin,history；也可仅 checkin 或 history。

### `NEWAPI_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：如站点校验浏览器指纹，从获取 Cookie 时的浏览器请求复制 User-Agent；不保证解除浏览器验证。
- 填写格式：单行 User-Agent 字符串；默认保留上游 Chrome 120 标识。

### `CONFIG_URL`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容输入：由本人管理的 HTTPS WebDAV 或直接下载配置地址。不得把用户名密码放进 URL。优先读取云端，失败回退 NEWAPI_ACCOUNTS；预演只读取本地占位账号。
- 填写格式：HTTPS 地址；内容为账号 JSON 数组或含 accounts 数组的对象。忽略云端通知配置。

### `CONFIG_AUTH`

- 必填：否
- 敏感：是
- 获取或设置：从本人云存储设置取得 WebDAV 用户名及应用密码，或该配置服务的只读令牌。只发送给 CONFIG_URL，不发送到签到站点。
- 填写格式：token:令牌 或 用户名:密码；用户名密码只以第一个冒号为边界，密码中的后续冒号保留。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择列表；未设置时本待验证候选默认不推送。设为 * 可选择所有脚本。
- 填写格式：以逗号、分号、空白或换行分隔；支持 catalogId 241e7ff85e417257、脚本文件名、scripts/相对路径及文件名通配符；空值关闭全部。全局开关优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙已配置的通知模块目录；也会尝试导入 notify.send 或查找 /ql/data/scripts/notify.py、/ql/scripts/notify.py。业务任务无需此文件即可运行。
- 填写格式：含 notify.py 的本地目录路径；不下载或安装模块。

## 多账号

一个非空行对应一个账号，同账号站点和凭据合并在单行 JSON 对象中；兼容旧 JSON 数组。每个账号独立核对并执行，任一账号或配置失败整体非零退出；不按 &、@ 或逗号拆分账号。

## 副作用与风险

- checkin 任务向目标站点提交每日签到并领取该站点签到额度。
- 仅配套密码已配置且需要登录或续期时创建新的站点登录会话；会话仅保存在当前进程。
- 正式运行且通知策略选中时向青龙配置的通知渠道发送脱敏任务汇总。
