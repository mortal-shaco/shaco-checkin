## 脚本功能

- 使用机场账号登录并通过 Cookie 会话执行每日签到
- 查询并显示账号的到期时间与剩余流量
- 支持多个机场和多个账号逐个独立运行
- 兼容原有连续编号环境变量，并支持逐行 JSON 账号配置
- 对临时网络故障和服务端错误执行有限重试，可选使用 HTTP 或 HTTPS 代理
- 提供完全断网的配置预演、时间轴日志、脱敏统计和单行 JSON 汇总
- 按全局开关和脚本筛选规则发送青龙脱敏通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AIRPORT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在机场网站使用浏览器可以正常登录的账号信息；将该机场的 HTTPS 根地址、登录用户名和密码写入同一行 JSON。请仅保存在青龙环境变量中。
- 填写格式：每个非空行一个 JSON 对象，字段为 {"url":"HTTPS 根地址","user":"登录用户名","password":"登录密码"}；JSON 解析可完整保留密码中的符号。

### 可选参数

### `AIRPORT{n}_URL`

- 必填：否
- 敏感：否
- 获取或设置：旧版兼容参数：填写机场网站的 HTTPS 根地址；新配置 AIRPORT_ACCOUNTS 存在时忽略这些变量。
- 填写格式：n 从 1 连续编号，例如 AIRPORT1_URL。

### `AIRPORT{n}_USER{m}`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容参数：填写对应机场可以正常登录的账号；新配置 AIRPORT_ACCOUNTS 存在时忽略这些变量。
- 填写格式：n 为从 1 连续编号的机场序号，m 为从 1 连续编号的账号序号；必须与同编号 PASS 同时存在。

### `AIRPORT{n}_PASS{m}`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容参数：填写对应机场账号的登录密码；新配置 AIRPORT_ACCOUNTS 存在时忽略这些变量。
- 填写格式：n 为从 1 连续编号的机场序号，m 为从 1 连续编号的账号序号；必须与同编号 USER 同时存在。

### `PROXY_URL`

- 必填：否
- 敏感：是
- 获取或设置：可选；由自有代理服务提供。无需代理时不要设置。
- 填写格式：完整的 http 或 https 代理地址；可包含代理认证信息，因此按敏感变量保存。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选的通知脚本筛选列表；用于只允许指定任务发送通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalogId、文件名或通配模式；* 表示全部，显式空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选；当 notify.py 不在青龙标准目录时，填写该文件所在目录。
- 填写格式：本机目录路径，目录内应有 notify.py。

### `AIRPORT_CHECKIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置、日志和通知流程但禁止联网时设置。
- 填写格式：1、true、yes 或 on 表示启用断网预演。
