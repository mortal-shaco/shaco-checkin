- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）

- 建议 Cron：`36 7,13 * * *`
- 发布哈希：`dbaaedb75f519adc5376af068d5b6e4cc14f2d1a2d0e429f098028b02dea35fc`
- 许可证：`GPL-3.0`

## 脚本功能

- 查询官方账号昵称、用户名或公开 UID 及当前积分和待领取积分
- 按原定时与早晚分界执行社区签到、核对签到奖励资格并领取奖励
- 解析官网现行积分任务目录，对不支持的任务提示手动完成
- 按官网积分领取记录及本地周期状态避免重复互动
- 显式开启后执行文章点赞、收藏、分享事件和回答点赞；不发布分享文本
- 显式开启后从当前列表观看有效视频并核验播放、弹幕查询和心跳请求，保留真实计时等待
- 下午领取全部待领取积分并查询最终积分
- 可选查询积分商城商品与库存，不自动兑换
- 兼容旧账号 JSON 参数及场景实验提示
- 多账号独立执行、无网络预演、完整时间轴日志、单行机器汇总和脱敏通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `aliyunWeb_data`

- 必填：是
- 敏感：是
- 获取或设置：登录阿里云开发者社区 https://developer.aliyun.com/，在浏览器开发者工具的网络面板找到 /developer/api/my/user/getUser 请求，复制完整 Cookie 请求头；也可从阿里云 App 积分商城同一请求获取。Cookie 失效时重新登录获取，勿公开分享。
- 填写格式：每个非空行一个账号的完整 Cookie；保留所有分号和等号，不用 @ 或 & 分隔账号。兼容每行一个含 token 字段的 JSON 对象，以及原有含 token、userId、userName、avatar 的 JSON 数组。userId 等身份信息可选，以官方返回值核对账号。

### 可选参数

### `ALIYUN_WEB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设为 1；正式执行设为 0 或不设置。
- 填写格式：0 或 1；默认 0。断网预演只核验参数与执行计划，不验证登录或业务。

### `aliyunWeb_time`

- 必填：否
- 敏感：否
- 获取或设置：按原脚本早晚流程设置时间分界。
- 填写格式：1 至 23 的整数，默认 12；本地时间小于此值执行签到与互动，其余时间领取积分。

### `aliyunWeb_timezone`

- 必填：否
- 敏感：否
- 获取或设置：按运行所在时区设置。
- 填写格式：有效时区名称，默认 Asia/Shanghai。

### `aliyunWeb_interact`

- 必填：否
- 敏感：否
- 获取或设置：需要自动对官网随机文章点赞、收藏、记录分享以及点赞回答时显式开启。
- 填写格式：true 或 false，默认 false；作为公开互动的安全开关。

### `aliyunWeb_video`

- 必填：否
- 敏感：否
- 获取或设置：需要记录视频观看时显式开启；运行可能持续最多约 30 分钟。
- 填写格式：true 或 false，默认 false；从当前视频列表选择并发送播放与心跳，弹幕接口仅查询不发布内容。

### `aliyunWeb_stock`

- 必填：否
- 敏感：否
- 获取或设置：需要同时查询积分商城库存时开启。
- 填写格式：true 或 false，默认 false；只查询，不兑换。

### `aliyunWeb_scene`

- 必填：否
- 敏感：否
- 获取或设置：兼容原变量；场景实验已不在现行积分任务列表。
- 填写格式：true 或 false，默认 false；开启仅提示手动完成，不创建或关闭云资源。

### `aliyunWeb_dedupe`

- 必填：否
- 敏感：否
- 获取或设置：保留默认值以避免同一周期重复互动。
- 填写格式：true 或 false，默认 true；依官网每日或每周周期保存成功请求记录。

### `aliyunWeb_reward_check`

- 必填：否
- 敏感：否
- 获取或设置：保留默认值以核对官网本周期积分领取明细。
- 填写格式：true 或 false，默认 true；明细异常时不执行本次互动。

### `QL_DATA_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通常提供此数据目录；独立运行可自行指定有写权限的持久目录。
- 填写格式：可选目录路径；默认脚本目录，在其 config 子目录写入只含账号摘要和周期日期的去重状态。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自定义通知模块目录时设置；否则自动查找青龙脚本目录及当前脚本目录。
- 填写格式：含 sendNotify.js 的目录；仅用于可选通知，不作为业务运行依赖。

### `aliyunWeb_notify`

- 必填：否
- 敏感：否
- 获取或设置：兼容旧通知开关。
- 填写格式：off 禁用通知，其他值遵循 QINGLONG_NOTIFY；断网预演仅生成通知汇总。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
