# 库街区社区与游戏签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）

- 建议 Cron：`43 9 * * *`
- 发布哈希：`07d4a5f8076ff0112bec1434df62985366b37bf621b1f898699fa2fd79acfa58`
- 许可证：`MIT`

## 脚本功能

- 库街区社区每日签到，沿用 gameId=2
- 查询账号身份，显示官方返回的昵称、用户名或公开用户 ID
- 查询全部默认绑定角色，逐角色执行战双帕弥什、鸣潮及其他返回游戏角色的签到
- 每行一个账号，兼容当前目录 KURO_TOKEN.txt 账号文件只读加载
- 显式添加账号模式支持短信验证码登录、极验提示、手动录入 Token 和安全保存账号文件
- 完全断网预演、请求超时、业务码检查及逐账号失败退出
- 分阶段时间轴、账号和全局统计、单行 TASK_SUMMARY 与青龙脱敏通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KURO_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录本人库街区 APP，Android 可用 HttpCanary/Reqable，iOS 可用 Stream/Thor，抓取 api.kurobbs.com 的请求，复制请求头 token 字段的值，不要复制整个请求头。也可在人工终端用 KURO_TYPE=add_account 登录后从本地文件配置到青龙。
- 填写格式：每个非空行一个完整 Token，去除行首尾空白并去重，不按逗号、& 或 @ 分隔。默认兼容读取当前目录 KURO_TOKEN.txt，青龙推荐配置本变量。

### 可选参数

### `KURO_TYPE`

- 必填：否
- 敏感：否
- 获取或设置：默认留空执行签到；人工终端显式设置 add_account 可选择短信登录或手动输入 Token，短信触发极验时改用手动抓包。
- 填写格式：留空、sign 或 add_account；添加模式不签到，以权限 0600 原子保存当前目录 KURO_TOKEN.txt，不输出手机号、验证码或 Token。

### `KURO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1。
- 填写格式：1/true/yes/on 开启，完全断网，不发送通知、不读写账号文件、不交互；签到预演仍需占位 KURO_TOKEN。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：配置需要通知的脚本选择器，替换默认空列表。
- 填写格式：逗号、分号或空白分隔；支持 d0719f985bead4d5、scripts/kurobbs.py、kurobbs.py、实际文件名与文件名通配符；* 全选，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录；也查找可导入 notify.send、/ql/data/scripts 与 /ql/scripts。
- 填写格式：目录路径；通知不可用或发送失败不改变业务退出码。
