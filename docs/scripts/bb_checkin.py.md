# BreezeBlue 每日积分签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/bb_checkin.py`
- 青龙命令：`python3 scripts/bb_checkin.py`
- 建议 Cron：`2 11 * * *`
- 发布哈希：`8c9994476dc2aac695767379baf2d70251ade55d806949e97d5762621ea08f61`
- 许可证：`MIT`

## 脚本功能

- 每日领取服务端自动定档积分，兼容显式积分档位参数
- 支持 Cookie 请求头及单行 cURL 导入，支持已有邮箱账号密码登录；会话失效时至多重登一次
- 识别今日已签到，明确验证领取结果，拒绝仅凭 HTTP 200 判定成功
- 查询官方显示名称、登录态、积分余额、签到状态、档位及下次重置时间
- 支持多账号、独立失败处理及停用开关
- 提供 run、test、list、status 动作及旧配置只读兼容
- 完全断网预演、脱敏时间轴日志、账号与子任务统计及单行 TASK_SUMMARY 汇总
- 按青龙全局开关及脚本名单发送脱敏通知，通知故障保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BB_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://breezeblue.ai，打开开发者工具的网络面板，刷新后选择本站 /api/me 请求，复制请求标头 Cookie 的完整值。也可填写已注册邮箱账号的邮箱和密码；Google 登录账号请使用 Cookie。
- 填写格式：每个非空行一个账号。支持原始 Cookie、Cookie: 请求头、单行 Copy as cURL、邮箱|密码（仅按首个 | 分割），或单行 JSON 对象。JSON 字段为 cookie、email、password、enabled（布尔值，默认启用）、reward_tier（留空由服务端定档，或 standard、discord）。同一对象可同时配置 Cookie 与邮箱密码供失效后重登。账号之间只能换行，不使用 & 或 @ 分隔。

### 可选参数

### `BB_CONFIG`

- 必填：否
- 敏感：是
- 获取或设置：可选旧版 config.json 的显式路径；仅兼容已有配置，推荐迁移至 BB_ACCOUNTS。不会写入或迁移文件。
- 填写格式：仅在 BB_ACCOUNTS 未设置时读取。支持旧版单账号对象或含 accounts 数组的对象；支持 cookie、email、password、enabled、reward_tier，忽略历史结果。

### `BB_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中按需要配置；命令行参数优先。
- 填写格式：run（默认签到），test（只查询登录态与余额），list 或 status（只读脱敏配置）；不安装系统任务、不启动守护进程。

### `BB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线演练时设为 1。
- 填写格式：1、true、yes、on 开启；不发送业务 HTTP、不执行通知器，不修改状态。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中填写需要发送通知的脚本选择名单；设置后替换默认名单，本脚本无默认入选项。
- 填写格式：逗号、分号或空白分隔目录标识、脚本相对路径、文件名或文件名通配符；* 表示全部，空值禁用全部。识别本任务 catalogId、来源 catalogId 和实际文件名。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，青龙 notify.py 所在目录；也会尝试 import notify、/ql/data/scripts、/ql/scripts。
- 填写格式：目录路径；通知失败或不可用不改变业务退出码。

## 多账号

每个非空行一个账号，配套凭据置于同一行；邮箱密码按第一个 | 分割以保留密码中的后续分隔符。账号独立处理，任一账号失败则整体非零退出；停用账号跳过，全部停用视为配置错误。

## 副作用与风险

- 正式运行 run 动作会为启用的账号领取每日积分
- 邮箱密码登录或重登会创建服务端登录会话，仅在内存保留
- 入选通知名单或强制开启通知时通过青龙通知器发送脱敏统计
