## 脚本功能

- 使用邮箱密码登录 LinkHub（linkhub.asia）
- 执行每日签到；已签到时识别为今日已完成
- 可选使用 HTTP_PROXY / HTTPS_PROXY
- 官方响应若返回公开身份则直接展示；否则使用账号序号
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LINKHUB_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://linkhub.asia 注册 LinkHub 账号并确认可登录用户中心。将登录邮箱与密码写入青龙环境变量；不要把凭据发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号，写成「邮箱|密码」，仅在首个竖线处拆分，密码中后续竖线原样保留。不使用换行以外的符号分隔账号。

### 可选参数

### `ACCOUNT_EMAIL`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游旧变量：未设置 LINKHUB_ACCOUNTS 时，与 ACCOUNT_PASSWORD 组合为单账号。新部署请优先使用 LINKHUB_ACCOUNTS。
- 填写格式：单个登录邮箱；须与 ACCOUNT_PASSWORD 同时提供。

### `ACCOUNT_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游旧变量：未设置 LINKHUB_ACCOUNTS 时，与 ACCOUNT_EMAIL 组合为单账号。新部署请优先使用 LINKHUB_ACCOUNTS。
- 填写格式：对应账号的登录密码；勿写入日志或通知。

### `HTTP_PROXY`

- 必填：否
- 敏感：否
- 获取或设置：可选；与上游一致，需要经 HTTP 代理访问时设置。
- 填写格式：代理 URL，例如 http://127.0.0.1:7890；不含账号口令时可不标敏感。

### `HTTPS_PROXY`

- 必填：否
- 敏感：否
- 获取或设置：可选；与上游一致，需要经 HTTPS 代理访问时设置。
- 填写格式：代理 URL，例如 http://127.0.0.1:7890。

### `LINKHUB_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTPS 超时秒数。
- 填写格式：5 至 90 的整数秒；默认 15。

### `LINKHUB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。可填 70123c591c5d6f37、脚本文件名或 scripts 相对路径。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。不是业务依赖。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。
