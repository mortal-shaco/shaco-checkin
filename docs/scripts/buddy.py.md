# WorkBuddy 加油站每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/buddy.py`
- 青龙命令：`python3 scripts/buddy.py`
- 建议 Cron：`54 10 * * *`
- 发布哈希：`11d2fea35aa78079a1e0ce6002001e6c9c6b05519628c4c2509fc7afc434d5de`
- 许可证：`MIT`

## 脚本功能

- 查询加油站今日签到状态、主题、连续签到天数和累计积分
- 自动领取每日签到奖励，领取后复查官方签到状态
- 识别已签到账号并跳过重复领取
- 支持 --check 仅查询状态
- 支持每行一个账号、账号隔离与失败汇总
- 支持完全离线预演、时间轴日志、逐账号统计和单行结构化汇总
- 按全局开关和脚本选择发送青龙脱敏通知，通知失败保留业务退出码
- 官方返回昵称、用户名、显示名称或公开 UID 时显示该身份

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BUDDY_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.workbuddy.cn，在开发者工具的网络面板找到 /billing/meter/checkin-status 的 POST 请求，复制请求头 Cookie 的完整值。失效后重新登录获取。仅用于本人账号。
- 填写格式：每个非空行一个账号，填写完整 Cookie 值（名称=值；多项使用英文分号），不包含 Cookie: 前缀，不以 &、@ 或分号分隔账号。等号后的凭据文本保持完整。

### 可选参数

### `BUDDY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 可进行完全断网预演，默认 0。预演仅检查配置并模拟阶段与通知。
- 填写格式：1/0、true/false、yes/no 或 on/off

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式的脚本选择列表，未设置时默认包含本脚本。设置后替换默认列表，空值关闭全部。支持目录标识、脚本相对路径、文件名及文件名通配符。
- 填写格式：逗号、分号或空白分隔，支持 f02d352e0599ff52、checkin.py、candidate.py 和 *

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 或 sendNotify.js 所在目录。优先尝试导入 notify.send，其次此目录与 /ql/data/scripts、/ql/scripts。通知不可用时记录原因并保留业务退出码。
- 填写格式：本机通知模块目录路径

## 多账号

BUDDY_COOKIE 每个非空行一个账号，整行作为 Cookie 请求头值。各账号独立处理和隔离会话，任一账号失败则整体非零退出。
