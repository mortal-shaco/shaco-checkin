# 智行火车每日签到与积分查询

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/zxhc.js`
- 青龙命令：`node scripts/zxhc.js`
- 建议 Cron：`24 10 * * *`
- 发布哈希：`bce841737081bf38b00f78504a786b92816349570984e9e3e863828fae4e80e0`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每日提交智行火车签到请求，明确区分签到成功与今日已签到
- 查询并展示官方返回的积分和优惠券数值
- 展示官方返回且不含凭据或手机号的昵称、用户名、显示名称或公开账号标识
- 每行一个账号独立运行，兼容原请求头与请求体变量
- 断网预演、请求超时、响应大小限制、失败闭合及账号和阶段统计
- 按青龙全局通知开关与名单发送脱敏总结，通知不可用时保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ZXHC_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人设备登录智行火车，使用本人信任的 HTTPS 抓包工具，进入每日签到页并手动签到，捕获 https://m.suanya.cn/restapi/soa2/18903/attendanceDay 的完整请求头和原始请求体。将两者合并为同一 JSON 对象；抓包涉及凭据，勿分享或写入日志。请求体字符串需按 JSON 规则转义。接口版本如变化，须依据新抓包重新核验，不能只猜测版本号。
- 填写格式：每个非空行一个 JSON 对象，含 headers 请求头对象和 body 原始请求体字符串；body 也可为 JSON 对象，但有签名时须使用原始字符串。换行仅用于分隔账号，不使用 & 或 @ 分隔。优先于兼容变量。

### 可选参数

### `senku_signheader_zxhc`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游同名抓包存储键，取签到请求头的 JSON；无需 box.dat。新配置优先使用 ZXHC_ACCOUNTS。
- 填写格式：仅未配置规范变量时启用；每个非空行一个请求头 JSON，与 senku_signbody_zxhc 行数及顺序一致。

### `senku_signbody_zxhc`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游同名抓包存储键，取同一账号签到请求的原始请求体。
- 填写格式：仅未配置规范变量时启用；每个非空行一个完整原始请求体，与请求头一一配对。

### `ZXHC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中配置；本地验证时必须开启。
- 填写格式：1、true、yes、on 表示断网预演，默认正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙全局环境中设置通知名单；设置后替换默认名单。
- 填写格式：逗号、分号或空白分隔；支持目录相对路径 zxhc/zxhc.js、文件名 zxhc.js、当前文件名、目录与当前文件名、目录编号 38a2ed952649bfb6，以及 * 通配符。空值关闭全部；未设置时本脚本默认不入选。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如需自定义通知助手目录，指向青龙提供的 sendNotify.js 所在目录。
- 填写格式：可选目录路径；否则依次查找 /ql/data/scripts/sendNotify.js、/ql/scripts/sendNotify.js。仅通知需要，业务不依赖此助手。

## 多账号

每个非空行对应一个账号；请求头和请求体合并在同一 JSON 对象中，不拆分凭据内的 & 或 @。按账号独立执行，单个账号配置或请求失败不阻断其他账号，任一失败则整体非零退出。
