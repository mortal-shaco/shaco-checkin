## 脚本功能

- 默认获取中奖记录并执行沾喜气，检查业务码及幸运值字段，输出本次幸运值。
- 显式启用签到后检查业务码及矿石字段，输出本次获得矿石及矿石总数。
- 显式启用免费抽奖后先查询免费次数，只请求一次免费抽奖；免费次数为零时跳过。
- 支持每行一个账号、独立失败隔离、完全断网预演、请求总超时与响应大小限制。
- 官方响应含非敏感昵称、用户名、显示名或公开 UID 时原样显示，凭据、手机号及原始响应不输出。
- 输出分阶段时间轴、账号与任务统计及单行 TASK_SUMMARY，通过青龙发送脱敏通知并支持全局开关。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JUEJIN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录掘金网页版，打开开发者工具的网络面板，手动执行目标操作并找到 api.juejin.cn/growth_api/v1/ 请求；从请求头获取 Cookie，从请求 URL 获取 aid、uuid、_signature。将 _signature 写入 signature 字段。每行所有字段必须来自同一账号同一会话；凭据过期后重新获取。不得公开这些值。
- 填写格式：每个非空行一个完整 JSON 对象；cookie、aid、uuid 为非空字符串；启用 signin 或 draw 时还需非空字符串 signature，兼容字段 _signature。Cookie 内的分号、等号、&、@ 均原样保留，JSON 特殊字符须转义。禁止使用 & 或 @ 分隔账号。

### 可选参数

### `JUEJIN_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：根据需要手动配置任务；默认只执行上游实际启用的沾喜气。
- 填写格式：逗号分隔 lucky、signin、draw；默认 lucky。组合执行顺序为签到、沾喜气、免费抽奖；draw 只在免费次数大于零时请求一次，禁止付费重试。

### `JUEJIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置为 1。
- 填写格式：1 为完全断网预演，其他值为正式运行；预演也不投递网络通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要限制通知范围时配置；本任务可用目录编号 428b6cfe6c4ed62e 选择。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径或文件名；文件名支持 * 通配符，* 选全部，空值全禁用；显式启停开关优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块位于自定义目录时填写该目录；默认依次查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：包含 sendNotify.js 的目录；未找到模块或投递失败只记录状态，不修改业务退出码。
