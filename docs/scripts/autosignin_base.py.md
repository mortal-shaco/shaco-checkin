# 广州信息技术职校微信签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/autosignin_base.py`
- 青龙命令：`python3 scripts/autosignin_base.py`
- 建议 Cron：`30 7 * * *`
- 发布哈希：`99c5ad963113497de929d47e1001c3dbfa3192233ff8aabb0d6e692ca2b2e3ed`
- 许可证：`MIT`

## 脚本功能

- 调用 gzsx.qidisoft.cn 学生微信平台 ComApi/PostObject 的 gzsxWebApi.DoSignin 完成每日签到
- 支持多账号：GZSX_ACCOUNTS 每行 apitoken|userid，兼容 GZSX_APITOKEN 与 GZSX_USERID 单账号别名
- 可选提交定位字段（纬度、经度、地址、距离、精度），默认留空不伪造学校坐标
- 可选自定义微信 User-Agent；官方响应若含姓名等公开身份则原样打印便于核对
- 完全断网预演、请求超时、时间轴日志、青龙通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `GZSX_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在微信中打开广州信息技术职业学校学生平台小程序或网页并完成绑定登录后，用开发者工具或抓包查看请求头 apitoken，以及签到接口载荷中的 UserID。不要把 Token 发给他人或写入公开仓库。
- 填写格式：每个非空行一个账号，格式 apitoken|userid；仅在第一个竖线处分割。不使用 & 或 @ 分隔账号。

### 可选参数

### `GZSX_APITOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名；仅当 GZSX_ACCOUNTS 为空时与 GZSX_USERID 一起生效。获取方式同 GZSX_ACCOUNTS。
- 填写格式：apitoken 字符串。

### `GZSX_USERID`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名；仅当 GZSX_ACCOUNTS 为空时与 GZSX_APITOKEN 一起生效。取自签到载荷 UserID 或登录响应中的公开 uid。
- 填写格式：用户公开 UserID 字符串。

### `GZSX_UA`

- 必填：否
- 敏感：否
- 获取或设置：可选。需要与微信端一致时，从微信内置浏览器请求头复制 User-Agent；不填使用脚本内置常见微信 UA。
- 填写格式：完整 User-Agent 字符串。

### `GZSX_LAT`

- 必填：否
- 敏感：否
- 获取或设置：可选定位纬度。学校要求定位签到时按本人真实位置填写；默认留空，不伪造坐标。
- 填写格式：纬度数字字符串，例如 23.145182。

### `GZSX_LNG`

- 必填：否
- 敏感：否
- 获取或设置：可选定位经度。学校要求定位签到时按本人真实位置填写；默认留空，不伪造坐标。
- 填写格式：经度数字字符串，例如 113.273506。

### `GZSX_ADDRESS`

- 必填：否
- 敏感：否
- 获取或设置：可选地址描述。与定位字段一并提交；默认留空。
- 填写格式：地址文本。

### `GZSX_DISTANCE`

- 必填：否
- 敏感：否
- 获取或设置：可选距离字段，对应上游 distance；默认留空。
- 填写格式：距离数字字符串。

### `GZSX_ACCURACY`

- 必填：否
- 敏感：否
- 获取或设置：可选精度字段，对应上游 accuracy；默认留空。
- 填写格式：精度数字字符串。

### `GZSX_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：手工配置单次请求超时秒数；不填默认 20 秒。
- 填写格式：5 到 60 之间的数字。

### `GZSX_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手工填写 1 启用完全断网预演；只校验配置与流程，不发起网络请求。
- 填写格式：1/true/yes/on 启用；0/false/no/off 或不填关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：当 QINGLONG_NOTIFY=auto 时生效；填写目录编号、文件名、相对路径或通配符；* 表示全部；显式空值关闭全部。
- 填写格式：逗号、分号、空白或换行分隔的选择器列表。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 或 sendNotify.js 所在目录；未设置时查找青龙标准目录。
- 填写格式：本地目录路径。
