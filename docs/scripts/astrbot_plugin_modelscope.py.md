- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/astrbot_plugin_modelscope.py`
- 青龙命令：`python3 scripts/astrbot_plugin_modelscope.py`
- 建议 Cron：`0 6 * * *`
- 发布哈希：`2197fd0b94c0590839e76f7b5b759abefc33601096791e4a00bb78ca1c949f0d`
- 许可证：`MIT`

## 脚本功能

- 每天北京时间 06:00 执行，也可在青龙手动运行一次；需将调度器时区设为 Asia/Shanghai。
- 支持多账号、完整 Cookie 与单独会话值；兼容旧式单账号输入，账号失败互不阻塞。
- 签到前查询今日账单，通过登录接口触发幂等签到，最多三次查询今日 EARN 记录并核对 daily_active 或 aliyun_bindlogin 规则。
- 按北京时间处理账单日期，区分本次新增到账、今日合计和今天已签到；展示魔粒可用及总余额。
- 展示官方返回的非敏感昵称、用户名或公开标识；凭据、手机号和原始响应不进入日志。
- 请求超时、响应大小限制、禁止重定向携带凭据、明确业务成功核验；无法核验到账时非零退出。
- 提供断网预演、带阶段耗时的时间轴日志、账号与任务统计及单行 TASK_SUMMARY 汇总。
- 成功、部分失败、失败和配置错误通过青龙通知工具发送脱敏总结；通知失败保留业务退出码，预演仅本地预览通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MODELSCOPE_COOKIES`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.modelscope.cn，在开发者工具网络面板选择本站已登录请求，复制包含 m_session_id 的 Cookie 请求头。不要使用模型调用 API Key；会话失效后重新登录获取。
- 填写格式：每个非空行一个账号，支持完整 Cookie、Cookie: 前缀、m_session_id=会话值或单独会话值；保留整行其它 Cookie，不用 &、@ 分隔账号；重复行去重。

### 可选参数

### `MODELSCOPE_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧式单账号兼容输入，获取方式同 MODELSCOPE_COOKIES；主变量为空时才读取。
- 填写格式：单账号 Cookie 或会话值。

### `MODELSCOPE_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选，默认 30；按网络状况设置单次网络操作超时。
- 填写格式：5 至 120 的整数，单位秒。

### `MODELSCOPE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 启用完全断网预演；只检查格式，不确认真实签到或凭据有效性。
- 填写格式：1/true/yes/on 启用；0/false/no/off 关闭，默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，auto 模式下设置后替换默认列表；可填本任务目录标识 7b0e6bc8644c6dfe、文件名、scripts/相对路径或文件名通配符。
- 填写格式：逗号、分号或空白分隔；* 选择全部，空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填青龙公开通知工具所在目录；也会尝试导入 notify.send 及 /ql/data/scripts、/ql/scripts。通知工具需已配置通知渠道。
- 填写格式：包含 notify.py 或 sendNotify.js 的目录；不是业务依赖，不可用时保留业务退出码。

## 多账号

每个非空行一个账号；同账号完整 Cookie 保留为一行；逐账号独立处理、重复行去重、账号间隔一秒；任一账号失败则整体非零退出。
