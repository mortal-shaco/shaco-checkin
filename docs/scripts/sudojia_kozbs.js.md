## 脚本功能

- 查询官方返回的公开昵称和当前积分。
- 检查今日签到状态，已签到时避免重复签到。
- 未签到时执行每日签到，以业务码 errno 严格等于数字 0 确认接口成功。
- 支持换行多账号、独立失败处理和整体失败退出码。
- 提供完全断网预演、阶段耗时、账号与任务统计以及单行结构化汇总。
- 正式执行后通过青龙发送脱敏汇总，支持全局关闭及通知失败不影响业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KOZBS_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录植白说官方商城微信小程序，在本人授权的抓包环境中查找 https://www.kozbs.com 请求，从请求头复制 x-dts-token 的值。凭据失效后重新登录获取，不要复制完整请求头。
- 填写格式：每个非空行填写一个账号的完整令牌；不使用 & 或 @ 分隔账号。

### 可选参数

### `KOZBS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置。
- 填写格式：1 为完全断网预演，其余值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置全局通知开关，默认开启。
- 填写格式：0、false、no、off 关闭，大小写不敏感；其余值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写青龙官方通知模块 sendNotify.js 所在目录；未配置时自动查找 /ql/data/scripts 与 /ql/scripts。
- 填写格式：本机通知模块目录路径，仅用于可选通知，不影响独立业务执行。

## 参数获取方法

完整获取说明已写在上方各变量条目中。禁止使用来源不明的第三方提取页，或把凭据粘贴到聊天、Issue 与公开日志。

## 多账号

每个非空行一个账号，去掉行首尾空白；账号独立执行，任一账号失败则整体非零退出。
