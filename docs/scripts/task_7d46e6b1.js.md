- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_7d46e6b1.js`
- 青龙命令：`node scripts/task_7d46e6b1.js`
- 建议 Cron：`59 15 8 * * *`

- 许可证：`GPL-3.0`

## 脚本功能

- 保留每天 08:15:59 的原六段调度时间与云闪付签到请求接口、空 JSON 请求体和兼容请求头。
- 通过账号对应的 Authorization 和 Cookie 执行签到，兼容上游单账号变量。
- 显示官方返回的连续签到天数、当月连续签到天数和可安全展示的昵称、用户名、显示名称或公开用户编号。
- 每行一个账号，失败独立处理，任一账号失败时整体非零退出。
- 提供完全断网的参数与请求结构预演，预演结果不代表真实业务成功。
- 提供带时间戳的编号阶段日志、账号统计、任务统计和唯一的单行 TASK_SUMMARY 汇总。
- 按青龙全局开关和任务选择列表发送脱敏汇总，保留天数信息；通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `YSF_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在云闪付官方客户端进入签到页面，用本人授权的抓包工具查看 https://youhui.95516.com/newsign/api/daily_sign_in 的 POST 请求头，将同一账号完整的 Authorization 和 Cookie 合并。保留 Authorization 可能包含的前缀。凭据失效时重新获取，不使用登录密码，不公开抓包内容。
- 填写格式：每个非空行一个账号：Authorization|Cookie。只在第一个竖线处分割，Cookie 后续内容原样保留；不使用 & 或 @ 分隔账号。设置此变量后优先使用它，不回退旧变量。

### 可选参数

### `YSF_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游的单账号输入；从上述签到请求获取 Authorization。仅未设置 YSF_ACCOUNTS 时与 YSF_COOKIE 配套使用。
- 填写格式：完整 Authorization 请求头值；仅支持单账号，不含换行。

### `YSF_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游的单账号输入；从同一账号上述签到请求获取 Cookie。仅未设置 YSF_ACCOUNTS 时与 YSF_TOKEN 配套使用。
- 填写格式：完整 Cookie 请求头值；保留分号、等号及后续字段，不含换行。

### `YSF_CITY`

- 必填：否
- 敏感：否
- 获取或设置：可从本人签到请求的 x-city 请求头获取；不设置则保留上游默认值 360900。
- 填写格式：六位数字城市编码。

### `YSF_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设为 1，正式任务留空。
- 填写格式：1、true、yes、on 启用断网预演；其他值为正式模式。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可设置为本任务目录编号 7d46e6b18960482b、云闪付签到.js、实际文件名或青龙 scripts 下相对路径；设置后替换默认选择，空值禁用全部。
- 填写格式：逗号、分号或空白分隔；支持文件名中的 * 通配符，单独 * 选择全部任务。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定青龙 sendNotify.js 所在目录；自动查找脚本同目录、/ql/data/scripts 和 /ql/scripts。通知模块缺失或失败不改变业务退出码。
- 填写格式：本机青龙通知目录，不是其他业务仓库依赖。

YSF_ACCOUNTS 每个非空行一个账号，Authorization 与 Cookie 必须属于同一账号；只在第一个竖线处分割。逐账号独立执行，一个失败不阻止其他账号，但整体非零退出。旧变量仅兼容单账号。
