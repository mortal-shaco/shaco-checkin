# LINUX DO 登录与浏览统计

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/l.py`
- 青龙命令：`python3 scripts/l.py`
- 建议 Cron：`37 */5 * * *`
- 发布哈希：`9c9e97ed107632272c9298cf39872a9d749e65ce050763bb2824f165db3ddc96`
- 许可证：`MIT`

## 脚本功能

- Cookie 登录身份校验并显示官方返回的公开用户名和信任等级
- 按原有浏览开关与数量参数，从首页发现并随机读取话题，校验标题及帖子正文
- 查询访问天数、浏览话题、已读帖子、阅读时长、给出点赞、收到点赞及发帖数
- 显示上游 TL0 至 TL1、TL1 至 TL2 的参考升级要求和达标情况
- 每行一个账号，账号互相隔离，任一账号失败返回非零退出码
- 完全断网预演、按阶段记录脱敏结果、账号与任务统计及单行结构化汇总
- 通过青龙通知模块发送脱敏汇总，失败或不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LINUXDO_COOKIES`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://linux.do，打开开发者工具的网络面板，选择本站已登录请求，复制请求头 Cookie 的完整值。不要复制其他站点凭据。过期后重新获取。
- 填写格式：每个非空行一个账号的完整 Cookie，字段以分号分隔，每个字段仅在第一个等号处分割；不使用 & 或 @ 分隔账号。

### 可选参数

### `BROWSE_ENABLED`

- 必填：否
- 敏感：否
- 获取或设置：按需要自行设置，兼容上游变量，默认 true。
- 填写格式：true、1、yes、on 启用；false、0、no、off 关闭。

### `TOPIC_LIMIT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置首页候选话题上限，默认 50。
- 填写格式：1 至 500 的整数；HTTP 首页无动态滚动，实际数量受返回页面限制。

### `BROWSE_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置随机读取话题数，默认 20；实际数量不超过发现数量。
- 填写格式：0 至 500 的整数，0 跳过浏览。

### `LINUXDO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设为 1；默认 0。
- 填写格式：1 完全断网，包括通知；使用本地样例，不验证账号或真实业务。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙全局通知开关，默认 1；通知渠道在青龙通知设置中配置。
- 填写格式：0、false、no、off 关闭，其余值启用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，设为青龙 notify.py 所在目录；未设置时检查脚本目录及青龙标准目录。
- 填写格式：通知模块目录的绝对路径；不属于业务运行依赖。
