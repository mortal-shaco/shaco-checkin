# 今日校园辅导员签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_c04cea4d.py`
- 青龙命令：`python3 scripts/task_c04cea4d.py`
- 建议 Cron：`0 21 * * *`
- 发布哈希：`d0fdc2cb82561c0750608c223d5a31454b38e544f906d2dae60b67c4fbb13db6`
- 许可证：`MIT`

## 脚本功能

- 按学校全称查询今日校园租户，解析统一身份认证登录地址与校园圈 host。
- 使用学号密码本机完成 CAS 登录，或直接载入校园圈会话 Cookie。
- 查询并提交辅导员签到（含可选请假任务、附加题默认答案与可选照片上传）。
- 支持逐行多账号、断网预演、超时控制、时间轴日志与单行 TASK_SUMMARY。
- 通过青龙 notify.py 或 sendNotify.js 发送脱敏任务汇总，遵守全局开关与脚本清单。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CPDAILY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在今日校园使用本校统一身份认证的学号与密码；学校全称须与 mobile.campushoy.com 租户列表一致（如南京审计大学）。定位请使用本人真实签到位置。若学校登录需要验证码或加密口令异常，可在浏览器登录校园圈后复制请求 Cookie，改用会话 JSON/管道格式。勿把真实密码或 Cookie 写入仓库。
- 填写格式：每个非空行一个账号。推荐 JSON：{"school":"学校全称","username":"学号","password":"密码","lon":"经度","lat":"纬度","address":"地址","abnormalReason":"异常/体温等","photo":"可选本地照片路径"}；会话模式用 cookie 字段（可加 host）。兼容管道：学校|学号|密码|经度|纬度|地址|异常原因（密码勿含|）；会话管道：session|学校|Cookie|经度|纬度|地址|异常原因。以 # 开头的行视为注释。

### 可选参数

### `CPDAILY_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：单账号兼容别名：仅当 CPDAILY_ACCOUNTS 为空时，与学校、密码、定位等别名一起组成一个账号。
- 填写格式：学号或工号字符串。

### `CPDAILY_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：单账号兼容别名：仅当 CPDAILY_ACCOUNTS 为空时生效。
- 填写格式：统一身份认证密码。

### `CPDAILY_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：单账号会话别名：浏览器登录校园圈后复制 Cookie；仅当 CPDAILY_ACCOUNTS 为空时生效。
- 填写格式：完整 Cookie 头值，不含 Cookie: 前缀。

### `CPDAILY_SCHOOL`

- 必填：否
- 敏感：否
- 获取或设置：单账号学校全称别名；须与今日校园租户名称一致。
- 填写格式：例如：南京审计大学

### `CPDAILY_HOST`

- 必填：否
- 敏感：否
- 获取或设置：可选：会话模式下若已知校园圈域名可填写；一般由学校查询自动解析。
- 填写格式：如 xxx.campusphere.net，不含协议。

### `CPDAILY_LON`

- 必填：否
- 敏感：否
- 获取或设置：单账号经度别名。
- 填写格式：数字字符串，如 118.619966

### `CPDAILY_LAT`

- 必填：否
- 敏感：否
- 获取或设置：单账号纬度别名。
- 填写格式：数字字符串，如 32.070899

### `CPDAILY_ADDRESS`

- 必填：否
- 敏感：否
- 获取或设置：单账号签到地址别名，须与定位匹配。
- 填写格式：中文地址文本

### `CPDAILY_ABNORMAL_REASON`

- 必填：否
- 敏感：否
- 获取或设置：单账号异常说明/体温等字段别名，按学校表单要求填写。
- 填写格式：短文本，可为空字符串

### `CPDAILY_PHOTO`

- 必填：否
- 敏感：否
- 获取或设置：任务要求拍照时提供青龙容器内可读的本地图片路径；不需要拍照可留空。
- 填写格式：绝对或相对文件路径

### `CPDAILY_EXTRA_DEFAULTS`

- 必填：否
- 敏感：否
- 获取或设置：当签到含附加选择题时，按题目顺序配置默认选项；标题必须与任务返回的 title 完全一致。
- 填写格式：JSON 数组，例如 [{"title":"请填报体温","value":"其它"}]

### `CPDAILY_TASK_KIND`

- 必填：否
- 敏感：否

- 必填：否

- 获取或设置：自行设置单次 HTTPS 请求超时；默认 20 秒。

### `CPDAILY_DRY_RUN`

- 必填：否

### `QINGLONG_NOTIFY_SCRIPTS`
