## 脚本功能

- 每天 00:01 执行吉利汽车每日签到，保留上游风控签名、请求头和日期格式；精确识别上游已有的已签到响应。
- 查询并展示连续签到天数。
- 查询并展示能量体余额。
- 查询 App 最新版本；查询失败沿用上游 3.25.0 回退版本，不代表业务成功。
- 保留 geely_val JSON 凭据及大写别名兼容，扩展为换行多账号，提供同账号配套凭据抓包说明。
- 完全断网预演配置、签名和三个请求的构造，不模拟真实业务成功。
- 独立实现 HTTPS、15秒绝对超时、响应大小限制和明确业务成功检查；账号失败不阻断其他账号。
- 展示官方响应中的非敏感昵称、用户名、显示名称或公开 UID，抑制凭据、手机号及原始响应。
- 提供分账号分阶段时间轴、任务统计和唯一单行 TASK_SUMMARY 机器汇总。
- 依据青龙全局开关和名单发送脱敏通知；通知失败保留业务退出码；断网预演不加载通知模块。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `geely_val`

- 必填：是
- 敏感：是
- 获取或设置：在本人授权设备的抓包工具中解密 app.geely.com HTTPS，登录吉利汽车 App 后打开个人中心，从 /my/getMyCenterCounts 请求头获取同一账号的 token 和 devicesn，保存到同一行 JSON。风控升级或登录失效时重新获取两项，获取后关闭抓包，不分享凭据。
- 填写格式：每个非空行是一个 JSON 对象，含非空字符串 token、devicesn；支持一个或多个账号，不能用 &、@ 分隔账号。字符串保持原样，不拆分内部内容。

### 可选参数

### `GEELY_VAL`

- 必填：否
- 敏感：是
- 获取或设置：旧版大写兼容输入，获取方法与 geely_val 相同；geely_val 非空时优先。
- 填写格式：与 geely_val 相同；规范配置优先使用 geely_val。

### `GEELY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1，启用完全断网预演。
- 填写格式：1、true、yes、on 启用；默认正式执行。预演不签到、不查询、不调用通知模块。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在全局通知模式为 auto 时设置需要通知的脚本选择器。
- 填写格式：逗号、分号或空白分隔；支持目录编号 0909dbea8968ed50、geely.js、实际文件名、脚本相对路径和文件名通配符；* 全选；空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙 sendNotify.js 所在目录；不设置时搜索标准青龙目录及脚本相邻目录。
- 填写格式：目录路径；只用于可选通知集成，不影响独立业务请求。
