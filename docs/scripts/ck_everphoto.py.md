## 脚本功能

- 使用手机号与密码字段值登录时光相册
- 执行每日签到并区分首次签到与今日已签到
- 显示接口返回的累积签到天数及非敏感账号身份
- 支持每行一个账号与原有账号对象列表格式
- 完全断网预演与逐账号失败隔离
- 带阶段耗时、账号统计和单行 TASK_SUMMARY 的脱敏日志
- 通过青龙 notify.py 发送脱敏汇总，通知不可用时保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `EVERPHOTO`

- 必填：是
- 敏感：是
- 获取或设置：登录本人时光相册账号，在浏览器开发者工具的网络面板查找 https://web.everphoto.cn/api/auth 请求，获取 mobile 和 password 字段。密码若已由客户端转换，应填写请求中的字段值，本脚本不猜测或转换密码。不要分享凭据或完整请求。
- 填写格式：每个非空行一个账号：手机号|密码字段值；仅按首个 | 分隔，后续 | 保留在密码内。不使用 & 或 @ 分隔账号。兼容原上游 EVERPHOTO 账号对象列表的 JSON 表示，字段为 mobile、password，均为字符串。

### 可选参数

### `EVERPHOTO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置。
- 填写格式：1、true、yes 或 on 开启完全断网预演；默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置；使用青龙已有的 notify.py 通知配置。
- 填写格式：默认 1；0、false、no、off 关闭。预演只展示脱敏通知内容，不实际投递，以保持完全断网。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写本人青龙安装中已有 notify.py 所在目录；不需要其他仓库。
- 填写格式：本地目录路径；未设置时尝试导入 notify，再查找 /ql/data/scripts/notify.py 和 /ql/scripts/notify.py。

## 多账号

每个非空行一个账号，手机号与密码字段值使用首个 | 合并；各账号独立执行，任何账号失败时整体非零退出。兼容原有账号对象列表 JSON 格式。
