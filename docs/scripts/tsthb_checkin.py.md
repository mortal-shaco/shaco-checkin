# 塔斯汀汉堡签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tsthb_checkin.py`
- 青龙命令：`python3 scripts/tsthb_checkin.py`
- 建议 Cron：`19 1 * * *`
- 发布哈希：`1b1dbd16d097b4946dbfb0c1ce4fdbab78ffa801a323f2f0f78bec56d1d03aed`
- 许可证：`MIT`

## 脚本功能

- 从官方活动列表查询当前签到活动，优先每日签到入口
- 校验账号并展示官方返回的非敏感身份，隐藏手机号
- 每日签到并展示奖励名称或积分
- 每行一个账号，账号独立执行与失败汇总
- 可配置的随机延迟及倒计时，保留每天 09:55 调度
- 完整断网预演、分阶段日志、任务统计及单行结构化汇总
- 青龙脱敏通知及全局开关，通知失败保留业务退出码
- 每次 HTTP 请求设置 20 秒整体等待时限，覆盖域名解析和慢速响应；签到不自动重试

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `tsthbck`

- 必填：是
- 敏感：是
- 获取或设置：在微信塔斯汀小程序登录，用本人授权的抓包工具查看 sss-web.tastientech.com 请求头中的 user-token；仅复制该字段值，过期后重新获取。
- 填写格式：每个非空行填写一个账号的完整 user-token，不填请求头名称；不使用 & 或 @ 分隔账号，字段内部字符保持原样。

### 可选参数

### `TSTHB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 启用完全断网预演；默认 0。
- 填写格式：1、true、yes、on 表示启用。预演不执行等待、HTTP 或通知模块，仅展示通知摘要。

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置；保留维护版默认 true。限时验证和需要立即执行时设置 false。
- 填写格式：忽略大小写，只有 true 启用随机延迟，其他值关闭。

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：自行设置随机等待上限；保留维护版默认 3600 秒。
- 填写格式：非负整数，单位秒；随机延迟开启时在 0 至该值之间随机选择并显示倒计时。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙 notify.py 所在目录；未配置时尝试导入 notify，并查找 /ql/data/scripts 和 /ql/scripts。签到本身不依赖通知文件。
- 填写格式：可选目录路径；不会下载安装通知组件。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
