- 建议 Cron：`40 1 * * *`
- 发布哈希：`5513d54f629ea9cf8f239c3e575031816074d482dc193bc604df3202c91a3640`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用可撤销访问令牌核对账号公开昵称或用户名，不再保存手机号和明文密码
- 默认查询当前积分并读取社区指引
- 可分别显式开启自动回答和文章分享，默认均关闭
- 自动回答优先使用一言 HTTPS 随机文案并按作者和来源归属格式发布，所有规定故障均回退到本地文案
- 关注与取关必须分别明确授权，操作前读取原状态，操作后恢复并再次核验
- 支持每行一个账号独立执行，并在任一账号失败时返回非零退出码
- 支持完全无网络的预演、时间轴日志、脱敏汇总和青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XNIU_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录小牛电动 APP，在本人设备抓取 app-api.niu.com 请求头中的 token，并从本人资料接口确认公开 user_id；不要填写手机号或密码。令牌失效后重新登录获取。
- 填写格式：每行一个账号，格式为“访问令牌#公开用户ID”；只在第一个 # 处分隔，多账号只能换行

### 可选参数

### `XNIU_ENABLE_COMMENT`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；确认愿意自动发布回答后手动设为 1，默认关闭。
- 填写格式：1 表示开启，其他值表示关闭

### `XNIU_ENABLE_SHARE`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；确认愿意登记分享行为后手动设为 1，默认关闭。
- 填写格式：1 表示开启，其他值表示关闭

### `XNIU_ENABLE_FOLLOW`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；仅在接受临时改变关注状态时手动设为 1，并且必须同时开启 XNIU_ENABLE_UNFOLLOW。
- 填写格式：1 表示明确允许关注动作，其他值表示关闭

### `XNIU_ENABLE_UNFOLLOW`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；仅在接受恢复原关注状态所需的取关动作时手动设为 1，并且必须同时开启 XNIU_ENABLE_FOLLOW。
- 填写格式：1 表示明确允许取关动作，其他值表示关闭

### `XNIU_FALLBACK_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；可填写随机文案服务失败时使用的本地公开回答，留空则使用脚本内置文案。
- 填写格式：不超过 280 个字符的公开文本

### `XNIU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；测试配置时设为 1，预演不会发起任何网络请求。
- 填写格式：1 表示开启无网络预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择器；可填写目录编号、脚本路径、文件名或通配符。
- 填写格式：多个选择器使用逗号、分号、空白或换行分隔；空值关闭全部脚本通知

## 多账号

XNIU_TOKEN 每个非空行代表一个账号；访问令牌与同账号公开用户ID使用第一个 # 连接，后续文本保持不变。账号独立执行，任一账号失败时进程返回非零退出码。

## 副作用与风险

- 开启 XNIU_ENABLE_COMMENT 后会向随机社区问题发布回答
- 开启 XNIU_ENABLE_SHARE 后会登记两次社区文章分享
- 同时开启关注与取关开关后会临时改变一个用户的关注状态，并要求恢复到原状态后才判定成功
