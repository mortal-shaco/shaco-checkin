# HelloGitHub月刊提醒

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/hellogithub.py`
- 青龙命令：`python3 scripts/hellogithub.py`
- 建议 Cron：`31 8 1 * *`
- 发布哈希：`45280c4f705f455b151b322e88d3201210a564c1bc8f637e13b884de6b7852c6`
- 许可证：`MIT`

## 脚本功能

- 每月 1 日 08:00 查询 HelloGitHub 最新月刊及发布时间
- 比较持久化期号，跳过已经提醒的月刊
- 动态提取页面构建标识并读取完整分类项目内容
- 展示刊名、简介、发布时间、期号、项目与分类数量、项目名称、语言、描述、星标、复刻、关注数及项目链接
- 按最多 3900 字符分段推送全部内容，保留在线阅读和上游 GitHub 链接
- 支持旧版期号状态文件迁移、断网预演、时间轴日志和结构化总结
- 通过青龙通知助手发送月刊和脱敏任务总结

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HELLOGITHUB_STATE_FILE`

- 必填：是
- 敏感：否
- 获取或设置：选择青龙脚本可写的持久化目录，自行指定 JSON 状态文件；迁移时填旧脚本目录/config/.hellogithub_bot_state.json 的绝对路径，以保留已发送期号。公开月刊接口无需账号凭据。
- 填写格式：单个绝对文件路径；文件不存在时从未发送开始，文件损坏时停止。

### 可选参数

### `HELLOGITHUB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1。
- 填写格式：1 启用完全断网预演，默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：需要时填写青龙 notify.py 所在目录；默认查找脚本同目录及青龙标准目录，也支持导入 notify.send。
- 填写格式：本地目录路径。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
