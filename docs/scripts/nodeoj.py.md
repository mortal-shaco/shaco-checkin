# NodeOJ每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/nodeoj.py`
- 青龙命令：`python3 scripts/nodeoj.py`
- 建议 Cron：`1 10 * * *`
- 发布哈希：`5dd2118ea48171d3eb009204b99c63bf2b3853e797bdd7b6660c32803b50aa26`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用 NodeOJ ssid Cookie 调用欧皇签到接口完成每日签到
- 识别今日已签到为已完成成功，HTML/登录失败与业务失败分别判定
- 支持每行一个 ssid 的多账号独立处理，任一账号失败时整体非零退出
- 提供完全断网预演、时间轴脱敏日志、账号与任务统计及单行 TASK_SUMMARY
- 按青龙全局开关发送脱敏通知，通知故障不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NODEOJ_SSID`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://nodeoj.com/ 后，在浏览器开发者工具中复制 Cookie 里的 ssid 值写入青龙环境变量。若不想频繁失效，可同时延长浏览器中该 Cookie 的有效期。不要把 ssid 发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号的 ssid 值。也可粘贴含 ssid= 的完整 Cookie 头，脚本会自动提取。账号之间只用换行分隔，不使用 &、@ 或其他符号。

### 可选参数

### `NODEOJ_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名。仅当未设置 NODEOJ_SSID 时生效，取值与 NODEOJ_SSID 相同。
- 填写格式：与 NODEOJ_SSID 相同：每行一个 ssid。

### `COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：上游云函数兼容别名。仅当未设置 NODEOJ_SSID 与 NODEOJ_COOKIES 时生效。
- 填写格式：与 NODEOJ_SSID 相同：每行一个 ssid。

### `NODEOJ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要在完全断网条件下检查配置与流程时设置。
- 填写格式：设为 1、true、yes 或 on 启用预演。

### `NODEOJ_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置单次 HTTPS 超时；不填写时为 20 秒。
- 填写格式：5 至 120 之间的整数秒。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 QINGLONG_NOTIFY=auto 时填写要通知的脚本选择器。
- 填写格式：可用逗号、分号、空白或换行分隔；支持 046c5c66d83d3094、candidate.py、nodeoj_signin.py、通配符或 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙 notify.py 不在默认位置时，填写其所在目录。
- 填写格式：包含 notify.py 的本地目录路径。

## 多账号

NODEOJ_SSID 每个非空行一个账号 ssid；也可粘贴含 ssid= 的 Cookie 头由脚本提取。逐账号独立签到，任一账号失败时进程整体返回非零退出码。不使用 &、@ 或其他符号分隔账号。
