## 脚本功能

- 使用 console_token 校验令牌并查询领取前后资源摘要，展示官方非敏感身份及已知数值积分字段。
- 查询活动配置，展示脱敏状态及配置项数量。
- 依次尝试显式确认的领取路径，首个明确业务成功后停止。
- 每行一个账号独立执行，任何失败汇总为非零退出。
- 完整断网预演、时间轴阶段日志、账号与子任务统计、唯一 TASK_SUMMARY 记录。
- 按青龙通知开关及脚本名单发送脱敏统计，通知不可用不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TELEAGENT_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录官网，在开发者工具存储中取得 console_token，或从已登录请求的 Authorization 提取裸令牌；不得公开。
- 填写格式：每个非空行一个账号；不使用 & 或 @ 分隔。

### `TELEAGENT_CLAIM_PATHS`

- 必填：是
- 敏感：否
- 获取或设置：在官网网络面板手动领取积分，确认实际同站 POST 空 JSON 对象请求及成功响应后复制路径；接口需要其他参数时须先适配。
- 填写格式：逗号分隔同站绝对路径；不得含域名、查询串、片段、编码或路径跳转。按顺序尝试，明确成功后停止。

### 可选参数

### `TELEAGENT_API_BASE`

- 必填：否
- 敏感：否
- 获取或设置：通常无需设置；为避免凭据外泄仅支持官方 HTTPS 站点。
- 填写格式：https://agent.teleai.com.cn，可含尾部斜线。

### `TELEAGENT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查设为 1，正式运行不设置或设为 0。
- 填写格式：1/true/yes/on 开启完全断网预演；仍需令牌占位值和领取路径。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式列出需通知脚本；本任务没有默认启用名单，未设置时不发送。
- 填写格式：逗号、分号、空白或换行分隔；支持 catalogId 956b31e72c16b768、文件名、脚本相对路径和文件名通配符；* 全选，空值全禁用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写本机可信的 notify.py 或 sendNotify.js 所在目录，也查找标准青龙目录及可导入的 notify。
- 填写格式：本机通知模块目录；不下载或安装通知模块。
