# 统一茄皇集市抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tyqhdraw.py`
- 青龙命令：`python3 scripts/tyqhdraw.py`
- 建议 Cron：`0 0 0 * * *`
- 发布哈希：`c2c1115b60fd085034eb55d28ffb8fd3cb6476263eeff23f53f5bea8ad892b7e`
- 许可证：`MIT`

## 脚本功能

- 登录并校验业务成功码与有效会话
- 查询调料包和番茄资产；打印官方返回的非秘密账号身份
- 显式开启后执行活动 58 集市兑换抽奖，每轮最多 10 次并检查奖品字段
- 使用本地透明掩膜图像匹配识别滑块并验证官方业务成功码；低置信度停止
- 查询实物礼品名称及非实物礼品数量
- 每行一个账号，账号独立失败隔离与整体非零退出
- 完全断网预演、青龙脱敏通知、逐阶段日志及单行任务汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `tyqhCookie`

- 必填：是
- 敏感：是
- 获取或设置：登录统一茄皇小程序，使用本机 HTTPS 抓包查看官方 public/api/login 请求 JSON 的 thirdId 和 wid；必须使用同一账号的配套字段，不要分享抓包。
- 填写格式：每个非空行 thirdId#wid#备注；备注可省略。先在首个 # 拆分 thirdId，再在剩余内容首个 # 拆分 wid 与备注，保留备注后续文本。不再使用 @ 分隔账号。

### 可选参数

### `TYQH_DRAW_ENABLE`

- 必填：否
- 敏感：否
- 获取或设置：默认 0，仅查询资产与奖品。确认官方活动规则和兑换成本后自行设为 1 开启抽奖。
- 填写格式：0 或 1；默认 0

### `TYQH_DRAW_LIMIT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置本轮抽奖次数上限；仅在抽奖开关开启时执行。
- 填写格式：1 至 10 的整数；默认 10

### `TYQH_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：验证配置时设为 1，所有接口和通知完全断网模拟。
- 填写格式：0 或 1；默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：默认启用青龙通知；可按需关闭。
- 填写格式：默认 1；0、false、no、off 关闭，不区分大小写

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录；未设置时尝试导入 notify 及标准青龙目录。
- 填写格式：本地目录路径

### `ocr_url`

- 必填：否
- 敏感：否
- 获取或设置：旧版参数，无需获取或设置；维护版通过本地图像匹配识别，不连接外部 OCR 服务。
- 填写格式：已废弃，设置后也不使用

## 多账号

每个非空行一个账号；同一账号的 thirdId 与 wid 写在同一行，保留原字段顺序。逐账号独立处理，任一账号失败则整体非零退出。
