# 恩山论坛签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/enshan_checkin.py`
- 青龙命令：`python3 scripts/enshan_checkin.py`
- 建议 Cron：`59 1 * * *`
- 发布哈希：`c60406102e692ce961e2d1aac2ce99d722a9f5ac8aa3cf6f6e668315af59756e`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用 Cookie 验证登录，保留签到页 WAF 解码、论坛页回退和响应 Cookie 更新。
- 获取隐藏字段、退出链接或 JavaScript 中的 formhash，提交每日签到，严格识别成功及今日已签到。
- 在已验证的签到响应提供连续签到天数时展示天数，并在结构化账号结果中输出；未提供时不推测。
- 签到前后查询恩山币和积分，保留四个积分页地址回退与临时错误重试，展示余额变化。
- 展示官方公开用户名、用户组及贡献，隐藏 Cookie、会话及原始响应。
- 每行一个账号独立执行，任一失败非零退出，配置错误同样非零退出。
- 保持每日 12:39 定时、兼容旧参数及可选随机启动延迟，默认无等待。
- 完全断网配置预演，跳过登录、查询、签到和通知网络发送，不宣称真实业务成功。
- 带时间戳的分阶段日志、账号及任务统计，保留 SUMMARY_JSON 并输出唯一单行 TASK_SUMMARY。
- 按全局开关生成或发送青龙脱敏通知，通知不可用或失败不改变业务退出码。
- 已验证签到后，按上游移动签到页与既有桌面签到页顺序读取今日签到积分和总签到天数；连续签到天数优先保留签到响应的值，缺失时补充页面值。
- 仅展示明确提供的非负签到统计，缺失项显示未知；可选统计读取失败不覆盖已验证签到结果。
- 兼容 EST_cookie 和 EST_ENABLE_RANDOM_WAIT，不再依赖浏览器可执行文件或本地凭据配置文件；Cookie 中自动获取登录身份。
- 正式通知增加各成功账号的余额、贡献及签到统计；配置错误、失败和断网预演也生成或发送摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ENSHAN_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录恩山论坛，在开发者工具的网络面板选取发往 www.right.com.cn 的请求，复制完整 Cookie 请求头值；仅填入青龙私密环境变量，不含 Cookie: 前缀。Cookie 已含账号身份，不再要求上游 EST_USER_UID 或 config.json。
- 填写格式：每个非空行一个账号的完整 Cookie；同一账号各字段用分号分隔，字段值内的等号保留；不得用 & 或 @ 分隔账号。

### 可选参数

### `enshan_cookie`

- 必填：否
- 敏感：是
- 获取或设置：旧版 Cookie 参数兼容输入；优先使用 ENSHAN_COOKIE，其次 enshan_cookie，最后 EST_cookie。由浏览器登录后的论坛请求头获取。
- 填写格式：与 ENSHAN_COOKIE 相同，每行一个账号；不从 config.json 读取或写回凭据。

### `EST_cookie`

- 必填：否
- 敏感：是
- 获取或设置：旧版 Cookie 参数兼容输入；优先使用 ENSHAN_COOKIE，其次 enshan_cookie，最后 EST_cookie。由浏览器登录后的论坛请求头获取。
- 填写格式：与 ENSHAN_COOKIE 相同，每行一个账号；不从 config.json 读取或写回凭据。

### `ENSHAN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙设置为 1 开启完全断网预演，只校验配置并生成通知预览。
- 填写格式：1、true、yes、on 开启；默认关闭。

### `ENSHAN_HTTP_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选 HTTP 请求超时；无需从账号获取。
- 填写格式：5 至 120 的整数秒，默认 20。

### `ENSHAN_MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：可选启动随机等待上限；无需从账号获取。
- 填写格式：0 至 3600 的整数秒，默认 0；优先于 MAX_RANDOM_DELAY 和 EST_ENABLE_RANDOM_WAIT。

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：旧版等待上限兼容参数；未配置 ENSHAN_MAX_RANDOM_DELAY 时使用。
- 填写格式：0 至 3600 的整数秒，默认 0。

### `EST_ENABLE_RANDOM_WAIT`

- 必填：否
- 敏感：否
- 获取或设置：上游随机延迟兼容开关；仅在两个等待上限都未配置时使用；维护版本默认无等待。
- 填写格式：1、true、yes、on 开启 0 至 900 秒等待；默认关闭，断网预演始终不等待。

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：旧版随机等待开关；无需从账号获取。
- 填写格式：默认开启；0、false、no、off 禁用等待。

### `ENSHAN_PRIVACY_MODE`

- 必填：否
- 敏感：否
- 获取或设置：保留旧版隐私参数兼容；凭据及手机号始终隐藏，官方公开用户名按返回值展示。
- 填写格式：布尔值；ENSHAN_PRIVACY_MODE 优先，默认开启；不会隐藏公开昵称。

### `PRIVACY_MODE`

- 必填：否
- 敏感：否
- 获取或设置：保留旧版隐私参数兼容；凭据及手机号始终隐藏，官方公开用户名按返回值展示。
- 填写格式：布尔值；ENSHAN_PRIVACY_MODE 优先，默认开启；不会隐藏公开昵称。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关；正式模式通过已有 notify.py 发送脱敏摘要，预演只生成摘要。
- 填写格式：默认 1；0、false、no、off 关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选青龙 notify.py 所在目录；未配置时尝试导入 notify 并发现青龙标准目录。通知不可用不会改变业务退出码。
- 填写格式：本地目录路径，非必填；脚本业务不依赖通知模块。

## 副作用与风险

- 正式运行提交每日签到，可能增加恩山币和积分。

- 正式运行且通知开启时，通过青龙通知模块发送脱敏任务汇总。
