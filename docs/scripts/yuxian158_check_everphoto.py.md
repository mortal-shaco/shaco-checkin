## 脚本功能

- 使用手机号和密码登录时光相册账号。
- 调用时光相册官方接口执行每日签到，并严格校验业务成功码与签到结果。
- 支持多账号逐行独立执行，并在官方接口提供昵称、用户名、显示名称或公开 UID 时原样显示该非敏感身份。
- 提供完全断网的配置预演、时间轴日志、账号与子任务统计及单行 JSON 机器摘要。
- 正式执行后可通过青龙 notify.py 或 sendNotify.js 发送不含凭据和原始响应的汇总通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `EVERPHOTO_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：使用本人时光相册账号的登录手机号和密码；请在青龙环境变量中配置，不要写入脚本或日志。
- 填写格式：每个非空行一个账号，格式为“手机号|密码”，仅按第一个竖线分割；也可每行填写含 mobile、password 的 JSON 对象。

### 可选参数

### `EVERPHOTO`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，内容来源与 EVERPHOTO_ACCOUNT 相同；新配置请改用规范变量。
- 填写格式：与 EVERPHOTO_ACCOUNT 相同，每个非空行一个账号。

### `时光`

- 必填：否
- 敏感：是
- 获取或设置：旧版中文兼容变量，内容来源与 EVERPHOTO_ACCOUNT 相同；新配置请改用规范变量。
- 填写格式：与 EVERPHOTO_ACCOUNT 相同，每个非空行一个账号。

### `EVERPHOTO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置且禁止联网时设为 1。
- 填写格式：1、true、yes 或 on 表示启用断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要只通知指定脚本时填写选择器；设置为空值会关闭全部脚本通知。
- 填写格式：使用逗号、分号、空白或换行分隔，可填写目录编号、scripts/everphoto_daily_checkin.py、文件名、文件名通配符或 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认目录时，填写其所在目录。
- 填写格式：包含 notify.py 或 sendNotify.js 的本地绝对目录。

## 多账号

EVERPHOTO_ACCOUNT 中每个非空行代表一个独立账号，按顺序处理；同一账号的手机号与密码只在第一个竖线处分割，任一账号失败时进程整体返回非零退出码。
