# Qoder CN 每日 Credits 领取

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/claim.js`
- 青龙命令：`node scripts/claim.js`
- 建议 Cron：`53 10 * * *`
- 发布哈希：`cae4725f3dd1876f7d53ecb2a5078aad20d4a1c50ac148541116eab3eb6ab442`
- 许可证：`MIT`

## 脚本功能

- 查询官方Credits活动，兼容上游三种列表包装结构；异常响应不当作无活动成功
- 按活动状态及时间窗口领取Credits，明确CLAIMED才计成功，识别幂等重放并查询奖励复核
- 保留显式强制重放开关、多账号独立处理和官方非秘密身份显示
- 完全离线演练、逐阶段与逐账号统计、唯一TASK_SUMMARY结构化汇总
- 可选按账号及北京时间10点切换活动日写入脱敏记录与日志，默认不写文件
- 按青龙开关及选择器通知；通知不可用不改变业务退出码，演练仅生成本地摘要

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `QODER_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人已登录的 Qoder CN 官方客户端开发者工具网络请求中，找到 openapi.qoder.com.cn 的 /sash/api/v1/me/campaigns 请求，复制 Authorization 中 Bearer 后的 Token。无法查看时请勿猜测，不需本地文件或其他程序。
- 填写格式：每个非空行一个不带Bearer前缀的Token，或包含token和可选expiresAt日期的JSON对象；只用换行分隔账号

### 可选参数

### `QODER_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为1进行完全离线配置与流程演练，不查询、不领取、不写记录、不调用可能联网的通知模块。
- 填写格式：1、true、yes、on启用，默认关闭

### `QODER_FORCE`

- 必填：否
- 敏感：否
- 获取或设置：仅需强制重放领取时显式启用，等价于--force，默认关闭。
- 填写格式：1、true、yes、on启用

### `QODER_CHECKIN_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自行指定可写目录，等价于--checkin-dir；按账号与北京时间10点切换的活动日写入结果，记录不替代官方核验。
- 填写格式：目录路径；默认不写文件

### `QODER_CHECKIN_LOG_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定脱敏统计日志目录。
- 填写格式：目录路径；默认不写文件

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自动模式选择通知脚本，可填914f52282cf5f911、脚本相对路径、文件名或通配符；空值关闭全部。
- 填写格式：逗号、分号、空白分隔；*匹配全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙sendNotify.js目录；否则查找/ql/data/scripts和/ql/scripts。
- 填写格式：目录路径
