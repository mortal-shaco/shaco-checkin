# 库街区自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/kurobbs_c0f8e834c99a.py`
- 青龙命令：`python3 scripts/kurobbs_c0f8e834c99a.py`
- 建议 Cron：`55 9 * * *`
- 发布哈希：`dc2bd45ac15ad54d2156eb64b9dfa2934e093dd409e1dcb9a9b10a264d35fc2f`
- 许可证：`MIT`

## 脚本功能

- 查询库街区个人资料并显示官方返回的昵称及公开用户 ID
- 查询默认绑定游戏角色，优先选择主来源的游戏编号 3，缺失时沿用相关来源首个默认角色
- 按北京时间月份领取游戏签到奖励
- 执行社区签到，兼容原社区游戏编号 2
- 支持单独执行游戏签到奖励或社区签到，默认执行两项
- 支持每行一个 TOKEN 的多账号独立执行及任一失败非零退出
- 兼容 Bark 与 Server酱3 可选推送，支持青龙通知及全局通知选择
- 完全断网预演、分阶段脱敏日志、账号统计及单行 TASK_SUMMARY 汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在自己的设备登录库街区，使用自己授权的 HTTPS 调试工具查看 api.kurobbs.com 请求头 token，复制完整值；登录失效后重新获取。不填写 Cookie、手机号或角色 ID。
- 填写格式：每个非空行一个账号的完整 token；不使用 &、@ 等符号分隔账号；每行保留原值中的符号

### 可选参数

### `KUROBBS_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按所需签到动作选择；默认同时执行两项签到。
- 填写格式：all（默认）、checkin（游戏签到奖励）、community（社区签到）

### `KUROBBS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地测试时设置为 1；预演不发送任何网络请求，包括通知。
- 填写格式：1/true/yes/on 开启；默认关闭

### `DEBUG`

- 必填：否
- 敏感：否
- 获取或设置：兼容原脚本变量；保留脱敏日志，不输出调试响应。
- 填写格式：兼容输入，不改变成功判定和日志脱敏

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式列出需要通知的脚本；设置后替换默认列表；此包未提供默认选中列表。
- 填写格式：逗号、分号、空白或换行分隔目录编号、脚本相对路径、文件名或文件名通配符；* 选择全部，空值关闭全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 notify.py 或 sendNotify.js 所在目录；优先尝试导入 notify，然后查找指定目录及青龙标准路径。
- 填写格式：本地通知模块目录；不可用时记录通知失败，保留业务退出码

### `BARK_SERVER_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选，从自己的 Bark 应用或自建服务获取服务根地址；与 BARK_DEVICE_KEY 配套。
- 填写格式：HTTPS 服务根地址

### `BARK_DEVICE_KEY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从自己的 Bark 应用获取推送设备密钥；与 BARK_SERVER_URL 配套。
- 填写格式：单个通知接收端密钥；不作为库街区账号凭据

### `SERVER3_SEND_KEY`

- 必填：否
- 敏感：是
- 获取或设置：可选，从自己的 Server酱3 控制台获取发送密钥，并通过公开包注册表安装 serverchan-sdk。
- 填写格式：单个通知接收端发送密钥；不作为库街区账号凭据
