- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sophnet_checkin.py`
- 青龙命令：`python3 scripts/sophnet_checkin.py`
- 建议 Cron：`3 10 * * *`
- 发布哈希：`76bf3057e9b9f5f97a29bd7f4ad7f70f06677971bbbc83fba160e67a473d1733`
- 许可证：`MIT`

## 脚本功能

- 通过刷新令牌兑换访问令牌，无需浏览器自动化或验证码。
- 签到前查询福利状态，今日已签到时跳过签到写入。
- 每日签到领取 Token 奖励，严格校验 HTTP 与业务状态，业务码 1 表示今日已签到。
- 显示可提现 Token、连续签到天数和累计签到天数；签到确认后统计查询失败会告警并保留签到成功结果。
- 官方返回昵称、用户名、显示名称或公开 UID 时展示安全的账号身份。
- 保留每日 08:10 调度、原凭据变量、超时、显式代理、脱敏调试和通知选项。
- 每行一个账号独立运行，任一账号失败导致整体非零退出。
- 无第三方业务依赖、无网络预演、分阶段时间轴日志、账号及任务统计和唯一单行 TASK_SUMMARY JSON。
- 通过青龙通知模块发送脱敏汇总，支持全局开关和选择名单；断网预演模拟通知，通知故障不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SOPHNET_REFRESH_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://www.sophnet.com 后，在该页面浏览器开发者工具控制台执行 localStorage.getItem('sophnet-auth-tab-sync-v1')，解析返回 JSON 并读取 p.refreshToken。凭据失效后重新登录获取，不要共享或记录该值。
- 填写格式：每个非空行一个账号的 refreshToken，忽略空行及行首尾空白，整行保留，不使用 & 或 @ 分隔账号。

### 可选参数

### `SOPHNET_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网预演时设置，默认关闭。
- 填写格式：1、true、yes、on 开启；预演仅校验本地配置和流程，不验证真实凭据，也不调用通知模块。

### `SOPHNET_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况配置，默认 30。
- 填写格式：1 至 300 的整数，单位秒，每次请求均生效。

### `SOPHNET_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：需要代理时填写自行管理的代理地址；默认直连，不继承系统代理。
- 填写格式：可选 HTTP 或 HTTPS 代理地址，可含代理认证信息，不会写入日志。TLS 始终校验证书。

### `SOPHNET_DEBUG`

- 必填：否
- 敏感：否
- 获取或设置：排查请求阶段时开启，默认关闭。
- 填写格式：true/false；只记录请求方法、固定接口路径和 HTTP 状态，不记录响应或凭据。

### `SOPHNET_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：沿用上游通知配置，默认 true。
- 填写格式：true/false；全局通知为 auto 时生效。

### `SOPHNET_NOTIFY_ONLY_FAIL`

- 必填：否
- 敏感：否
- 获取或设置：沿用上游配置，默认 false。
- 填写格式：true/false；auto 模式下正式执行全部成功时可静默，配置错误和预演仍纳入通知流程。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选通知名单，设置后替换默认选择，空值禁用全部。
- 填写格式：逗号、分号或空白分隔，支持目录编号 da2b7014b2824de3、脚本相对路径、文件名、文件名通配符和 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙提供的通知模块所在目录。
- 填写格式：目录中放置 notify.py 或 sendNotify.js；同时自动发现可导入的 notify 和 /ql/data/scripts、/ql/scripts。使用 JavaScript 通知时需要青龙的 Node.js。

## 多账号
