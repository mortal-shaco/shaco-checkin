# 芯幻签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/xhcyv_checkin.py`
- 青龙命令：`python3 scripts/xhcyv_checkin.py`
- 建议 Cron：`5 10 * * *`
- 发布哈希：`c2327396a6f0bff8bcd4e7eef9a566624de9a2e5b401eaed021dce312e2dea99`
- 许可证：`MIT`

## 脚本功能

- 每天 08:05 签到，保留上游计划。
- 账号密码登录，从官方 Set-Cookie 获取 x_bbs_token；支持直接凭据及旧参数。
- 需要验证码时使用公开依赖 ddddocr 识别，最多两次登录；两步验证提示使用凭据。
- 签到前检查状态，已签到不重复提交，识别重复签到业务码 11006。
- 显示签到积分、名次、连签、连签奖励、会员加成、当前积分及等级。
- 显示官方昵称、用户名、显示名称和公开 UID，抑制凭据、手机号及原始响应。
- 保留 --check 在线自检，仅登录和查询状态、身份及积分。
- 可选本地凭据缓存、到期重新登录、缓存凭据失效回退账密登录。
- 代理、HTTP 超时、读取请求有限重试；提交请求不自动网络重试。
- 多账号换行、独立处理、任一账号失败整体非零退出。
- 完全断网预演和模拟通知，青龙全局通知开关、筛选、成功静默选项、Python 和 JavaScript 通道。
- 分阶段时间轴日志、账号与任务统计、唯一 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XHCYV_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人芯幻注册账号及密码。也可登录 https://xhcyv.com，在浏览器开发者工具的应用、Cookies 中复制本站 x_bbs_token。两步验证账号应使用登录后的凭据。
- 填写格式：每个非空行一个账号#密码，兼容账号:密码、账号&密码，按最早的字段分隔符只切一次，保留后续密码字符。也可每行填写一个以 eyJ 开头的三段 JWT，只用换行分账号。

### 可选参数

### `XHCYV_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧变量，从本人已登录网页的 Cookies 获取 x_bbs_token。推荐改用主变量。
- 填写格式：每行一个凭据，禁止用 & 分账号；与主变量同时设置时追加执行并排在前面。

### `XHCYV_ACCOUNT`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧单账号变量，填写本人注册账号，与 XHCYV_PASSWORD 配套。
- 填写格式：单个账号，与主变量同时设置时追加执行。

### `XHCYV_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：填写 XHCYV_ACCOUNT 对应的本人密码。
- 填写格式：原始密码，保留字段内部字符。

### `XHCYV_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网配置预演时开启。
- 填写格式：1 开启，默认关闭；不验证真实业务，不加载外部通知模块。

### `XHCYV_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按容器网络设置请求超时。
- 填写格式：1 至 300 的整数秒，默认 30。

### `XHCYV_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：从本人可达代理配置获取；未设置时依次读取 HTTPS_PROXY、https_proxy、HTTP_PROXY、http_proxy。
- 填写格式：HTTP 或 HTTPS 代理地址，可包含认证信息，日志不输出。

### `XHCYV_DEBUG`

- 必填：否
- 敏感：否
- 获取或设置：需要排查请求步骤时开启。
- 填写格式：true 开启，默认 false，仅记录方法、固定地址和耗时。

### `XHCYV_CACHE`

- 必填：否
- 敏感：否
- 获取或设置：确认脚本目录安全后按需开启。
- 填写格式：1 开启，默认关闭。脚本同目录 xhcyv_token.json，权限 0600、原子写入、跨进程锁，过期不足一小时重新登录。

### `XHCYV_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：按需设置本脚本通知开关。
- 填写格式：true 或 false，默认 true，受全局通知开关及选择控制。

### `XHCYV_NOTIFY_ONLY_FAIL`

- 必填：否
- 敏感：否
- 获取或设置：需要全部成功时静默可开启。
- 填写格式：true 或 false，默认 false。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：按青龙通知选择需求设置，未设置时默认选中本任务。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；* 选中全部，空字符串关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写青龙 notify.py 或 sendNotify.js 所在目录；同时支持导入 notify.send 和查找 /ql/data/scripts、/ql/scripts。
- 填写格式：通知模块目录路径；通知不可用或失败不改变业务退出码。

## 多账号

每个非空行一个账号，账号与密码放在同一行，只按第一个字段分隔符切分；兼容纯凭据。逐账号隔离，任一账号失败整体非零退出。
