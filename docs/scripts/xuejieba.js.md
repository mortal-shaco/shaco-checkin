# 学姐吧每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/xuejieba.js`
- 青龙命令：`node scripts/xuejieba.js`
- 建议 Cron：`0 50 11 * * *`
- 发布哈希：`35640f297cb60727a2177636174c3865ae5c4f188842f0c73f99cf199c836b8e`
- 许可证：`MIT`

## 脚本功能

- 使用账号 Cookie 和其中的 b2_token 完成学姐吧每日签到
- 展示本次积分、连续签到天数和当前积分等已验证结果
- 支持每行一个账号并按账号独立统计结果
- 支持完全断网预演、请求超时、响应大小限制和严格业务成功判定
- 输出脱敏时间轴日志、单行结构化任务摘要并按青龙策略发送通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XUEJIEBA_COOKIE_LIST`

- 必填：是
- 敏感：是
- 获取或设置：登录学姐吧后，打开浏览器开发者工具，在发往 xuejieba2026.com 的网络请求标头中复制完整 Cookie；不要把真实值写入脚本、日志或公开仓库。
- 填写格式：每行一个账号的完整 Cookie；每行必须包含 b2_token=<值>，通常同时包含 gg_info=<值>。分号仅用于分隔同一账号的 Cookie 字段。

### 可选参数

### `XUEJIEBA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时设置为 1；正式运行时不设置或设为 0。
- 填写格式：启用值为 1、true、yes 或 on，不区分大小写。

### `XUEJIEBA_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置签到请求超时；不设置时使用 10000 毫秒。
- 填写格式：1000 至 60000 的整数毫秒值。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 QINGLONG_NOTIFY=auto 时填写需要通知的脚本选择器；可使用目录、文件名、通配符或目录编号。
- 填写格式：选择器以逗号、分号、空白或换行分隔；* 表示全部；空值表示全部关闭。

## 多账号

XUEJIEBA_COOKIE_LIST 每个非空行表示一个账号；同一行内保留该账号完整 Cookie，账号按行独立执行，任一账号失败时进程整体返回非零退出码。
