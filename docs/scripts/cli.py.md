# 中山大学人脸签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/cli.py`
- 青龙命令：`python3 scripts/cli.py`
- 建议 Cron：`*/5 7-22 * * *`
- 发布哈希：`5dc94bcbe4ea2e5814123703857e16eea36e6dfdd19ff79e44286e403365c271`
- 许可证：`MIT`

## 脚本功能

- 查询中山大学人脸签到活动列表并选择进行中活动
- 提交 JPEG 人脸完成签到，并再次拉列表核验已签到状态
- 已签到活动视为成功；无进行中活动则失败退出
- 可选开启 GPS 定位提交（默认关闭，与上游一致）
- 展示学号与活动名称等公开身份信息，隐藏人脸 Base64、加密载荷与原始响应
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SYSU_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：准备中山大学人脸识别签到使用的学号，以及本人正面 JPEG 人脸照片。将学号写入青龙环境变量；图片可写本地路径，或先转为 Base64 后追加在学号后。不要把学号、照片或 Base64 发给他人，也不要写入公开仓库、日志或通知。
- 填写格式：每个非空行一个账号。格式为「学号」或「学号|人脸图片路径或 Base64」。仅按每行第一个竖线 | 分割学号与图片；账号之间只用换行分隔，不使用 &、@ 或 &&。

### 可选参数

### `SYSU_STUDENT_ID`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：未设置 SYSU_ACCOUNTS 时使用本变量，格式与 SYSU_ACCOUNTS 相同。
- 填写格式：同 SYSU_ACCOUNTS；优先使用 SYSU_ACCOUNTS。

### `SYSU_FACE_IMAGE`

- 必填：否
- 敏感：是
- 获取或设置：当账号行未附带图片时，作为共用 JPEG 路径或 Base64。多账号若人脸不同，请写在各自账号行内。
- 填写格式：本地 JPEG 文件路径，或纯 Base64 / data:image/jpeg;base64,... 形式。

### `SYSU_SUBMIT_GPS`

- 必填：否
- 敏感：否
- 获取或设置：默认关闭定位提交（与上游注释行为一致）。仅在活动明确要求 GPS 且本人确认坐标可用时开启。
- 填写格式：设为 1、true、yes 或 on 时额外调用 submitPosition；其他或未设置则不提交定位。

### `SYSU_LONGITUDE`

- 必填：否
- 敏感：否
- 获取或设置：仅在开启 SYSU_SUBMIT_GPS 时使用；按本人实际签到位置填写经度。
- 填写格式：十进制经度字符串；默认 113.9539。

### `SYSU_LATITUDE`

- 必填：否
- 敏感：否
- 获取或设置：仅在开启 SYSU_SUBMIT_GPS 时使用；按本人实际签到位置填写纬度。
- 填写格式：十进制纬度字符串；默认 22.801604。

### `SYSU_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 120 的数字；默认 30。

### `SYSU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。

## 多账号

SYSU_ACCOUNTS 每个非空行一个账号（学号 或 学号|人脸图片）。账号逐个独立查询活动、可选提交定位并人脸签到；任一账号失败则整体非零退出。不使用 &、@ 或 && 分隔账号。
