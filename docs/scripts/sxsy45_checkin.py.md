# 尚香书苑签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sxsy45_checkin.py`
- 青龙命令：`python3 scripts/sxsy45_checkin.py`
- 建议 Cron：`4 10 * * *`
- 发布哈希：`e57473c0e4d5f92afd40edacfca0e27ab1bc87bb7ad4387c7bb20a5b4ab281c6`
- 许可证：`MIT`

## 脚本功能

- 内置候选域名探测、重定向导航页解析和主动导航页回退；仅允许本站域名族的 HTTPS 地址
- 账密登录、本地 ddddocr 图片验证码识别、致命登录错误停止重试
- Cookie 直签、账密模式本地缓存复用、明确失效后自动重登一次；临时故障和人机质询保留缓存
- 每日签到与算术验证，兼容无需算术验证的签到结果，显式业务结果或统计回查确认
- 连续天数、等级、积分奖励和累计天数统计；展示接口返回的公开 UID
- 默认直连、显式代理、请求超时、临时错误退避和人机质询分类
- 逐行多账号独立执行、断网预演、时间轴阶段日志、账号和任务统计及单行结构化汇总
- 按全局开关与名单通知，兼容原通知选项，通知异常保持业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SXSY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在尚香书苑注册并取得自己的用户名和密码；也可在浏览器登录后打开开发者工具的网络面板，从本站已登录请求的请求头复制完整 Cookie。不要复制响应 Set-Cookie，不要向他人提供凭据。
- 填写格式：每个非空行一个账号，填用户名#密码，或无 # 的完整 Cookie；账密仅按第一个 # 分割，密码中的后续 #、&、@ 原样保留；禁止使用 & 或 @ 分隔账号。Cookie 格式为键=值; 键=值。

### 可选参数

### `SXSY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置，启用后仅校验配置并模拟流程及通知，完全不联网且不读写缓存。
- 填写格式：true/false，默认 false

### `SXSY_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按运行网络条件在青龙中设置。
- 填写格式：1 至 300 的整数秒数，默认 30

### `SXSY_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：可选，填写自己可用的 HTTP 或 HTTPS 代理地址；默认直连且忽略全局代理变量。
- 填写格式：HTTP/HTTPS 代理地址；direct、none、off、0、false、- 表示直连；默认空

### `SXSY_DEBUG`

- 必填：否
- 敏感：否
- 获取或设置：需要额外脱敏诊断时在青龙中开启。
- 填写格式：true/false，默认 false，不打印验证码、凭据或原始响应

### `SXSY_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游通知选项，在全局自动模式且命中通知名单时生效。
- 填写格式：true/false，默认 true；全局显式启用优先

### `SXSY_NOTIFY_ONLY_FAIL`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游仅失败通知选项，全局自动模式下全部实跑成功时跳过通知。
- 填写格式：true/false，默认 false；全局显式启用优先

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：设置需要通知的脚本名单，支持目录路径、文件名及通配符，也可填写本任务目录标识 fccba94cf57739f4；未设置时没有默认命中项。
- 填写格式：逗号、分号或空白分隔；* 表示全部；显式空值禁用名单中的全部任务

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写现有青龙 notify.py 或 sendNotify.js 所在目录；也会自动查找标准青龙脚本目录。
- 填写格式：本地目录路径；通知缺失或失败保持业务退出码
