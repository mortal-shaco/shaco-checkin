## 脚本功能

- 使用雨云用户名和密码登录，并为每个账号维护独立 Cookie 与 CSRF 会话。
- 执行每日签到并领取积分，严格校验 HTTP 状态、JSON 结构和业务成功码。
- 查询并显示当前积分；官方接口返回昵称、用户名、显示名称或公开 UID 时直接显示该身份。
- 默认关闭自动续费；逐账号明确启用并提供 API Key 后，检查云服务器到期时间、续费积分价格和余额保护条件，再按配置续费。
- 支持每行一个账号、旧版账号 JSON 数组和仅签到的用户名加密码简写格式。
- 提供完全断网预演、分账号时间轴日志、青龙通知和单行 TASK_SUMMARY JSON 汇总。
- 使用雨云用户名和密码登录，并在独立账号会话中维护 Cookie 与 CSRF 令牌。
- 执行每日签到并领取积分，仅以 HTTP 状态、响应结构和业务码共同确认成功。
- 查询并展示账号积分；接口返回非敏感昵称、用户名、显示名称或公开 UID 时原样展示。
- 业务步骤完成或失败后，在已登录的情况下执行退出登录并核验结果。
- 支持每行一个账号、账号失败隔离以及任一账号失败时整体返回非零状态。
- 提供完全断网预演、分阶段脱敏日志、逐账号统计和单行 TASK_SUMMARY JSON 汇总。
- 按全局开关和脚本选择器调用青龙 Python 或 JavaScript 通知，并在通知失败时保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `RAINYUN_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：用户名和密码来自雨云官网账号；如需续费，API Key 从雨云控制台的 API 设置中创建。推荐把同一账号的字段写在同一行 JSON 对象中。 沿用旧任务时也可只设置 rainyun_ck。
- 填写格式：每个非空行一个账号，推荐 {"username":"用户名","password":"密码","autoRenew":false,"apiKey":"可选 API Key"}；仅签到兼容 用户名#密码，并只在第一个 # 处分隔；也兼容上游 JSON 二维数组。

### 可选参数

### `rainyun_ck`

- 必填：否
- 敏感：是
- 获取或设置：旧版雨云任务变量；每行填写一个雨云官网账号的用户名和密码。仅在 RAINYUN_ACCOUNT 未设置时使用。
- 填写格式：每行 用户名#密码；只在第一个 # 处分隔。迁移后保留原值即可；不要与 RAINYUN_ACCOUNT 重复填写同一账号。

### `RAINYUN_CONFIG`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；按需设置请求超时、续费天数、触发阈值和最低积分保留值。
- 填写格式：JSON 对象；支持 api_request_timeout、renew_days、renew_threshold_days、min_points_reserve。

### `RAINYUN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；设置为 1 可执行完全断网预演。
- 填写格式：布尔值；1、true、yes、on 表示启用。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择器，可填写目录编号、文件名、应用标识或通配符。
- 填写格式：使用逗号、分号、空白或换行分隔；星号表示全部；显式空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在标准目录时，填写包含 notify.py 或 sendNotify.js 的目录。
- 填写格式：青龙容器内的绝对目录路径。

## 多账号

RAINYUN_ACCOUNT 每个非空行代表一个账号；推荐每行一个 JSON 对象以绑定该账号的密码、续费开关和 API Key。简写格式只在第一个 # 处分隔用户名与密码。各账号使用独立会话并独立统计，任一账号失败时进程返回非零状态。 兼容旧变量 rainyun_ck，RAINYUN_ACCOUNT 优先；勿同时放入同一账号。
