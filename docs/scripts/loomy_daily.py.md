## 脚本功能

- 每日首次登录刷新每日赠送积分，按天幂等，以 HTTP 成功且业务码 000000 核验。
- --tasks 查询八项新手任务的分组、标题、积分与完成进度。
- 显式设置 LOOMY_ONBOARDING=1 批量领取未完成新手任务，--no-onboarding 可关闭；--claim KEY 单独领取一项。
- 八项任务共 10000 分：首次消息、选择技能、生成 PPT、设置定时、安装技能、远程控制、创建搭子与分享搭子；仅上报领取，不实际执行对应应用操作。
- 结清后保存凭据指纹与任务进度，避免重复查询；--refresh 忽略本地记录强制核验。
- 换行多账号独立执行，--only N 筛选；官方响应提供公开身份时显示，凭据和原始响应不输出。
- 完全断网预演、分阶段时间轴日志、每账号与最终统计、一条 TASK_SUMMARY 结构化汇总。
- 青龙组件推送脱敏总结，支持全局及 --no-notify 开关，保留四种上游可选推送渠道作为兼容后备；通知故障不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LOOMY_TOKENS`

- 必填：是
- 敏感：是
- 获取或设置：在官方 Loomy 客户端登录，在本人授权的开发者工具或网络抓包中读取 loomyad.xunfei.cn 请求的 token 头，或 Authorization: Bearer 后的 session。登录态失效时重新登录并更新。不要公开凭据。
- 填写格式：每个非空行一个账号，填写 session 或 备注|session；仅在第一个 | 处分割，后续凭据文本完整保留。不得使用 & 或 @ 分隔账号。

### 可选参数

### `LOOMY_ONBOARDING`

- 必填：否
- 敏感：否
- 获取或设置：用户自行设置；默认关闭。仅在实际完成任务并确认领取时启用。
- 填写格式：0（默认，仅每日积分）或 1（批量领取）；--no-onboarding 优先关闭

### `LOOMY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时自行设置；不会发出请求、调用通知组件或写入结清记录。
- 填写格式：1 启用，0 默认正式执行

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：用户自行设置青龙全局通知开关。
- 填写格式：默认 1；0、false、no、off 关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 或 sendNotify.js 所在目录；同时自动发现标准青龙目录及可导入的 notify 模块。
- 填写格式：本机通知目录路径

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从本人 PushPlus 后台获取推送令牌。 青龙通知不可用时作为兼容推送通道。
- 填写格式：推送令牌

### `BARK_URL`

- 必填：否
- 敏感：是
- 获取或设置：从本人 Bark 应用获取 HTTPS 推送地址。 青龙通知不可用时作为兼容推送通道。
- 填写格式：完整 HTTPS 地址

### `WECOM_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：从本人企业微信群机器人设置获取 Webhook 地址或 key。 青龙通知不可用时作为兼容推送通道。
- 填写格式：HTTPS Webhook 地址或机器人 key

### `DINGTALK_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：从本人钉钉群机器人设置获取 HTTPS Webhook 地址。 青龙通知不可用时作为兼容推送通道。
- 填写格式：完整 HTTPS 地址

### `DINGTALK_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：从本人钉钉群机器人的加签设置获取密钥，仅和相应 Webhook 配套使用。 青龙通知不可用时作为兼容推送通道。
- 填写格式：加签密钥

## 副作用与风险

- 正式默认执行刷新账号每日赠送积分。
- 显式批量或单项领取时上报新手任务完成状态并领取积分。
- 正式查询或领取确认全部结清时更新脚本目录中的 loomy_onboarding.json 本地结清记录，只存凭据指纹和任务进度。
- 启用通知且非预演时通过青龙组件或可选兼容通道发送脱敏总结。
