# 今日校园广东海洋大学签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/fcpdaily_2_0.py`
- 青龙命令：`python3 scripts/fcpdaily_2_0.py`
- 建议 Cron：`58 9 * * *`
- 发布哈希：`dc27b26c35fe77fd4758a67382602ca6e3d74880127c4a62386f96672f654296`
- 许可证：`GPL-3.0`

## 脚本功能

- 广东海洋大学今日校园统一认证登录与有界验证码识别，使用公共 ddddocr 发行包内模型，无需外部 OCR 程序
- 可使用本人 Cookie 跳过登录，业务查询再次验证会话
- 查询当日待签到任务，显式开启后提交首个任务的真实定位、异常原因
- 独立生成 DES 加密扩展头，使用随机设备标识且不记录设备信息
- 多账号、旧版 INI 字段兼容及倒序处理、配置校验和断网预演
- 脱敏时间轴日志、编号阶段耗时、账号统计、单行 TASK_SUMMARY 汇总
- 按青龙通知规则投递脱敏摘要，通知失败保持业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CPDAILY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人广东海洋大学统一身份认证学号和今日校园学工号登录密码。可使用本人已登录今日校园网页请求中的完整 Cookie 跳过登录，过期后自行重新获取。定位和异常原因必须据实填写。
- 填写格式：每个非空行一个 JSON 对象，包含 username 和 password，或 username 和 cookie。提交模式还必须包含 longitude（-180 至 180）、latitude（-90 至 90）、position（真实位置）、isMalposition（整数 0 或 1）；为 1 时 abnormalReason 必须非空。只读查询无需定位字段。JSON 字符串按规范转义，整行解析保留密码及 Cookie 中的分隔符。

### 可选参数

### `CPDAILY_CONFIG`

- 必填：否
- 敏感：否
- 获取或设置：可选旧版 INI 配置入口，填写本人配置文件路径。CPDAILY_ACCOUNTS 非空时优先使用账号变量。
- 填写格式：UTF-8 INI 每节一个账号，保留旧字段 username、password、longitude、latitude、abnormalReason、position 和倒序处理；提交还需显式增加 isMalposition=0 或 1。

### `CPDAILY_SUBMIT`

- 必填：否
- 敏感：否
- 获取或设置：确认本人真实定位、异常原因和学校签到要求后手动开启，默认只读查询。
- 填写格式：1/true/yes/on 开启，0/false/no/off 关闭，默认 0；每次仅提交首个待签到任务，不重试提交。

### `CPDAILY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收设置为 1。
- 填写格式：布尔开关，默认 0；开启时不登录、不查询、不提交、不加载验证码模型、不调用通知模块。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：选择要通知的脚本，可填 7f49669014a1d273、candidate.py、Fcpdaily-2.0.py、脚本相对路径或文件名通配符。
- 填写格式：逗号、分号、空白或换行分隔；* 匹配全部，设置为空关闭自动选择。未设置时本脚本默认不列入通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块位于自定义目录时填写；也自动尝试导入 notify.send 及 /ql/data/scripts、/ql/scripts 中的通知模块。
- 填写格式：包含 notify.py 或 sendNotify.js 的目录路径；通知模块不可用或失败保持业务退出码。

## 多账号

每个非空行一个 JSON 账号对象，配套凭据和定位合并在同一对象，不使用 & 或 @ 分隔账号。各账号独立处理，任一失败则整体非零退出。
