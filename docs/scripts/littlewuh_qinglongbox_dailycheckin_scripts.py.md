- 许可证：`MIT`

## 脚本功能

- Cookie 登录配置检查，支持每行一个账号并保留 Cookie 值中的等号
- 从本站页面读取当前登录公开 UID 并按返回值显示，获取签到令牌
- 咔叽网单每日签到，明确区分签到成功、明确今日已签到和未确认成功
- HTTPS 证书验证、请求超时、响应大小限制和同站安全跳转检查
- 完全断网预演，不验证真实业务成功，不产生签到动作
- 按账号及编号阶段输出带时间戳的脱敏日志、耗时和统计，保留账号信息及签到信息输出，追加单行 TASK_SUMMARY JSON
- 成功、部分失败、失败、配置错误和预演后尝试青龙脱敏通知；通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NZZ_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://www.2nzz.com，打开开发者工具的网络面板，选择本站已登录请求，复制请求头 Cookie 的值，不含 Cookie: 前缀；请勿分享或写入公开仓库。失效后重新登录并获取。
- 填写格式：每个非空行一个账号；完整 Cookie 的字段用分号分隔，键和值仅在第一个等号处分割，保留值中的后续等号；不使用 & 或 @ 分隔账号。

### 可选参数

### `NZZ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 开启完全断网预演；默认 0 正式签到。
- 填写格式：1、true、yes、on 开启；其他值关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙环境变量中设置；默认 1，关闭时设为 0。
- 填写格式：0、false、no、off 关闭，其他值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙现有 notify.py 所在目录；默认依次查找青龙标准脚本目录和可导入的 notify 模块。无需另行下载依赖，缺失时只记录通知不可用。
- 填写格式：本机目录路径，不含 notify.py 文件名。

## 多账号

NZZ_COOKIE 每个非空行一个账号，各账号独立 Cookie 会话；任一账号配置错误或签到未确认成功，整体以非零退出。
