## 脚本功能

- 获取论坛签到页面及 formhash 登录参数。
- 每天 08:00 签到领取贡献，明确识别签到成功和今日已签到。
- 逐行多账号独立处理，任一账号失败返回非零退出码。
- 使用一言 HTTPS 随机签到文案，解析文本、作者和来源并保留署名格式；失败时使用本地文案，不向文案服务发送凭据。
- 保留页面编码识别、中文表单编码和 XML CDATA 业务结果解析。
- 返回官方非敏感用户名时显示，凭据、原始响应和敏感身份不输出。
- 提供完全断网预演，模拟签到、文案获取和通知。
- 青龙通知覆盖成功、部分失败、失败、配置错误及预演；不可用或失败时保留业务退出码。
- 输出时间轴阶段日志、账号和任务统计及单行 TASK_SUMMARY JSON。
- 独立标准库 HTTP 实现，带超时、响应大小限制及跨站重定向保护。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `cycd_cookie`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.2cycdx.com/，按 F12 打开网络面板，刷新页面，选择论坛文档请求，从请求头复制完整 Cookie；每个账号分别登录获取。
- 填写格式：每个非空行一个账号的完整 Cookie；保留行内分号、等号、& 和 @，不用这些符号分隔账号。

### 可选参数

### `CYCD_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时自行设置为 1。
- 填写格式：1、true、yes、on 表示开启；默认 0。

### `CYCD_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可自行填写一言不可用时使用的本地签到文案。
- 填写格式：可选纯文本，合并空白后最多 280 字；空值使用内置文案。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙现有通知设置；需要关闭时自行设置为 0。
- 填写格式：默认 1；0、false、no、off 关闭通知。断网预演只模拟通知，不调用通知模块。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填入青龙现有 notify.py 所在目录；未设置时自动查找标准通知位置。
- 填写格式：本机目录路径，仅用于可选通知，不影响业务退出码。

每个非空行一个账号；使用完整 Cookie，不拆分行内字符。逐个独立执行，任一账号失败则整体非零退出。
