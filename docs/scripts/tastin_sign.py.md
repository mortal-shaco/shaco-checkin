# 塔斯汀每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tastin_sign.py`
- 青龙命令：`python3 scripts/tastin_sign.py`
- 建议 Cron：`40 9 * * *`
- 发布哈希：`07e4d3986b364b941f551ec1c2279a61c8ee7da8688e8ca197e8f51af5159a7a`
- 许可证：`MIT`

## 脚本功能

- 验证账号认证并查询当前积分
- 从积分商城签到入口发现活动，失败时按配置起点只读探测当期活动并核验开放状态
- 执行每日签到并识别明确的今日已签提示
- 展示连续签到天数、奖励名称、积分奖励及优惠券内容和有效期
- 查询签到后最终积分
- 对可恢复的只读网络请求最多尝试五次，指数退避，单账号限定十五分钟
- 兼容原单账号认证参数、门店、版本、活动起点及 SMTP 设置，支持逐行多账号
- 支持显式可信代理与 TLS 校验，阻止认证请求重定向
- 可选安全 SMTP 邮件，认证失效提醒及签到结果通知
- 青龙名单通知和全局开关，通知失败保留业务退出码
- 完全断网预演、时间轴日志、账号与子任务统计以及单行 TASK_SUMMARY 汇总
- 展示官方非机密账号身份，隐藏凭据和手机号

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TASTIN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录本人塔斯汀微信小程序，通过本人授权的 HTTPS 调试记录获取 sss-web.tastientech.com 请求头 user-token 与同账号签到请求体 memberPhone 加密手机号令牌。仅在青龙环境变量保存，勿上传抓包。
- 填写格式：每个非空行一个账号：token|memberPhone；仅在第一个竖线处分割，后续内容原样保留；禁止明文手机号，不使用 & 或 @ 分隔账号。

### 可选参数

### `TASTIN_USER_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从本人小程序请求头 user-token 获取。
- 填写格式：旧单账号兼容入口；未配置 TASTIN_ACCOUNTS 时与 TASTIN_MEMBER_PHONE 配套使用。

### `TASTIN_MEMBER_PHONE`

- 必填：否
- 敏感：是
- 获取或设置：从同账号签到请求体 memberPhone 获取加密手机号令牌。
- 填写格式：旧单账号配套凭据，不能填明文手机号；TASTIN_ACCOUNTS 优先。

### `TASTIN_SHOP_ID`

- 必填：否
- 敏感：否
- 获取或设置：从本人小程序请求头 gray-shop-id 获取。
- 填写格式：正整数，默认 28416；所有账号共用。

### `TASTIN_VERSION`

- 必填：否
- 敏感：否
- 获取或设置：从本人小程序请求头 version 获取。
- 填写格式：小程序版本号，默认 3.78.0。

### `TASTIN_ACTIVITY_ID`

- 必填：否
- 敏感：否
- 获取或设置：从本人小程序签到请求体 activityId 获取。
- 填写格式：正整数，默认 74；入口发现失败时从此起点只读探测连续 30 个编号，仅对核验有效且开放的活动签到。

### `TASTIN_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：确需代理时由本人配置可信代理服务，不会下载免费代理或自动使用系统代理。
- 填写格式：可选 HTTP 或 HTTPS 代理地址，可能含代理凭据须保密；始终校验证书。

### `TASTIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收设为 1；正式任务不设置或设为 0。
- 填写格式：1、true、yes、on 开启完全断网预演；业务请求、邮件、青龙通知均不联网。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：按需设置任务通知选择器，未设置时默认名单包含本任务目录编号。
- 填写格式：auto 模式下以逗号、分号或空白分隔目录编号、脚本路径、文件名或文件名通配符；* 匹配全部，显式空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写青龙自有 notify.py 或 sendNotify.js 所在目录，无需私有工作流仓库。
- 填写格式：可选本地目录；另支持 import notify.send、/ql/data/scripts、/ql/scripts；通知缺失或失败不改变业务退出码。

### `SMTP_HOST`

- 必填：否
- 敏感：否
- 获取或设置：从本人邮件服务商获取 SMTP 设置。
- 填写格式：可选服务器主机名，需配套 SMTP_USER 与 SMTP_PASS。

### `SMTP_PORT`

- 必填：否
- 敏感：否
- 获取或设置：从本人邮件服务商获取 SMTP 设置。
- 填写格式：默认 465 使用 TLS，其他端口必须成功 STARTTLS 才认证。

### `SMTP_USER`

- 必填：否
- 敏感：是
- 获取或设置：从本人邮件服务商获取 SMTP 登录账号。
- 填写格式：单个邮件登录账号，不输出到日志。

### `SMTP_PASS`

- 必填：否
- 敏感：是
- 获取或设置：从本人邮件服务商申请 SMTP 授权码。
- 填写格式：SMTP 密码或授权码，不输出到日志。

### `SMTP_TO`

- 必填：否
- 敏感：是
- 获取或设置：填写本人接收通知的邮箱地址。
- 填写格式：可选单个邮箱，默认 SMTP_USER，不输出到日志。

### `SMTP_NOTIFY_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：需要所有签到结果邮件时设置为 1。
- 填写格式：1、true、yes 开启；默认仅在明确认证失效时提醒；遵守全局通知开关，预演不发送。

## 多账号

每个非空行一个账号，token 与同账号加密手机号令牌用第一个竖线分隔，后续竖线保留。账号独立处理，任一账号失败则整体非零退出；新变量优先，旧参数仅兼容单账号。
