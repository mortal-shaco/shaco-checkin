## 脚本功能

- 保留 Cookie 登录校验、官方公开用户名原样显示和逐行多账号参数兼容
- 保留每日奖励领取、已经领取识别及连续签到天数查询
- 保留账号余额的金币、银币、铜币展示
- 保留最近每日登录奖励账目说明及可识别金额，页面缺失时明确说明
- 保留全局及账号专属 HTTP/HTTPS 代理链，账号配置优先并支持显式直连
- 增加显式开关控制的最新主题去重浏览，每轮默认八篇，每篇停留五至十秒
- 增加官方活跃度检查，达到 half、almost 或 done 即停止，缺少活跃度时失败闭合
- 增加 UTC 日期访问计数、每日上限、访问前持久化预留及同账号并发锁
- 增加仅浏览及签到和浏览组合模式，保持默认每日签到定时计划
- 保留完全断网参数校验和流程预演，不写状态文件
- 保留青龙脱敏通知、时间轴分阶段日志、逐账号与总任务统计及唯一单行 TASK_SUMMARY 汇总
- 根据同应用参考支持明确领取成功文案，并在响应未确认时只读复查签到页

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `V2EX_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.v2ex.com，在开发者工具网络面板选择本站已登录请求，复制完整 Cookie 请求头值。无需复制请求头名称，保留所有字段。
- 填写格式：每个非空行一个账号，填写完整 Cookie，或单行 JSON 对象，含 cookie 字符串及可选 proxy 字符串。Cookie 内等号、分号及其他文本保持原样，不使用 & 或 @ 分隔账号。

### 可选参数

### `V2EX_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：可选，使用自己管理的 HTTP 或 HTTPS 代理地址。青龙依赖管理安装公开 npm 包 https-proxy-agent 7.x，仅启用代理时需要。账号 JSON 中的 proxy 优先，空字符串为直连。
- 填写格式：HTTP/HTTPS URL，可含代理认证，默认直连。

### `V2EX_CHECKIN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙任务环境设置。默认开启签到领奖，可在仅浏览的小时任务中关闭。
- 填写格式：1 开启，0 关闭，默认 1。不得与浏览同时关闭。

### `V2EX_BROWSE`

- 必填：否
- 敏感：否
- 获取或设置：在青龙任务环境显式开启浏览。启用后请求最新主题页及主题页，会产生服务端访问记录；每次访问后等待 5 至 10 秒。默认关闭。
- 填写格式：1 开启，0 关闭，默认 0。

### `V2EX_TOPIC_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：可选，设置每轮浏览的去重主题数量，对应原扩展 topicCount。
- 填写格式：1 至 80 的整数，默认 8。

### `V2EX_MAX_VISIT_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：可选，设置 UTC 日期内的主题访问次数上限，对应原扩展 maxVisitCount。失败请求也预留次数，避免重试越界。
- 填写格式：1 至 80 的整数，默认 80。

### `V2EX_STATE_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，选择可写的持久目录，所有本脚本的定时任务必须共用此目录。以官方用户名摘要区分账号，仅保存日期、访问计数和停止标记。锁异常遗留时先确认同账号任务全部停止，再删除对应 .lock 目录。
- 填写格式：目录路径，默认脚本目录下 .v2ex-state。仅正式启用浏览时写入。清空目录会重置限额，请勿每日清理。

### `V2EX_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙任务环境设置以完全断网预演参数和流程。不会访问本站、写入浏览计数或调用通知模块。
- 填写格式：1 为断网预演，默认正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，替换默认通知选择列表。支持维护目标及来源 catalogId、scripts/sudojia_v2ex.js、sudojia_v2ex.js、当前文件名及文件名通配符。
- 填写格式：逗号、分号、空白或换行分隔；* 选择全部，空字符串全部关闭。全局显式开启优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录。未设置时依次发现 /ql/data/scripts/sendNotify.js 和 /ql/scripts/sendNotify.js。
- 填写格式：本地目录路径，不会下载或安装模块。

## 多账号

每个非空行一个账号，账号配置集中于 V2EX_COOKIE。完整 Cookie 不再按字段拆分；单行 JSON 可组合该账号 Cookie 和代理。逐账号独立执行，任一账号失败则进程非零退出。
