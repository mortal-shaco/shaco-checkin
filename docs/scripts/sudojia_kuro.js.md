# 库街区每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_kuro.js`
- 青龙命令：`node scripts/sudojia_kuro.js`
- 建议 Cron：`4 2 * * *`
- 发布哈希：`c73dca2506d0ebf117aab21be64589d040c616f85e36faddffbfd9dc9aef24bf`
- 许可证：`GPL-3.0`

## 脚本功能

- 检查 Token 与鸣潮角色，保留 H5 到 Android 的验证回退
- 社区每日签到并显示获得库洛币及连续签到天数
- 查询账户库洛币余额
- 鸣潮每日签到及当日奖励查询
- 查询战双绑定角色，有角色时每日签到并查询当日奖励
- 显示官方返回的非敏感账号身份
- 多账号独立处理、请求超时和严格业务结果检查
- 断网预演、分阶段日志、账号统计及结构化任务汇总
- 通过青龙通知模块发送脱敏汇总，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KURO_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录库街区官网 https://www.kurobbs.com/，在浏览器开发者工具 Application → Local storage 中复制 auth_token 的值；也可从本人已登录 APP 发往 api.kurobbs.com 的请求头获取 token。游戏须绑定角色并开启库街区展示。
- 填写格式：每个非空行填写一个账号的完整 Token；不使用 & 或 @ 分隔账号。

### 可选参数

### `KURO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 进行断网预演。
- 填写格式：1 为预演，其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写已有青龙 sendNotify.js 所在目录；未设置时查找青龙标准脚本目录。
- 填写格式：本地目录路径；业务请求不依赖通知模块。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号，顺序独立执行；角色资料仅保存在所属账号内，任一账号失败则进程非零退出。
