# 微博超话关注批量签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/wb.py`
- 青龙命令：`python3 scripts/wb.py`
- 建议 Cron：`20 8 * * *`
- 发布哈希：`22183f6c6cde10adefcdb921dbfa1722fa1f25f52a9dfb9392a818ca9b83458b`
- 许可证：`MIT`

## 脚本功能

- 使用网页 Cookie 校验登录态后，分页拉取账号全部关注超话并逐个签到
- 识别签到成功、今日已签到及其他成功业务码；失败计入账号失败
- 官方资料接口返回的非敏感昵称或公开 UID 原样展示，隐藏 Cookie 与原始响应
- 支持每行一个 Cookie 的多账号，独立汇总结果，任一失败整体非零退出
- 完全断网预演、请求超时与响应大小限制、时间轴日志与单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WEIBO_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在电脑浏览器登录 weibo.com，打开开发者工具 → Network，刷新个人页或超话页，复制任意 weibo.com 请求的完整 Cookie 请求头（需含 SUB、XSRF-TOKEN 等登录字段）。密码变更或退出登录后需重新获取。请勿公开分享。
- 填写格式：每个非空行一个账号 Cookie；可选「备注|Cookie」，仅拆分首个竖线。不要用 @、& 或 ---- 分隔账号。

### 可选参数

### `WEIBO_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：未设置 WEIBO_COOKIE 时读取本变量，获取方式相同。
- 填写格式：与 WEIBO_COOKIE 相同，仅支持换行分隔多账号。

### `WEIBO_FOLLOW_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地或青龙预演时设为 1，不发起任何微博网络请求。
- 填写格式：1/true/yes/on 启用；默认关闭

### `WEIBO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：兼容别名，与 WEIBO_FOLLOW_DRY_RUN 等效。
- 填写格式：1/true/yes/on 启用

### `WEIBO_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选，调整单次 HTTP 超时秒数。
- 填写格式：5 到 60 的数字，默认 15

### `WEIBO_SIGN_INTERVAL`

- 必填：否
- 敏感：否
- 获取或设置：可选，调整同一账号相邻超话签到的基础间隔秒数。
- 填写格式：0 到 60 的数字，默认 1.5

### `WEIBO_ACCOUNT_INTERVAL`

- 必填：否
- 敏感：否
- 获取或设置：可选，调整多账号之间的等待秒数。
- 填写格式：0 到 300 的数字，默认 10

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，限制仅对匹配的脚本发通知；空值表示全部禁用。
- 填写格式：逗号/分号/空白/换行分隔的选择器，* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，自定义 notify.py 所在目录。
- 填写格式：绝对路径目录
