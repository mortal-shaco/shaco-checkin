# Readfree 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/readfree.py`
- 青龙命令：`python3 scripts/readfree.py`
- 建议 Cron：`26 10 * * *`
- 发布哈希：`1e797c93a0120cc3d04de9e3a5ff6df3c2b6f7ee9d87f169754eda16883e0354`
- 许可证：`MIT`

## 脚本功能

- 使用每行一个账号的 JSON 配置，支持 Cookie 签到和显式开启的交互验证码登录。
- 检查个人签到主页登录状态；从官方返回的个人主页链接核对并显示公开用户名，不输出凭据。
- 在同一 HTTPS 会话中执行每日签到，仅明确成功或今日已签到页面标记判为通过。
- 提供完全断网预演、分账号分阶段日志、统计与唯一 TASK_SUMMARY 机器汇总。
- 按青龙全局开关和脚本名单发送脱敏通知；通知不可用时保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `READFREE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://readfree.me，在个人主页地址获取公开用户名 username；在开发者工具的网络面板复制本站请求的 Cookie 请求头。每行将同一账号的 username 与 cookie 合并为一个 JSON 对象并存入青龙私密环境变量。交互登录可改为 username、email、password 三个字段，邮箱和密码使用自己注册的账号，不要公开分享。
- 填写格式：每个非空行一个 JSON 对象：含 username、cookie；或含 username、email、password。Cookie 内的分号、等号及密码符号由 JSON 字符串完整保留，不用 & 或 @ 分隔账号。

### 可选参数

### `READFREE_INTERACTIVE_LOGIN`

- 必填：否
- 敏感：否
- 获取或设置：仅需要验证码密码登录时手动设置为 1，并在交互终端执行；定时任务应使用 Cookie。脚本显示临时验证码图片路径，自行查看并输入答案，不启动图片查看器。
- 填写格式：1 开启；默认关闭。验证码图片在输入结束或异常退出时删除，不持久保存会话。

### `READFREE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时设置为 1。
- 填写格式：1 为完全断网预演；默认正式运行。预演检查配置格式并模拟登录、签到和通知，不代表业务成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要通知时设置本脚本目录编号 1aac1845bed1f454、Readfree.py、实际文件名或文件名通配符；也支持 scripts/Readfree.py 等相对路径。
- 填写格式：逗号、分号、空白或换行分隔；* 匹配全部；空值关闭全部；设置后覆盖默认名单。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙通知模块所在目录；默认自动尝试导入 notify.send，并查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径，不填写凭据。通知不可用或失败不改变业务退出码。

## 多账号

每个非空行一个账号 JSON 对象；同账号的配套凭据放在同一对象内。各账号独立处理，任一账号失败时整体非零退出。
