## 脚本功能

- 保留用户名和密码登录官方接口并在内存获取会话
- 新增 Cookie 或 session 值认证签到，兼容旧 COOKIES 变量并统一为换行账号
- 保留 acw_sc__v2 WAF 挑战求解与单次挑战重试，不打印挑战值
- 保留严格业务成功校验，区分签到成功、今日已签到与失败
- 保留官方返回的非凭据用户名、昵称或公开 UID；无官方身份时使用账号序号，抑制手机号及控制字符
- 保留每行一个账号的多账号独立处理，新增坏行隔离；任一账号失败时整体非零退出
- 保留完全断网预演、有限请求超时、时间轴分阶段日志、账号与任务统计、DRY_RUN_OK 和单行 TASK_SUMMARY
- 保留青龙 Python 与 JavaScript 通知发现及降级链路，支持全局开关与脚本名单，通知失败不改变业务退出码
- 兼容显式配置的 Telegram 脱敏通知，预演不联网
- 使用标准库自行实现 HTTPS，限制响应大小并阻止跨站重定向凭据，不依赖外部仓库或应用

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ANYROUTER_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：密码方式：在 https://anyrouter.top 注册并使用本人的用户名和密码。Cookie 方式：本人登录官方站点后，在浏览器开发者工具的网络面板查看 /api/user/sign_in 请求头 Cookie；如有 new-api-user，将该公开编号填入同一行 uid。会话过期后重新获取，切勿分享。
- 填写格式：每个非空行一个账号：用户名|密码，或 JSON 对象，字段 cookie 为完整 Cookie 或 session 值、uid 为可选公开用户编号；密码仅在首个竖线处分割，后续竖线保留；两种方式可逐行混用

### 可选参数

### `COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容入口，从本人官方签到请求头获取 Cookie；仅规范变量未设置时使用，建议迁移至 ANYROUTER_ACCOUNTS。
- 填写格式：每个非空行一个完整 Cookie 或 session 值；不接受原有的 ||| 账号分隔符

### `ANYROUTER_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置请求超时，默认 20 秒。
- 填写格式：5 至 60 的有限数字，单位秒

### `ANYROUTER_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 执行完全断网预演，仅检查本地配置，不验证凭据或业务成功。
- 填写格式：1、true、yes、on 开启；0、false、no、off 关闭，默认 0

### `BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：可省略；仅兼容官方地址，不再接受原始默认第三方中转，避免泄露凭据。
- 填写格式：仅 https://anyrouter.top，可带末尾斜线

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写需要通知的脚本标识；未设置默认不选中本任务；空字符串禁用所有默认选择。
- 填写格式：逗号、分号、空白或换行分隔，支持维护目录编号 71b8e4efd81a4495、scripts/anyrouter_signin.py、anyrouter_signin.py、candidate.py、文件名通配符和 *

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录；也会查找可导入 notify 模块和青龙标准目录。
- 填写格式：本地通知组件目录路径，通知组件仅用于可选投递，不参与业务请求

### `TG_BOT_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可选保留原始 Telegram 通知：从 Telegram BotFather 获取本人机器人的令牌，须同时设置 TG_CHAT_ID；受青龙全局通知策略控制。
- 填写格式：机器人令牌，断网预演不会发送

### `TG_CHAT_ID`

- 必填：否
- 敏感：是
- 获取或设置：从本人 Telegram 机器人聊天中获取目标聊天编号；与 TG_BOT_TOKEN 配套设置。
- 填写格式：目标聊天编号，通知只包含脱敏统计

## 多账号

每个非空行一个账号，同一账号的配套凭据写在同一行。密码仅在首个竖线处分割；Cookie 与可选 uid 用同一 JSON 对象。支持两种认证方式逐行混合；空行和以 # 开头的注释忽略，任何账号失败时整体非零退出；不使用 &、@ 或 ||| 分隔账号。
