# 掌瓦每日商店推送

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/valorantstore.py`
- 青龙命令：`python3 scripts/valorantstore.py`
- 建议 Cron：`10 0 * * *`
- 发布哈希：`b64a7e83e69ac9347604f8ef3512e77c2f4f121de89159ff4f42619b89bd55df`
- 许可证：`MIT`

## 脚本功能

- 按原每日 08:15 定时查询掌上无畏契约每日商店，不购买商品。
- 刷新 access_token、client ticket、web ticket 和临时票据；刷新失败仍尝试旧会话查询并以失败状态退出。
- 查询绑定账号并按官方返回显示昵称；无昵称时使用账号序号。
- 报告每日皮肤名称、品质、点券价格、点赞数及北京时间刷新时间。
- 使用背景与商品图片生成商品长图，可选 Telegram 图片推送；图片失败保留文字报告并记录失败。
- 通过青龙通知发送包含商店报告、账号总数、成功数和失败数的脱敏总结；通知不可用不改变业务退出码。
- 支持每行一个账号、无网络预演、阶段耗时及账号和任务统计，输出唯一单行 TASK_SUMMARY。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `VALORANT_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在本人授权设备上登录掌上无畏契约，通过合法抓包方式取得 app.mval.qq.com 每日商店请求的完整 Cookie，并从 refresh_client_ticket 请求体取得同一账号的 ct。将 ct 追加为 Cookie 字段；票据过期后重新抓包。不要公开或发送给他人。
- 填写格式：每个非空行一个账号；字段以分号分隔、名称与值以第一个等号分隔，后续等号原样保留。至少包含 userId、openid、access_token、ct，保留 tid、acctype 等其他原始 Cookie 字段。不使用 & 或 @ 分隔账号。

### 可选参数

### `VALORANT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 启用完全断网预演；默认 0。
- 填写格式：1 启用；0、false、no、off 关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙 notify.py 所在目录；脚本也查找同目录及 /ql/data/scripts、/ql/scripts，最后兼容 import notify.send。不需要私有工作流仓库。
- 填写格式：本地目录路径。

### `TG_BOT_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可选，从 Telegram 的 BotFather 创建机器人取得令牌；与 TG_USER_ID 配套启用商品长图。
- 填写格式：机器人令牌；仅向 Telegram 官方 HTTPS 接口发送。

### `TG_USER_ID`

- 必填：否
- 敏感：是
- 获取或设置：可选，取得自己已授权接收该机器人消息的用户或群组聊天编号；与 TG_BOT_TOKEN 配套填写。
- 填写格式：十进制聊天编号，群组编号可为负数。

### `VALORANT_FONT_PATH`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定当前运行环境已经安装且获准使用的中文字体以改善长图中文显示；不填写使用 Pillow 内置字体。脚本不下载或安装字体。
- 填写格式：可读本地字体文件路径；不是必需文件，不依赖固定私有路径。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

VALORANT_COOKIE 每个非空行一个完整账号 Cookie，ct 与该账号其他字段合并在同一行；按顺序独立执行，任一账号失败则整体非零退出。

- 通知开启且配置 Telegram 时发送商品长图；生成的本地临时图片在发送后删除。
