# BT吧签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/btbar.py`
- 青龙命令：`python3 scripts/btbar.py`
- 建议 Cron：`46 8 * * *`
- 发布哈希：`1e492d2f4657a2b5e73bbe6c407e48b654df65606fd4744797aaae12338b45e3`
- 许可证：`GPL-3.0`

## 脚本功能

- BT吧（u.aibtba.com）账号密码登录后每日签到领取 BT 币
- 识别当日首次签到成功与重复签到（获得 0 BT 币）
- 读取连续签到天数与当前 BT 币余额
- 官方 Cookie 返回昵称或公开 UID 时直接展示以便核对账号
- 多账号按行处理；规范变量 BTBAR_ACCOUNTS（手机号或邮箱|密码），兼容上游 BTBAR_USER/BTBAR_PASSWORD
- 完全断网预演 BTBAR_DRY_RUN、HTTPS 超时、业务成功/已签到判定
- 脱敏时间轴日志、账号与任务统计、单行 TASK_SUMMARY 与青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BTBAR_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://u.aibtba.com/ 注册并登录后，使用手机号或邮箱与登录密码。每个非空行填写一个账号，格式为「手机号或邮箱|密码」。不要把真实密码写入公开仓库、日志或通知。
- 填写格式：每行一个账号：手机号或邮箱|密码（仅在第一个 | 处分割，密码可含 |）；账号之间只用换行分隔，不使用 & 或 @

### 可选参数

### `BTBAR_USER`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游单账号别名：与 BTBAR_PASSWORD 同时设置时可代替 BTBAR_ACCOUNTS；仅当规范变量为空时生效。
- 填写格式：单个手机号或邮箱字符串

### `BTBAR_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游单账号别名：与 BTBAR_USER 同时设置时可代替 BTBAR_ACCOUNTS；仅当规范变量为空时生效。
- 填写格式：单个密码字符串

### `BTBAR_PAST_LOGIN_TIME`

- 必填：否
- 敏感：否
- 获取或设置：可选，对应上游 PastLoginTime；用于 Hm_lvt 曾经登录时间戳。连续登录时可填首次登录时间戳，也可从含 Hm_lvt 的 Cookie 中提取。留空则使用当前时间。
- 填写格式：9 至 12 位 Unix 时间戳，或多个逗号分隔的时间戳

### `BTBAR_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置；只校验配置并模拟登录/签到阶段，不访问网络、不改动签到状态、不真实发送通知。
- 填写格式：1、true、yes、on 开启完全断网预演；默认关闭

### `BTBAR_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次 HTTPS 请求超时秒数。
- 填写格式：5 到 60 的数字；默认 15

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录；失败不改变业务退出码。
- 填写格式：目录路径；还会尝试 /ql/data/scripts 与 /ql/scripts
