# LaTeX工作室签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/checkin_latex.py`
- 青龙命令：`python3 scripts/checkin_latex.py`
- 建议 Cron：`10 1 * * *`
- 发布哈希：`8cefcf59aea239b9f46242064af95ad62c627668077b6ff19c280ce1d70ced02`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 使用 latexstudio.net Token 读取账号资料（昵称、会员套餐、余额、积分、累计签到天数、上次登录）
- 调用每日签到接口并核验业务成功或今日已签到
- 展示官方返回的昵称等公开身份信息，隐藏 Token 与原始响应
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `COOKIE_LATEX_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录 latexstudio.net（LaTeX 工作室）后，在个人中心或浏览器开发者工具网络请求中获取接口使用的 token，写入青龙环境变量。不要把 Token 发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号 Token。账号之间只用换行分隔，不使用 &、@ 或 &&。

### 可选参数

### `LATEX_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 90 的整数秒；默认 20。

### `LATEX_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。

## 多账号

COOKIE_LATEX_TOKEN 每个非空行一个账号 Token。账号逐个独立读取资料并签到；任一账号失败则整体非零退出。不使用 &、@ 或 && 分隔账号。

## 副作用与风险

- 正式运行时向 latexstudio.net 提交每日签到，改变账号当日签到状态并可能发放积分或余额相关奖励
