# 中国移动签到有礼

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/cmcc_auto.py`
- 青龙命令：`python3 scripts/cmcc_auto.py`
- 建议 Cron：`29 10 * * *`
- 发布哈希：`f7e60870bba36ff98b58570f2b6a78d1ffda85c94969aeea3db26571598dee9a`
- 许可证：`MIT`

## 脚本功能

- 使用原接口及请求头进行中国移动每日签到，严格验证官方成功状态。
- 展示官方奖品、本月累计及非敏感账号昵称、用户名或公开 UID。
- 识别 TODAY_MARKED 为今日已完成，避免重复签到误报失败。
- 支持逐行多账号隔离执行，网络和服务器异常最多三次尝试，设有超时、响应大小限制及证书校验。
- 保留可选飞书互动卡片通知和摘要文件写入。
- 提供青龙通知选择开关、脱敏时间轴日志、逐账号与全局统计及单行 TASK_SUMMARY 记录。
- 支持完全断网演练，不以演练结果冒充真实业务成功。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CMCC_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在微信进入中国移动官方签到有礼并登录，使用本人授权的开发者工具或 HTTPS 抓包工具，找到 https://wx.10086.cn/qwhdhub/api/mark/do/mark 的请求，复制完整 Cookie 请求头值，不含 Cookie: 前缀；失效时重新登录获取。
- 填写格式：每个非空行一个账号；同一 Cookie 内的分号、&、@ 均原样保留，不作为账号分隔符。

### 可选参数

### `CMCC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网演练时设置为 1；演练不发送签到、文本或通知请求，也不写结果文件。
- 填写格式：1、true、yes、on 开启；默认正式执行。

### `FEISHU_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：可选：在飞书群添加自定义机器人并复制其 HTTPS Webhook，作为秘密变量保存；沿用上游无签名卡片接口，不支持需要签名的机器人。
- 填写格式：https://open.feishu.cn/open-apis/bot/v2/hook/ 后接机器人地址；留空跳过。

### `RESULT_FILE`

- 必填：否
- 敏感：否
- 获取或设置：可选：指定本人可写的专用摘要文件；沿用上游覆盖写入，避免指向重要文件。
- 填写格式：本地文件路径；默认不写入，演练不写入。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选：设置自动通知选择列表，替换默认选择；QINGLONG_NOTIFY 强制开启或关闭优先。
- 填写格式：目录编号 c4106d0130339343、脚本相对路径、文件名或文件名通配符；逗号、分号、空白或换行分隔，* 选择全部，空字符串禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙通知模块所在目录；自动尝试导入 notify.send、脚本目录以及 /ql/data/scripts、/ql/scripts 下的 notify.py 或 sendNotify.js。
- 填写格式：本地目录路径；通知为可选集成，签到不依赖该模块。
