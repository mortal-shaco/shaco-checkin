- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/cloud_genshin.py`
- 青龙命令：`python3 scripts/cloud_genshin.py`
- 建议 Cron：`30 9 * * *`
- 发布哈希：`096201548995791c9aefabf7d0d21799646ea0119cee2d786aa1a02ec58d2df3`
- 许可证：`MIT`

## 脚本功能

- 云原神每日免费时长领取
- 识别今日已领取或达免费时长上限
- 查询剩余免费时长、畅玩卡状态与米云币数量
- 识别 combo_token 失效或防沉迷
- 多账号独立处理与脱敏汇总通知
- 断网预演配置验证

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CLOUD_GENSHIN_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在本人手机安装并登录云原神 App，使用抓包工具捕获访问 api-cloudgame.mihoyo.com 请求头中的 x-rpc-combo_token 整串；不要把 token 提交到公开仓库或聊天。
- 填写格式：每个非空行一个账号的 combo_token 原文；不要用 &、@ 或其他符号分隔账号

### 可选参数

### `CLOUD_GENSHIN_DEVICE_ID`

- 必填：否
- 敏感：否
- 获取或设置：可选。需要固定设备标识时填写；默认按 token 稳定生成 UUID。多账号时可每行对应一个设备 ID，仅一行时全账号共用。
- 填写格式：UUID 或上游设备 ID 字符串；多账号时每行一个

### `CLOUD_GENSHIN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：网络较慢时可适当增大单次请求超时
- 填写格式：5..60 整数或小数秒，默认 15

### `CLOUD_GENSHIN_ACCOUNT_GAP`

- 必填：否
- 敏感：否
- 获取或设置：多账号串行执行时的间隔，降低连续请求压力
- 填写格式：0..120 秒，默认 2；断网预演不睡眠

### `CLOUD_GENSHIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时手动设置为 1
- 填写格式：1/true/yes/on 启用；0/false/no/off 关闭

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本白名单启用通知时设置；空值表示全部禁用
- 填写格式：catalog-id、脚本路径、文件名或 glob，可用逗号/分号/空白/换行分隔；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认路径时，设为 notify.py 或 sendNotify.js 所在目录
- 填写格式：本地目录绝对路径

## 多账号

CLOUD_GENSHIN_TOKEN 中每个非空行是一个独立账号的 combo_token；逐账号执行，任一账号失败时进程整体非零退出
