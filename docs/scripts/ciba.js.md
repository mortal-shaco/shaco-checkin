## 脚本功能

- 从词霸公开 HTTPS 接口获取每日一句。
- 按显示配置分别输出英文原文、中文释义或两者。
- 支持多行独立显示配置，并在任一配置失败时返回非零退出码。
- 提供完全断网的预演模式、时间轴日志、脱敏通知和单行结构化任务汇总。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CIBA_LIST`

- 必填：是
- 敏感：否
- 获取或设置：在青龙环境变量中手动新建 CIBA_LIST；此变量只是显示配置，不是账号凭据，也不需要从网页抓取 Cookie 或 Token。
- 填写格式：每个非空行是一项显示配置，推荐写成“配置名称|中文开关|英文开关”；开关支持是/否、1/0、true/false、on/off。单个非空值默认同时显示中文和英文，旧配置可继续使用 @ 分隔字段。

### 可选参数

### `CIBA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时手动设置为 1；正式运行时删除或设为 0。
- 填写格式：启用值为 1、true、yes、on、是或启用。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要只通知部分脚本时手动设置，留空会关闭全部脚本通知。
- 填写格式：使用逗号、分号、空白或换行分隔选择器；可填写 5901669d3162577e、output/candidate.js、candidate.js、通配符或 *。
