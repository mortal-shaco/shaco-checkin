# 携程旅行签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ctrip.js`
- 青龙命令：`node scripts/ctrip.js`
- 建议 Cron：`11 10 * * *`
- 发布哈希：`18861f1a3a9bfe67309633b772c7092a500ce54f468227de99e537b8e25d1f42`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 携程每日签到，明确识别签到成功、今日已签到和登录失效业务码
- 查询登录账号总积分并校验积分字段，不将缺失积分当作零
- 支持每行一个账号及原版 CTRIP_AUTH 多账号 JSON，逐账号独立执行并汇总失败
- 官方响应含昵称、用户名、显示名称或公开 UID 时输出身份，隐藏授权、手机号及其他敏感信息
- 可选 Bark 推送和青龙 sendNotify.js 脱敏汇总，支持全局开关、列表及通配符选择
- 提供完全断网预演、分阶段时间轴、账号及任务统计和唯一 TASK_SUMMARY 记录
- 独立实现 HTTPS POST，限制请求时间和响应体大小，禁止重定向及签到自动重试

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CTRIP_AUTH`

- 必填：是
- 敏感：是
- 获取或设置：在本人设备登录携程旅行微信小程序或携程网页版 https://m.ctrip.com/，使用本人授权的网络调试工具查看携程请求 JSON 的 head.auth。上游授权响应的 ticket 即原脚本保存的 auth。多账号不要退出登录；授权失效后重新登录并手动更新，禁止公开抓包记录。
- 填写格式：每个非空行填写一个账号的完整 auth，账号之间仅换行，不按 &、@ 或其他符号拆分。兼容原版完整 JSON：account 对象内每个账号记录含字符串 auth；对象键仅作兼容，不作为官方身份输出。

### 可选参数

### `CTRIP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置为 1；正式任务取消设置。
- 填写格式：1、true、yes、on 启用断网预演，默认关闭；预演不加载通知模块、不调用 Bark。

### `CTRIP_BARK_KEY`

- 必填：否
- 敏感：是
- 获取或设置：从本人 Bark APP 获取推送密钥；不需要 Bark 时留空。
- 填写格式：单个 Bark 推送密钥；受全局通知开关控制，不作为携程授权。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要限定推送脚本时在青龙环境变量中设置；未设置时本任务默认选中。
- 填写格式：以逗号、分号、空白或换行分隔目录 ID、脚本相对路径、文件名或含 *、? 的文件名通配符；本任务支持 5e853b28200fc8af、Ctrip.js、scripts/Ctrip.js 及实际文件名和相对路径。设置后覆盖默认列表，空值关闭全部，* 选择全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙已配置 sendNotify.js 时可填写其所在目录；默认查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径，仅用于可选青龙通知模块；缺失或失败只记录状态。

## 多账号

每个非空行一个账号，整行均为 auth；不使用 &、@ 等账号分隔符。兼容原版 account 对象 JSON，逐账号独立执行签到及积分查询；任一账号或子任务失败均以非零退出。
