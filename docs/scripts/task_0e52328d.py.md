## 脚本功能

- 使用掘金 Web Cookie 发布「好好生活计划」主题沸点打卡
- 正式运行优先通过一言生成公开文案并按策略署名，失败回退本地文案
- 可选下载并经 ImageX 上传配图，失败时允许无图发布
- 展示官方返回的账号昵称或公开 UID 便于核对
- 支持多账号按行独立处理，任一账号失败则进程非零退出
- 支持 JUEJIN_FRIENDS_DRY_RUN 完全断网预演
- 按青龙通知策略发送脱敏任务摘要，并输出时间轴日志与 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JUEJIN_FRIENDS_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录掘金网页版（juejin.cn），在浏览器开发者工具网络面板复制任意已登录请求头中的完整 Cookie。须包含会话相关字段（如 sessionid）。不要写入脚本正文。
- 填写格式：每个非空行一个账号的完整 Cookie；账号之间只用换行分隔，勿使用 & 或 @ 分隔账号。

### 可选参数

### `JUEJIN_FRIENDS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1/true/yes/on 启用完全断网预演，只校验配置与流程，不请求一言、不上传图片、不发布沸点。
- 填写格式：1/true/yes/on 表示启用；其他或未设置表示正式运行

### `JUEJIN_FRIENDS_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：公开文案本地兜底。断网预演、一言不可用或超长时使用。正式运行优先请求一言 HTTPS。
- 填写格式：纯文本，建议不超过 200 字；缺省为「每日打卡，好好生活。」

### `JUEJIN_FRIENDS_DAY`

- 必填：否
- 敏感：否
- 获取或设置：打卡正文中的 day 标记。未设置时使用当天日期 YYYYMMDD。
- 填写格式：短文本或数字，如 1 或 20261105

### `JUEJIN_FRIENDS_THEME_ID`

- 必填：否
- 敏感：否
- 获取或设置：沸点主题 ID，对应好好生活计划活动。一般保持默认即可。
- 填写格式：数字字符串；缺省 7163537723910225960

### `JUEJIN_FRIENDS_THEME_TAG`

- 必填：否
- 敏感：否
- 获取或设置：主题话题展示名，写入正文标签。一般保持默认即可。
- 填写格式：纯文本；缺省「JUEJIN FRIENDS 好好生活计划」

### `JUEJIN_FRIENDS_UPLOAD_IMAGE`

- 必填：否
- 敏感：否
- 获取或设置：是否下载并上传配图。默认开启以保留上游能力；设为 0/false/no/off 可关闭（仅发文字）。配图失败时自动无图发布。
- 填写格式：1/true/yes/on 或 0/false/no/off；缺省视为开启

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选。设置后替换默认可通知脚本名单；空值禁用全部；* 匹配全部。可用 catalog-id、文件名或 glob。
- 填写格式：逗号/分号/空白/换行分隔的选择器；空字符串禁用；* 表示全部
