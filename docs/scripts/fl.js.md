# FL 自动登录签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/fl.js`
- 青龙命令：`node scripts/fl.js`
- 建议 Cron：`52 10 * * *`
- 发布哈希：`690c5178ee8ff03691fb2d59f512e21396bcb74b10989e354cd86473995423af`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用邮箱和密码自动登录 FL，保留上游接口、请求方法、授权头及旧环境变量兼容性
- 执行每日签到，明确判断签到成功及官方已签到响应，显示奖励 MB 和累计签到流量 GB
- 官方返回非敏感昵称、用户名或公开 UID 时按原值显示，凭据、邮箱和手机号不输出
- 按行支持多账号独立处理，任一账号失败整体非零退出
- 请求和响应体超时、响应体积限制、禁止重定向、登录瞬态错误一次重试及失败闭合
- 完全断网预演，包括跳过登录、签到和所有通知网络行为
- 保留可选 PushPlus 结果通知，增加遵循全局开关及名单的青龙通知，发送失败保留业务退出码
- 按账号及阶段输出时间轴、任务统计和唯一 TASK_SUMMARY 结构化摘要
- 独立 Node.js 18 及以上脚本，无第三方依赖或安装引导

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FL_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://flzt.org 注册或登录，使用自己的登录邮箱和密码，无需抓包。在青龙环境变量中新建此变量；优先使用此规范变量。
- 填写格式：每个非空行一个账号，格式为邮箱|密码；仅按第一个竖线分割，后续竖线属于密码；密码不去除首尾空格，账号之间不可使用 & 或 @ 分隔。

### 可选参数

### `USER_EMAIL`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游变量，填写 FL 网站的登录邮箱；仅未设置 FL_ACCOUNTS 时生效。
- 填写格式：每个非空行一个邮箱，与 USER_PASSWORD 的非空行逐行配对，不支持合并分隔符。

### `USER_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游变量，填写对应账号的登录密码；建议迁移至 FL_ACCOUNTS。
- 填写格式：每个非空行一个密码，与 USER_EMAIL 逐行配对，保留密码首尾空格。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在 PushPlus 官网个人中心获取推送令牌；设置后保留上游可选结果通知，通知内容只含账号序号、状态及流量统计。
- 填写格式：单个推送令牌；断网预演不发送，QINGLONG_NOTIFY 关闭时不发送。

### `FL_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：由运行者设置为 1 开启完全断网预演。
- 填写格式：1 为预演；未设置或其他值执行真实登录及签到。预演仅验证配置，不代表真实业务成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中指定需要通知的脚本；使用本脚本目录编号、脚本文件名、相对 scripts 的路径或文件名通配符。
- 填写格式：逗号、分号或空白分隔，支持 *；空值禁用全部；设置后替换默认名单；QINGLONG_NOTIFY 显式开关优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：需要自定义青龙通知模块目录时设置；默认查找 /ql/data/scripts 和 /ql/scripts，优先 sendNotify.js，其次 notify.py。
- 填写格式：包含青龙 sendNotify.js 或 notify.py 的目录；通知模块是可选集成，不影响脚本独立运行，发送异常不改变业务退出码。

## 多账号

FL_ACCOUNTS 每个非空行一个账号，邮箱与密码仅按第一个竖线分割；各账号独立处理，任一账号失败整体非零退出。兼容旧邮箱与密码变量按非空行逐行配对。

## 副作用与风险

- 正式执行登录会创建服务端登录会话或授权令牌
- 正式执行每日签到会更新签到记录并增加账号流量奖励
- 启用通知时通过青龙通知模块或可选 PushPlus 发送脱敏任务摘要
