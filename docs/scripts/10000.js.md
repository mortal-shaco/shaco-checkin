# 中国电信签到与金币查询

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/10000.js`
- 青龙命令：`node scripts/10000.js`
- 建议 Cron：`10 10 * * *`
- 发布哈希：`4e2337e41d01c358be3cc976d319169d7f0e56b11aac93283ccb9f956eb470a2`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 多账号中国电信签到，保留上游毫秒时间戳、smlprgrm 来源及 AES-128-ECB/PKCS7 十六进制请求封装。
- 通过 data.code=1 确认签到成功；仅 data.code=0 且消息包含已签到时识别为今日已完成。
- 可选按账号查询金币总数与首页提示，保留 resoultCode=0 判定；官方返回昵称、用户名、显示名或公开 UID 时显示非凭据身份。
- 兼容上游手机号与首页请求体变量名称，按换行迁移账号；无需请求头、私有仓库或 BoxJs 文件。
- 逐账号阶段日志、耗时和子任务统计，恰好一条 TASK_SUMMARY JSON；配置错误、部分失败及通知不可用均有明确状态。
- 完全断网预演，包含本地参数校验和加密构造；通知仅生成脱敏离线预览。
- 真实执行结束后通过青龙 sendNotify.js 发送脱敏汇总，支持全局开关与脚本选择列表；通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TELECOM_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人中国电信账号查看手机号。可选首页请求体通过本人授权调试工具捕获 https://wapside.189.cn:9001/api/home/homeInfo 的完整 JSON 请求体，原样粘贴并确认属于本行账号。无需捕获或上传请求头。由 BoxJs 迁移时手动复制数据，不读取其私有文件。
- 填写格式：每个非空行填写手机号，或手机号|首页请求体JSON；只在第一个 | 分割，后续字符原样保留；不使用逗号、& 或 @ 分隔账号。配置此变量时优先于旧变量。

### 可选参数

### `chavy_mobile_10000`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游同名 BoxJs 手机号配置，手动迁移到环境变量；推荐使用 TELECOM_ACCOUNTS。
- 填写格式：仅在 TELECOM_ACCOUNTS 未设置时使用；每个非空行一个手机号。旧逗号格式需改为换行。

### `chavy_signbody_10000`

- 必填：否
- 敏感：是
- 获取或设置：从本人授权调试工具捕获同一接口的完整 JSON 请求体，或手动迁移上游同名存储值。推荐改为 TELECOM_ACCOUNTS 的同账号配套字段。
- 填写格式：完整非空 JSON 对象；只绑定旧手机号变量的第一个账号，不跨账号复用；设置 TELECOM_ACCOUNTS 后忽略。

### `TELECOM_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置。
- 填写格式：1 为完全离线预演，其他值为真实签到；预演不调用业务接口或通知组件。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中设置通知脚本选择列表；遵循仅通知选中脚本策略，此任务没有额外默认选中项。设置后替换默认列表。
- 填写格式：逗号、分号或空白分隔 catalog-id、脚本相对路径、文件名或文件名通配符；* 为全部，空值为全部禁用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 sendNotify.js 所在目录。未设置时检查 /ql/data/scripts 与 /ql/scripts。
- 填写格式：本地目录路径；组件缺失或失败只记录状态，不改变业务退出码。

## 多账号

每个非空行一个账号；手机号与可选首页请求体通过首个 | 配套绑定。各账号独立处理，任何账号或已配置的首页查询失败均整体非零退出。
