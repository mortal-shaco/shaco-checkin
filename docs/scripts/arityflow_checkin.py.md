# ArityFlow 独立子站签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/arityflow_checkin.py`
- 青龙命令：`python3 scripts/arityflow_checkin.py`
- 建议 Cron：`9 10 * * *`
- 发布哈希：`af407d680bf190e489478bf88113453c177cc662410e5b116910ba397be21c77`
- 许可证：`MIT`

## 脚本功能

- 独立子站账号登录及官方非敏感身份展示
- 查询今日签到状态，已签到时跳过提交
- 支持官方签到码和本人当次同源 Turnstile 令牌；未提供必要验证参数时明确失败
- 识别链接图片或内嵌图片验证码，最多四次换图重试
- 直接 HTTP 签到，支持显式可信 HTTPS API 代理
- 提交后只读复查确认签到，保留奖励与签到日期结果字段
- 每行一个账号、独立失败处理及非零失败退出码
- 保留原命令行单账号用法和结果字典字段
- 断网预演、时间轴日志、唯一结构化汇总和青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AF_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在官方独立签到子站注册账号；从主站 /api/status 的 checkin_url 或官方签到入口获取 HTTPS 子站地址。用户名和密码属于子站，不是主站 API Key。可选 code 从官方签到活动获取；可选 cf_token 从本人在同一子站完成人机验证后的浏览器开发者工具 /api/checkin 请求体获取，短时且通常单次有效，自动定时任务可能需要人工更新。
- 填写格式：每个非空行：HTTPS子站地址|JSON对象；对象必填字符串 username、password，可选字符串 code、cf_token。仅在第一个 | 处分割，其余内容按 JSON 解析；密码中的特殊字符遵循 JSON 转义规则。

### 可选参数

### `AF_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 执行完全断网预演；只验证配置，不证明真实签到成功。
- 填写格式：1、true、yes、on 启用，默认关闭

### `AF_PROXY`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写本人可信的 HTTPS API 转发根地址，代理将收到账号凭据；发送 X-Af-Proxy: 1，保持 TLS 校验并禁止重定向，不再兼容不可信自签证书。
- 填写格式：不含凭据、查询参数或片段的 HTTPS 根地址；默认直连

### `AF_REMOTE`

- 必填：否
- 敏感：否
- 获取或设置：原整段远程执行模式依赖外部应用，已禁用。迁移时清除此变量；非空会报告配置错误，避免静默改变行为。
- 填写格式：必须留空

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式设置通知名单，支持目录相对路径、文件名、文件名通配符或目录编号 5acc9f86bbf1003a。默认名单为空；设置空值关闭全部，星号选择全部。
- 填写格式：逗号、分号、空白或换行分隔

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录；也支持 import notify.send 和 /ql/data/scripts/notify.py、/ql/scripts/notify.py。预演只进行禁用网络的通知尝试。
- 填写格式：本机通知模块目录

## 多账号

每个非空行一个账号，地址和同账号配套字段合并在 AF_ACCOUNTS 中；只在首个 | 处分割。账号独立处理，任一账号失败时进程非零退出；旧命令行单账号参数仅在未设置 AF_ACCOUNTS 时兼容。
