# 天翼云盘每日签到及抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/189.py`
- 青龙命令：`python3 scripts/189.py`
- 建议 Cron：`44 10 * * *`
- 发布哈希：`f6ddc45a652f9a2e44c5b23853506fff5d3f139f62a3dbec473b19100a91fc54`
- 许可证：`MIT`

## 脚本功能

- 使用账号密码及 RSA 加密登录天翼云盘，兼容原单账号命令行参数。
- 每日签到领取空间，区分新签到和已经签到。
- 签到抽奖和相册签到抽奖，分别提供开关，默认均开启。
- 登录遇到验证码时给出官方客户端验证说明。
- 按行多账号独立会话和失败隔离，业务失败时非零退出。
- 请求超时、官方域名跳转限制和明确业务字段校验，不输出凭据或原始响应。
- 官方响应提供安全的非凭据公开身份时显示，手机号、会话和账号密码不输出。
- 完全断网预演、分阶段时间轴日志、账号统计、单行 TASK_SUMMARY JSON 和青龙脱敏通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `189_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在天翼云盘官网或官方客户端注册并设置登录密码；使用自己的登录账号和密码，无需抓包。若提示验证码，请先在官方客户端完成验证。兼容原 --username 和 --password 单账号参数，两者须同时提供，提供时优先于本变量；为避免进程参数泄漏，建议使用环境变量。
- 填写格式：每个非空行一个账号，格式为 账号|密码；仅在第一个 | 处分割，密码后续的 | 和空白保留，不使用 & 或 @ 分隔账号。

### 可选参数

### `189_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设置为 1 启用完全断网预演；预演不验证真实账号、不执行签到或抽奖，通知仅模拟。
- 填写格式：1/0、true/false、yes/no、on/off；默认 0。

### `189_DRAW_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：按需设为 0 跳过签到抽奖，保留上游默认开启。
- 填写格式：1/0、true/false、yes/no、on/off；默认 1。

### `189_DRAW_PHOTOS`

- 必填：否
- 敏感：否
- 获取或设置：按需设为 0 跳过相册签到抽奖，保留上游默认开启；仅请求抽奖，不上传照片、不启用相册备份，资格不足会报告失败。
- 填写格式：1/0、true/false、yes/no、on/off；默认 1。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要推送时填写本脚本目录编号 e9e87f29cf49ea77、安装后的文件名或 scripts 相对路径，支持文件名通配符和 *；设置后替换默认选择，空值禁用全部，未设置时本脚本不默认入选，QINGLONG_NOTIFY=1 可直接启用。
- 填写格式：逗号、分号、空白或换行分隔选择项。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写现有青龙通知模块所在目录；同时支持导入 notify.send，或使用 /ql/data/scripts、/ql/scripts 中的 notify.py、sendNotify.js；不下载或安装通知模块。
- 填写格式：本机已有通知目录路径。
