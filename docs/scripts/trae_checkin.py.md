# Trae 每日签到与积分查询

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/trae_checkin.py`
- 青龙命令：`python3 scripts/trae_checkin.py`
- 建议 Cron：`7,23,37 * * * *`
- 发布哈希：`48fcb1d1293f0294117939c644bdc2d29e6834e55f602867cf411c6a2082a19b`
- 许可证：`GPL-3.0`

## 脚本功能

- 每日签到：先查状态，按需领取积分并以同一设备复查确认；当日已核验完成的账号零请求复用本地状态。
- 独立积分查询：TRAE_TASK=credits 或 credits 命令只读查询；保留 entitlement 到 ide_user_ent_usage 的备用链，兼容用量汇总和权益包余额计算。
- 同账号网页会话换令牌、长效 sessionid 续期和显式桌面凭据回退，保留百分号编码、真实设备绑定及配套指纹。
- 桌面令牌自动续期、纯标准库 P-256 设备签名和客户端产品线回退；轮换令牌以 0600 权限原子缓存，兼容 JWT 标准及自定义到期声明。
- 显式凭据文件兼容：icubeAuth、storagePath、authPath 和 TRAE_AUTH_DIR；可选 cryptography 解密，显式存储可提供同设备证明，不扫描客户端目录。
- 显式 login 交互授权：本地回调和隐藏粘贴表单、超时控制、续期接口核验与安全凭据保存；无外部应用或其他仓库依赖。
- 每行多账号独立执行、旧参数兼容、指定账号筛选、默认全签与按小时轮签、北京时间早窗、限流冷却、可选熔断及错峰。
- 只使用官方成功证据判断签到及余额；公开昵称、用户名和 UID 可见，重复配置和失效凭据单独统计，任一账号未完成整体非零退出。
- 完全断网预演；时间轴、编号阶段、各账号和全任务统计、完成时间、通知状态及唯一单行 TASK_SUMMARY 结构化汇总。
- 按通知名单及全局开关调用青龙 notify.py 或 sendNotify.js，保留企业微信与 PushPlus 及其旧变量别名；预演提交脱敏摘要且拦截通知器网络、子进程和文件写入。
- 兼容 Worker 的 TRAE_TOKEN 换行账号格式和 JWT 到期提示，缺少本人真实设备号时失败。
- 官方余额成功响应提供权益包时，显示各包名称、总额、已用及剩余；保留原有汇总优先级及全部备用接口。
- 可选 WxPusher 汇总通知，与青龙、企业微信及 PushPlus 一样遵守全局开关和名单；通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TRAE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人官方客户端登录请求中获取 accessToken、同账号真实 x-device-id；可在本人已登录 www.trae.cn 的浏览器开发工具应用面板复制 X-Cloudide-Session 或 sessionid 的 Cookie Value。刷新证明取自同设备 storage.json；不分享、不提交这些值。
- 填写格式：每个非空行一个 JSON 对象：accessToken 或 refreshToken 或 session/sessionid，配套 deviceId 为 12 至 20 位数字；可含 deviceKeyPem、devicePubPem、machineId、fingerprint、uid、name、expiresAt、authPath、storagePath、icubeAuth。兼容旧 JSON 数组；正式签到可显式使用本人凭据文件，预演必须提供占位明文凭据。

### 可选参数

### `TRAE_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从本人官方客户端请求头复制 Authorization 的 JWT 及同账号 x-device-id；建议改用 TRAE_ACCOUNTS。
- 填写格式：可选旧输入，仅其他账号来源均为空时使用；每个非空行 TOKEN#x-device-id#备注；支持 Cloud-IDE-JWT 前缀；备注后续 # 保留；不提供共享设备兜底。

### `TRAE_TASK`

- 必填：否
- 敏感：否
- 获取或设置：根据本轮需要设置。
- 填写格式：checkin 默认签到与余额；credits 只查余额；login 显式本地交互授权；支持同名命令参数。

### `TRAE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网验证时设置为 1。
- 填写格式：1 启用，0 关闭；默认 0；不联网、不读取真实凭据文件、不写入文件。

### `WXPUSHER_APP_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在本人 WxPusher 应用后台取得应用令牌。
- 填写格式：可选；与 WXPUSHER_UID 配套；受 QINGLONG_NOTIFY 及通知名单控制。

### `WXPUSHER_UID`

- 必填：否
- 敏感：是
- 获取或设置：在本人关注 WxPusher 应用的用户信息中取得接收 UID。
- 填写格式：可选；一个本人通知接收 UID；不作为 Trae 账号分隔符。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：配置允许通知的任务名单。
- 填写格式：逗号、分号或空白分隔；支持 71de90498a3a6ded、trae_checkin.py、实际文件名、相对路径及文件名通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本人青龙通知器所在目录。
- 填写格式：目录内 notify.py 或 sendNotify.js；亦自动使用青龙标准通知位置；失败保留业务退出码。

### `TRAE_DEVICE_ID`

- 必填：否
- 敏感：是
- 获取或设置：从本人官方客户端请求头或 storage.json 的 iCubeAuthInfo://icube-dc:<数字> 取得真实设备号。
- 填写格式：12 至 20 位数字；login 必需，单账号兼容输入；多账号推荐写入各 JSON。

### `TRAE_AUTH_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在需要显式读取已授权文件或执行 login 时配置本人安全目录。
- 填写格式：目录中 auth-*.json；login 默认脚本旁 auths；不扫描客户端目录。

### `TRAE_STORAGE_PATH`

- 必填：否
- 敏感：是
- 获取或设置：可选提供本人安全上传的官方客户端 storage.json。
- 填写格式：显式本地文件路径；不自动扫描；加密内容需公开依赖 cryptography。

### `TRAE_ICUBE_AUTH`

- 必填：否

- 填写格式：加密存储值或 JSON；加密解密需 cryptography；不扫描客户端。

### `TRAE_DEVICE_KEY_PEM`

- 必填：否
- 敏感：是
- 获取或设置：从本人同设备存储中取得私钥。
- 填写格式：PEM 私钥；用于设备证明续期，推荐放入账号 JSON。

## 副作用与风险

- 正式 checkin 动作在官方状态确认未签到且开放时领取每日签到积分。
- 正式令牌续期可能轮换服务端 refreshToken；网页长效 Cookie 续期可能更新服务端会话，并将新凭据写入权限 0600 的本地缓存。
- 正式签到写入本地当天已核验状态及限流冷却记录。
- 显式 login 动作建立官方授权会话，监听本机回调并在核验后写入权限 0600 的本人授权文件。
- 通知策略选中且启用时，通过本人配置的青龙、企业微信或 PushPlus 渠道发送脱敏摘要；预演禁止网络投递及通知器文件写入。
- 显式配置 WxPusher 且通知策略允许时向本人接收 UID 发送脱敏汇总。
