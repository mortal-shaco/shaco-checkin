# Trae 每日签到与积分查询

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/trae_checkin.py`
- 青龙命令：`python3 scripts/trae_checkin.py`
- 建议 Cron：`7,23,37 * * * *`
- 发布哈希：`45962500ef7a2bad52fda864d421f76bf3639e6ee0fb6dee695b394eb34199b8`
- 许可证：`MIT`

## 脚本功能

- 每日查询签到状态、按需签到，官方已签不重复领取；签到后查询真实积分余额
- 独立 credits 模式显示总额、已用及余额，保留权益接口到用量接口的回退链
- 访问凭据复用、过期或鉴权失败自动续期，保留新版设备证明、IDE_PC、SOLO_PC 与旧客户端兼容链
- 即时安全缓存轮换后的凭据，后续复用最新访问及刷新凭据
- 多账号独立处理、指定账号筛选、北京时间小时轮签及早窗全签
- 北京时间当日去重、账号独立限流冷却、可选熔断、启动及账号间错峰
- 青龙通知、可选企业微信与 PushPlus，通知失败保留业务退出码
- 完全断网预演、编号时间轴、官方非敏感身份展示、分账号统计和唯一单行 TASK_SUMMARY
- 兼容显式明文及加密凭据、storage 文件和旧参数，无需桌面端或私有仓库
- 显式 login 交互登录，自带本机 HTTP 授权回调及隐藏粘贴表单，有限等待并通过续期接口核验
- 显式兼容 Trae Work auth 文件及 auth 目录，优先使用绑定 claimDeviceId 和同设备 fingerprint
- 兼容显式 RANDOM_SIGNIN、MAX_RANDOM_DELAY，保留规范脚本默认错峰及上游 8 点、20 点定时配置能力
- 网页会话换取访问令牌，长效 sessionid 在会话失效时续期并复用安全缓存
- 领取后复查今日签到状态，明确完成才写入去重状态
- 使用官方成功响应及安全缓存中的公开 UID 识别多个会话对应同一账号，单列重复配置统计；各条目仍独立核验签到状态和余额，不重复领取已经完成的签到
- 兼容主来源 account_name、expires_at 字段及显式 TRAE_JITTER_MAX，保留维护默认错峰和主来源 8 点 30 分定时配置能力
- 网页会话鉴权失效且已显式提供同账号桌面凭据时自动回退，不因网络错误切换账号或设备
- 领取接口报错后只读复查官方当日状态，确认已完成才能成功，未确认时保持失败及冷却
- 需更新凭据账号单独统计；逐字引用的 TRAE_ACCESS_TOKEN_2 至 _9 与实际解析一致，修正上次导入失败

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TRAE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：规范账号变量：在本人官方 Trae 中国版客户端登录响应或显式上传的 storage/auth 文件取得配套凭据；网页登录 https://www.trae.cn 后在浏览器开发者工具的应用、Cookie 中复制 X-Cloudide-Session 和 sessionid 的单个 Value，保留百分号编码。设备号从本人同账号客户端 storage.json 的 iCubeAuthInfo://icube-dc:<数字> 键取得；设备密钥和 machineId 必须来自同一设备。不要生成设备号、借用其他账号设备或分享凭据。
- 填写格式：每个非空行一个 JSON 对象；accessToken 或 refreshToken 或 session/sessionid 至少一种，配套 deviceId 为同账号真实 12 至 20 位数字。可选 deviceKeyPem、devicePubPem、machineId、uid、name、expiresAt、fingerprint；兼容 access_token、refresh_token、device_id、account_name、expires_at。显式 icubeAuth、storagePath 或 authPath 可替代明文凭据；旧 JSON 数组仅作兼容。预演只用占位明文，不读凭据文件。
