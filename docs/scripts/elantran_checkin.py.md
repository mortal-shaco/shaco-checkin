# Elantran社区签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/elantran_checkin.py`
- 青龙命令：`python3 scripts/elantran_checkin.py`
- 建议 Cron：`28 9 * * *`
- 发布哈希：`f108b0dc22c997a1db49f248d4fa65dd7553faadb04d5f83d94e75ce1cb53a90`
- 许可证：`MIT`

## 脚本功能

- Elantran 小程序每日社区签到，并查询签到状态与总积分
- 按星期执行社区互动：周五点赞最多 3 帖并可选发帖/评论，周末发帖与评论，工作日仅签到
- 正式运行发帖/评论优先使用一言公开文案并署名，失败回退本地文案；dry-run 不请求一言
- 解码 JWT 展示公开昵称与 UID 便于核对账号
- 支持多账号按行独立处理，任一账号失败则进程非零退出
- 支持 ELANTRAN_DRY_RUN 完全断网预演
- 按青龙通知策略发送脱敏任务摘要，并输出时间轴日志与 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ELANTRAN_AUTH`

- 必填：是
- 敏感：是
- 获取或设置：打开 Elantran 微信小程序，在开发者工具或抓包工具中查看业务请求的 Authorization 请求头，复制 Bearer 后的 JWT Token，写入青龙环境变量。不要把 Token 发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号的 JWT；账号之间只用换行分隔，勿使用 & 或 @。

### 可选参数

### `ELANTRAN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：1/true/yes/on 启用完全断网预演；其他或未设置表示正式运行

### `ELANTRAN_SKIP_SOCIAL`

- 必填：否
- 敏感：否
- 获取或设置：仅需每日签到、跳过周五点赞与周末发帖/评论时设为开启。默认关闭以保留上游按星期执行的社区互动。
- 填写格式：1/true/yes/on 跳过点赞/发帖/评论；缺省关闭

### `ELANTRAN_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：公开发帖/评论文案的本地兜底。断网预演、一言不可用或解析失败时使用。正式运行优先请求一言 HTTPS，且不会把账号凭据发给文案服务。
- 填写格式：纯文本，建议不超过 280 字

### `ELANTRAN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 90 的整数秒；默认 30

### `ELANTRAN_ACTION_DELAY_SEC`

- 必填：否
- 敏感：否
- 获取或设置：社区互动动作之间的间隔秒数。维护版默认 2 秒，替代上游 60–600 秒随机等待。
- 填写格式：0 至 120 的整数秒；默认 2

### `ELANTRAN_ACCOUNT_DELAY_SEC`

- 必填：否
- 敏感：否
- 获取或设置：多账号之间的间隔秒数。维护版默认 3 秒，替代上游固定 10 分钟。
- 填写格式：0 至 600 的整数秒；默认 3

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选。设置后替换默认可通知脚本名单；空值禁用全部；* 匹配全部。可用 catalog-id、文件名或 glob。
- 填写格式：逗号/分号/空白/换行分隔的选择器；空字符串禁用；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件

## 多账号

ELANTRAN_AUTH 每个非空行一个 JWT 账号；账号之间仅用换行分隔。账号逐个独立签到与互动；任一账号失败则整体非零退出。不使用 & 或 @ 分隔账号。
