- 建议 Cron：`1 11 * * *`

## 脚本功能

- 每日会员成长值签到
- 每日获取题目并提交接口提供的答案
- 查询会员等级与当前成长值
- 保留完整 Cookie 与单个 BDUSS 两种凭据输入，支持逐行多账号
- 离线配置检查和任务预演
- 逐阶段脱敏日志、账号统计和单行 TASK_SUMMARY 结构化汇总
- 按全局开关及脚本名单调用青龙通知，通知故障保留业务退出码
- 接口提供非敏感昵称、用户名或公开 UID 时显示账号身份

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BAIDUWP_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://pan.baidu.com，在开发者工具的网络面板选中本人已登录请求，复制完整 Cookie 请求头值，建议保留 BDUSS 和 STOKEN。也兼容仅填 BDUSS 的值，服务端要求额外凭据时需重新获取完整 Cookie。请勿分享凭据。
- 填写格式：每个非空行一个账号，填写完整 Cookie 或单个 BDUSS 值。Cookie 的每项仅在第一个等号处分割，后续等号保留。不使用 &&、&、@ 分隔账号，旧 && 配置需迁移为换行。

### 可选参数

### `BAIDUWP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线校验时手动设置为 1，正式运行时删除或设置为 0。
- 填写格式：1、true、yes、on 开启完全断网预演，其余值为正式执行。预演仍检查必填凭据格式。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写需要通知的脚本选择器，设置后替换默认空名单。
- 填写格式：用逗号、分号、空白或换行分隔目录编号、脚本相对路径、文件名或文件名通配符。可填 39580db6919e11a5 或 checkin_baiduwp.py，* 选择全部，空值禁用名单通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙自带通知模块时无需设置，自定义通知模块位置时填写其目录。
- 填写格式：包含 notify.py 或 sendNotify.js 的目录。依次尝试导入 notify.send、自定义目录及 /ql/data/scripts、/ql/scripts。JavaScript 通知需要青龙已安装 Node.js，业务请求仅依赖 Python 标准库。

## 多账号

BAIDUWP_COOKIE 每个非空行一个账号，同一账号的 Cookie 字段保留在同一行，逐账号独立处理。任一账号的配置、签到、答题或信息查询失败时整体非零退出。
