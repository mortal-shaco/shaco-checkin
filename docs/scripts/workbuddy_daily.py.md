## 脚本功能

- 国内默认任务保持每日签到、已达标成长奖励领取、猫猫旅行、Buddy信息和徽章查询；积分、用量、成长等级、能量、任务状态及两类连签保持可查询。
- 签到先探测开放与当日状态，领取后回读今日已签；旅行到达时提交服务端record_id并验证奖励积分，空闲派遣后回读；未知结构不能冒充成功。
- 国内兼容 --query、--refresh、--no-desktop、--only、--gap、--mp-gap、--tasks、--skip-tasks 和原任务代码；黑白名单控制主动任务，保留既有默认及副作用边界。
- 国内 --credit-report 为独立只读积分日报；--json 保留原脱敏数值数组，周期容量优先、累计容量回退及总用量补全算法保持不变；与刷新、查询及任务筛选互斥。国际版同样支持 --intl --credit-report --json。
- 可选抽奖、盲盒、连登兑换、昨日补签、礼包补偿保持独立任务开关，默认不消耗这些资源；补签按服务端日历选断点并可用 WORKBUDDY_MAKEUP_MAX_PER_RUN 限制张数；礼包与补偿先查状态再按回执积分确认。
- 显式授权的画布、灵感、专家团、应用、主题、资料库、专家、模板、GLM5.2对话、夜猫子及七环成长链保持原有真实对话、桌面事件、小程序事件与网页回退；每项以服务端终态核验，模拟上报不表示真实桌面业务。
- 链式任务第一至六环保留原小程序进度、接受、间隔抖动、回读及领奖；第七环优先PC任务列表、接受和桌面灵感事件，未下发时保留原小程序回退链。
- 新增显式选择的无畏契约拼豆专家及中国电商运营专家、抖音策略师、商家宣传页与海报设计师、直播电商教练；合法任务深链优先专家ID、精确市场查询、静态专家市场及已审核ID回退，保持真实对话与事件回退链。
- 新增显式授权的 daily_activity：事件上报后按热力图计分回读；可配置真实对话回退；不读写上游私有状态路径。
- 国内夜猫子 black_cat 保持北京时间23:00至次日08:00窗口，应单独以30 23 * * *运行并显式选中及授权；默认日常调度仍为0 7,12 * * *。
- 国际 --intl 保持独立凭据、活动状态探测、当日领奖与回读；关闭活动仅按已知业务码41000或明确状态处理。
- 国际保活须显式授权；保留四模型及自定义模型回退链，采用参考中5.8.4请求头，每次生成会话与追踪标识，SSE需有效回答及完成标志才成功；保活与领奖分开核验。
- 国际 --intl --trial 保持独立的一次性专家加油包领取，HTTP及业务码核验，14051表示已领；与日报、刷新和保活开关互斥，不加入默认日常任务。
- 国内事件头与桌面指纹对齐官方5.9.3（UA、commit、releaseDate、qimei36）；续期只使用官方HTTPS接口，轮换前检查本人指定0600缓存可写并原子保存；不依赖其他仓库、桌面程序或安装引导。
- 逐行多账号、完全断网预演、有限超时、HTTPS证书验证、禁止重定向、响应大小上限、逐阶段脱敏日志、官方非敏感身份原样显示、账号与任务统计，以及唯一单行TASK_SUMMARY汇总。
- 所有终态及配置错误均生成脱敏通知摘要，遵循全局开关与选择清单，支持青龙notify.py或sendNotify.js；预演模拟发送，通知缺失或失败保留业务退出码。
- 新增独立只读 --status / -s 签到面板，查询官方活动状态；--status --json输出上游账号结果结构，原 --credit-report --json数值数组保持不变。
- 新增活动周期、每日及今日积分、累计积分、奖励节点及距离、周打卡标记和计数、本期打卡日历最近14条、网页入口提示；仅整理已有官方查询字段，不额外执行网页操作。
- 新增逐行WB_ACCESS_TOKEN与WB_ACCESS_TOKENS兼容输入、单账号WB_USER_ID、可选WB_PROXY及只读状态查询WB_RETRY；账号分隔统一为换行。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WORKBUDDY_REFRESH_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录本人 WorkBuddy 国内官方网页，在浏览器开发者工具网络面板查看签到请求的 Authorization Bearer 值作为AT；RT仅从本人官方登录或续期响应取得。只复制明文值，加密信封不可用。无需其他仓库或客户端程序。
- 填写格式：国内任务必填规范变量，每个非空行一个账号，支持单个JWT、AT:RT、手机号:AT:RT或手机号:RT；国际独立任务改用WORKBUDDY_INTL_TOKENS。只在首个字段边界拆分配套凭据，RT后续文本保留。

### 可选参数

### `WORKBUDDY_INTL_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：登录本人 www.workbuddy.ai 官方网站，从本人官方授权响应取得AT和可选RT，公开uid从本人账号资料或官方响应取得；国内版凭据不可混用。
- 填写格式：运行 --intl 时必填；每行AT或备注|AT|uid|RT，RT后续文本保留。

### `WORKBUDDY_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：登录本人 www.workbuddy.ai 官方网站，从本人官方授权响应取得AT和可选RT，公开uid从本人账号资料或官方响应取得；国内版凭据不可混用。
- 填写格式：国际版旧单账号AT别名，仅规范国际变量为空时使用。

### `WB_ACCESS_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：登录本人 WorkBuddy 国内官方网页，在浏览器开发者工具网络面板查看签到请求的 Authorization Bearer 值作为AT；RT仅从本人官方登录或续期响应取得。只复制明文值，加密信封不可用。无需其他仓库或客户端程序。
- 填写格式：国内旧别名，每个非空行AT或uid:AT；规范变量优先，多个账号禁止逗号分隔。

### `WB_ACCESS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：登录本人 WorkBuddy 国内官方网页，在浏览器开发者工具网络面板查看签到请求的 Authorization Bearer 值作为AT；RT仅从本人官方登录或续期响应取得。只复制明文值，加密信封不可用。无需其他仓库或客户端程序。
- 填写格式：国内旧别名，每个非空行AT或uid:AT；规范变量优先，与旧多账号变量合并读取。

### `WB_USER_ID`

- 必填：否
- 敏感：是
- 获取或设置：从本人官方账户响应或JWT的sub字段取得，用于旧变量的X-User-Id请求头。
- 填写格式：仅旧单账号有效；多账号须逐行uid:AT。

### `WB_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：按本人可信代理服务配置，脚本默认直接访问官方HTTPS接口。
- 填写格式：HTTP或HTTPS代理URL，可包含敏感代理认证信息，不输出日志。

### `WB_RETRY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中按需要设置，只影响 --status 的只读请求。
- 填写格式：0至5的整数，默认2；只重试网络错误或HTTP 5xx，不重试签到写入。

### `WORKBUDDY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无凭据联网测试需求时在青龙设置为1。
- 填写格式：1/true/yes/on启用完全断网预演；默认0。

### `WORKBUDDY_INTL_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：国际版可独立设置为1。
- 填写格式：1/true/yes/on，仅 --intl 有效。

### `WORKBUDDY_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：根据脚本帮助和任务代码按需选择；不设置时保持默认日常动作。
- 填写格式：逗号或空格分隔任务名，不用于分隔账号；默认checkin travel claim buddy_info badges。支持lottery blindbox redeem gift makeup daily_activity及原成长任务代码。

### `WORKBUDDY_ONLY_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：旧任务筛选变量，优先使用WORKBUDDY_TASKS。
- 填写格式：逗号或空格分隔任务名，仅规范变量未设置时使用。

### `WORKBUDDY_SKIP_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中设置要排除的原任务代码。
- 填写格式：逗号或空格分隔任务名；--tasks和--skip-tasks命令行参数优先。

### `WORKBUDDY_ALLOW_REPORT`

- 必填：否
- 敏感：否
- 获取或设置：本人理解模拟事件、真实对话及积分消耗后显式设置。
- 填写格式：仅1授权已显式选中的成长事件或每日活跃任务；默认未授权。

### `WORKBUDDY_ACTIVITY_CHAT_FALLBACK`

- 必填：否
- 敏感：否
- 获取或设置：本人按每日活跃回退需求设置。
- 填写格式：0关闭事件未计分时的真实对话回退，默认启用；前提为显式选中daily_activity且授权事件。

### `WORKBUDDY_MP_GAP`

- 必填：否
- 敏感：否
- 获取或设置：按小程序对话频率需要设置或使用 --mp-gap。
- 填写格式：有限非负秒数，默认45。

### `WORKBUDDY_MAKEUP_MAX_PER_RUN`

- 必填：否
- 敏感：否
- 获取或设置：显式选择makeup后按可接受补签卡消耗设置。
- 填写格式：默认1，范围1至10。

### `WORKBUDDY_TOKEN_STORE`

- 必填：否
- 敏感：是
- 获取或设置：本人指定私有可写缓存文件位置，所在目录须已存在；已有文件须为本人专用普通文件且权限0600。
- 填写格式：可选本机文件路径，仅续期保存时使用；只有RT或显式 --refresh 时必填，不上传公开仓库。

### `WORKBUDDY_INTL_TOKEN_STORE`

- 必填：否
- 敏感：是
- 获取或设置：本人指定国际版私有缓存文件位置，所在目录须存在，已有文件权限0600。
- 填写格式：国际版显式 --refresh 时必填，原子保存轮换令牌。

### `WORKBUDDY_INTL_KEEPALIVE`

- 必填：否
- 敏感：否
- 获取或设置：本人允许模型调用和潜在积分消耗后设置，或使用 --keepalive。
- 填写格式：1/true/yes/on启用，默认关闭；--no-keepalive优先关闭。

### `WORKBUDDY_INTL_MODELS`

- 必填：否
- 敏感：否
- 获取或设置：按本人可用官方模型名称选择，留空使用原四模型回退链。
- 填写格式：逗号分隔模型名称，仅保活启用后使用。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙设置通知选择清单，配置后替代默认选择。
- 填写格式：逗号、分号、空白或换行分隔目录标识、脚本路径、文件名或通配符；*全部，空值禁用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写已有青龙notify.py或sendNotify.js所在目录。
- 填写格式：可选本机目录；同时支持import notify及青龙标准目录。

## 多账号

每个非空行一个账号，国内配套凭据使用同一行，国际版凭据独立；账号按序处理，任一账号失败整体非零退出。旧变量只在国内规范变量为空时读取。

## 副作用与风险

- 默认执行可能每日签到、领取已完成成长任务奖励、领取已到达旅行奖励或派遣空闲Buddy旅行。
- 国内只有RT、显式--refresh或配置私有缓存后满足原按需条件时，轮换令牌并原子写入本人指定0600缓存；国际仅显式--refresh时轮换。
- 显式选择lottery、blindbox、redeem、makeup、gift时分别消耗抽奖次数、能量、兑换连登奖励、消耗补签卡、领取礼包与补偿。
- 显式选择成长任务且WORKBUDDY_ALLOW_REPORT=1时接受任务、上报事件、创建对话或安装热门技能、改变主题、领取奖励；新建的网页会话在调用结束时发送停止请求，仅操作本次创建的会话；模型对话可能消耗积分。
- 显式选择daily_activity且授权时发送活跃事件，按配置可能补一次真实模型对话。
- 国际默认按开放状态领取当日奖励；显式保活可能消耗模型积分，--trial可能领取一次性专家加油包。
- 实际执行且通知被策略选中时，通过现有青龙通知模块投递脱敏任务总结。
