## 脚本功能

- 国内默认任务保持每日签到、已达标成长奖励领取、猫猫旅行、Buddy信息和徽章查询；积分、用量、成长等级、能量、任务状态及两类连签保持可查询。
- 签到先探测开放与当日状态，领取后回读今日已签；旅行到达时提交服务端record_id并验证奖励积分，空闲派遣后回读；未知结构不能冒充成功。
- 国内兼容 --query、--refresh、--no-desktop、--only、--gap、--mp-gap、--tasks、--skip-tasks 和原任务代码；黑白名单控制主动任务，保留既有默认及副作用边界。
- 国内 --credit-report 为独立只读积分日报；--json 保留原脱敏数值数组，周期容量优先、累计容量回退及总用量补全算法保持不变；与刷新、查询及任务筛选互斥。国际版同样支持 --intl --credit-report --json。
- 可选抽奖、盲盒、连登兑换、昨日补签、礼包补偿保持独立任务开关，默认不消耗这些资源；补签按服务端日历选断点并可用 WORKBUDDY_MAKEUP_MAX_PER_RUN 限制张数；礼包与补偿先查状态再按回执积分确认。
- 显式授权的画布、灵感、专家团、应用、主题、资料库、专家、模板、GLM5.2对话、夜猫子及七环成长链保持原有真实对话、桌面事件、小程序事件与网页回退；每项以服务端终态核验，模拟上报不表示真实桌面业务。
- 链式任务第一至六环保留原小程序进度、接受、间隔抖动、回读及领奖；第七环优先PC任务列表、接受和桌面灵感事件，未下发时保留原小程序回退链。
- 新增显式选择的无畏契约拼豆专家及中国电商运营专家、抖音策略师、商家宣传页与海报设计师、直播电商教练；合法任务深链优先专家ID、精确市场查询、静态专家市场及已审核ID回退，保持真实对话与事件回退链。
- 新增显式授权的 daily_activity：事件上报后按热力图计分回读；可配置真实对话回退；不读写上游私有状态路径。
- 国内夜猫子 black_cat 保持北京时间23:00至次日08:00窗口，应单独以30 23 * * *运行并显式选中及授权；默认日常调度仍为0 7,12 * * *。
- 国际 --intl 保持独立凭据、活动状态探测、当日领奖与回读；关闭活动仅按已知业务码41000或明确状态处理。
- 国际保活须显式授权；保留四模型及自定义模型回退链，采用参考中5.8.4请求头，每次生成会话与追踪标识，SSE需有效回答及完成标志才成功；保活与领奖分开核验。
- 国际 --intl --trial 保持独立的一次性专家加油包领取，HTTP及业务码核验，14051表示已领；与日报、刷新和保活开关互斥，不加入默认日常任务。
- 国内事件头与桌面指纹对齐官方5.9.3（UA、commit、releaseDate、qimei36）；续期只使用官方HTTPS接口，轮换前检查本人指定0600缓存可写并原子保存；不依赖其他仓库、桌面程序或安装引导。
- 逐行多账号、完全断网预演、有限超时、HTTPS证书验证、禁止重定向、响应大小上限、逐阶段脱敏日志、官方非敏感身份原样显示、账号与任务统计，以及唯一单行TASK_SUMMARY汇总。
- 所有终态及配置错误均生成脱敏通知摘要，遵循全局开关与选择清单，支持青龙notify.py或sendNotify.js；预演模拟发送，通知缺失或失败保留业务退出码。
- 新增独立只读 --status / -s 签到面板，查询官方活动状态；--status --json输出上游账号结果结构，原 --credit-report --json数值数组保持不变。
- 新增活动周期、每日及今日积分、累计积分、奖励节点及距离、周打卡标记和计数、本期打卡日历最近14条、网页入口提示；仅整理已有官方查询字段，不额外执行网页操作。
- 新增逐行WB_ACCESS_TOKEN与WB_ACCESS_TOKENS兼容输入、单账号WB_USER_ID、可选WB_PROXY及只读状态查询WB_RETRY；账号分隔统一为换行。
- 新增独立 --school 开学季入口，默认只读活动期与任务状态；不串联日常签到、国际任务或刷新，保持不同活动窗口与风险边界。
- 开学季显式选择 --school-tasks query,share,report,claim,lottery；已知分享、三次小程序对话事件、桌面对话事件和开学季专家事件保留上游字段，以官方任务终态回读确认；report 另需事件授权，不声称真实桌面操作。
- 开学季奖励仅对已完成任务领取并回读 claimed；抽奖先查余额、使用独立请求标识并核验奖品回执，每轮有次数上限且不重试写请求。学生认证、未知任务和协议由本人处理。
- 开学季专家从官方 BackToSchool 分类查询，缺失时失败闭合，不伪造专家标识；HTTP、业务码、活动期或字段不明确均非成功。
- 开学季显式选择 growth 且授权时处理已知 school_season 小程序成长任务，复用维护版小程序接受、间隔与上报流程，以 claimed 终态核验；未下发或未解锁则跳过，不适配未知任务。
- 合并 Cookie 认证的加油站每日签到；--buddy-cookie 为独立入口，--check 仅查询，保留主题、今日状态、连续天数与累计积分；领取后回读核验，已签跳过。
- 仅配置 BUDDY_COOKIE 且无参数、无原令牌变量时兼容直接运行；同时配置凭据时默认维持原日常任务，Cookie 入口拒绝混入国际、成长或续期参数。
- Cookie 逐行独立账号，内存会话支持服务端轮换、删除和过期；有限超时与响应大小限制、禁重定向、断网预演、脱敏日志及通知；无需浏览器或私有模块。
- 日常保持 0 7,12 * * *；Cookie 入口可独立以 54 10 * * * 运行；夜猫子及开学季调度保持既有约定。
- 合并每日积分独立入口 --daily-checkin，兼容 --token 与 WB_DAILY_CHECKIN_TOKEN；仅配置此变量时支持无参数执行，与其他凭据同时配置时显式选择。
- 保留用户、组织、租户请求头与可选本人本机登录文件；无需安装客户端，环境凭据即可独立执行。
- 国内签到及新入口按原顺序回退两个官方状态接口；状态未知时停止领取，写请求仅一次并回读今日已签。
- 独立入口保留本次积分、累计积分、余额、连签与活动名称的逐账号 JSON，正确保留数值零；38 9 * * * 可单独调度。
- 新增独立旅行只读详情和到达倒计时、官方目的地选择，以及显式授权的领奖后连续派遣；兼容 travel、--travel-status、--travel-auto、--location、--no-travel、--check-only、--no-notify。
- 按青龙每日调度查询状态后领取 WorkBuddy 每日签到积分；服务端已签到则跳过领取。
- 支持 status 参数只查询今日状态、连续天数、累计积分和签到日期；支持 --json 逐账号结构化结果
- 签到响应须有明确业务码并二次查询确认；状态查询超时和临时 HTTP 错误最多尝试四次
- 多账号隔离执行、旧令牌变量兼容、断网预演、时间轴日志、脱敏通知与单行机器汇总
- 状态查询按来源顺序回退两个官方状态接口和两个官方域名；认证失败停止回退，领取请求仅一次。
- 显式 --verify-wallet 查询真实账户余额，领取前后按资源包比较增长与失效，增长不足时短暂等待后只读复查并失败闭合；status 模式仅查询。
- 兼容 --status 只读入口；沿用维护发布调度每日10:38，可自行配置原每日09:30。
- 新增独立只读 credits / --expire 积分到期入口，按资源汇总提供的包代码查询付费和免费逐笔记录，分页有界、按账号去重并按到期排序；缺字段、业务失败或分页不完整均失败退出。
- 展示逐笔剩余、总量、获取方式、使用状态、到期和周期刷新时间；优先扣减结束时间，再取周期结束和失效时间，兼容秒、毫秒与北京时间字符串。
- 支持 --expiring-days 非负天数筛选和 --html 安全转义片段；以使用中记录为中心展示前后各十笔，--json 保留完整脱敏明细；入口仅查询且独立于签到、余额增长核验。
- 通过 --local-daily 将新积分明细入口合入现有规范脚本；同时配置凭据时默认仍运行原日常任务。
- 显式 --tasks accept 按每批最多20项接取未锁定的待接任务，逐条核对回执并回读 accepted、in_progress、completed 或 claimed；默认不接单，首只 Buddy 协议由本人处理。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WORKBUDDY_REFRESH_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：从本人已登录的官方网页开发者工具网络面板取得请求 Authorization 的 Bearer 值，或本人官方授权登录响应取得明文 accessToken、refreshToken；不复制加密信封，不依赖程序解密，不在日志中公开。
- 填写格式：国内版必填的规范变量。每个非空行一个账号：AT:RT、手机号:AT:RT、手机号:RT 或单个 JWT；仅在首字段与配套字段处各切分一次，后续令牌文本完整保留。国际版 --intl 时改用 WORKBUDDY_INTL_TOKENS。；Cookie 加油站独立入口无需配置，改用 BUDDY_COOKIE。

### `WORKBUDDY_INTL_TOKENS`

- 必填：是
- 敏感：是
- 获取或设置：从本人 www.workbuddy.ai 官方授权登录响应获取明文 AT、可选 RT 和公开 UID；与国内版不通用。
- 填写格式：国际版 --intl 时必填；每个非空行 AT 或 备注|AT|uid|RT；国内版无需设置。

### `BUDDY_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.workbuddy.cn，在开发者工具的网络面板找到 /billing/meter/checkin-status 的 POST 请求，复制请求头 Cookie 的完整值。失效后重新登录获取。仅用于本人账号。
- 填写格式：每个非空行一个账号，填写完整 Cookie 值（名称=值；多项使用英文分号），不包含 Cookie: 前缀，不以 &、@ 或分号分隔账号。等号后的凭据文本保持完整。；仅加油站入口必填，同时配置令牌时使用 --buddy-cookie 显式运行。

### `WB_DAILY_CHECKIN_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在本人已登录的 WorkBuddy 客户端登录信息中读取 auth.accessToken 或 auth.access_token；也可从本人向 https://www.codebuddy.cn 发起的已认证请求中获取 Authorization 的 Bearer 令牌部分。不要分享或公开这些值。macOS 文件位于 ~/Library/Application Support/CodeBuddyExtension/Data/Public/auth/workbuddy-desktop.info；Windows 位于 LOCALAPPDATA 或 APPDATA 下相同相对路径；Linux 位于 XDG_DATA_HOME 或 ~/.local/share 下相同相对路径。可在无客户端的青龙环境直接填写令牌，无需复制客户端或安装额外程序。
- 填写格式：每个非空行一个账号；每行为原始令牌、uid+token（只在第一个 + 处分割），或单行 JSON 对象，字段 token 必填，uid、org、domain 可选。uid 对应 account.uid/id，org 对应 account.enterpriseId/enterprise_id，domain 对应 auth.domain 或根级 domain。不同账号只能换行分隔。兼容 --token 参数优先输入；未配置环境变量时可选读取本人本机登录文件。；仅独立 --daily-checkin 入口必填；与原凭据同时配置时须显式选择该入口。

### `WORKBUDDY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人已登录的 WorkBuddy 会话开发者工具 Network 中查看 checkin-activity-status 请求，复制 X-User-Id 及 Authorization 的 Bearer 后的访问令牌。无法打开开发者工具时向官方客户端支持查询本人访问令牌的获取方式；不扫描进程，不上传请求。
- 填写格式：每个非空行一个 uid|accessToken，仅按首个 | 分隔；令牌过期后重新获取。

### 可选参数

### `WB_ACCESS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从本人已登录的官方网页开发者工具网络面板取得请求 Authorization 的 Bearer 值，或本人官方授权登录响应取得明文 accessToken、refreshToken；不复制加密信封，不依赖程序解密，不在日志中公开。 旧变量仅在规范变量为空时兼容。
- 填写格式：可选旧别名；每行 AT 或 uid:AT；兼容 Bearer 前缀。

### `WB_ACCESS_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：从本人已登录的官方网页开发者工具网络面板取得请求 Authorization 的 Bearer 值，或本人官方授权登录响应取得明文 accessToken、refreshToken；不复制加密信封，不依赖程序解密，不在日志中公开。 旧变量仅在规范变量为空时兼容。
- 填写格式：可选旧别名；每行 AT 或 uid:AT。

### `WB_USER_ID`

- 必填：否
- 敏感：否
- 获取或设置：从本人官方账号响应取得公开 UID；配合旧别名使用。
- 填写格式：仅限单账号；多账号必须逐行 uid:AT。

### `WORKBUDDY_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从本人国际版官方授权登录响应取得明文 AT。
- 填写格式：国际版规范变量未设置时兼容的单账号 AT。

### `WORKBUDDY_TOKEN_STORE`

- 必填：否
- 敏感：是
- 获取或设置：本人创建私有可写目录并指定缓存文件，不上传仓库；续期前会检查权限与可写性。
- 填写格式：可选绝对路径；已有文件须普通文件、非符号链接且权限0600。只有 RT、--refresh 或按需轮换时必须设置。

### `WORKBUDDY_INTL_TOKEN_STORE`

- 必填：否
- 敏感：是
- 获取或设置：本人创建私有可写目录并指定国际版令牌缓存文件，不上传仓库。
- 填写格式：可选绝对路径；仅 --intl --refresh 使用，已有文件须普通文件且权限0600。

### `WORKBUDDY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中自行设置。
- 填写格式：1、true、yes 或 on 开启完全断网预演；默认0。

### `WORKBUDDY_INTL_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中自行设置。
- 填写格式：国际版兼容预演开关；1、true、yes 或 on 开启，默认0。

### `WORKBUDDY_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需自行选择 --tasks 同名任务；默认只选签到、旅行、已完成任务领奖、Buddy信息和徽章。
- 填写格式：逗号或空白分隔任务名：checkin、travel、claim、buddy_info、badges、lottery、blindbox、redeem、gift、makeup、daily_activity，以及现有成长任务名或任务代码。；新增 accept 显式批量接单，可与 checkin、claim、travel 同轮组合；不加入默认任务。

### `WORKBUDDY_ONLY_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需自行设置；WORKBUDDY_TASKS 未设置时兼容。
- 填写格式：与 WORKBUDDY_TASKS 相同的可选旧别名。

### `WORKBUDDY_SKIP_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需自行设置，或用 --skip-tasks。
- 填写格式：逗号或空白分隔需排除的日常任务名；不用于 --school。

### `WORKBUDDY_ALLOW_REPORT`

- 必填：否
- 敏感：否
- 获取或设置：理解会发送模拟遥测、创建对话或改变主题等行为后自行设置。
- 填写格式：仅精确值1授权已显式选中的成长任务和开学季 report、growth；默认不授权。

### `WORKBUDDY_ACTIVITY_CHAT_FALLBACK`

- 必填：否
- 敏感：否
- 获取或设置：按需自行设置。
- 填写格式：daily_activity 热力图未计分时的真实对话回退；默认开启，0、false、no 或 off 关闭。

### `WORKBUDDY_MP_GAP`

- 必填：否
- 敏感：否
- 获取或设置：按需自行设置或用 --mp-gap。
- 填写格式：小程序对话间隔秒数，默认45，有限非负数。

### `WORKBUDDY_MAKEUP_MAX_PER_RUN`

- 必填：否
- 敏感：否
- 获取或设置：按需自行设置。
- 填写格式：每轮最多补签张数，默认1，范围1至10。

### `WORKBUDDY_INTL_KEEPALIVE`

- 必填：否
- 敏感：否
- 获取或设置：理解模型调用可能消耗积分后自行设置；也可用 --keepalive，--no-keepalive 优先关闭。
- 填写格式：1、true、yes 或 on 开启；默认0。

### `WORKBUDDY_INTL_MODELS`

- 必填：否
- 敏感：否
- 获取或设置：按需从官方当前支持模型中自行选择；未设置时保留维护版四模型回退链。
- 填写格式：可选逗号分隔模型名，依次回退。

### `WB_PROXY`

- 必填：否

## 副作用与风险

- 默认执行可能每日签到、领取已完成成长任务奖励、领取已到达旅行奖励或派遣空闲Buddy旅行。
- 国内只有RT、显式--refresh或配置私有缓存后满足原按需条件时，轮换令牌并原子写入本人指定0600缓存；国际仅显式--refresh时轮换。
- 显式选择lottery、blindbox、redeem、makeup、gift时分别消耗抽奖次数、能量、兑换连登奖励、消耗补签卡、领取礼包与补偿。
- 显式选择成长任务且WORKBUDDY_ALLOW_REPORT=1时接受任务、上报事件、创建对话或安装热门技能、改变主题、领取奖励；新建的网页会话在调用结束时发送停止请求，仅操作本次创建的会话；模型对话可能消耗积分。
- 显式选择daily_activity且授权时发送活跃事件，按配置可能补一次真实模型对话。
- 国际默认按开放状态领取当日奖励；显式保活可能消耗模型积分，--trial可能领取一次性专家加油包。
- 实际执行且通知被策略选中时，通过现有青龙通知模块投递脱敏任务总结。
- 仅显式选择开学季 share 时激活已知分享任务并提交微信分享完成状态，不向外发布文本。
- 仅显式选择开学季 report 且事件授权开启时激活已知任务并发送小程序、桌面或专家遥测，改变活动任务进度。
- 仅显式选择开学季 claim 时领取已完成活动奖励；选择 lottery 时消耗至多指定次数的开学季抽奖机会。
- 仅显式选择开学季 growth 且授权时，接受已知 school_season 成长任务、发送带活动标记的小程序事件并领取达标奖励。
- Cookie 加油站入口为尚未签到的账号领取每日奖励；--check 只查询。服务端轮换 Cookie 仅存于本轮账号内存。
- 仅选择每日积分独立入口时，为官方状态确认未签且未明确关闭活动的账号领取每日积分，并回读今日已签。
- 仅显式 --travel-auto 时，已到达旅行领奖后回读空闲和当日上限，再派遣下一次旅行。
- 仅选择 --local-daily run 且服务端确认尚未签到时领取每日积分，并回读今日已签；--verify-wallet 额外只读核验资源包增长。
- 仅显式选择 accept 时批量接取待接成长任务，改变任务接受状态；不执行任务事件、模型对话或协议确认。
