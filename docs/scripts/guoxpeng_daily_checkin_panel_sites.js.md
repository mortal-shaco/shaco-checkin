## 脚本功能

- 适配安装 k_misign 插件的 Discuz 论坛，支持论坛安装子目录及可选浏览器标识
- 保留 base_url、cookie、user_agent 参数名称，提供每行一个账号的青龙环境变量入口
- 检查今日签到排名，已完成时避免重复操作；提取签到按钮链接执行，并重新读取签到页严格复核排名
- 显示确认页的奖励；官方登录用户区返回昵称或公开 UID 时显示非敏感身份
- 识别登录失效、人机验证、HTTP 错误、空响应、超时、响应超限及异常编码，无法确认成功时非零退出
- HTTPS 同源凭据隔离和有限重定向，拒绝非签到端点及操作，不记录凭据或原始响应
- 完全断网预演、逐账号分阶段计时、子任务统计、最终状态和单行 TASK_SUMMARY 结构化汇总
- 遵循青龙通知开关与选择列表发送脱敏汇总，模块缺失、通知失败或超时不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MISIGN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录目标 Discuz 论坛，必要时先完成人机验证；F12 网络面板访问 plugin.php?id=k_misign:sign，复制请求头 Cookie 的值。论坛地址应为实际安装首页，包含子目录。可选 user_agent 从同一请求头 User-Agent 获取。
- 填写格式：每个非空行一个 JSON 对象，字段为 base_url、cookie 和可选 user_agent；也支持 论坛地址|Cookie，仅在首个竖线分割，后续凭据文本完整保留。不使用 & 或 @ 分隔账号。地址无协议时补 HTTPS，只接受不含凭据、查询和片段的 HTTPS 首页地址。

### 可选参数

### `MISIGN_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：可选：从获取 Cookie 时的浏览器请求头复制 User-Agent；账号 JSON 的 user_agent 优先，未配置使用原脚本默认值。
- 填写格式：单行可打印英文请求头值

### `MISIGN_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：可选：按网络情况设置，默认 15000。
- 填写格式：1000～60000 的整数，单位毫秒，覆盖单次请求、重定向及响应读取

### `MISIGN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设置为 1 进行完全断网预演，不请求网站或调用通知发送器；不设置执行正式签到。
- 填写格式：1 表示断网预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选：通知脚本选择列表，设置时替换默认空列表。支持目录编号、脚本相对路径、文件名和星号文件名通配符；* 匹配全部，空值禁用全部自动通知。
- 填写格式：逗号、分号、空白或换行分隔的选择列表

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙 sendNotify.js 所在目录；不配置时探测 /ql/data/scripts 和 /ql/scripts。通知失败只记录提示，保留签到退出码。
- 填写格式：本机青龙通知模块目录路径
