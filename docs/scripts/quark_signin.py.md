# 夸克网盘每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/quark_signin.py`
- 青龙命令：`python3 scripts/quark_signin.py`
- 建议 Cron：`13 18 * * *`
- 发布哈希：`7315dc777e89a94234068968658eb4d3d879265fa426080ac6d60fd318c78763`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 验证夸克账号 Cookie 并显示官方返回的昵称或公开身份
- 查询当日签到状态，识别今日已签到
- 领取每日存储空间奖励并展示奖励和连签进度
- 换行配置多账号，独立处理并汇总失败
- 可选随机延迟、请求超时、完全断网预演
- 脱敏时间轴日志、账号及任务统计、结构化汇总和青龙通知
- 失败时输出固定响应字段的类型及有限数字业务码，辅助定位问题且不输出原始响应
- 同一账号变量可选择网页 Cookie 或移动端 kps、sign、vcode 组合凭据；移动端按上游明确的请求参数认证和签到，默认网页模式保持不变
- 有效字段存在时展示官方会员类型、总容量及签到累计获得容量
- 移动端凭据缺项、重复项或非法格式在断网预演及实时模式中明确失败，不输出凭据
- 展示官方已用容量、使用百分比及会员到期时间，零总容量时安全处理。
- 兼容主来源 QUARK_KPS、QUARK_SIGN、QUARK_VCODE 单账号参数，规范变量优先。
- 支持可选 SMTP 邮件摘要，使用经过证书校验的 TLS、连接超时和全局通知开关。
- 签到后重新查询并核验今日签到状态，移动模式清除查询缓存后复查。
- 支持通知清单选择及受断网约束的通知预演，通知失败保留业务退出码。
- 移动参数百分号解码后单次请求编码，保留字面加号与等号。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `QUARK_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：网页模式：登录 https://pan.quark.cn/，在浏览器开发者工具网络面板复制自己的请求头 Cookie 完整值。移动模式：登录夸克手机应用，从自己的 capacity/growth/info 或 growth/sign 请求查询参数获取同账号 kps、sign、vcode，保留原始编码。
- 填写格式：每个非空行一个账号；网页为完整 Cookie 或 pc|完整 Cookie；移动为 mobile|kps=值;sign=值;vcode=值。仅按首个 | 切分模式，不使用 & 或 @ 分隔账号。

### 可选参数

### `QUARK_KPS`

- 必填：否
- 敏感：是
- 获取或设置：兼容主来源旧单账号配置，从自己的手机应用容量接口获取对应参数。QUARK_COOKIE 非空时优先，建议迁移到规范变量。
- 填写格式：三项配套填写同一账号的原始编码值，不接受多行。

### `QUARK_SIGN`

- 必填：否
- 敏感：是
- 获取或设置：兼容主来源旧单账号配置，从自己的手机应用容量接口获取对应参数。QUARK_COOKIE 非空时优先，建议迁移到规范变量。
- 填写格式：三项配套填写同一账号的原始编码值，不接受多行。

### `QUARK_VCODE`

- 必填：否
- 敏感：是
- 获取或设置：兼容主来源旧单账号配置，从自己的手机应用容量接口获取对应参数。QUARK_COOKIE 非空时优先，建议迁移到规范变量。
- 填写格式：三项配套填写同一账号的原始编码值，不接受多行。

### `QUARK_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行配置，离线验收时启用。
- 填写格式：1/true/yes/on 启用；默认关闭。

### `QUARK_TIMEOUT_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：按网络环境自行配置。
- 填写格式：3 至 60 的整数秒，默认 15。

### `QUARK_RANDOM_DELAY_MAX_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：需要错峰时自行配置。
- 填写格式：0 至 3600 的整数秒，默认 0；每个正式账号随机等待，预演不等待。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写希望发送通知的脚本选择器。
- 填写格式：逗号、分号、空白或换行分隔；支持来源编号、scripts/quark_signin.py、文件名及通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写已配置青龙通知渠道的 notify.py 所在目录；也自动尝试 import notify.send、/ql/data/scripts、/ql/scripts。
- 填写格式：可选本机目录路径。

### `SMTP_SERVER`

- 必填：否
- 敏感：否
- 获取或设置：从自己的邮箱服务商获取 SMTP 主机名。
- 填写格式：与 EMAIL、PASSWORD 配套填写时启用邮件，受全局通知选择控制。

### `SMTP_PORT`

- 必填：否
- 敏感：否
- 获取或设置：从自己的邮箱服务商获取端口。
- 填写格式：1 至 65535 的整数，默认 25；465 为隐式 TLS，其他端口强制 STARTTLS。

### `EMAIL`

- 必填：否
- 敏感：是
- 获取或设置：填写自己的发送及接收邮箱。
- 填写格式：单个邮箱地址，与 SMTP_SERVER、PASSWORD 配套。

### `PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：在自己的邮箱安全设置中启用 SMTP 并获取授权码。
- 填写格式：SMTP 授权码，避免使用邮箱登录密码。

## 多账号

每个非空行一个账号，可混合网页和移动模式。同账号配套参数放在同一行，仅按首个 | 切分模式，字段按首个等号切分。账号独立执行，任一失败整体非零退出。旧分立变量仅兼容单账号。
