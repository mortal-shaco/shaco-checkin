# 夸克网盘每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/quark_signin.py`
- 青龙命令：`python3 scripts/quark_signin.py`
- 建议 Cron：`15 0 * * *`
- 发布哈希：`f579c1bccda6aad0574f1796454f4f197da7ade6d2c974714b368dcaa59473ac`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 验证夸克账号 Cookie 并显示官方返回的昵称或公开身份
- 查询当日签到状态，识别今日已签到
- 领取每日存储空间奖励并展示奖励和连签进度
- 换行配置多账号，独立处理并汇总失败
- 可选随机延迟、请求超时、完全断网预演
- 脱敏时间轴日志、账号及任务统计、结构化汇总和青龙通知
- 失败时输出固定响应字段的类型及有限数字业务码，辅助定位问题且不输出原始响应
- 同一账号变量可选择网页 Cookie 或移动端 kps、sign、vcode 组合凭据；移动端按上游明确的请求参数认证和签到，默认网页模式保持不变
- 有效字段存在时展示官方会员类型、总容量及签到累计获得容量
- 移动端凭据缺项、重复项或非法格式在断网预演及实时模式中明确失败，不输出凭据

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `QUARK_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：网页模式：登录 https://pan.quark.cn/，在浏览器开发者工具网络面板复制本人账号请求头中完整 Cookie 值。移动端模式：登录夸克手机应用，通过本人抓包工具读取容量查询或签到请求中的 kps、sign、vcode 原始编码值，将同账号三项参数以分号组合；不要复制设备标识、手机号或整个 URL。
- 填写格式：每个非空行一个账号。网页模式为完整 Cookie 或 pc|完整 Cookie；移动端模式为 mobile|kps=原始值; sign=原始值; vcode=原始值。仅识别首个模式分隔符，后续文本完整保留；账号不使用 &、@ 分隔。默认网页模式，不自动切换接口。

### 可选参数

### `QUARK_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 启用完全断网预演。
- 填写格式：1/true/yes/on 启用，默认关闭；预演只验证配置、展示流程和生成通知摘要。

### `QUARK_TIMEOUT_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况自行设置。
- 填写格式：3 至 60 的整数秒，默认 15。

### `QUARK_RANDOM_DELAY_MAX_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：按需要自行设置每个实时账号执行前随机等待的上限。
- 填写格式：0 至 3600 的整数秒，默认 0；预演不等待。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 notify.py 所在目录；未填写时自动尝试导入 notify 及青龙标准脚本目录。
- 填写格式：目录路径，无需配置任何业务凭据；预演不加载或调用通知模块。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号，网页 Cookie 与移动端三项签名凭据可混用。移动端三项凭据必须属于同一账号并组合在同一行；只按首个模式分隔符切分，不丢弃后续文本。各账号独立处理，任一账号失败时整体退出码为非零。
