# 老王FIP签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/laowangfip_checkin.py`
- 青龙命令：`python3 scripts/laowangfip_checkin.py`
- 建议 Cron：`7 10 * * *`
- 发布哈希：`2f65c336c4ab546b52d9e21557554a25ae92418aaf223c03dd2fde1d36f1d0b3`
- 许可证：`MIT`

## 脚本功能

- 用户名密码登录与每日签到
- tncode 滑块图像求解、轨迹签名、多候选验证与换图重试
- 验证登录态，识别今日已签到并跳过重复签到
- 查询连续签到、签到等级、积分奖励和总天数
- 逐行多账号独立处理，任一失败整体非零退出
- 专用代理优先与青龙全局代理回退，支持缺代理即失败
- 可恢复错误重试，错误密码不重试
- 可选安全会话缓存复用与失效清理
- 显示官方返回的公开 UID 和不含联系方式的账号名称
- 离线预演、阶段时间轴、账号与任务统计及唯一 TASK_SUMMARY 汇总
- 青龙脱敏通知，支持统一开关、任务选择及旧通知参数

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LWFIP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人在老王论坛注册并已确认可登录的用户名和密码，在青龙环境变量中填写，无需抓包。
- 填写格式：每个非空行一个用户名#密码账号，仅按首个 # 切分，密码中的 #、&、@ 及空格保留。禁止使用 & 或 @ 分隔账号。

### 可选参数

### `LWFIP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网预演时设为 1。
- 填写格式：布尔值，默认 false。预演不请求网络、不读写缓存、不导入通知模块。

### `LWFIP_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：默认 https://laowangfip372.vip，仅在核实官方站点迁移后修改。
- 填写格式：HTTPS 源站，不含认证、路径、查询参数及片段。

### `LWFIP_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：从本人使用的代理服务获取；未设置时依次读取 HTTPS_PROXY、https_proxy、HTTP_PROXY、http_proxy、ALL_PROXY、all_proxy。
- 填写格式：代理 URL，可含认证，默认直连。支持 HTTP 及 SOCKS 代理，禁止公开含认证的地址。

### `LWFIP_PROXY_REQUIRED`

- 必填：否
- 敏感：否
- 获取或设置：需要代理缺失时立即失败则开启。
- 填写格式：布尔值，默认 false。

### `LWFIP_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按需要在青龙环境变量中设置请求超时秒数。
- 填写格式：整数，最小 1，默认 30。

### `LWFIP_MAX_CAPTCHA_RETRY`

- 必填：否
- 敏感：否
- 获取或设置：按需要在青龙环境变量中设置单次滑块验证码重试次数。
- 填写格式：整数，最小 1，默认 5。

### `LWFIP_MAX_RETRY`

- 必填：否
- 敏感：否
- 获取或设置：按需要在青龙环境变量中设置账号最大尝试次数。
- 填写格式：整数，最小 1，默认 5。

### `LWFIP_RETRY_INTERVAL`

- 必填：否
- 敏感：否
- 获取或设置：按需要在青龙环境变量中设置账号重试等待秒数。
- 填写格式：整数，最小 0，默认 60。

### `LWFIP_DEBUG`

- 必填：否
- 敏感：否
- 获取或设置：需要查看滑块候选、步骤和脱敏错误分类时开启。
- 填写格式：布尔值，默认 false，不输出响应、URL、异常堆栈或凭据。

### `LWFIP_COOKIE_CACHE`

- 必填：否
- 敏感：否
- 获取或设置：需要跨次复用登录态时显式开启，脚本所在目录应只由本人访问。
- 填写格式：布尔值，默认 false。开启后写入按站点与账号哈希命名的 cookie_*.json，权限 0600、原子替换。缓存含凭据，禁止入库及共享，失效后删除并重新登录。

### `LWFIP_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游通知开关，在全局开关为 auto 且未设置选择列表时生效。
- 填写格式：布尔值，默认 true。

### `LWFIP_NOTIFY_ONLY_FAIL`

- 必填：否
- 敏感：否
- 获取或设置：只需失败通知时显式开启，在全局开关为 auto 且未设置选择列表时生效。
- 填写格式：布尔值，默认 false。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：全局开关为 auto 时设置选择列表，替换默认任务通知选择。
- 填写格式：逗号、分号或空白分隔，支持 catalogId 91d3322eb735e2d2、脚本相对路径、文件名及通配符。* 选择全部，空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙已有 notify.py 或 sendNotify.js 所在目录，仅用于通知集成。
- 填写格式：目录路径，优先尝试导入 notify.send，随后查找本目录、/ql/data/scripts、/ql/scripts。通知失败保留业务退出码，预演仅模拟投递。
