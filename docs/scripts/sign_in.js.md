# 上马官网每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sign_in.js`
- 青龙命令：`node scripts/sign_in.js`
- 建议 Cron：`24 8 * * *`
- 发布哈希：`bee473bd82eaa154d3308365dccdf9535f8ef244b7940cbc7203956ac93be98e`
- 许可证：`MIT`

## 脚本功能

- 使用上马官网账号密码完成护照站登录并获取会话令牌，再调用积分签到接口。
- 识别业务码 code=0 为签到成功、code=5001 为今日已签（不视为失败）。
- 官方返回非敏感昵称、用户名、显示名称或公开 UID 时直接展示，便于核对账号。
- 支持每行一个「用户名|密码」多账号；兼容上游 SM_USERNAME + SM_PASSWORD 单账号变量。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验参数、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SHANGMA_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：使用本人上马（上海马拉松）官网账号。在 https://www.shang-ma.com/ 或 https://passport.shang-ma.com/ 注册/登录后，将手机号或邮箱与登录密码写入本变量。勿使用他人凭据或日志中的敏感信息。
- 填写格式：每个非空行一个账号，格式为「用户名|密码」，只在首个竖线处拆分，密码中后续竖线保留。不使用 & 或 @ 分隔账号。

### 可选参数

### `SM_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游单账号变量：仅当未设置 SHANGMA_ACCOUNT 时与 SM_PASSWORD 成对读取；获取方式与 SHANGMA_ACCOUNT 中的用户名相同。
- 填写格式：单个上马官网用户名（手机号或邮箱）；需同时配置 SM_PASSWORD。

### `SM_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游单账号变量：仅当未设置 SHANGMA_ACCOUNT 时与 SM_USERNAME 成对读取。
- 填写格式：单个上马官网登录密码；需同时配置 SM_USERNAME。

### `SHANGMA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不请求 SSO/登录/签到接口、不投递真实通知。

### `SHANGMA_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：1000 至 60000 的整数毫秒；缺省或非法值使用 15000。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 398c67c56c038d25、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

SHANGMA_ACCOUNT 每个非空行一个账号，格式为「用户名|密码」，只在首个竖线拆分。账号逐个独立登录与签到并统计，任一账号失败则整体非零退出，其余账号继续执行。

## 副作用与风险

- 正式运行时向上马官网提交每日积分签到，可能更新账号签到状态与积分。
- 正式运行时会登录护照站并建立会话令牌。
- 启用通知且非预演时，通过青龙 notify 发送脱敏账号统计。
