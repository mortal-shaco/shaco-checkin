# 哔哩哔哩每日任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/yuxian158_check_bilibili.py`
- 青龙命令：`python3 scripts/yuxian158_check_bilibili.py`
- 建议 Cron：`2 0 * * *`
- 发布哈希：`c958a220e197219d11f854e3bea8c0f63a886c97426f4d271b2f33240e912f2a`
- 许可证：`MIT`

## 脚本功能

- 验证登录状态，并显示官方接口返回的昵称和公开 UID
- 执行哔哩哔哩漫画每日签到和直播每日签到
- 查询每日经验完成情况、当前经验、硬币余额以及直播金银瓜子余额
- 按显式开关上报视频观看进度和登记视频分享计数
- 按每日目标为分区视频或关注用户投稿投币，并可选择同时点赞
- 按显式开关领取大会员 B 币券、优惠券和漫画大会员福利
- 按显式数量和公开 UID 为指定 UP 主充电
- 支持每行一个 Cookie 的多账号独立执行、断网预演、脱敏统计和青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BILIBILI_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录哔哩哔哩网页后，打开浏览器开发者工具的网络面板，从本人发往 api.bilibili.com 的请求中复制完整 Cookie 值，不要包含 Cookie: 请求头名称。
- 填写格式：每行一个账号；每行是以分号分隔的名称=值字段，且必须包含 SESSDATA 和 bili_jct。字段按首个等号切分，值中的后续等号会保留。

### 可选参数

### `BILIBILI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；需要完全断网预演时自行设置。
- 填写格式：布尔值，1、true、yes、on 表示开启；默认 0。

### `BILIBILI_MANGA_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；用于控制漫画签到。
- 填写格式：布尔值；默认 1，关闭后不执行漫画签到。

### `BILIBILI_LIVE_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；用于控制直播签到。
- 填写格式：布尔值；默认 1，关闭后不执行直播签到。

### `BILIBILI_WATCH`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；确认接受写入观看进度后自行开启。
- 填写格式：布尔值；默认 0。

### `BILIBILI_SHARE`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；确认接受增加视频分享计数后自行开启。
- 填写格式：布尔值；默认 0。此动作不发布文字内容。

### `BILIBILI_COIN_NUM`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；按希望完成的每日投币数量设置。
- 填写格式：0 至 5 的整数；默认 0，表示不投币。

### `BILIBILI_COIN_TYPE`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；选择投币候选视频范围。
- 填写格式：0 或 1；默认 1，优先加入关注用户投稿，0 仅使用分区视频。

### `BILIBILI_SELECT_LIKE`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；需要投币时同时点赞才开启。
- 填写格式：布尔值；默认 0，仅在投币动作中生效。

### `BILIBILI_VIP_RECEIVE`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；大会员账号需要领取 B 币券和优惠券时自行开启。
- 填写格式：布尔值；默认 0。

### `BILIBILI_VIP_MANGA`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；需要领取漫画大会员福利时自行开启。
- 填写格式：布尔值；默认 0。

### `BILIBILI_ELEC_NUM`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；确认接受消耗 B 币充电后设置电池数量。
- 填写格式：0 至 10000 的整数；默认 0，表示不充电。非零时必须同时设置 BILIBILI_ELEC_UID。

### `BILIBILI_ELEC_UID`

- 必填：否
- 敏感：否
- 获取或设置：从拟充电 UP 主的公开个人空间地址或公开资料中取得 UID。
- 填写格式：非负整数 UID；默认 0。

### `BILIBILI_AID`

- 必填：否
- 敏感：否
- 获取或设置：从拟操作视频的公开页面或接口资料中取得 AV 号；不设置时自动选择分区视频。
- 填写格式：非负整数；默认 0。

### `BILIBILI_CID`

- 必填：否
- 敏感：否
- 获取或设置：从拟操作视频的公开页面数据中取得 CID；不设置时由视频详情接口查询。
- 填写格式：非负整数；默认 0。

### `BILIBILI_PROGRESS`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；按需要设置观看进度秒数。
- 填写格式：1 至 86400 的整数；默认 300，仅在观看上报开启时生效。

### `BILIBILI_REGION`

- 必填：否
- 敏感：否
- 获取或设置：从哔哩哔哩公开分区资料中选择分区编号。
- 填写格式：1 至 10000 的整数；默认 1。

### `BILIBILI_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；按网络状况设置单次请求超时。
- 填写格式：1 至 60 的整数秒；默认 15。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择器，无需从哔哩哔哩获取。
- 填写格式：以逗号、分号、空白或换行分隔选择器；支持目录路径、文件名、通配符、catalogId 和 *；设置为空表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写青龙 notify.py 所在目录；通常无需设置，脚本会检查青龙标准位置。
- 填写格式：本机目录路径，不要填写脚本文件名。

## 多账号

BILIBILI_COOKIE 中每个非空行表示一个账号；各账号独立处理，任一账号失败时进程整体返回非零状态。
