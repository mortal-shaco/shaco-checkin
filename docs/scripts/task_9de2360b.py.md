## 脚本功能

- 通过官方院校列表和详情发现问卷服务，也支持直接指定可信院校域名
- 使用本人官方登录 Cookie 查询当前首份待填问卷及字段，避免第三方密码代理
- 显式提交前逐题核对必填题标题、数量和选项，支持文本、单选、多选和图片
- 使用临时授权自行实现阿里云 OSS 图片上传和附件预览，也支持已有 HTTPS 附件地址
- 显式提交本人确认的答案和地址，检查明确成功或已填写消息，不自动重试提交
- 每行一个账号，独立处理且任何账号失败时整体非零退出
- 完全断网预演、请求超时、HTTPS 校验、禁止重定向和脱敏分阶段日志
- 支持青龙通知开关、脚本选择和通知模块发现，通知故障保留业务退出码
- 输出账号统计、任务统计以及唯一单行 TASK_SUMMARY 记录

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CPDAILY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：本人通过学校官方今日校园入口登录，在浏览器开发者工具或本人设备合法抓包中取得问卷请求的 Cookie 和服务域名。Cookie 过期后重新登录，禁止将学号密码发送给第三方。可填写学校全称以启用官方院校发现。提交时从本人当前请求取得 Cpdaily-Extension，逐题确认答案及地址。不要沿用上游硬编码设备头。
- 填写格式：每个非空行一个 JSON 对象，必填 cookie，以及 host（不带协议的 campusphere.net 或 cpdaily.com 子域名）或 school（学校全称）。提交另需 address、extension、defaults。defaults 为按必填题顺序排列的对象数组，每项含 title、value，兼容上游每项的 default 对象包装。类型 1/5 为文本字符串，类型 2 为单选选项原文，类型 3 为逗号连接的多选选项原文，类型 4 为本地图片路径或已有 HTTPS 附件地址。账号只用换行分隔，Cookie 中分号及等号原样保留，不用 & 或 @ 分隔账号。

### 可选参数

### `CPDAILY_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：自行选择查询或提交；仅在确认实际问卷答案、地址和附件后设置 submit。
- 填写格式：query 或 submit；默认 query，只查询、不上传或提交。

### `CPDAILY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网预演设为 1；正式执行时移除。
- 填写格式：1、true、yes、on 开启；预演不读取图片，不调用业务接口或通知，不验证登录及线上提交成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行填写需要通知的脚本。未设置时本脚本不在默认通知名单，空值禁用全部。
- 填写格式：逗号、分号或空白分隔；支持目录编号 9de2360bf4ea8141、文件名、scripts/相对路径、文件名通配符及 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙现有可信通知模块目录。默认探测 notify 模块、指定目录和青龙标准目录。
- 填写格式：含 notify.py 或 sendNotify.js 的现有本地目录；脚本不会下载或安装模块。
