## 脚本功能

- 使用知末官方签到接口完成每日签到，并在接口明确返回时展示积分奖励。
- 识别接口明确返回的今日已签到状态，并将其作为已完成处理。
- 支持以换行分隔多个账号，逐账号独立执行并汇总结果。
- 提供完全断网的预演模式，用占位 Cookie 校验配置和执行流程。
- 输出带时间戳的分阶段日志、账号统计、任务统计和单行结构化摘要。
- 真实运行结束后通过青龙 sendNotify.js 发送不含凭据和原始响应的摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ZNZMO_COOKIE_LIST`

- 必填：是
- 敏感：是
- 获取或设置：登录知末网站后，在浏览器开发者工具的网络请求中找到 api.znzmo.com 请求，复制完整 Cookie 请求头；不要把 Cookie 分享给他人。
- 填写格式：每行一个账号的完整 Cookie，例如由 SESSION、user-uuid、znzmo-id 等站点实际下发字段组成；分号属于 Cookie 内容，不能用于分隔账号。

### 可选参数

### `ZNZMO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；设置为 1、true、yes 或 on 时启用完全断网预演。
- 填写格式：布尔开关，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选通知脚本筛选列表，可填写目录编号、znzmo.js、candidate.js 或通配符；留空值会关闭全部脚本通知。
- 填写格式：使用逗号、分号、空白或换行分隔；星号表示全部脚本。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如青龙通知脚本不在标准目录，可填写包含 sendNotify.js 的本机目录。
- 填写格式：本机目录绝对路径。

## 多账号

ZNZMO_COOKIE_LIST 每个非空行表示一个账号；逐账号独立执行，任何账号失败都会令进程返回非零退出码。
