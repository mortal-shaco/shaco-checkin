# 看雪论坛签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/kanxue.js`

- 建议 Cron：`0 35 11 * * *`

- 许可证：`MIT`

## 脚本功能

- 使用完整 Cookie 执行看雪论坛每日签到，保持上游环境变量、请求地址和每日 11:35 计划。
- 支持每行一个账号，独立执行并汇总各账号结果。
- 核验 HTTP 状态和业务码；明确已签到消息视为已完成，其他业务拒绝失败退出。
- 断网预演只检查配置，不验证登录或真实签到结果。
- 展示官方返回的非敏感昵称、用户名或公开 UID，并隐藏凭据及原始响应。
- 输出带时间戳的阶段日志、统计和单行 TASK_SUMMARY 记录。
- 通过青龙 sendNotify.js 发送脱敏结果，支持全局通知开关及通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KANXUE_COOKIE_LIST`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://bbs.kanxue.com 后，打开开发者工具网络面板，选择发往看雪论坛的已登录请求，复制请求头 Cookie 的完整值；不要复制响应 Set-Cookie 或将凭据发给他人。登录失效后重新获取。
- 填写格式：每个非空行一个账号的完整 Cookie 值，形如 字段名=字段值; 字段名=字段值；保留分号和等号，不使用 & 或 @ 分隔账号。

### 可选参数

### `KANXUE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 开启断网预演，正式执行时删除或设置为 0。
- 填写格式：1/true/yes/on 开启，其余值关闭；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙已有通知配置；需要关闭通知时手动设置本变量。
- 填写格式：默认 1；0/false/no/off 关闭，不区分大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙 sendNotify.js 所在目录；默认依次查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：目录路径；通知组件为可选青龙集成，不影响签到独立运行。

完整获取说明已写在上方各变量条目中。禁止使用来源不明的第三方提取页，或把凭据粘贴到聊天、Issue 与公开日志。

## 多账号

每个非空行一个账号，保留行内完整 Cookie，不拆分分号、等号、& 或 @；账号顺序独立处理，任一账号失败或配置错误则整体非零退出。
