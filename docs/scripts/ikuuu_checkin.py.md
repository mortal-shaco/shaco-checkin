## 脚本功能

- 保留维护目标的 Python 标准库独立 HTTP 实现、每日 21 点定时和云函数 handler 兼容入口。
- 支持规范邮箱密码和 Cookie 凭据，兼容 ikuuu、IKUUU_COOKIES；换行多账号独立执行，保留密码与 Cookie 后续分隔字符。
- 登录与签到校验官方整数 ret；成功仅认 ret=1，已签到仅认 ret=0 且明确已签到消息；布尔值及未知响应失败闭合。
- 可选读取个人资料并校验非空响应，官方返回安全昵称、用户名、显示名称或公开 UID 时按原值展示。
- 可选读取剩余流量，支持中英文标签和普通页面、originBody 编码页面，新增缺失填充及 GBK 编码兼容。
- 提取签到流量奖励，保留读取失败仍继续签到并聚合账号失败的既有语义。
- 保留可配置 HTTPS 主机及最长一小时随机错峰；显式开关启用无凭据域名探测、本地备用列表和官方状态页回退。
- 提供完全断网预演、参数验证和请求计划，不加载通知模块、不访问状态页、不等待、不写本地缓存。
- 保留青龙通知、可选 PushPlus 与 Server酱通知及旧参数兼容、通知名单与全局开关，通知失败保留业务退出码。
- 输出带时间戳的编号阶段、每账号统计、任务统计、起止时间，保留 IKUUU_SUMMARY 并输出唯一 TASK_SUMMARY 单行记录。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `IKUUU_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：在 iKuuu 官网注册或找回密码；也可在本人已登录官网的浏览器开发者工具 Network 中复制 /user 请求的 Cookie 请求头。请仅填入青龙环境变量。
- 填写格式：每个非空行一个账号：邮箱|密码 或 cookie:完整 Cookie；仅按首个 | 拆分，密码后续字符保留；Cookie 包含 uid、email、key。

### 可选参数

### `ikuuu`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧版环境变量；推荐迁移至 IKUUU_ACCOUNT，仅在未设置规范变量时读取。
- 填写格式：每行邮箱#密码，仅按首个 # 拆分；不使用 & 分隔账号。

### `IKUUU_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧版 Cookie 变量，从本人浏览器官网 /user 请求头获取；推荐迁移至规范变量的 cookie: 行。
- 填写格式：每行 Cookie 或 备注||Cookie，仅按首个 || 拆分；与规范变量同时设置时合并执行，备注不输出，# 开头行忽略。

### `IKUUU_HOST`

- 必填：否
- 敏感：否
- 获取或设置：从官网核对当前官方域名后填写；必须是可信主机，否则可能泄漏凭据。
- 填写格式：只填主机名，不含协议、端口或路径；邮箱模式默认 ikuuu.nl，Cookie 模式默认 ikuuu.win。

### `IKUUU_AUTO_DOMAIN`

- 必填：否
- 敏感：否
- 获取或设置：需要域名故障切换时显式开启，先通过官网核对候选归属；开启即允许将凭据用于探测选中的官方域名。
- 填写格式：0 或 1；默认 0，保留原固定域名行为。开启后先无凭据探测主域名及本地候选，全部失败再读取官方状态页补充；最多探测 12 个域名，不重放业务请求。

### `IKUUU_CANDIDATE_HOSTS`

- 必填：否
- 敏感：否
- 获取或设置：从 iKuuu 官方渠道获得备用域名并核对归属；仅在开启域名切换时使用。
- 填写格式：每行一个 ikuuu.顶级域名 主机名，不含协议、路径；不接受状态页主机 ikuuu.uk；连同主域名最多 12 个。

### `IKUUU_PROFILE`

- 必填：否
- 敏感：否
- 获取或设置：需要读取个人资料时开启。
- 填写格式：0 或 1，默认 0；读取失败仍继续签到，但账号整体失败。

### `IKUUU_FLOW`

- 必填：否
- 敏感：否
- 获取或设置：需要查询剩余流量时开启。
- 填写格式：0 或 1；Cookie 模式默认 1，邮箱模式默认 0；查询失败账号整体失败。

### `IKUUU_MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：按需设置最大错峰等待秒数。
- 填写格式：0 至 3600 的整数，默认 0；预演不等待。

### `IKUUU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时设置为 1。
- 填写格式：0 或 1，默认 0；启用后不发送请求、不加载通知模块、不写状态、不等待。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：按需设置通知脚本选择范围，设置后替换默认名单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；* 全选，空值全禁；未设置时本任务默认启用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块不在标准位置时填写自定义通知目录。
- 填写格式：包含 notify.py 的目录；另兼容导入 notify.send 及 /ql/data/scripts、/ql/scripts 中的 notify.py。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在 PushPlus 官网账号中获取，仅在需要额外通知时配置。
- 填写格式：可选令牌，受青龙全局通知开关和脚本名单控制。

### `SERVERCHAN_SENDKEY`

- 必填：否
- 敏感：是
- 获取或设置：在 Server酱官网账号中获取，仅在需要额外通知时配置。
- 填写格式：可选 SendKey，受青龙全局通知开关和脚本名单控制。

### `SCKEY`

- 必填：否
- 敏感：是
- 获取或设置：兼容原通知配置，推荐使用独立命名的规范变量。
- 填写格式：等于 1 时允许读取旧 TOKEN 作为 PushPlus 令牌；其他非空值作为 Server酱 SendKey；规范变量优先。

### `TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：仅兼容旧版 PushPlus 令牌；推荐改用 PUSHPLUS_TOKEN。
- 填写格式：仅在 SCKEY=1 且 PUSHPLUS_TOKEN 为空时读取。

## 多账号

每个非空行一个账号，同一账号的邮箱密码或完整 Cookie 合并在一行；账号独立执行，任一账号失败则进程非零退出。不使用 & 或 @ 分隔账号。
