## 脚本功能

- 支持邮箱密码登录，并仅在官方登录响应 ret=1 时继续执行。
- 支持 Cookie 会话签到，兼容规范账号变量、旧版 ikuuu 与 IKUUU_COOKIES。
- 每日签到仅在官方 ret=1 或消息明确证明今日已经签到时判定成功，并提取流量奖励。
- 可选读取个人资料并核验非空响应；官方返回安全昵称、用户名、显示名称或公开 UID 时按原值展示。
- 可选查询剩余流量，支持普通页面和 originBody 编码页面中的中英文剩余流量字段。
- 支持换行多账号独立执行、密码和 Cookie 后续分隔字符保留、任一账号失败时整体非零退出。
- 支持官方主机名配置、最多一小时随机错峰以及云函数 handler 兼容入口。
- 支持完全断网预演，不等待、不加载通知模块、不发起账号或通知请求。
- 按账号输出编号阶段、脱敏结果、耗时和统计，并保留 IKUUU_SUMMARY 与唯一 TASK_SUMMARY 记录。
- 通过青龙 notify.py 发送脱敏任务总结，并兼容显式配置的 PushPlus 与 Server酱通知；通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `IKUUU_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：邮箱密码模式使用在 ikuuu 官网注册或找回的邮箱和密码；Cookie 模式在浏览器登录官网后，从开发者工具 Network 的 /user 请求复制 Cookie 请求头。不要把凭据发送到聊天或日志。
- 填写格式：每行一个账号；邮箱密码写成 邮箱|密码，只在第一个竖线处分割；Cookie 写成 cookie:完整Cookie，且 Cookie 至少包含 uid、email、key。

### 可选参数

### `ikuuu`

- 必填：否
- 敏感：是
- 获取或设置：旧版邮箱密码变量，仅在未设置 IKUUU_ACCOUNT 时兼容读取。
- 填写格式：每行一个 邮箱#密码，只在第一个井号处分割。

### `IKUUU_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：浏览器登录 ikuuu 官网后，从开发者工具 Network 的 /user 请求复制 Cookie 请求头。
- 填写格式：每行一个完整 Cookie；可写成 备注||完整Cookie，只在第一个双竖线处分割。

### `IKUUU_HOST`

- 必填：否
- 敏感：否
- 获取或设置：仅在官方更换域名时填写当前官方 HTTPS 主机名。
- 填写格式：只填写主机名，不含协议、端口、路径或查询参数。

### `IKUUU_PROFILE`

- 必填：否
- 敏感：否
- 获取或设置：需要额外核验个人资料页面时设为 1。
- 填写格式：1 表示开启；0、false、no、off 表示关闭，默认关闭。

### `IKUUU_FLOW`

- 必填：否
- 敏感：否
- 获取或设置：需要在签到后查询剩余流量时设为 1。
- 填写格式：1 表示开启；0、false、no、off 表示关闭；Cookie 模式默认开启，邮箱密码模式默认关闭。

### `IKUUU_MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：按需设置签到前的随机错峰上限。
- 填写格式：0 到 3600 的整数秒，默认 0。

### `IKUUU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试参数与执行计划时设为 1。
- 填写格式：1 表示完全断网预演；0、false、no、off 表示实际运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要覆盖默认通知脚本列表时设置。
- 填写格式：使用逗号、分号、空白或换行分隔脚本选择器；支持目录相对路径、文件名、通配符、目录编号或 *；空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在青龙 notify.py 不位于标准目录时填写其所在目录。
- 填写格式：包含 notify.py 的本机目录路径。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在 PushPlus 官网账号中获取；仅在需要额外 PushPlus 通知时填写。
- 填写格式：PushPlus 用户令牌。

### `SERVERCHAN_SENDKEY`

- 必填：否
- 敏感：是
- 获取或设置：在 Server酱官网获取 SendKey；仅在需要额外 Server酱通知时填写。
- 填写格式：6 到 128 位字母、数字、点、下划线或连字符。

### `SCKEY`

- 必填：否
- 敏感：是
- 获取或设置：旧版通知兼容变量；优先改用 SERVERCHAN_SENDKEY。值为 1 时仅作为旧版 PushPlus 分支的显式标记。
- 填写格式：Server酱 SendKey，或旧配置中的固定值 1。

### `TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版 PushPlus 兼容变量；仅在明确设置 SCKEY=1 且未设置 PUSHPLUS_TOKEN 时读取，优先改用 PUSHPLUS_TOKEN。
- 填写格式：PushPlus 用户令牌。

## 多账号

每行一个账号并独立执行；同一账号的配套凭据放在同一行，只在第一个字段分隔符处分割，因此密码或 Cookie 后续内容会完整保留；任一账号失败时进程整体返回非零退出码。
