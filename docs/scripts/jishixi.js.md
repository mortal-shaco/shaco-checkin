# 技实习自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/jishixi.js`
- 青龙命令：`node scripts/jishixi.js`
- 建议 Cron：`42 8 * * *`
- 发布哈希：`b0c03db78520304c7e0a3e6bb524b07f01582f7188a2d722939ab30d3f105527`
- 许可证：`MIT`

## 脚本功能

- 使用学号与密码登录技实习平台，完成设备登记并获取会话 Cookie
- 读取打卡加密参数并以 TripleDES 提交实习日志打卡（含经纬度与地址）
- 支持多账号换行配置、完全断网预演、超时控制与业务成功判定
- 时间轴日志、账号阶段统计、脱敏通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JISHIXI_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用广州市工贸技师学院技实习账号的学号与登录密码；每个非空行一个账号。推荐 JSON 行写入学号、密码与本人实习地点；或使用“学号|密码”并配合共享坐标环境变量。凭据只写入青龙环境变量，勿提交到公开仓库或日志。
- 填写格式：JSON：{"user_account":"学号","psw":"密码","posLong":经度,"posLati":纬度,"posAddress":"地址","interContent":"可选日志"}；或学号|密码（仅在首个竖线拆分，后续全文为密码）。多账号用换行分隔。

### 可选参数

### `JISHIXI_POS_LONG`

- 必填：否
- 敏感：否
- 获取或设置：填写本人真实实习地点经度；账号 JSON 未提供 posLong 时作为共享默认值。须与现场打卡位置相符，勿使用他人或示例坐标。
- 填写格式：十进制度数，范围 -180 到 180

### `JISHIXI_POS_LATI`

- 必填：否
- 敏感：否
- 获取或设置：填写本人真实实习地点纬度；账号 JSON 未提供 posLati 时作为共享默认值。须与现场打卡位置相符。
- 填写格式：十进制度数，范围 -90 到 90

### `JISHIXI_POS_ADDRESS`

- 必填：否
- 敏感：否
- 获取或设置：填写本人真实实习签到地址文本；账号 JSON 未提供 posAddress 时作为共享默认值，需与学校要求描述一致。
- 填写格式：非空地址字符串

### `JISHIXI_INTER_CONTENT`

- 必填：否
- 敏感：否
- 获取或设置：可选实习日志正文；未设置时使用本地默认短句。账号 JSON 的 interContent 优先。该字段为实习系统内部日志，不是公开发帖。
- 填写格式：非空文本字符串

### `JISHIXI_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：技实习接口根地址；默认广州市工贸技师学院域名。其他学校若接口兼容可改为对应 HTTPS 根地址。
- 填写格式：HTTPS 根地址，默认 https://gzgm.cydgsx.com

### `JISHIXI_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：单次 HTTP 请求超时毫秒数；网络较慢时可适当增大。
- 填写格式：整数毫秒，默认 20000，允许范围 1000–120000

### `JISHIXI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：完全断网预演时设置为 1；只校验配置与流程，不发起网络请求，不声明真实打卡成功。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径

## 多账号

每个非空行一个账号；学号与密码写在同一行（JSON 或学号|密码）。位置可写在账号 JSON，或使用共享 JISHIXI_POS_*。逐账号独立执行，任一账号失败时进程非零退出。
