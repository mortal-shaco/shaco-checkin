# 机场签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ck_airport.py`
- 青龙命令：`python3 scripts/ck_airport.py`
- 建议 Cron：`16 2 * * *`
- 发布哈希：`051d35dc78db52be0c4bac836fb5367cf2a18e1dc98a84d8df5f97eabfc80abc`
- 许可证：`MIT`

## 脚本功能

- 使用机场邮箱和密码登录 SSPanel，正确编码表单并维护会话 Cookie。
- 每日签到，仅明确 ret=1 或明确今日已签到业务响应判定成功。
- 查询 editXY 主题的用户等级、到期时间和剩余流量；主题不支持的字段明确跳过。
- 支持多机场多账号、旧 JSON 数组输入、逐账号独立处理和失败非零退出。
- 完全断网预演、带时间戳的分阶段脱敏日志、逐账号统计和单行 TASK_SUMMARY 汇总。
- 在官方接口返回公开身份时展示昵称、用户名、显示名称或公开 UID，不输出凭据或原始响应。
- 通过青龙 notify.py 发送脱敏任务汇总并支持全局开关；断网预演仅展示通知摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AIRPORT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在各机场官方网站注册账号，填写官网 HTTPS 地址和登录邮箱、密码；从青龙环境变量界面添加本变量。不需要获取 Cookie，不读取私有仓库配置。
- 填写格式：每个非空行一个 JSON 对象，包含 url、email、password 三个非空字符串。同账号凭据放在同一对象中，特殊字符按 JSON 转义；不能用 & 或 @ 分隔账号。兼容 JSON 对象数组。

### 可选参数

### `AIRPORT`

- 必填：否
- 敏感：是
- 获取或设置：旧 AIRPORT 配置兼容输入：将原配置中的 url、email、password 转为 JSON 填入青龙。推荐迁移到 AIRPORT_ACCOUNTS；两个变量都设置时优先 AIRPORT_ACCOUNTS。
- 填写格式：支持 JSON 对象数组或每行一个 JSON 对象，字段与 AIRPORT_ACCOUNTS 一致。

### `AIRPORT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1，正式运行设为 0 或不设置。
- 填写格式：1 表示完全断网预演：校验配置并展示任务阶段，不登录、不签到、不发送网络通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在自定义青龙通知位置时填写已有 notify.py 所在目录。也自动查找可导入的 notify 模块、脚本同目录和青龙标准目录。
- 填写格式：目录路径；通知模块不存在、失败或超时不改变业务退出码。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号
