## 脚本功能

- 保留数美设备指纹协议及进程内设备凭据缓存
- 服务器时间校准，失败时使用本地时间
- 鹰角 Token 授权并登录森空岛
- 查询账号绑定的明日方舟与终末地角色并显示官方昵称或公开角色标识
- 遍历全部明日方舟绑定角色每日签到并显示奖励
- 遍历全部终末地角色每日签到并显示奖励
- 每行一个账号，独立处理账号与角色，汇总失败并非零退出
- 完全断网预演、分阶段耗时日志与唯一 TASK_SUMMARY 结构化汇总
- 通过青龙通知模块发送脱敏统计，支持全局关闭及通知失败保持业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SKYLAND_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在自己的浏览器登录鹰角网络官方账号页面 https://user.hypergryph.com/ ，再访问 https://web-api.hypergryph.com/account/info/hg 获取响应 content 中的账号 Token。若官方登录流程变化，从本人已登录客户端的授权请求获取 token；不要公开响应、Token 或 Cookie。
- 填写格式：每个非空行一个完整账号 Token；禁止用逗号、& 或 @ 分隔多个账号。

### 可选参数

### `SKYLAND_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 开启完全断网预演。
- 填写格式：1、true、yes、on 开启，默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知默认开启；需要关闭时设置为 0。
- 填写格式：0、false、no、off 关闭，默认 1。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 notify.py 所在目录；默认发现青龙标准路径或导入 notify.send，无通知模块仍可执行签到。
- 填写格式：本地通知模块目录路径。

## 多账号

SKYLAND_TOKEN 每个非空行一个账号，忽略空行；账号与角色独立执行，任一失败整体非零退出。
