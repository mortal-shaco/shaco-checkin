# 成都大学ISP每日登记

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/services.js`
- 青龙命令：`node scripts/services.js`
- 建议 Cron：`1 7 * * *`
- 发布哈希：`291ac990009d2ce43c08c8c1c2da96cabcb4c601b9f9fd83721da0ef44597a43`
- 许可证：`MIT`

## 脚本功能

- 自动发现或使用指定 weblogin.asp 登录入口
- 获取图形验证码与会话 Cookie 并提交学号密码登录
- 按当日日期与自填地址/坐标提交 ISP 每日位置登记
- 识别登记成功与今日登记已存在
- 多账号逐行处理、断网预演、时间轴日志与单行 TASK_SUMMARY
- 青龙脱敏通知；通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CDU_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：填写成都大学 ISP / 学工在线（xsswzx.cdu.edu.cn）的学号与密码；每个非空行一个账号。不要提交或分享真实凭据。
- 填写格式：每行一个账号：学号|密码（仅在首个竖线处拆分，后续密码原文保留）；或单行 JSON {"username":"...","password":"..."}。不使用 & 或 @ 分隔账号。

### `CDU_ADDRESS`

- 必填：是
- 敏感：是
- 获取或设置：由账号本人填写真实登记地址文本。上游硬编码住址已移除，本变量无默认值。
- 填写格式：中文地址文本，例如：省市区街道门牌

### `CDU_ADDSXY`

- 必填：是
- 敏感：是
- 获取或设置：由账号本人填写与地址对应的经纬度。上游硬编码坐标已移除，本变量无默认值。
- 填写格式：经度,纬度（如 104.07859,30.55403）

### 可选参数

### `USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：上游旧版单账号学号变量；仅当未设置 CDU_ACCOUNTS 时，与 PASSWORD 一起作为兼容输入读取。
- 填写格式：单个学号字符串

### `PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：上游旧版单账号密码变量；仅当未设置 CDU_ACCOUNTS 时，与 USERNAME 一起作为兼容输入读取。
- 填写格式：单个密码字符串

### `CDU_LOGIN_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选。已知可用的 weblogin.asp 完整地址时填写，可跳过门户页自动发现。
- 填写格式：https://xsswzx.cdu.edu.cn/.../weblogin.asp

### `CDU_INDEX_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选。自定义门户发现页；默认使用成都大学 ISP website.asp。
- 填写格式：HTTPS URL

### `CDU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演排查时设为 1；正式登记勿开启。
- 填写格式：1/true/yes/on 启用断网预演；0/false/no/off 或不设置表示正式运行

### `CDU_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：网络较慢时可自行调大超时；默认 15000 毫秒。
- 填写格式：1000 至 60000 的整数毫秒

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选。设置后仅对列表中的脚本启用通知；空值表示全部关闭。
- 填写格式：逗号/分号/空白/换行分隔的 catalog-id、文件名或 glob；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙 notify.py / sendNotify.js 所在目录；容器内部一般无需设置。
- 填写格式：绝对路径目录

## 多账号

每个非空行一个账号；同一账号的学号与密码写在同一行（学号|密码 或 JSON）。登记地址与坐标使用 CDU_ADDRESS / CDU_ADDSXY。任一账号失败则进程以非零退出码结束。
