## 脚本功能

- 使用夸父资源社账号 Cookie 执行每日签到
- 支持每行一个账号并逐账号输出脱敏结果与统计
- 识别明确的签到成功和今日已签到结果
- 支持完全断网的参数校验预演
- 按青龙通知策略发送不含凭据和原始响应的任务总结

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KFZY_COOKIE_LIST`

- 必填：是
- 敏感：是
- 获取或设置：登录夸父资源社网页后，在浏览器开发者工具的网络请求中查看发送给 www.kfzy.net 的 Cookie；仅复制包含 bbs_sid 与 bbs_token 的 Cookie。请妥善保管，不要发送给他人。
- 填写格式：每行一个账号，单行必须同时包含 bbs_sid=...; bbs_token=...；分号后的其他 Cookie 字段会原样保留。

### 可选参数

### `KFZY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时设置为 1；预演只校验账号格式，不访问任何接口，也不会签到。
- 填写格式：启用值可使用 1、true、yes 或 on。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：如只希望部分脚本发送通知，可填写本脚本的目录编号、路径、文件名或通配符；留空会关闭全部脚本通知。
- 填写格式：多个选择器用逗号、分号、空格或换行分隔；本脚本可用 ec84855cfbf1a288、sign/kfzy.js、kfzy.js 或 *。

## 多账号

KFZY_COOKIE_LIST 中每个非空行代表一个账号；脚本逐个独立校验和签到，任一账号失败都会使进程以非零状态退出。
