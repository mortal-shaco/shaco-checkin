# 神经研究所每日任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/easonfans_daily.py`
- 青龙命令：`python3 scripts/easonfans_daily.py`
- 建议 Cron：`0 20 * * *`
- 发布哈希：`57162a2a5060eebdca324c8d6b7ca062e2ab8044286cf668b650a1b8cb3f0c6e`
- 许可证：`MIT`

## 脚本功能

- 校验登录状态并显示官方昵称或公开 UID
- 每日 dsu_paulsign 签到（含已签到判断）
- 幸运转盘免费次数检测与抽奖
- 本地题库保守匹配每日答题（最多三题，无法唯一匹配则不提交）
- 可选留言墙表情/文本留言（默认关闭）
- 多账号逐行处理与断网预演

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `EASONFANS_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://www.easonfans.com/forum/ 后，打开开发者工具网络面板，从本站任意请求的请求头复制完整 Cookie 值。
- 填写格式：每个非空行一个账号的完整 Cookie 字符串，不含 Cookie: 前缀；不要用 & 或 @ 分隔账号。

### 可选参数

### `EASONFANS_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：一般无需修改；仅当论坛根路径变更时填写。
- 填写格式：HTTPS 论坛根地址，默认 https://www.easonfans.com/forum/ ，仅允许 easonfans.com 域名。

### `EASONFANS_QUIZ_BANK`

- 必填：否
- 敏感：否
- 获取或设置：自行准备有权使用的题库；可为 JSON 数组或题库纯文本。未配置时跳过答题，不影响签到与转盘。
- 填写格式：JSON 形如 [{"question":"题干","answer":"答案"}] ，或“题干—答案”纯文本；勿放入凭据。

### `EASONFANS_MESSAGE_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：需要自动留言时设为正整数；公开默认关闭，避免骚扰其他用户。
- 填写格式：0 至 50 的整数；默认 0 表示关闭留言。

### `EASONFANS_MESSAGE_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：开启留言后用于控制两次留言间隔，降低操作过快风险。
- 填写格式：1 至 600 的秒数；默认 25。

### `EASONFANS_EMOJI_INDEX`

- 必填：否
- 敏感：否
- 获取或设置：选择签到心情表情序号，对应上游心情列表。
- 填写格式：0 至 8 的整数；默认 0。

### `EASONFANS_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：留言正文在一言不可用或断网预演时使用；勿填写 Cookie 或其他凭据。
- 填写格式：不超过 280 字的纯文本；默认 [em:1:]。

### `EASONFANS_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次业务请求超时。
- 填写格式：3 至 60 的秒数；默认 20。

### `EASONFANS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：仅向名单内脚本发送通知；可写目录标识、文件名或通配符。
- 填写格式：逗号、分号、空白或换行分隔；* 表示全部；显式空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自定义青龙 notify.py 或 sendNotify.js 所在目录。
- 填写格式：绝对目录路径。
