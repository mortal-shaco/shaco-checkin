# 超星学习通巡课签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/chaoxing_assistant.js`
- 青龙命令：`node scripts/chaoxing_assistant.js`
- 建议 Cron：`*/10 7-22 * * *`
- 发布哈希：`b7316880844bbc02d474056a583b004d03155c76dcb577c0b0a05c3d0fc9e55c`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用超星账号密码登录并校验 Cookie 含 UID，展示官方 realname 或公开 uid。
- 刷新课程表，轮询各课程进行中签到活动并执行普通/手势签到，识别签到成功与已签到。
- 只读检查待完成任务点与未完成作业状态并写入巡视摘要，不自动提交作业。
- 可选 HTTPS 报告地址推送巡视摘要；默认关闭，不写本地缓存文件。
- 支持每行一个账号及可选备注前缀，账号失败隔离并汇总退出状态。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验账号格式与报告地址协议、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CHAOXING_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人超星学习通 / 超星尔雅账号密码。在手机 App 或 https://passport2.chaoxing.com 可登录验证的同一组凭据；勿填写他人账号或日志中的敏感信息。
- 填写格式：每个非空行一个账号，格式「账号,密码」，只在第一个逗号处拆分（密码可含逗号）。可选备注前缀「备注|账号,密码」，只在首个竖线处拆分。不使用 & 或 @ 分隔账号。

### 可选参数

### `CHAOXING_SCHOOLID`

- 必填：否
- 敏感：否
- 获取或设置：单位/学校统一认证账号才需要填写；个人手机号或学号登录通常留空。
- 填写格式：学校 ID 字符串；应用于本任务全部账号的登录 schoolid 参数，默认空。

### `CHAOXING_REPORT_URL`

- 必填：否
- 敏感：否
- 获取或设置：需要把巡视摘要推到自建 Webhook / Server 酱类 HTTPS 地址时手动配置；不需要可不填。地址中可用 %s 占位摘要文本。
- 填写格式：必须以 https:// 开头的完整 URL；未设置则跳过报告推送。预演不会请求该地址。

### `CHAOXING_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不访问超星、不签到、不投递真实通知。

### `CHAOXING_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：1000 至 60000 的整数毫秒；缺省或非法值使用 20000。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 413b9423260e2104、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

CHAOXING_ACCOUNTS 每个非空行一个账号；可选备注仅按第一个竖线分割，账号与密码仅按第一个逗号分割。账号逐个独立登录、巡课、签到与统计，任一账号失败则整体非零退出，其余账号继续执行。

## 副作用与风险

- 正式运行时对进行中的课堂签到活动提交签到，可能改变账号签到状态。
- 配置了 CHAOXING_REPORT_URL 时，向该 HTTPS 地址发送巡视摘要请求。
- 启用通知且非预演时，通过青龙 notify 发送脱敏账号统计。
