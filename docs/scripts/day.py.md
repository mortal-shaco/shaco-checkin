# PHPWind论坛每日任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/day.py`
- 青龙命令：`python3 scripts/day.py`
- 建议 Cron：`58 8 * * *`
- 发布哈希：`f480d68c95ff0941df221fd5a4cf36b0010ec950d145e990b31fe9025a43b474`
- 许可证：`MIT`

## 脚本功能

- 使用用户名与密码登录可配置 PHPWind 风格论坛主站
- 申请每日任务（H_name=tasks actions=job）并校验响应含完成标志
- 领取每日任务奖励（actions=job2）并校验业务成功或已完成
- 展示登录用户名作为公开身份，隐藏密码与原始响应
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FORUM_AUTO_SIGN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在目标 PHPWind 论坛注册并确认可登录。将用户名与密码写入青龙环境变量；不要把凭据发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号，写成「用户名|密码」，仅在首个竖线处拆分，密码中后续竖线原样保留。账号之间只用换行分隔。

### `FORUM_AUTO_SIGN_BASE_URL`

- 必填：是
- 敏感：否
- 获取或设置：填写论坛主站根地址（上游 day.py 中的主站 URL）。须为真实可访问站点，不能使用 xxx.net 占位域名。
- 填写格式：例如 https://www.example.net；仅需协议与主机名，不要带登录或插件路径。

### 可选参数

### `FORUM_AUTO_SIGN_JUMP_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选覆盖登录表单 jumpurl；未设置时默认使用主站 index.php?。部分站点需指向 bbs 子域时可单独配置。
- 填写格式：完整 URL，例如 https://bbs.example.net/index.php?

### `FORUM_AUTO_SIGN_TASK_CID`

- 必填：否
- 敏感：否
- 获取或设置：每日任务插件 cid，与上游 day.py 中 cid=15 对应；不同论坛任务编号可能不同。
- 填写格式：正整数；默认 15。

### `FORUM_AUTO_SIGN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 90 的数字秒；默认 20。

### `FORUM_AUTO_SIGN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。

## 多账号

FORUM_AUTO_SIGN_ACCOUNTS 每个非空行一个账号，格式为用户名|密码，仅拆首个竖线。账号逐个独立登录与领取任务；任一账号失败则整体非零退出。不使用 & 或 @ 分隔账号。
