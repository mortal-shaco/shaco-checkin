# 欧文 Soul-Mates 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ouwen.py`
- 青龙命令：`python3 scripts/ouwen.py`
- 建议 Cron：`0 18 * * *`
- 发布哈希：`c5a1e97cc298ca1dc24fa723e94f6be8393a52c502165a3b302a3c899e067543`
- 许可证：`MIT`

## 脚本功能

- 使用账号密码登录 Soul-Mates / 欧文 PC 客户端接口并获取会话
- 提交每日签到并区分签到成功、今日已签到与业务失败
- 展示官方返回的非凭据公开身份（昵称、用户名或 UID），未返回时使用账号序号
- 支持每行一个账号的多账号独立处理，任一账号失败时非零退出
- 支持完全断网预演、请求超时、时间轴日志、脱敏通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `OUWEN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用在 Soul-Mates / 欧文（pc.chatclient.soul-mates.ai）注册或登录时的账号与明文密码。仅写入青龙环境变量，不要分享或提交到公开仓库。
- 填写格式：每个非空行一个账号：账号|密码；仅在第一个竖线处分割，密码中后续竖线保留。空行和以 # 开头的注释行忽略。

### 可选参数

### `OUWEN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置单次 HTTPS 请求超时；留空使用 15 秒。
- 填写格式：5 至 60 之间的秒数

### `OUWEN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用；预演不访问业务接口，也不声明真实签到成功。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启完全断网预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试导入 notify 和青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径

## 多账号
