# 上海云媒体积分任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/shyp.py`
- 青龙命令：`python3 scripts/shyp.py`
- 建议 Cron：`49 9 * * *`
- 发布哈希：`844c9bfcfcde0851fc30ef516280cb48cac08cebcbc55bd6ffc24a56edbefa5a`
- 许可证：`MIT`

## 脚本功能

- 校验账号凭据并查询总积分、今日积分、签到记录及任务进度
- 按服务端进度执行阅读与视频积分任务并刷新核验完成状态
- 显式启用收藏任务，可选择收藏后取消收藏
- 显式启用评论任务，从两页文章去重后选择目标
- 评论优先获取一言并保留作者与出处，异常使用本地文本
- 显式启用分享积分任务，保留打开文章与提交积分的顺序
- 按行配置多账号并独立处理，任一账号失败返回非零退出码
- 断网预演、分阶段脱敏日志、逐账号统计与单行结构化汇总
- 支持青龙通知开关、名单及通知模块降级发现

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SHYP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录本人上海云媒体客户端，在本人授权的网络调试中读取 https://app.ypmedia.cn/media-basic-port/api/app/personal/score/info 的请求头 token、deviceid、siteid 和 User-Agent。将原 config/token.json 的 shyp.accounts 对象逐个转换成一行；不读取私有配置文件，不使用商城 Authorization。凭据过期后重新登录获取。
- 填写格式：每个非空行一个 JSON 对象：必填 token 和 device_id；可选 site_id（默认 310110）、user_agent（默认 okhttp/4.10.0）、account_name（仅兼容保留，不作为官方身份输出）。字段值原样保留，账号以换行分隔，禁止使用 & 或 @ 分隔。

### 可选参数

### `SHYP_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中选择所需任务。收藏、评论和分享会改变账号或公开内容，必须主动启用。
- 填写格式：逗号分隔 read、video、favor、comment、share；默认 read,video。query 单独使用时仅查询积分、签到状态与任务。

### `SHYP_UNFAVOR`

- 必填：否
- 敏感：否
- 获取或设置：仅在明确需要收藏后取消收藏时设置；可能影响已有收藏状态。
- 填写格式：默认 0；1 启用；必须同时选择 favor。支持 true/false、yes/no、on/off。

### `SHYP_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：自行填写公开评论备用文本；一言请求失败、超时、超长、非 JSON 或缺少文本时使用。
- 填写格式：可选，空白合并后最长 280 字；空值或超长时采用内置本地短句。

### `SHYP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设为 1 执行断网预演；不会调用业务、一言或通知网络。
- 填写格式：默认 0；1 启用；支持 true/false、yes/no、on/off。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：配置自动通知名单；设置后替换默认名单，本脚本未配置名单时不发送。
- 填写格式：逗号、分号、空白或换行分隔；支持目录相对路径、文件名、文件名通配符、目录编号 c8112572b797324b 或 *；显式空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定现有青龙 notify.py 或 sendNotify.js 所在目录；也会检查标准青龙目录及可导入的 notify。
- 填写格式：本地通知模块目录路径；仅用于通知，不是业务依赖。

## 多账号

每个非空行一个账号 JSON；同一对象组合 token 和 device_id，账号独立执行；任一账号配置错误或业务失败时整体非零退出。
