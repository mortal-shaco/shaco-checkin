# 天翼云盘签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ty_netdisk_checkin.py`
- 青龙命令：`python3 scripts/ty_netdisk_checkin.py`
- 建议 Cron：`6 1 * * *`
- 发布哈希：`d91babb1a86918da573c6078ae632df83e9ae11023606ab9ae06c4f25a8a16b6`
- 许可证：`MIT`

## 脚本功能

- 使用天翼云盘官方密码登录流程和 RSA 公钥加密，为每个账号建立独立 Cookie 会话。
- 执行每日签到，区分新签到和今日已签到，显示确认的奖励空间并严格核验业务字段。
- 通过独立开关抽取当天已有签到奖励机会和相册任务奖励机会，识别 50M 空间及没有剩余机会。
- 保留每日 16:01 调度、默认最多一小时随机延迟及正式多账号间 10～30 秒随机间隔。
- 逐行多账号独立执行，保留密码中的后续分隔符和空格，任一账号失败整体非零退出。
- 官方响应提供昵称、用户名、显示名称或公开 UID 时显示非敏感身份，同时抑制手机号、凭据、会话和原始响应。
- 提供完全断网预演、凭据格式检查、分阶段时间轴日志、账号与任务统计及单行 TASK_SUMMARY 记录。
- 每账号 HTTP 总时限覆盖域名解析、连接、官方重定向和响应读取；限制响应大小，不自动重试状态变更。
- 区分域名解析、连接、TLS 和超时故障，对登录、签到和奖励响应执行明确业务成功检查。
- 按全局开关和任务选择器发送脱敏青龙通知，依次支持 notify.py 与 sendNotify.js；通知故障不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在天翼云盘官方客户端为本人账号设置或确认可用的账号密码；如登录要求验证码，先在官方客户端人工完成验证。凭据只保存在青龙环境变量中，不要公开。
- 填写格式：每个非空行一个账号，填写 用户名|密码；只在第一个 | 处分割，因此密码中的后续 |、&、@ 和空格均保留。不得使用 & 或 @ 分隔账号。

### 可选参数

### `TY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 进行完全断网预演，只校验配置和任务路由。
- 填写格式：1、true、yes、on 启用；默认 0。

### `TY_DRAW_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：确认愿意消耗账号当天已有的签到抽奖机会后自行开启；默认关闭。
- 填写格式：1、true、yes、on 开启；0、false、no、off 关闭。

### `TY_DRAW_PHOTOS`

- 必填：否
- 敏感：否
- 获取或设置：确认愿意消耗账号已有的相册任务抽奖机会后自行开启；脚本不会开启相册备份或上传照片，默认关闭。
- 填写格式：1、true、yes、on 开启；0、false、no、off 关闭。

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置是否在任务开始前加入随机延迟；正式日常执行默认开启，调试时可关闭。
- 填写格式：true（默认）或 false，也接受 1/0、yes/no、on/off。

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：自行设置任务开始前的最大随机延迟秒数。
- 填写格式：0～86400 的整数，默认 3600。

### `TY_ACCOUNT_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置每个账号全部业务 HTTP 的总时限，不包含随机等待。
- 填写格式：10～600 的整数秒，默认 60。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要只通知部分脚本时自行设置；设置后替换默认任务列表，空值关闭全部任务通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalogId、scripts 相对路径、文件名或文件名通配符；* 表示全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙现有 notify.py 或 sendNotify.js 所在目录；未设置时仍会检查标准青龙目录。
- 填写格式：本地目录路径；脚本不会下载或安装通知组件。

## 副作用与风险

- 正式模式每日签到可能增加账号奖励空间。
- 显式开启签到奖励后，正式模式可能消耗当天已有签到抽奖机会并增加奖励空间。
- 显式开启相册奖励后，正式模式可能消耗已有相册任务抽奖机会并增加奖励空间。
- 正式模式启用通知时通过可用的青龙通知组件发送脱敏任务总结。
