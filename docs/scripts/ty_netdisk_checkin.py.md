# 天翼云盘签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ty_netdisk_checkin.py`
- 青龙命令：`python3 scripts/ty_netdisk_checkin.py`
- 建议 Cron：`2 1 * * *`
- 发布哈希：`130c3675b7d206bfb866cf0bff34ba803c71769281621d172826d0e662f2c362`
- 许可证：`MIT`

## 脚本功能

- 使用官方密码登录流程和 RSA 加密建立独立账号 Cookie 会话
- 每日签到、区分新签到和今日已签到、显示奖励空间并严格校验业务结果
- 每行配套凭据、多账号独立执行、任一失败整体非零退出
- 保留每日16:01计划、可配置随机延迟及账号间10～30秒随机间隔
- 显示官方非敏感昵称或公开身份，抑制手机号、凭据、会话及原始响应
- 青龙任务汇总通知、时间轴日志、阶段耗时、账号统计及单行 TASK_SUMMARY 记录
- 完全断网预演、凭据格式检查及旧环境变量迁移提示
- 兼容密码页字段属性顺序、已抵达密码页的重定向和上游 callbackMsg JSONP 登录响应
- 脱敏诊断 HTTP 状态、短数字业务码、固定协议字段类型、HTML 或空正文；账号结果及通知保留失败阶段
- 每账号 HTTP 总时限覆盖域名解析和响应读取；请求开始和耗时日志；无自动重试
- Python 3.9+ 标准库自实现 HTTP、Cookie 与 RSA 公钥加密，限制响应大小及官方 HTTPS 重定向
- 区分域名解析失败、网络连接失败、TLS 验证失败和超时
- 通过独立开关抽取当天签到奖励和已有相册任务奖励；沿用规范脚本及其每日16:01计划，不建立并行产品任务
- 奖励抽取明确校验响应字段及业务码，识别50M空间和无剩余机会；未知错误或缺少奖励字段时失败且不自动重试
- 奖励阶段独立处理失败并保留失败阶段；前置登录或签到未确认时跳过奖励；每账号总时限覆盖启用的奖励请求
- 保留密码后续分隔符和空格、原有汇总字段；预演覆盖启用的奖励阶段并从HTTP入口禁止网络
- 通知依次尝试可导入的notify.py、指定或标准青龙目录中的notify.py、sendNotify.js；限制通知耗时并抑制模块输出

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在天翼云盘官方客户端确认登录用户名和账号密码；仅有短信登录时先在官方客户端设置密码。每个账号将用户名和密码合在一行添加到青龙环境变量。需要验证码时先人工完成官方登录，本脚本不绕过验证码。原私有 CLOUD189 配置的 phone/password 须迁移到此变量。
- 填写格式：每个非空行一个账号：用户名|密码；仅切分第一个竖线，密码内的竖线、&、@和空格原样保留；账号之间只能换行

### 可选参数

### `TY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证时在青龙环境变量设置为1；正式执行时设为0或删除。
- 填写格式：1、true、yes、on启用；默认0

### `TY_DRAW_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：希望签到后抽取当天已有的签到奖励机会时手动启用。
- 填写格式：1、true、yes、on启用；0、false、no、off关闭；默认0

### `TY_DRAW_PHOTOS`

- 必填：否
- 敏感：否
- 获取或设置：希望抽取已有相册任务奖励机会时手动启用；需自行在官方客户端取得资格，本脚本不启用相册备份或上传照片。
- 填写格式：1、true、yes、on启用；0、false、no、off关闭；默认0

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：按需要设置签到前随机等待；沿用已维护版本默认值，验证时可设为false。
- 填写格式：仅true启用；默认true

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量填写签到前随机延迟的最大秒数。
- 填写格式：0～86400的整数；默认3600；断网预演不等待

### `TY_ACCOUNT_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量填写每个账号HTTP流程的总秒数；包括登录、签到及启用的奖励阶段，不包括随机等待。
- 填写格式：10～600的整数；默认60；需要Python 3.9及以上的青龙Linux或其他支持信号计时器的系统

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙通知模块所在目录；不需要额外仓库或业务依赖。未设置时查找可导入的notify.py及青龙标准脚本目录，再尝试sendNotify.js。
- 填写格式：可选目录路径；通知模块不可用或失败不改变业务退出码

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号，用户名与密码用第一个竖线配对；不得用&或@分隔账号。各账号独立执行；任意账号配置或业务失败，整体非零退出。

## 副作用与风险

- 正式模式每日签到可能增加账号奖励空间
- 启用签到奖励开关后，正式模式可能消耗当天已有签到抽奖机会并增加奖励空间
- 启用相册奖励开关后，正式模式可能消耗已有相册任务抽奖机会并增加奖励空间
- 正式模式按通知配置发送脱敏任务结果
