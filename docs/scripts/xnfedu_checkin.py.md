# 新南方职培学院签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/xnfedu_checkin.py`
- 青龙命令：`python3 scripts/xnfedu_checkin.py`
- 建议 Cron：`13 8 * * *`
- 发布哈希：`90fc574b183fc88942b131f82504d53f2fa70170244fd1e919558b277559f119`
- 许可证：`MIT`

## 脚本功能

- 新南方职业培训学院继续教育站点登录与每日签到
- 识别今日已签到为已完成成功，并读取剩余/累计红豆
- 官方页面返回姓名等非秘密身份时直接展示以便核对账号
- 多账号按行处理；规范变量 XNFEDU_ACCOUNTS，兼容 XNFEDU_USERNAME/XNFEDU_PASSWORD
- 完全断网预演 XNFEDU_DRY_RUN、HTTPS 超时、业务成功/已签到判定
- 脱敏时间轴日志、账号与任务统计、单行 TASK_SUMMARY 与青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XNFEDU_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用新南方职业培训学院继续教育站点（jxedu.xnfedu.com）的学员登录账号与密码。在青龙环境变量中按每行一个账号填写；不要把真实凭据写入公开仓库、日志或通知。
- 填写格式：每行一个账号，格式：用户名|密码；仅按第一个竖线分割，密码中可含竖线；账号之间只用换行分隔，不使用 & 或 @

### 可选参数

### `XNFEDU_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：未配置 XNFEDU_ACCOUNTS 时填写单个用户名，须与 XNFEDU_PASSWORD 同时提供。推荐改用 XNFEDU_ACCOUNTS。
- 填写格式：学员登录用户名文本

### `XNFEDU_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：与 XNFEDU_USERNAME 配套填写单个密码；已配置 XNFEDU_ACCOUNTS 时忽略。
- 填写格式：学员登录密码文本

### `XNFEDU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置；只校验配置并模拟登录/签到阶段，不访问网络、不改动签到状态、不真实发送通知。
- 填写格式：1、true、yes、on 开启完全断网预演；默认关闭

### `XNFEDU_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次 HTTPS 请求超时秒数。
- 填写格式：5 到 60 的数字；默认 20

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录；失败不改变业务退出码。
- 填写格式：目录路径；还会尝试 /ql/data/scripts 与 /ql/scripts
