- 管理状态：`已检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_moto.js`

- 建议 Cron：`26 0 * * *`

- 许可证：`GPL-3.0`

## 脚本功能

- 查询账号信息并显示官方昵称，刷新当前运行中的会话凭据
- 提交每日签到，严格根据签到接口数字业务码 0 确认成功；按明确要求暂停签到状态查询及二次核验
- 查询当前能量
- 每行一个账号，独立执行并汇总失败退出码
- 完全无网络预演，检查参数并展示流程
- 青龙脱敏通知、分阶段日志和单行 TASK_SUMMARY 统计
- 输出请求路径、HTTP 状态及脱敏业务码分类，区分网络、格式、凭据、重复签到提示和业务失败

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MOTO_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录摩托范 App，在本人授权的抓包环境中查看 https://api.58moto.com 的请求头 token 和同一账号的 uid；组合后填入青龙环境变量。不得公开分享抓包内容。
- 填写格式：每个非空行填写 token#uid，仅按第一个 # 分隔；uid 为数字，不支持 & 或 @ 分隔账号。

### 可选参数

### `MOTO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时手动设为 1；正式运行删除该变量或设为 0。
- 填写格式：1 表示完全无网络预演，其他值表示正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启。预演只生成摘要，不调用外部通知，以保证无网络。
- 填写格式：0、false、no、off 关闭通知，忽略大小写；默认 1。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；未设置时依次查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机目录路径，仅用于可选通知，不是业务依赖。

## 参数获取方法

完整获取说明已写在上方各变量条目中。禁止使用来源不明的第三方提取页，或把凭据粘贴到聊天、Issue 与公开日志。

## 多账号

每个非空行一个账号，token 和 uid 必须属于同一账号；仅按首个 # 分隔。独立处理各账号，任一账号失败则进程非零退出。
