# Arctime每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/arctime_auto_sign.py`
- 青龙命令：`python3 scripts/arctime_auto_sign.py`
- 建议 Cron：`56 8 * * *`
- 发布哈希：`0c5bdf4174af4e638d4f584d95ee80b46911c6afe7bcb93ceed50688653219a3`
- 许可证：`MIT`

## 脚本功能

- 使用用户名密码登录 Arctime 移动站个人中心
- 查询当前积分并执行每日签到领取积分
- 识别今日已签到状态并视为业务完成
- 多账号逐行独立处理与失败汇总
- 完全断网预演、时间轴日志与单行 TASK_SUMMARY
- 青龙脱敏通知及全局通知开关

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ARCTIME_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人 Arctime（http://m.arctime.cn）注册账号的用户名与登录密码。切勿写入公开仓库或日志。
- 填写格式：每个非空行一个账号：用户名|密码；仅按第一个竖线分割，密码中后续竖线原样保留；支持空行与 # 注释；不要用 & 或 @ 分隔账号

### 可选参数

### `ARCTIME_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写 Arctime 登录用户名；仅当 ARCTIME_ACCOUNTS 为空且同时提供 ARCTIME_PASSWORD 时生效。
- 填写格式：单个用户名字符串

### `ARCTIME_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写对应登录密码；仅当 ARCTIME_ACCOUNTS 为空且同时提供 ARCTIME_USERNAME 时生效。
- 填写格式：单个密码字符串

### `ARCTIME_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自定义单次 HTTP 请求超时秒数
- 填写格式：5 到 60 的数字秒，默认 20

### `ARCTIME_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演、只校验配置时手动设置为 1
- 填写格式：1/true/yes/on 启用预演；默认实际执行

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本白名单启用通知时设置；空值表示全部禁用
- 填写格式：catalog-id、脚本路径、文件名或 glob，可用逗号/分号/空白/换行分隔；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认路径时，设为 notify.py 或 sendNotify.js 所在目录
- 填写格式：本地目录绝对路径

## 多账号

ARCTIME_ACCOUNTS 中每个非空行是一个独立账号，格式为 用户名|密码（仅按第一个竖线分割）；各账号独立登录与签到，任一账号失败时进程整体非零退出
