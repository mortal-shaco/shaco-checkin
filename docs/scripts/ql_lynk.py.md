## 脚本功能

- 逐行多账号签到，保留每天 9 点定时与旧版主账号参数兼容
- 私有缓存与令牌续期，保留经业务验证的短期 accessToken 回退
- 查询今日签到、连续天数与补签卡；使用原生签名和 Content-MD5 签到并回查
- 查询能量体、累计获得、成长等级与成长值
- 查询连续、月度、季度、年度签到任务进度和奖励
- 生成文章手工分享链接
- 显式开启后使用分享账号完成查找、前置校验与上报，并核验能量体增长
- 青龙通知与七类可选直推渠道，支持全局开关和脚本选择器
- 完全断网预演、时间轴日志、账号和任务统计、单行结构化汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LYNK_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在自己的领克 App 登录抓包中，从 app-services.lynkco.com.cn 的 mobileCodeLogin 响应取得 refreshToken，从登录 URL 的 deviceId 参数取得设备 ID。
- 填写格式：每行 refreshToken|deviceId，只在第一个 | 拆分，不同账号只用换行分隔。

### 可选参数

### `LYNK_REFRESH_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容输入，获取方式同 LYNK_ACCOUNTS；规范变量未设置时生效，兼容经过业务验证的短期 accessToken。
- 填写格式：单个令牌，配套 LYNK_DEVICE_ID；也支持每行 token|deviceId。

### `LYNK_DEVICE_ID`

- 必填：否
- 敏感：是
- 获取或设置：从自有领克 App 登录 URL 的 deviceId 参数取得。
- 填写格式：旧版主账号或仅含令牌的分享账号的配套设备 ID，无默认值。

### `LYNK_TOKEN_B`

- 必填：否
- 敏感：是
- 获取或设置：从已授权分享账号的登录响应和请求取得相同字段，仅显式开启自动分享时使用。
- 填写格式：每行 token|deviceId；仅 token 时沿用当前主账号设备 ID；不再支持逗号分隔。

### `LYNK_AUTO_SHARE`

- 必填：否
- 敏感：否
- 获取或设置：需要自动点击文章分享时显式启用，默认关闭。
- 填写格式：1/true/yes/on 开启；其余关闭。

### `LYNK_SHARE_CONTENT_ID`

- 必填：否
- 敏感：否
- 获取或设置：从领克 App 文章链接的 id 参数取得。
- 填写格式：数字编号，默认 2072260486405246976。

### `LYNK_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置，不访问业务或通知网络、不读写缓存。
- 填写格式：1/true/yes/on 启用。

### `LYNK_CACHE_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可指定受保护的持久缓存目录，轮换令牌只写入独立的 0600 缓存，不改写青龙环境文件。
- 填写格式：目录路径，默认运行用户主目录下 .cache/lynk-sign；清缓存会丢失轮换凭据。

### `QINGLONG_NOTIFY`

- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

### `QINGLONG_NOTIFY_DIR`

- 必填：否

## 多账号

LYNK_ACCOUNTS 每行一个 token|deviceId，只在首个 | 拆分。兼容旧版主账号配置；分享账号也每行一个账号。逐账号独立处理，任一账号或分享子任务失败时整体非零退出。

## 副作用与风险

- 正式执行时续期登录令牌并在私有缓存中保存轮换结果
- 未签到时写入签到记录并可能领取奖励
- 显式开启自动分享后使用分享账号上报文章点击，可能增加能量体
- 通知启用时向青龙和可选渠道发送脱敏统计
- 显式使用 --clear-cache 删除当前配置账号的令牌缓存
