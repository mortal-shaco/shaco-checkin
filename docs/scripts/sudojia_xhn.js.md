# 新湖南每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_xhn.js`
- 青龙命令：`node scripts/sudojia_xhn.js`
- 建议 Cron：`51 4 * * *`
- 发布哈希：`b0131f2d77c0d1f5ae6271d2a7604798ee3313db307e23390343d2d5e316abbd`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用抓包表单登录并检查授权令牌
- 每日签到并核验业务成功码
- 查询当前可用积分并验证响应字段
- 逐行多账号独立执行，任一失败整体非零退出
- 完全断网预演及参数检查
- 带时间戳的分阶段日志、账号统计和单行结构化总结
- 通过青龙发送脱敏汇总；预演只输出通知摘要，不联网
- 显示官方返回的非敏感昵称、显示名或公开账号身份

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XHN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用真机注册新湖南 APP，在本人登录前开启抓包，登录成功后复制 https://xhnapi2.voc.com.cn/v5/user/login 的完整请求体。不要复制响应或请求头。登录失效后重新抓取。
- 填写格式：每个非空行一个账号的 URL 编码表单，包含 password、logintype、RegistrationID、appid、type、username；保留全部原始字段与编码，& 仅分隔表单字段，不分隔账号。

### 可选参数

### `XHN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 启用完全断网预演。
- 填写格式：1 为预演，其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙环境变量中设置；默认开启。
- 填写格式：0、false、no、off 关闭通知，忽略大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 sendNotify.js 所在目录；未设置时依次查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径；通知不可用不影响业务退出码。

## 参数获取方法

完整获取说明已写在上方各变量条目中。禁止使用来源不明的第三方提取页，或把凭据粘贴到聊天、Issue 与公开日志。

## 多账号

每个非空行一个完整登录表单，忽略空行；账号独立处理，任一账号失败则整体非零退出。
