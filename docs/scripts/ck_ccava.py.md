# CCAVA每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ck_ccava.py`
- 青龙命令：`python3 scripts/ck_ccava.py`
- 建议 Cron：`55 18 * * *`
- 发布哈希：`de4c8a9cb4f76800d04f9aca4d80b49599231295f1a1f0dff1e922c5eb4bd360`
- 许可证：`MIT`

## 脚本功能

- 每日签到，保留每天 18:55 的上游计划
- 显示签到响应中有效的月光币余额
- 识别今天已签到和失效凭据，未知响应不视为成功
- 官方返回昵称、用户名、显示名称或公开 UID 时显示可核对身份并抑制凭据及手机号
- 支持逐行多账号，独立处理并汇总失败
- 完全断网预演、带时间戳的分阶段日志、账号统计和单行结构化任务总结
- 通过青龙 notify.py 发送脱敏结果通知，支持全局关闭；断网模式仅预演通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CCAVA_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在 https://pc.ccava.net 登录后，打开浏览器开发者工具的网络面板，从该站点已登录请求的请求头复制完整 Cookie 值，不含 Cookie: 前缀。上游私有 get_data 配置中 CCAVA 列表的每个 cookie 值可原样迁移为一行。不要公开或上传此值。
- 填写格式：每个非空行一个账号的完整 Cookie；保留 Cookie 内部分号和等号，不用 & 或 @ 分隔账号。

### 可选参数

### `CCAVA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置；用于完全断网预演参数、签到流程、余额查询和通知。
- 填写格式：1、true、yes 或 on 开启；默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知默认开启；需要关闭时自行设置为 0。
- 填写格式：0、false、no 或 off 关闭；默认 1。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙现有 notify.py 所在目录；优先使用可导入的 notify.send，再检查此目录及青龙标准脚本目录。无需安装私有工作流工具。
- 填写格式：本机目录路径；通知失败不会改变业务退出码。

## 多账号

CCAVA_COOKIE 的每个非空行表示一个账号，逐行独立执行；任意账号失败均整体非零退出。
