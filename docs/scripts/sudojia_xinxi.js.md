# 心喜签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_xinxi.js`
- 青龙命令：`node scripts/sudojia_xinxi.js`
- 建议 Cron：`43 12 * * *`
- 发布哈希：`fcdb27ec00935e010ddc68dcaae974b36d3d5effd2de4cf408cd1971f28d6a3d`
- 许可证：`GPL-3.0`

## 脚本功能

- 查询官方昵称并原样显示非凭据身份，查询执行前后喜点
- 每日签到并显示奖励与连续签到天数，识别今日已签到
- 显式启用后查询免费次数并最多执行一次免费抽奖，禁止积分抽奖
- 显式启用分享任务及商城浏览奖励，各最多两次，浏览提交前等待三十秒
- 逐行多账号独立处理、请求超时、业务状态和响应字段校验
- 完全断网预演、青龙脱敏通知、分阶段日志及单行结构化汇总
- 显示官方返回的历史喜点，不显示手机号
- 显式启用后查询每日任务列表
- 显式启用后查看会员权益奖励并识别已完成
- 兼容旧 xx_sso 凭据变量，统一换行多账号，拒绝旧批量删帖设置

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XINXI_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在心喜微信小程序登录后，使用自己的抓包工具查看 api.xinc818.com 请求头 sso；仅使用自己的账号。未设置本变量时可使用旧变量 xx_sso。
- 填写格式：每个非空行填写一个完整 sso，不使用 #、& 或 @ 分隔账号；值不可含空白或控制字符。

### 可选参数

### `xx_sso`

- 必填：否
- 敏感：是
- 获取或设置：旧脚本凭据变量，获取方式与 XINXI_TOKEN 相同；仅当 XINXI_TOKEN 未设置时生效。
- 填写格式：每个非空行一个完整 sso；旧 # 分隔需迁移为换行。

### `XINXI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 启用完全断网预演，通知仅生成预览。
- 填写格式：0 或 1，默认 0。

### `XINXI_FREE_DRAW`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 启用最多一次免费抽奖，不执行积分抽奖。
- 填写格式：0 或 1，默认 0。

### `XINXI_REWARD_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 启用分享任务记账和商城浏览奖励，各最多两次，浏览提交前等待三十秒。
- 填写格式：0 或 1，默认 0。

### `XINXI_DAILY_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 查询每日任务，不自动执行返回的任务。
- 填写格式：0 或 1，默认 0。

### `XINXI_MEMBER_BENEFITS`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 查看会员权益并领取任务奖励。
- 填写格式：0 或 1，默认 0。

### `xx_del_topic`

- 必填：否
- 敏感：否
- 获取或设置：旧批量删除开关；本维护版禁止批量删帖，设为 1 时以配置错误退出。
- 填写格式：移除该变量或设为 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启。
- 填写格式：0、false、no、off 关闭，其他值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已有 sendNotify.js 所在目录；不配置时使用青龙标准目录。
- 填写格式：本地通知模块目录路径。

## 多账号

每个非空行一个账号，按行独立处理；任一账号失败时整体非零退出。XINXI_TOKEN 优先于 xx_sso，不合并两个变量。
