# 智汇福大晚点名签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/fzu.py`
- 青龙命令：`python3 scripts/fzu.py`
- 建议 Cron：`35 21 * * *`
- 发布哈希：`46b75eb4e97121a81bee898481c70cf3d0ef98686666d4b72c24a1d0ab87d5bf`
- 许可证：`MIT`

## 脚本功能

- 查询今日晚点名计划与签到状态
- 按配置经纬度做校区定位范围校验
- 提交晚点名打卡
- 按服务器时间进行迟到判定
- 可选强制 21:30-23:59 签到窗口
- 已签到或无考勤计划时跳过

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FZU_ATTN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：打开智汇福大 App → 业务 → 晚点名签到，从免登打开的 H5 地址栏复制 ?token= 后的 token 值（不要分享、不要提交到公开仓库）。同一账号再附上本人真实所在位置的高德经纬度；实际地点文案可选。本脚本不代替 App 登录，也不保存学号密码。
- 填写格式：每个非空行一个账号：token|经度|纬度 或 token|经度|纬度|实际地点。仅按首个竖线分割出 token，其余字段再按竖线拆分。不使用 &、@ 分隔账号。# 开头行忽略。可选前缀 token=。

### 可选参数

### `FZU_ATTN_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容输入；未设置 FZU_ATTN_ACCOUNTS 时使用。获取方式与账号行中的 token 相同，建议合并到规范变量，并同时配置经纬度。
- 填写格式：单个 token；可写成 token|经度|纬度[|地点]。若仅写 token，须配合 FZU_ATTN_LONGITUDE / FZU_ATTN_LATITUDE。

### `FZU_ATTN_LONGITUDE`

- 必填：否
- 敏感：否
- 获取或设置：可选。账号行未写经度时使用的默认经度；单账号兼容配置时与纬度一起填写本人宿舍/校区真实坐标。
- 填写格式：十进制度数，如 119.123456。

### `FZU_ATTN_LATITUDE`

- 必填：否
- 敏感：否
- 获取或设置：可选。账号行未写纬度时使用的默认纬度。
- 填写格式：十进制度数，如 26.123456。

### `FZU_ATTN_ACTUAL_LOCATION`

- 必填：否
- 敏感：否
- 获取或设置：可选。账号行未写地点文案时的默认 actualLocation 字段；可填校区或楼栋名称。
- 填写格式：短文本，可为空。

### `FZU_ATTN_ENFORCE_WINDOW`

- 必填：否
- 敏感：否
- 获取或设置：可选。是否强制仅在北京时间 21:30-23:59 晚点名窗口内打卡（对齐上游 GitHub 定时窗口语义）。
- 填写格式：1/true/yes/on 开启（默认）；0/false/no/off 关闭。断网预演不受窗口影响。

### `FZU_ATTN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选。单次 HTTP 超时秒数。
- 填写格式：3–120 之间的数字，默认 15。

### `FZU_ATTN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验证配置时设置为 1。
- 填写格式：1、true、yes、on 启用完全断网预演；0、false、no、off 或空值关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中将本任务加入通知名单；存在该变量时替换默认名单。
- 填写格式：逗号、分号或空白分隔；支持 0a782191e8bccbe2、scripts/fzu_attn_checkin.py、fzu_attn_checkin.py、文件名通配符及 *；空值关闭全部名单通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定本人青龙 notify.py 或 sendNotify.js 所在目录；也自动查找青龙标准目录。
- 填写格式：目录路径；优先 Python 通知，兼容 JavaScript 通知。通知缺失、超时或失败保留业务退出码。

## 多账号

每个非空行一个账号。规范变量 FZU_ATTN_ACCOUNTS 填写 token|经度|纬度[|实际地点]（仅按首个竖线分割出 token）。未设置时兼容 FZU_ATTN_TOKEN，并可配合 FZU_ATTN_LONGITUDE / FZU_ATTN_LATITUDE / FZU_ATTN_ACTUAL_LOCATION。账号独立处理，任一失败则进程非零退出。
