## 脚本功能

- 使用手机号与密码登录蘑菇钉/工学云 API，获取 token、userId 与实习计划 planId。
- 查询考勤同步列表，按今日上班/下班状态自动提交 START 或 END 打卡。
- 支持多次交替打卡、关闭打卡、坐标末三位抖动、自定义 UA/设备类型/备注。
- 可选行内 token/userId/planId 跳过首次登录；失效后自动重新登录。
- 官方返回昵称或公开 userId 时直接打印以便核对；手机号、密码、Token 永不输出。
- 支持每行一个账号；兼容 MOGUDING_USER；账号失败隔离并汇总非零退出。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验账号字段、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MOGUDING_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人蘑菇钉/工学云 App 注册手机号与登录密码；国家、省市区、详细地址与经纬度需与实习打卡点一致，经纬度可用公开地图坐标查询工具获取。勿将手机号、密码、Token 写入公开仓库、日志或通知。
- 填写格式：每个非空行一个账号。推荐单行 JSON：{"phone":"手机号","password":"密码","country":"中国","province":"省","city":"市","area":"区","address":"详细地址","longitude":"经度","latitude":"纬度"}，可选 signIn/multiple/randomLocation/type/desc/UA/token/userId/planId。也可「手机号|密码|经度|纬度|地址|省|市|区|国家」或「手机号|密码|{位置JSON}」，只在首个竖线处拆分手机号。不使用 & 或 @ 分隔账号。

### 可选参数

### `MOGUDING_USER`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：仅当未设置 MOGUDING_ACCOUNTS 时读取；获取方式与字段要求同 MOGUDING_ACCOUNTS。
- 填写格式：与 MOGUDING_ACCOUNTS 相同；每行一个账号 JSON 或竖线格式。

### `MOGUDING_SIGN_IN`

- 必填：否
- 敏感：否
- 获取或设置：需要全局关闭实际上班/下班提交时手动设置；账号 JSON 的 signIn 优先。
- 填写格式：1、true、yes、on 开启打卡（默认）；0、false、no、off 仅登录查询并跳过提交。

### `MOGUDING_MULTIPLE`

- 必填：否
- 敏感：否
- 获取或设置：需要按上次类型交替多次打卡时手动开启；账号 multiple 优先。默认每天上班+下班各一次判定。
- 填写格式：1/true 开启多次交替；其他或未设置表示关闭。

### `MOGUDING_RANDOM_LOCATION`

- 必填：否
- 敏感：否
- 获取或设置：需要轻微抖动经纬度末三位时手动开启；默认关闭（已移除上游示例中的默认开启）。账号 randomLocation 优先。
- 填写格式：1/true 开启抖动；其他或未设置表示关闭。

### `MOGUDING_TYPE`

- 必填：否
- 敏感：否
- 获取或设置：需要覆盖默认设备类型时手动设置；账号 type 优先。
- 填写格式：通常为 android；缺省 android。

### `MOGUDING_DESC`

- 必填：否
- 敏感：否
- 获取或设置：需要统一签到备注时填写；账号 description/desc 优先。
- 填写格式：任意短文本；可留空。

### `MOGUDING_UA`

- 必填：否
- 敏感：否
- 获取或设置：需要自定义 User-Agent 时填写；账号 UA 优先。未设置使用内置安卓 UA，不再读取 uaList.json。
- 填写格式：完整 User-Agent 字符串。

### `MOGUDING_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不请求 API、不写本地文件、不投递真实通知。

### `MOGUDING_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：1000 至 120000 的整数毫秒；缺省或非法值使用 20000。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 3827d2e03a385b9d、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

MOGUDING_ACCOUNTS（或兼容别名 MOGUDING_USER）每个非空行一个账号；同一账号的手机号、密码与打卡位置组合在同一行。账号逐个独立登录与打卡统计，任一账号失败则整体非零退出，其余账号继续执行。
