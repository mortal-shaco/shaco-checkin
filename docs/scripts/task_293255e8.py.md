## 脚本功能

- 账号密码登录联想官方服务并核验登录会话
- 每日签到及明确的今日已签到识别
- 查询并展示连续签到天数
- 展示官方返回的非敏感昵称、用户名或公开标识
- 兼容上游单账号参数及可选 Server 酱签到情况推送
- 按行多账号、独立会话与失败非零退出
- 完全断网预演、青龙可选统一通知及结构化任务统计

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LENOVO_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人在联想官网注册的账号及登录密码。账号需能通过普通账号密码登录；若要求验证码，请先在官方页面处理，本脚本不绕过验证码。
- 填写格式：每个非空行一个账号，格式为 账号|密码；只在第一个 | 分割，密码后续的 | 和空格保留。账号不能包含 |。

### 可选参数

### `USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游：本人联想账号，仅在未设置 LENOVO_ACCOUNTS 时与 PASSWORD 配套使用。
- 填写格式：单账号用户名，不使用账号分隔符。

### `PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游：本人联想登录密码。
- 填写格式：完整单账号密码，与 USERNAME 配套。

### `LENOVO_TICKET`

- 必填：否
- 敏感：是
- 获取或设置：默认保留上游共享业务参数。如官方接口变更，可在本人官方网页登录请求的 ticket 及签到请求的 sts 字段核对；两者需适用同一流程，不复制 Cookie。没有参考证据时不猜测替换。
- 填写格式：可选的单个业务参数；不设置使用上游值，设置为空则配置失败。

### `LENOVO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置，用于离线检查。
- 填写格式：1、true、yes、on 开启；默认 0。断网预演不登录、不签到、不发送任何网络通知。

### `PUSH_KEY`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游旧版 Server 酱密钥，可从本人 Server 酱账户获取；推荐迁移到青龙通知。
- 填写格式：单个密钥，只允许字母、数字、下划线和连字符；不设置则不调用旧推送。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙填写需要通知的脚本名单，设置时替换默认名单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径或文件名通配符；* 选全部，空值禁用青龙通知。未配置名单时 auto 默认不选中本脚本。显式 PUSH_KEY 保留旧推送兼容。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙通知模块所在目录；也会查找可导入的 notify 模块和青龙标准目录。
- 填写格式：包含 notify.py 或 sendNotify.js 的本地目录。通知失败不改变业务退出码。

## 多账号

每个非空行一个账号，账号与密码只在第一个 | 分割；每个账号独立会话顺序执行。任一账号失败则整体非零退出。兼容变量仅支持单账号，显式设置主变量时不回退。
