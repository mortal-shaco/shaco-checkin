## 脚本功能

- 国内版和国际版套餐任务合并为一个规范脚本；默认国内版，通过 --region cn/intl/all 或 ZCODE_REGION 显式选择，保持各自凭据及设备隔离。
- 读取套餐列表、权益额度和每日或一次性周期，按最高优先级领取，同优先级取首项，支持 ZCODE_PLAN_ID 指定套餐。
- 支持账号设备值、账号验证码、全局验证码补齐、客户端版本及自动识别操作系统平台；兼容已有设备文件，只读且非必需。
- 支持 --preview 只读模式、--only N 账号筛选和 --no-notify；每行一个账号，兼容备注前缀并保留验证码中的竖线等后续字符。
- 保留维护版显式启用的客户端启动和日活事件补报；默认关闭，预览始终关闭，上报失败仍继续其余业务但保留失败退出码。
- 严格核验 HTTP 状态、整数业务码及套餐响应；官方明确返回 1003 时计为本期已领取，1005 提示下次重试时间，3001 和 3007 提供参数修复指引。
- 固定北京时间展示套餐有效期、执行起止时间；保留每日 09:00 调度元数据，青龙调度时区需设置 Asia/Shanghai。
- 完全断网预演；可选青龙 notify.py 或 sendNotify.js 通知，保留 PushPlus、Bark、企业微信、钉钉加签及旧青龙接口的顺序回退链，支持全局开关及脚本选择。
- 时间轴分阶段日志、官方非秘密账号身份、账号及任务统计、唯一单行 TASK_SUMMARY 结构化汇总；不输出凭据和原始响应，任一账号失败非零退出。
- 仅用 Python 标准库实现 HTTPS 请求，验证 TLS、限制响应大小、设置超时、禁止重定向与写请求自动重试；无需其他仓库、应用程序或安装引导。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ZCODE_CN_TOKENS`

- 必填：是
- 敏感：是
- 获取或设置：在官方 ZCode 国内版完成登录，在浏览器开发者工具网络面板找到 https://zcode.z.ai/api/v1/zcode-plan/billing/preview 或 billing/claim 请求。Authorization 中 Bearer 后的完整内容为套餐 JWT，X-Device-Mid 为设备值；claim 的 X-Aliyun-Captcha-Verify-Param 为验证码。套餐 JWT 与推理 API Key、推理 access_token 不同。验证码可能短时一次性，业务码 3007 时重新抓取。此变量是默认国内版任务的必填凭据。
- 填写格式：每行一个账号；支持 套餐JWT、套餐JWT|设备值、套餐JWT|设备值|验证码、备注|套餐JWT|设备值|验证码。只依次按首个竖线拆字段，验证码剩余字符完整保留；不以 & 或 @ 分隔账号。设备留空时兼容读取脚本旁已有的对应区域设备文件，否则确定性生成且不写文件。

### 可选参数

### `ZCODE_INTL_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：使用官方 ZCode 国际版账号完成登录，从同一套餐请求获取国际版套餐 JWT、设备值和验证码；不能使用国内版凭据或推理 access_token。选择 --region intl 时此变量必填；--region all 按国内、国际顺序处理已配置账号。人工网页授权仅用于获取参数，不在定时任务内自动执行。
- 填写格式：每行一个账号；支持 套餐JWT、套餐JWT|设备值、套餐JWT|设备值|验证码、备注|套餐JWT|设备值|验证码。只依次按首个竖线拆字段，验证码剩余字符完整保留；不以 & 或 @ 分隔账号。设备留空时兼容读取脚本旁已有的对应区域设备文件，否则确定性生成且不写文件。

### `ZCODE_REGION`

- 必填：否
- 敏感：否
- 获取或设置：按账号所属区域设置；命令行 --region 优先。
- 填写格式：cn、intl 或 all；默认 cn

### `ZCODE_PLAN_ID`

- 必填：否
- 敏感：否
- 获取或设置：先用 --preview 查看套餐，再从官方套餐响应的 plan_id 字段获取；留空按最高优先级选择，同优先级取首项。
- 填写格式：单个套餐标识，可选

### `ZCODE_APP_VERSION`

- 必填：否
- 敏感：否
- 获取或设置：从官方客户端版本信息或领取请求头 X-ZCode-App-Version 获取。
- 填写格式：客户端版本号，默认 3.14.0

### `ZCODE_CAPTCHA_PARAM`

- 必填：否
- 敏感：是
- 获取或设置：在官方浏览器领取请求的 X-Aliyun-Captcha-Verify-Param 中复制完整值；仅补齐账号行未配置的验证码，多账号优先分别填写。
- 填写格式：完整验证码参数，不改写内容

### `ZCODE_ACTIVATION`

- 必填：否
- 敏感：否
- 获取或设置：只有确认需要补报客户端启动及日活事件时才手动开启；上报失败仍继续预览和领取，但本轮非零退出。
- 填写格式：0 或 1；默认 0；--preview 始终关闭上报

### `ZCODE_CN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置；不验证真实凭据，不请求业务或通知接口，也不读取、写入设备文件。
- 填写格式：1、true、yes、on 开启整个进程断网预演；默认关闭

### `ZCODE_INTL_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：国际版兼容的断网预演开关，任一区域开关开启即覆盖整个进程。
- 填写格式：1、true、yes、on 开启；默认关闭

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：设置后替换默认通知名单；可填写 a0a7b04503bfb900、checkin/zcode_cn_daily.py、文件名或文件名通配符。
- 填写格式：逗号、分号、空白或换行分隔；* 选择全部；显式空值关闭全部，仍服从全局关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙现有 notify.py 或 sendNotify.js 所在目录；自动查找可导入的 notify 模块、脚本目录及 /ql/data/scripts、/ql/scripts。
- 填写格式：现有通知模块的目录路径；无需下载或安装引导

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可选从 PushPlus 官方账号获取推送令牌；青龙通知不可用时按顺序尝试兼容通道。
- 填写格式：完整推送令牌

### `BARK_URL`

- 必填：否
- 敏感：是
- 获取或设置：可选从自己的 Bark 客户端获取专属推送地址；不得使用非 HTTPS 地址。
- 填写格式：完整 HTTPS 推送地址

### `WECOM_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：可选从企业微信群机器人配置获取 Webhook 或其 key。
- 填写格式：HTTPS Webhook 地址或机器人 key

### `DINGTALK_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：可选从钉钉群自定义机器人配置获取 Webhook。
- 填写格式：完整 HTTPS Webhook 地址

### `DINGTALK_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：机器人启用加签时，从同一钉钉机器人的安全设置获取，与 Webhook 配套使用。
- 填写格式：完整加签密钥；可选通知配置

### `QL_URL`

- 必填：否
- 敏感：否
- 获取或设置：兼容已有青龙通知接口配置，在本地青龙配置中查询；仅在其他通知通道不可用时使用。
- 填写格式：青龙面板 HTTPS 根地址，与 QL_TOKEN 配套；可选

### `QL_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容已有青龙通知接口令牌，从自己的青龙通知配置获取，不用于套餐认证。
- 填写格式：与 QL_URL 配套的完整令牌；可选

## 多账号

每个非空行一个账号，忽略以 # 开头的注释行；每行一个账号；支持 套餐JWT、套餐JWT|设备值、套餐JWT|设备值|验证码、备注|套餐JWT|设备值|验证码。只依次按首个竖线拆字段，验证码剩余字符完整保留；不以 & 或 @ 分隔账号。设备留空时兼容读取脚本旁已有的对应区域设备文件，否则确定性生成且不写文件。账号独立执行，任一失败整体非零退出。--only N 只处理所选区域范围内的第 N 个账号。

## 副作用与风险

- 默认实际运行在成功预览后提交一次套餐领取请求，可能增加账号套餐权益；--preview 或断网预演不领取。
- 仅 ZCODE_ACTIVATION=1 且非预览、非预演时上报 app_launch 和 app_daily_active，可能影响账号领取资格。
- 通知已启用且非断网预演时向青龙配置或兼容推送通道发送脱敏任务统计；通知失败不改变业务退出码。
