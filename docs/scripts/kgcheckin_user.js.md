# 酷狗概念版 VIP 签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/kgcheckin_user.js`
- 青龙命令：`node scripts/kgcheckin_user.js`
- 建议 Cron：`1 1 * * *`
- 发布哈希：`35acb497114bc92f5eeb53f5356f6f71f4f8973450dad2a3f13ccd46f4178b08`
- 许可证：`MIT`

## 脚本功能

- 多账号独立运行与失败闭合
- 官方昵称原样显示，凭据及原始响应不输出
- 显式开启听歌领取和广告领取 VIP，识别今日已领取及次数用尽
- 查询 VIP 到期时间
- 显式开启北京时间每周续期并保存最新令牌
- 沿用每天一次调度窗口起点 01:00，默认随机等待 1 至 60 分钟；支持立即执行
- 本地扫码登录、发送短信验证码、短信登录
- 账号追加、覆盖、查看数量、清空指定账号文件
- 青龙通知及上游企业微信、钉钉加签、飞书、云湖、Server酱、PushPlus、Telegram、Bark、Discord 渠道
- 完全断网预演、阶段日志及单行结构化汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KG_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人酷狗客户端请求或原作者 ScriptCat 登录后的账号配置中获取 userid 和 token；也可通过本脚本 qr 或 phone 授权后保存到显式账号文件。
- 填写格式：每行一个 userid#token；仅在首个 # 分割，后续内容保留；亦支持每行一个账号 JSON 对象。兼容输入 USERINFO 或账号文件存在时无需重复填写。

### 可选参数

### `USERINFO`

- 必填：否
- 敏感：是
- 获取或设置：从原作者 ScriptCat 账号配置复制，优先使用 KG_ACCOUNTS。
- 填写格式：兼容旧版含 userid、token 的 JSON 数组。

### `KG_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：按需要选择，登录及管理操作仅手动执行。
- 填写格式：默认 sign 随机延迟运行；now 立即运行；qr 扫码登录；sms 发送短信；phone 短信登录；list 查看账号数量；clear 清空显式账号文件。

### `KG_TASKS`

- 必填：否

### `KG_ACCOUNT_FILE`

## 多账号

每个非空行一个账号，userid#token 仅在首个 # 分割；各账号独立处理，任何账号失败整体非零退出；兼容 USERINFO JSON 数组。

## 副作用与风险

- 显式开启 listen 时上报听歌活动并领取 VIP
- 显式开启 ad 时上报广告活动并领取 VIP
- 显式开启续期时更换令牌并保存指定账号文件
- 手动 sms 发送短信验证码，qr 或 phone 创建登录会话并保存授权凭据
- 手动 qr 创建短期本地二维码文件并在结束后删除
- 手动 clear 清空指定账号文件；登录及续期更新该文件
- 正式运行时按开关向青龙及配置渠道发送脱敏通知
