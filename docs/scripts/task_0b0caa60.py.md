## 脚本功能

- 使用独立 HTTPS 客户端核验登录并显示官方返回的非敏感账号身份
- 读取签到日历并按当日参数签到
- 浏览服务端商品列表，保留每个商品 5 秒等待并领取奖励
- 显式启用分享商品任务进度上报及奖励领取
- 显式启用推送消息任务进度上报及奖励领取
- 保留旧版 config.json 账号字段兼容，支持规范换行多账号配置
- 完全断网预演、超时与响应大小限制、业务码核验及失败非零退出
- 逐账号时间轴、阶段耗时、分类统计和唯一 TASK_SUMMARY 机器汇总
- 按全局开关和列表选择发送脱敏青龙通知，通知异常保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HEYTAP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在自己的欢太商城 APP 登录后，使用 HTTPS 调试工具查看 www.heytap.com/cn/oapi/users/web/member/info 或 store.oppo.com/cn/oapi/credits/web/credits/show 请求，复制该账号的完整 Cookie 与 User-Agent；不要分享抓包。规范配置使用本变量；未设置时兼容当前目录旧版 config.json 数组的 cookies 和 User-Agent 字段。
- 填写格式：每个非空行一个账号：完整 Cookie、一个实际制表符、完整 User-Agent；只在第一个制表符处分割，保留后续内容。账号之间仅使用换行，不使用 & 或 @。

### 可选参数

### `HEYTAP_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：自行选择要执行的每日任务；默认 sign,browse。share 与 push 仅在明确接受任务进度上报副作用后加入，不会实际分享到微信。
- 填写格式：逗号分隔的非空任务集合：sign（签到）、browse（浏览及领奖）、share（分享进度上报及领奖）、push（推送进度上报及领奖）。

### `HEYTAP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置为 1；正式运行时移除或设为 0。
- 填写格式：1/true/yes/on 启用完全断网预演；不会核验账号有效性，也不会发送网络通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式中填写本脚本目录编号 0b0caa60f0060df6、实际文件名、scripts 相对路径或文件名通配符；未设置且默认列表未收录时不通知。
- 填写格式：使用逗号、分号、空白或换行分隔；* 选择全部，显式空值关闭全部；设置后替换默认列表。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如青龙通知模块未安装在标准目录，填写现有 notify.py 或 sendNotify.js 的所在目录；不需要额外下载。
- 填写格式：可选本地目录；先尝试导入 notify.send，再检查此目录、/ql/data/scripts 和 /ql/scripts；JavaScript 通知需要青龙现有 Node.js。

## 多账号

每个非空行一个账号，Cookie 与 User-Agent 用第一个实际制表符分隔；逐账号独立会话和统计，单个账号失败继续其他账号，任一账号失败整体非零退出。兼容当前目录 config.json 账号数组；HEYTAP_ACCOUNTS 优先。
