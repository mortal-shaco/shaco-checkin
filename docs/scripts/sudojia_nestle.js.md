- 建议 Cron：`30 2 * * *`

## 脚本功能

- 查询官方用户信息并显示昵称等非敏感公开身份，不显示手机号或凭据。
- 查询任务列表并显示可用于授权的任务编号。
- 仅提交显式白名单中的任务，以接口 errcode=200 验证成功；默认仅查询。
- 查询当前巢币余额。
- 每天08:28运行，支持按行配置多个账号及逐账号失败隔离。
- 提供完全断网的模拟预演、带时间戳的分阶段日志和单行 TASK_SUMMARY 汇总。
- 正式运行后发送脱敏青龙通知，通知失败不改变业务退出码；预演仅展示通知摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NESTLE_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录微信“雀巢会员”小程序，在自己授权的抓包环境中找到 crm.nestlechinese.com 的请求头 authorization，复制其值并去掉 Bearer 前缀；失效后重新登录获取。不要分享凭据。
- 填写格式：每个非空行一个账号的 Token，也兼容带 Bearer 前缀的值；不支持 & 或 @ 分隔账号。

### 可选参数

### `NESTLE_TASK_GUIDS`

- 必填：否
- 敏感：否
- 获取或设置：先留空运行查询，从日志读取任务编号，并在小程序核对对应任务的内容、要求和风险；仅填入自己明确授权执行的任务编号。
- 填写格式：每行一个任务编号，仅含英文字母、数字、下划线或连字符，最多128字符；白名单对所有账号生效，任一指定任务不在列表中则该账号失败。默认不提交任何任务。

### `NESTLE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地预演时设置为 1。
- 填写格式：1 表示完全断网模拟；其他值为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙环境变量中配置；默认开启。
- 填写格式：0、false、no、off（不区分大小写）关闭通知；断网预演仅展示通知摘要。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已配置的青龙 sendNotify.js 所在目录；未设置时查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地通知模块目录；仅通知使用，不作为业务运行依赖。

## 多账号

NESTLE_TOKEN 每个非空行一个账号，独立处理；任一账号失败时进程非零退出。

## 副作用与风险

- 显式配置 NESTLE_TASK_GUIDS 后，向任务完成接口提交授权任务，可能改变任务完成状态和巢币奖励。
- 正式运行且通知开启时，通过青龙通知模块发送脱敏任务摘要。
