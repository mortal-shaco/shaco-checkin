## 脚本功能

- 检查 CordCloud 登录会话，支持网页完成验证后的 Cookie 登录。
- 会话失效时可使用同账号邮箱密码调用上游已有登录接口，登录业务码和用户面板状态联合验证。
- 调用每日签到接口，依据明确成功业务码确认结果，依据明确的已签到消息识别重复签到。
- 逐行多账号独立运行，任何账号失败时整体非零退出。
- 提供完全断网预演、分账号分阶段日志、子任务统计和单行结构化汇总。
- 正式执行结束后通过青龙通知模块发送脱敏汇总，支持全局开关和脚本筛选，通知异常保留业务退出码。
- 官方 JSON 响应提供非敏感昵称、用户名、显示名称或公开 UID 时显示账号身份。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CORDCLOUD_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人 CordCloud 官方站点登录并完成邮箱二次验证，打开浏览器开发者工具的网络面板，从 /user 请求的请求头复制完整 Cookie。也可使用本人注册邮箱和登录密码。需要二次验证或网页挑战时使用已验证的 Cookie。只在青龙私有环境变量中保存。
- 填写格式：每个非空行一个 JSON 对象，字段 cookie 为完整 Cookie 请求头值，或同时填写 email、password。可同时填写三者以便会话失效后尝试密码登录。可选 baseUrl 默认为 https://cordc.net，必须为 HTTPS 站点根地址。可选 loginPath 默认为 /auth/login。JSON 字符串内的引号和反斜杠须转义。账号仅按换行分隔，Cookie 内的等号和分号、密码内的 & 和 @ 均保持原样。

### 可选参数

### `CORDCLOUD_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置。
- 填写格式：设为 1 完全断网预演，仅验证配置并模拟会话、登录、签到和通知；其他值执行正式任务。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要筛选通知脚本时设置，未设置时本任务默认启用通知。
- 填写格式：逗号、分号、空白或换行分隔，可用目录编号 1007059beed08b37、scripts/checkin.js、checkin.js、实际文件名或带 * 的文件名模式；* 匹配全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：通知模块不在青龙标准目录时，填写管理员配置的 sendNotify.js 所在目录。
- 填写格式：可选本地目录；还会依次查找 /ql/data/scripts/sendNotify.js 和 /ql/scripts/sendNotify.js。模块须导出 sendNotify。

## 多账号

CORDCLOUD_ACCOUNTS 每个非空行一个账号 JSON 对象。同账号的 Cookie、邮箱和密码放在同一对象内，每个账号独立维护内存会话。任一账号配置、登录或签到失败，继续处理其余账号并整体非零退出。
