- 建议 Cron：`25 2 * * *`
- 发布哈希：`584efede452b4dd4e61001383dbb053be78b85ecfabc022ec9ebeb22250baab1`
- 许可证：`GPL-3.0`

## 脚本功能

- 验证登录状态并显示接口返回的昵称，不输出手机号或凭据。
- 每日执行贝因美小程序签到，仅业务码 0 判定签到成功，未知状态按失败处理。
- 支持每行一个账号，失败隔离和整体非零退出。
- 完全断网预演、分阶段耗时日志、账号及任务统计和单行结构化汇总。
- 实际运行通过青龙 sendNotify.js 发送脱敏结果通知，支持全局开关；预演仅输出通知模拟摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BYM_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：登录贝因美微信小程序，使用自己的授权抓包工具检查 h5.youzan.com 请求。取 extra-data 请求头内的 sid，以及签到 checkinV2.json 请求查询参数 access_token，二者必须属于同一账号。凭据时效较短，失效后重新登录获取。原 BYM_SID 单值配置需迁移至此变量，脚本不再使用源码内置令牌。
- 填写格式：每个非空行填写 SID|access_token，仅按第一个竖线拆分，其后文本完整保留；不要使用 & 或 @ 分隔账号。

### 可选参数

### `BYM_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 启用完全断网预演。
- 填写格式：1 表示预演，其余值表示实际执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙环境变量中设置，默认开启。
- 填写格式：0、false、no、off（不区分大小写）关闭通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；未设置时自动检查 /ql/data/scripts 和 /ql/scripts。业务执行不依赖通知模块。
- 填写格式：本地目录路径。

## 参数获取方法

完整获取说明已写在上方各变量条目中。禁止使用来源不明的第三方提取页，或把凭据粘贴到聊天、Issue 与公开日志。

## 多账号

每个非空行一个账号，以首个竖线组合 SID 与 access_token；账号独立执行，任一账号失败则整体非零退出。
