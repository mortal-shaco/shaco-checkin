## 脚本功能

- 使用账号密码登录 www.hao4k.cn Discuz 论坛
- 打开 k_misign 签到页并识别今日已签到（您的签到排名）
- 提取 formhash 执行 k_misign 签到，再回读确认页验证成功
- 展示可解析的非敏感用户显示名，隐藏密码与原始响应
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HAO4K_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：在 https://www.hao4k.cn 注册并确认可登录。将论坛用户名与密码写入青龙环境变量；不要把凭据发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号，写成「用户名&密码」，仅在首个 & 处拆分，密码中后续 & 原样保留。不使用换行以外的符号分隔账号。

### 可选参数

### `HAO4K_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游旧变量：未设置 HAO4K_ACCOUNT 时，与 HAO4K_PASSWORD 组合为单账号。新部署请优先使用 HAO4K_ACCOUNT。
- 填写格式：单个论坛用户名；须与 HAO4K_PASSWORD 同时提供。

### `HAO4K_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游旧变量：未设置 HAO4K_ACCOUNT 时，与 HAO4K_USERNAME 组合为单账号。新部署请优先使用 HAO4K_ACCOUNT。
- 填写格式：对应账号的登录密码；勿写入日志或通知。

### `HAO4K_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 90 的整数秒；默认 20。

### `HAO4K_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。可填 7a56bf211c074a00、脚本文件名或 scripts 相对路径。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。不是业务依赖。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。
