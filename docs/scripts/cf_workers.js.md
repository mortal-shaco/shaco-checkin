# 机场账号每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/cf_workers.js`
- 青龙命令：`node scripts/cf_workers.js`
- 建议 Cron：`42 10 * * *`
- 发布哈希：`aba64c871a6ed26bd0b64d9f993af1e4be0021ada323480f130df4e37d8e420e`
- 许可证：`Apache-2.0`

## 脚本功能

- 邮箱密码登录并每日签到
- 初始会话获取、Cookie 合并和会话就绪检查
- 青龙定时和终端手动执行、多账号独立处理与旧参数兼容
- 断网预演、业务成功校验、超时及脱敏结构化日志
- 按青龙通知策略发送汇总，可选官方 Telegram 通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CF_WORKERS_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：从本人机场登录页取得 HTTPS 域名，使用注册邮箱和登录密码；在青龙添加该变量。完整旧单账号参数仍兼容，推荐迁移。
- 填写格式：每个非空行一个 JSON 对象，包含 domain、email、password；密码按 JSON 转义后解析，原样保留。

### 可选参数

### `JC`

- 必填：否
- 敏感：是
- 获取或设置：本人站点域名，优先于 DOMAIN
- 填写格式：仅旧版单账号兼容；必须配齐域名、邮箱、密码，设置 CF_WORKERS_ACCOUNTS 后忽略旧参数。

### `DOMAIN`

- 必填：否
- 敏感：是
- 获取或设置：JC 的兼容别名
- 填写格式：仅旧版单账号兼容；必须配齐域名、邮箱、密码，设置 CF_WORKERS_ACCOUNTS 后忽略旧参数。

### `ZH`

- 必填：否
- 敏感：是
- 获取或设置：本人注册邮箱，优先于 USER
- 填写格式：仅旧版单账号兼容；必须配齐域名、邮箱、密码，设置 CF_WORKERS_ACCOUNTS 后忽略旧参数。

### `USER`

- 必填：否
- 敏感：是
- 获取或设置：ZH 的兼容别名，建议避免系统默认用户名
- 填写格式：仅旧版单账号兼容；必须配齐域名、邮箱、密码，设置 CF_WORKERS_ACCOUNTS 后忽略旧参数。

### `MM`

- 必填：否
- 敏感：是
- 获取或设置：本人登录密码，优先于 PASS
- 填写格式：仅旧版单账号兼容；必须配齐域名、邮箱、密码，设置 CF_WORKERS_ACCOUNTS 后忽略旧参数。

### `PASS`

- 必填：否
- 敏感：是
- 获取或设置：MM 的兼容别名
- 填写格式：仅旧版单账号兼容；必须配齐域名、邮箱、密码，设置 CF_WORKERS_ACCOUNTS 后忽略旧参数。

### `CF_WORKERS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网预演时设为 1。
- 填写格式：1 为断网预演，其他值正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写任务来源编号、脚本相对路径、文件名或文件名通配符。
- 填写格式：逗号、分号或空白分隔；* 匹配全部；空值关闭全部选择。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：指定青龙 sendNotify.js 所在目录；默认检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机目录，仅通知使用，不是签到依赖。

### `TGTOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Telegram 官方 BotFather 取得本人的机器人令牌；须配合 TGID，遵守通知总开关与选择规则。
- 填写格式：官方机器人令牌，不使用第三方代理。

### `TGID`

- 必填：否
- 敏感：是
- 获取或设置：可选：取得本人 Telegram 会话标识，配合 TGTOKEN。
- 填写格式：单个聊天标识。

## 多账号

每个非空行一个 JSON 账号对象，包含同账号域名、邮箱、密码；独立执行，任一账号配置或业务失败均非零退出。
