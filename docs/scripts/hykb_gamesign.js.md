# 好游快爆游戏签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/hykb_gamesign.js`
- 青龙命令：`node scripts/hykb_gamesign.js`
- 建议 Cron：`50 1 * * *`
- 发布哈希：`1fcd8a43f8b7f9078cf775d5f3e7b6515a2973925afaffbcd483e75d4c72f8e0`
- 许可证：`MIT`

## 脚本功能

- 发现官方游戏签到集合中未结束的活动并去重，无法解析时失败闭合。
- 逐活动登录并每日签到，明确识别签到成功及今日已签，返回累计签到天数时显示。
- 可选择记录试玩前置动作，真实运行等待 65 秒后重新登录、签到并核验结果。
- 可选择记录分享前置动作，重新登录、签到并核验结果，不发布公开文字。
- 识别失效凭据，显示官方返回的非敏感昵称、用户名、显示名或公开 UID。
- 多账号独立执行，失败非零退出，完全断网预演、时间轴日志、逐账号统计和单行 TASK_SUMMARY 汇总。
- 真实执行后使用青龙通知模块发送脱敏汇总，通知失败不改变业务退出码；预演仅展示通知内容。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HYKB_SCOOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在自己的好游快爆账号登录后，进入游戏签到活动，使用本地抓包工具读取 https://huodong3.3839.com/n/hykb/signcard/ajax.php 请求表单中的 scookie 值。只在本地青龙环境变量中保存，不提交仓库或分享截图。原脚本 config.hykb.scookie 的值可直接迁入本变量。
- 填写格式：每个非空行一个账号，只填写 scookie 值，不添加 scookie= 或 Cookie 请求头。支持原始值及已百分号编码的值；内部 |、&、@ 等字符保留，不作为账号分隔符。

### 可选参数

### `HYKB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地预演时设为 1，真实运行时设为 0 或不设置。
- 填写格式：1 或 0；默认 0。预演不请求业务接口，也不载入通知发送模块。

### `HYKB_ALLOW_EXPERIENCE`

- 必填：否
- 敏感：否
- 获取或设置：只有明确同意向官方活动记录试玩动作时才设为 1。遇到试玩前置条件后记录试玩、等待 65 秒并再次核验签到；预演不实际等待。
- 填写格式：1 或 0，默认 0。关闭时如活动要求试玩则记失败，不伪报已签到。

### `HYKB_ALLOW_SHARE`

- 必填：否
- 敏感：否
- 获取或设置：只有明确同意向官方活动记录分享动作时才设为 1。遇到分享前置条件后记录分享，再登录并核验签到。
- 填写格式：1 或 0，默认 0。仅记录官方 sharelimit 动作，不发布公开文本；关闭时如需分享则记失败。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙现有 sendNotify.js 所在目录；不填写时依次查找 /ql/data/scripts/sendNotify.js 和 /ql/scripts/sendNotify.js。无需另行安装或下载。
- 填写格式：本地目录路径，只用于可选通知；业务功能不依赖该文件。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

HYKB_SCOOKIE 每个非空行一个账号，逐账号独立执行；不按 &、@ 或 | 分割。任一账号参数或任务失败，整体退出码为 1，其他账号继续处理。

## 副作用与风险

- 默认向所发现的未结束游戏活动提交每日签到，可能领取相应活动奖励。
- 仅在 HYKB_ALLOW_EXPERIENCE=1 且活动要求试玩时，记录官方试玩前置动作。
- 仅在 HYKB_ALLOW_SHARE=1 且活动要求分享时，记录官方分享前置动作。
- 真实模式且 QINGLONG_NOTIFY 开启、通知模块可用时，发送脱敏任务通知。
