## 脚本功能

- 显示官方返回的昵称、用户名、显示名称或公开 UID，不输出手机号或凭据
- 查询任务列表，签到、阅读和视频积分任务，检查操作后任务进度
- 可选收藏、公开评论和分享积分任务，默认关闭；保留上游跳过任务 004 的行为
- 评论优先请求一言，按作者及出处署名；所有声明的服务失败情形回退本地文本，预演不请求服务
- 查询当前积分及限时、虚拟两类可兑换商品，不自动兑换
- 每行一个账号、独立错误处理、超时及响应大小限制、有限循环
- 完全断网预演、青龙脱敏通知、时间轴日志、每账号统计和单行结构化汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SHYP_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录上海杨浦 APP，使用本人设备的抓包工具查看 https://ypapi.shmedia.tech 请求头 token。复制完整值，不含字段名；过期后重新登录获取。
- 填写格式：每个非空行一个账号的完整 token；仅换行分隔，不使用 & 或 @ 分隔。

### 可选参数

### `SHYP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：按需手动设置；完全断网预演，模拟接口结果，不表示线上成功。
- 填写格式：0 或 1；默认 0

### `SHYP_ENABLE_FAVOR`

- 必填：否
- 敏感：否
- 获取或设置：按需手动设置；收藏文章并获取积分，默认关闭。
- 填写格式：0 或 1；默认 0

### `SHYP_ENABLE_COMMENT`

- 必填：否
- 敏感：否
- 获取或设置：按需手动设置；公开发表评论并获取积分，默认关闭。
- 填写格式：0 或 1；默认 0

### `SHYP_ENABLE_SHARE`

- 必填：否
- 敏感：否
- 获取或设置：按需手动设置；调用分享积分接口，默认关闭。
- 填写格式：0 或 1；默认 0

### `SHYP_COMMENT_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：自行填写适合公开发布的本地回退评论，不要包含个人信息。远程一言失败时使用；不设置则使用内置文本。
- 填写格式：压缩空白后 1 至 280 个字符

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启。预演会尝试通知入口，但阻止其联网投递。
- 填写格式：0、false、no、off 关闭，其他值开启

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；默认查找 /ql/data/scripts 和 /ql/scripts。通知不可用或失败不影响业务退出码。
- 填写格式：本机目录路径
