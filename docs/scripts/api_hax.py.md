## 脚本功能

- 查询并按地区汇总 Hax 开通数量。
- 按虚拟化类型分组展示 Hax 可开通区域及开通页面链接。
- 展示 Woiden 可开通区域及开通页面链接。
- 保留 HAX 启用开关和每六小时第 21 分钟定时。
- 完全断网预演、独立查询失败隔离、页面校验及结构化汇总。
- 通过青龙通知模块发送公开结果和统计，通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HAX`

- 必填：是
- 敏感：否
- 获取或设置：无需凭据，手动设置青龙环境变量 HAX=1，替代上游私有配置启用开关。
- 填写格式：单个非敏感开关；1 启用；0、false、no、off 或空值不启用。未启用报告配置错误并非零退出。

### 可选参数

### `HAX_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 进行断网预演。
- 填写格式：默认 0；1 使用内置样本且不加载通知模块。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙已有 notify.py 所在目录；默认自动查找标准目录或导入 notify。
- 填写格式：本地目录路径，仅用于可选通知，不是业务运行依赖。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
