## 脚本功能

- 使用雨云用户名和密码登录，保持登录 Cookie 与 CSRF 令牌。
- 执行每日签到并领取积分，仅以 HTTP 状态和结构化业务码确认成功。
- 查询并展示账号积分，展示接口返回的非敏感昵称、用户名或公开 UID。
- 业务步骤完成或失败后，在已成功登录的情况下执行退出登录并核验结果。
- 支持每行一个账号的独立会话和失败隔离。
- 提供完全断网预演、分阶段脱敏日志、账号与任务统计及单行 TASK_SUMMARY 汇总。
- 通过青龙 notify.py 发送脱敏统计通知，支持全局开关；配置错误和部分失败同样汇总，预演跳过实际发送。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `rainyun_ck`

- 必填：是
- 敏感：是
- 获取或设置：使用雨云官网注册的账号用户名和登录密码；不需要抓取 Cookie，也不使用开放接口密钥。若账号需要验证码且接口拒绝空验证码，本脚本会报告失败，请先在官网核对账号登录要求。
- 填写格式：每个非空行一个账号：用户名#密码。仅在第一个 # 处分隔，密码后续的 # 和空格完整保留；用户名按上游规则转换为小写。不使用 & 或 @ 分隔账号。

### 可选参数

### `RAINYUN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中自行设置，预演时设置为 1。
- 填写格式：默认 0；设置 1 开启完全断网预演，仅验证参数与执行计划，跳过业务请求和通知实际发送。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙的全局通知开关，默认开启。
- 填写格式：默认 1；0、false、no、off 关闭通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如通知模块不在默认路径，将本机青龙 notify.py 所在目录填入此变量；未配置则尝试导入 notify 并搜索 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机目录路径，可选。业务脚本不依赖通知模块存在，通知失败保留业务退出码。

## 多账号

每个非空行一个账号，格式为用户名#密码，仅在第一个 # 处分隔。账号独立使用会话，单账号失败不阻止后续账号；任一账号失败或配置无效时整体非零退出。
