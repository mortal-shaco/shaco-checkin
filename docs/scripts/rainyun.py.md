## 脚本功能

- 使用雨云用户名和密码登录，并在独立账号会话中维护 Cookie 与 CSRF 令牌。
- 执行每日签到并领取积分，仅以 HTTP 状态、响应结构和业务码共同确认成功。
- 查询并展示账号积分；接口返回非敏感昵称、用户名、显示名称或公开 UID 时原样展示。
- 业务步骤完成或失败后，在已登录的情况下执行退出登录并核验结果。
- 支持每行一个账号、账号失败隔离以及任一账号失败时整体返回非零状态。
- 提供完全断网预演、分阶段脱敏日志、逐账号统计和单行 TASK_SUMMARY JSON 汇总。
- 按全局开关和脚本选择器调用青龙 Python 或 JavaScript 通知，并在通知失败时保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `rainyun_ck`

- 必填：是
- 敏感：是
- 获取或设置：使用雨云官网账号的用户名和密码；每个账号单独一行，不要填写 Cookie、Token 或示例凭据。
- 填写格式：每行一个 用户名#密码，仅在第一个 # 处分隔，密码中后续的 # 会保留。

### 可选参数

### `RAINYUN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；设置为 1 可进行完全断网预演。
- 填写格式：布尔值，1、true、yes、on 表示启用。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择器；可填写目录编号、scripts/rainyun.py、rainyun.py 或通配符。
- 填写格式：使用逗号、分号、空白或换行分隔；显式空值表示全部关闭。

## 多账号

rainyun_ck 每个非空行代表一个账号；同一行仅在第一个 # 处分隔用户名和密码，各账号使用独立会话并独立统计，任一账号失败时进程返回非零状态。
