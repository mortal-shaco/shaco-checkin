# 蜜雪冰城每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_mxbc.js`
- 青龙命令：`node scripts/sudojia_mxbc.js`
- 建议 Cron：`22 1 * * *`
- 发布哈希：`4020cb6cea155a8106ad14fd30bd679c3afdf25b1c6c7f46aad9ebec6cf7b3a4`
- 许可证：`GPL-3.0`

## 脚本功能

- 验证小程序账号登录状态，显示官方返回的非敏感昵称、用户名、显示名称或公开 UID；不显示手机号。
- 每日签到并显示本次雪王币奖励和连续签到天数。
- 签到后查询当前雪王币余额；签到失败仍尝试查询，整体保持失败状态。
- 支持每行一个 Token 的多账号，账号之间独立处理。
- 支持完全断网预演，验证参数和三阶段执行流程。
- 自带 HTTPS 请求、RSA-SHA256 签名、统一请求与签名时间戳、15 秒总超时、响应大小限制和严格业务成功校验。
- 提供时间轴日志、阶段耗时、每账号及全任务统计，以及恰好一条 TASK_SUMMARY JSON。
- 正式运行在成功、部分失败、失败和配置错误后发送脱敏青龙通知，通知失败不改变业务退出码；离线预演输出脱敏通知摘要，不调用网络通知通道。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MXBC_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在本人蜜雪冰城小程序登录后，用抓包工具查看 https://mxsa.mxbc.net 的账号接口请求头，提取 Access-Token 值。不要复制整个请求头或向他人发送抓包记录；失效后重新登录获取。
- 填写格式：每个非空行一个完整 Access-Token；去除行首尾空白，不使用 &、@ 或其他符号分隔账号。

### `MXBC_SIGNING_KEY`

- 必填：是
- 敏感：是
- 获取或设置：正式运行需要应用 RSA 签名私钥。已有签名材料的来源为原上游 sudojia/AutoTaskScript 的 src/wx_mini/sudojia_mxbc.js 中 privateKeyStr；仅在确认有权使用后提取 PEM 完整文本。也可使用服务认可的授权应用签名材料。本版不内置、不下载签名私钥，不可用请求中的 sign 或 Access-Token 代替。离线预演无需此变量。
- 填写格式：完整 RSA 私钥 PEM 文本（保留实际换行和 BEGIN/END 标记），或完整 PEM 文本的 Base64 编码；同一应用的账号共用此签名配置。

### 可选参数

### `MXBC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验证时手动设置为 1，正式运行时设为 0 或不设置。
- 填写格式：1 表示完全断网预演；其他值为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：需要自定义通知位置时，填写可信的青龙 sendNotify.js 或 notify.py 所在目录；不设置时依次查找 /ql/data/scripts、/ql/scripts，最后尝试 Python 导入 notify。
- 填写格式：本机可信通知模块目录的路径；业务执行不依赖该目录。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

MXBC_TOKEN 每个非空行一个账号，逐个独立验证、签到和查询；任一账号失败则整体非零退出。签名私钥为应用公共配置，不使用符号拼接账号。
