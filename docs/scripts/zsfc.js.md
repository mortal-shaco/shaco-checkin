# 掌上飞车签到与商城

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/zsfc.js`
- 青龙命令：`node scripts/zsfc.js`
- 建议 Cron：`51 0,21 * * *`
- 发布哈希：`1dcf297f28101fffe1ab2fbb67748e9bddca422c1cd42ac2befb347fc85f9522`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每日签到并识别已签到状态
- 查询本月累计签到天数，补领已达到门槛的累计奖励
- 浏览游戏背包并领取查看动态、浏览背包、游戏活跃的已达标每日奖励
- 周六及周日领取进行游戏、花费点券的已达标每周奖励；不自动游戏或花费点券完成任务
- 可选查询商城点券和消费券余额、紫钻会员折扣，精确匹配指定商品，按规格计算购买计划
- 显式开启的16点后预算内商城购买，支持月底消费券和点券策略、非月底补齐最低档、月份轮换商品以及永久商品防重记录
- 逐行多账号、完全断网预演、超时及大小限制、明确业务成功检查、脱敏分阶段日志与结构化汇总
- 按青龙通知开关和脚本选择器发送成功、失败、部分失败或配置错误总结；预演仅模拟通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ZSFC_CONFIG`

- 必填：是
- 敏感：是
- 获取或设置：在掌上飞车 APP 进入资讯栏签到（每日福利），从 comm.ams.game.qq.com/ams/ame/amesvr 请求体获取 iActivityId 和查询累签的 iFlowId；从 Cookie 获取 accessToken（或 access_token）、openId（或 openid），解码 tokenParams 获取 roleId、uin、areaId。再进入游戏栏掌飞商城，从 bang.qq.com/app/speed/mall/main2 的查询参数获取 token、userId 及其余同账号字段。将值手动填入账号 JSON；每月重新抓取活动和流水编号；商城登录失效时重新抓取。不要向他人提供抓包或凭据。
- 填写格式：每个非空行一个完整 JSON 对象，禁止用 & 或 @ 分隔账号；必含 accessToken、openid、iActivityId、iFlowId、uin、areaId、userId、token、roleId；每个字段也兼容 zsfc_ 前缀。凭据保留原值，不按字符拆分；活动、流水和区服编号用数字字符串。

### 可选参数

### `ZSFC_iFlowdId`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游签到抓包写入的流水和活动组合；优先使用各账号 JSON 内的独立字段。
- 填写格式：查询流水编号/活动编号；仅在账号对应字段缺失时补足；多账号不同活动时必须写在各自 JSON 内。

### `ZSFC_FLOWS`

- 必填：否
- 敏感：否
- 获取或设置：对照当月每日福利页面对应奖励请求的 iFlowId 手动更新；上游硬编码编号可能过期。
- 填写格式：JSON 对象，可覆盖 daily（周日至周六七个编号数组）、accumulative（天数到编号对象）、dailyTask 和 weeklyTask（任务名到编号对象）；各编号必须为数字。只更新实际观察到的流水，不填猜测值。

### `ZSFC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：断网检查时设置，正式运行时不设置或设为 0。
- 填写格式：1 开启完全断网预演；0 正式运行；预演不加载通知模块，不写购买记录。

### `ZSFC_SHOP`

- 必填：否
- 敏感：否
- 获取或设置：需要自动购买时显式开启，默认关闭以避免消费。
- 填写格式：1 开启，0 关闭；优先于可选兼容输入 zsfc_shop；每天16点后执行购买。

### `zsfc_shop`

- 必填：否
- 敏感：否
- 获取或设置：兼容原 BoxJS 的商城购买开关，可迁移到 ZSFC_SHOP。
- 填写格式：true 或 false；仅在 ZSFC_SHOP 未设置时生效；默认关闭。

### `ZSFC_SHOP_MAX_SPEND`

- 必填：否
- 敏感：否
- 获取或设置：自行设置每账号每轮最多花费的商城金额，开启购买时必须提供。
- 填写格式：正整数；默认无预算，开启购物但未设置将配置失败；默认仅允许消费券，不主动花费点券。

### `ZSFC_SHOP_ALLOW_MONEY`

- 必填：否
- 敏感：否
- 获取或设置：仅在明确接受点券消费时开启。
- 填写格式：1 允许点券，默认 0；月底最后两天可搭配点券，非月底仅允许点券补齐最低档，仍受总预算约束。

### `ZSFC_SHOP_NAME`

- 必填：否
- 敏感：否
- 获取或设置：从掌飞商城复制在售商品的完整名称。
- 填写格式：完整商品名称；未设置时按月份循环选择进气系统+1、点火装置+1、引擎装置+1；兼容 zsfc_bang_shopname。

### `zsfc_bang_shopname`

- 必填：否
- 敏感：否
- 获取或设置：兼容原 BoxJS 的指定商品名，可迁移到 ZSFC_SHOP_NAME。
- 填写格式：完整商品名称；仅在 ZSFC_SHOP_NAME 未设置时生效。

### `ZSFC_SHOP_STATE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：可选指定可写的本地防重记录文件，不依赖私有仓库；默认候选脚本旁 .zsfc-shop-state.json。
- 填写格式：本地文件路径；仅启用正式购物时使用。永久商品请求前记录待确认状态，成功后记录已购买；待确认也阻止再次购买，请核对库存后手动处理记录。不同账号使用摘要区分，不保存凭据。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中填写要通知的脚本；设置后替换默认名单。
- 填写格式：逗号、分号或空白分隔；支持目录相对路径 zsfc/zsfc.js、文件名 zsfc.js 或 candidate.js、目录编号 d0e6679f8cb579d7，支持 * 通配符；* 选择全部，空值不选任何脚本。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块在自定义目录时设置。
- 填写格式：包含 sendNotify.js 的目录；随后依次查找 /ql/data/scripts 和 /ql/scripts；模块不可用只记录通知失败。

## 多账号

ZSFC_CONFIG 每个非空行一个完整账号 JSON 对象；同账号登录及商城字段合并保存，兼容 zsfc_ 字段前缀。账号依次独立执行，单个账号配置或业务失败不阻止其余账号；任一账号失败则进程非零退出。
