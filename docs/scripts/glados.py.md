# GLaDOS每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/glados.py`
- 青龙命令：`python3 scripts/glados.py`
- 建议 Cron：`30 0 * * *`
- 发布哈希：`e4bc864a58ac64f8e3b8c4ae8e1d7e9bcc8564d23f488c540b7c012fb39713d4`
- 许可证：`Apache-2.0`

## 脚本功能

- 使用 GLaDOS 账号 Cookie 执行每日签到，并明确校验接口业务结果。
- 查询并显示官方返回的账号身份和剩余可用天数。
- 支持每行一个账号的多账号独立处理与汇总统计。
- 支持完全断网预演、时间轴日志、机器可读汇总和青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `GR_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录 GLaDOS 网页后，在浏览器开发者工具的网络请求中复制发往 glados.rocks 的完整 Cookie 请求头；请勿把该值发送给他人。
- 填写格式：每行一个账号的完整 Cookie；Cookie 内的 & 保持原样，不得用 & 或 @ 分隔账号。

### 可选参数

### `GLADOS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；设为 1 可执行完全断网预演。
- 填写格式：启用值为 1、true、yes 或 on。

### `GLADOS_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；按网络情况设置单次请求超时秒数。
- 填写格式：1 到 60 之间的数字，默认 15。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；填写需要通知的脚本选择器，空值表示全部关闭。
- 填写格式：可用逗号、分号、空白或换行分隔；支持目录、文件名、通配符、catalogId 或 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：通常无需设置；仅在通知脚本不位于青龙标准目录时填写其所在目录。
- 填写格式：包含 notify.py 或 sendNotify.js 的本地目录绝对路径。

## 多账号

GR_COOKIE 中每个非空行代表一个账号；各账号独立执行，任一账号失败时进程返回非零退出码。
