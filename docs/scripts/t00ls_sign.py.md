# T00ls每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/t00ls_sign.py`
- 青龙命令：`python3 scripts/t00ls_sign.py`
- 建议 Cron：`21 1 * * *`
- 发布哈希：`48f6d4c05fe8db0de44d5ea6f1414af35a66268506a31f27290e143c0dee4372`
- 许可证：`MIT`

## 脚本功能

- 使用官方 API 完成 T00ls 每日签到，识别今日已签并核验 sign_today。
- 支持用户名密码（MD5）登录与 Cookie 登录，可选安全提问；展示官方返回的用户名。
- 查询累计签到次数、TuBi、TCV 等非凭据状态；可选零点换日残留重试。
- 可选自动/强制补签（默认关闭，避免消耗 TuBi）。
- 支持逐行多账号、完全断网预演、超时控制、时间轴日志与单行 TASK_SUMMARY。
- 通过青龙 notify.py 或 sendNotify.js 发送脱敏任务汇总，遵守全局开关与脚本清单。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `T00LS_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://www.t00ls.com 使用本人账号。密码登录：填写用户名与登录密码（脚本内部转 MD5）；若账号启用了安全提问，追加提问编号与答案。也可在浏览器登录后复制发往 www.t00ls.com 的 Cookie。勿把真实凭据写入仓库、日志或示例。
- 填写格式：每个非空行一个账号。密码登录：用户名|密码，或 用户名|密码|提问编号(0-7)|答案（默认仅在首个竖线处分割；若末两段可明确识别为提问编号与答案则从右侧拆出）。Cookie 登录：整行粘贴 Cookie。账号之间只用换行分隔。

### 可选参数

### `T00LS_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容别名；未设置 T00LS_ACCOUNTS 时可读此变量，每行一份 Cookie。优先使用规范变量 T00LS_ACCOUNTS。
- 填写格式：每个非空行一个账号的 Cookie 字符串。

### `T00LS_USERNAME`

- 必填：否
- 敏感：否
- 获取或设置：可选单账号兼容别名；仅当 T00LS_ACCOUNTS 与 T00LS_COOKIE 皆空，且同时提供 T00LS_PASSWORD 或 T00LS_PASSWORD_MD5 时生效。优先使用 T00LS_ACCOUNTS。
- 填写格式：单个用户名字符串。

### `T00LS_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：可选单账号兼容别名：明文登录密码；脚本内部计算 MD5 后提交。勿写入公开仓库。
- 填写格式：单个密码字符串。

### `T00LS_PASSWORD_MD5`

- 必填：否
- 敏感：是
- 获取或设置：可选单账号兼容别名：已计算的 32 位小写/大写 MD5；若同时提供明文密码，本项优先。
- 填写格式：32 位十六进制 MD5。

### `T00LS_QUESTION_ID`

- 必填：否
- 敏感：否
- 获取或设置：可选：单账号安全提问编号，配合 T00LS_USERNAME 使用。0 表示无安全提问。
- 填写格式：整数 0 到 7。

### `T00LS_QUESTION_ANSWER`

- 必填：否
- 敏感：是
- 获取或设置：可选：单账号安全提问答案，配合 T00LS_QUESTION_ID 使用。
- 填写格式：单个答案字符串。

### `T00LS_AUTO_BU_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：可选：开启自动补签。默认关闭。开启后仅在检测到漏签且今日尚未尝试时调用补签接口，每次约消耗 20 TuBi。
- 填写格式：1、true、yes 或 on 启用；默认关闭。

### `T00LS_FORCE_BU_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：可选：强制补签一次（不检查是否漏签），每次约消耗 20 TuBi，仅用于核对接口。默认关闭。
- 填写格式：1、true、yes 或 on 启用；默认关闭。

### `T00LS_BU_SIGN_WITHIN_DAYS`

- 必填：否
- 敏感：否
- 获取或设置：可选：自动补签允许的最大漏签天数；超过则跳过。
- 填写格式：正整数；默认 3。

### `T00LS_STALE_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：可选：零点后站点尚未换日时的签到重试次数。设为 0 可关闭。
- 填写格式：非负整数；默认 3。

### `T00LS_STALE_WAIT`

- 必填：否
- 敏感：否
- 获取或设置：可选：换日重试前等待秒数。
- 填写格式：数字秒；默认 30。

### `T00LS_STATE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：可选：本地状态文件路径，用于漏签判断与补签限频；不含凭据明文。
- 填写格式：可写文件路径；默认脚本旁 t00ls-state.json。

### `T00LS_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：可选：覆盖接口域名；一般无需修改。
- 填写格式：HTTPS 根地址；默认 https://www.t00ls.com。

### `T00LS_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置单次 HTTPS 请求超时；默认 20 秒。
- 填写格式：数字秒，范围 5 到 120。

### `T00LS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：用于首次配置检查与完全断网预演；不代表真实业务成功。
- 填写格式：1、true、yes 或 on 启用；不访问业务接口。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行选择需要推送的脚本；设置后替代默认通知清单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；支持 06364e72aec0863e、scripts/t00ls_sign.py；* 选择全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：指定已安装青龙通知模块所在目录，否则依次发现可导入的 notify、/ql/data/scripts、/ql/scripts。
- 填写格式：目录路径，包含 notify.py 或 sendNotify.js。

## 多账号

每个非空行一个账号，格式为 用户名|密码、用户名|密码|提问编号|答案，或整行 Cookie；账号之间只用换行分隔。各账号独立执行，任一账号失败时整体非零退出。

## 副作用与风险

- 正式执行时向 T00ls 提交每日签到，可能增加累计签到次数与 TuBi。
- 显式开启补签时调用补签接口，每次约扣除 20 TuBi。
- 密码登录会向官方登录接口提交密码 MD5；可选写入本地状态文件记录签到基线（不含凭据）。
- 通知启用且助手可用时发送脱敏任务汇总；无网络预演不访问业务接口。
