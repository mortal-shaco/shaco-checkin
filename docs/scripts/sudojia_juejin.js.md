# 稀土掘金每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_juejin.js`
- 青龙命令：`node scripts/sudojia_juejin.js`
- 建议 Cron：`43 2 * * *`
- 发布哈希：`d329961780c19c38e674fad87bc53f38f6783af9082e67d703866ec73a7ece50`
- 许可证：`GPL-3.0`

## 脚本功能

- 检查登录和今日签到状态
- 显示官方返回的账号昵称
- 每日签到，已签到时不重复提交，重复签到业务码须经状态复核
- 查询矿石余额
- 统计连续和累计签到天数
- 换行多账号独立处理和失败退出
- 完全断网参数预演
- 青龙脱敏汇总通知和阶段日志、单行结构化统计
- 兼容完整 Cookie、旧分开签名参数及 JUEJIN_COOKIE_2 至 JUEJIN_COOKIE_5，推荐每行合并一个账号
- 显式开关控制免费抽奖，只在验证免费次数后抽取一次
- 显式开关控制沾喜气，无幸运记录时跳过
- 显式开关控制首个未收集 Bug 的消除并复核状态
- 查询幸运值，可独立关闭新增查询

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JUEJIN_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录自己的掘金账号，在浏览器开发者工具网络面板查看签到请求。复制请求头中的完整 Cookie 或在应用面板取得 sessionid；复制 check_in 请求问号后的原始查询串，不要复制网址、重新排序或混用账号。须含 uuid、spider、msToken、a_bogus，aid 如提供须为 2608。签名可能随时过期，应重新抓取，不保证三十天有效。扩展 document.cookie 可能缺少 HttpOnly 会话，优先使用真实请求头。
- 填写格式：每个非空行一个账号，格式为 sessionid#原始查询串或完整 Cookie#原始查询串，仅在第一个 # 分隔。账号之间只用换行，查询串的 & 是字段分隔符。兼容旧 Cookie 配置加本账号分开的签名变量，推荐合并配置。

## 多账号

每个非空行一个账号；同账号会话和查询串在首个 # 合并，后面的原始查询串完整保留。绝不以 & 或 @ 分割账号。旧附加账号变量依次追加，每个账号独立执行；任一账号或全局配置失败则非零退出。

## 副作用与风险

- 尚未签到时提交每日签到，领取矿石奖励
- 显式启用后在免费次数大于零时提交一次抽奖，使用一次免费机会
- 显式启用后提交沾喜气，改变幸运值
- 显式启用后收集首个未收集 Bug，改变收集及奖励状态
- 正式运行且通知启用并可用时发送青龙脱敏摘要
