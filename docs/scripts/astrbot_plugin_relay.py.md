- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/astrbot_plugin_relay.py`
- 青龙命令：`python3 scripts/astrbot_plugin_relay.py`
- 建议 Cron：`39 9 * * *`
- 发布哈希：`ad26f2acfb102182f52671db904358be482b6c7aa8197f0173b85551801737ee`
- 许可证：`MIT`

## 脚本功能

- 独立 HTTP 实现 NewAPI、Veloera 及同源站每日签到，无需 AstrBot 或私有仓库
- 支持系统访问令牌、账号密码、浏览器 Cookie 三种认证及多站多账号
- 保留四条签到路径顺序：check_in、checkin、clock_in、sign_in；仅接口不存在或明确返回前端页面时继续探测，避免不确定请求立即重复变更
- 自动补全本站用户 ID 并发送 New-Api-User、Veloera-User、VoApi-User 请求头
- 提供只读查询及凭据验证开关，不因绑定或查询触发签到
- 查询余额、已用额度、签到奖励；支持多种奖励字段和余额差值，按 quota_per_unit 换算并保留小额精度
- 展示官方返回的非秘密账号身份；识别已签到、未启用、鉴权错误及人机验证，不绕过校验
- 每日 08:30 青龙调度、确定性延迟、有限失败重试、账号选择及单账号定时开关
- 兼容结构化账号字段及上游简单旧行式参数，复杂凭据用每行一个 JSON 对象无歧义保存
- 完全断网预演、分阶段时间轴、账号及任务统计、唯一 TASK_SUMMARY 记录和受全局策略控制的青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `RELAY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：每个站点分别登录；个人设置→安全设置生成系统访问令牌（不能用 sk- API 密钥），个人资料查看本站用户 ID。密码模式使用本站登录用户名及密码。Cookie 模式在浏览器自行完成人机校验后，从本站请求头复制完整 Cookie。全部凭据仅保存在青龙环境变量中。
- 填写格式：每个非空行一个 JSON 对象；url 必填，mode 为 token/password/cookie，分别填写 token、username 和 password、cookie；uid 为本站数字用户 ID，可留空尝试自动补全。可选 name、enabled、sched（后两者为布尔值）。同一行 JSON 保留凭据内所有分隔符，不用 & 或 @ 分账号。兼容上游简单旧行式：名称|HTTPS地址|token=令牌|uid=编号；user/pass、key/id/base 等旧字段仍可用，复杂凭据请用 JSON。

### 可选参数

### `RELAY_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：按需在青龙环境变量设置；默认执行签到。
- 填写格式：checkin 为签到并查询余额；query 或 verify 为只读账号验证及余额查询，密码模式仍需登录取得会话。默认 checkin。

### `RELAY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无网络预演时设为 1。
- 填写格式：1/true/yes/on 启用，不发送任何请求或通知、不等待；预演成功只代表配置通过。

### `RELAY_SELECT`

- 必填：否
- 敏感：否
- 获取或设置：按需设置原始账号序号或配置中的 name。
- 填写格式：空值处理全部启用且 sched 不为 false 的账号；非空值精确选择一个序号或名称，并允许手动处理 sched=false 的启用账号。

### `RELAY_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络条件设置。
- 填写格式：5–120 的整数秒，默认 20，所有 HTTP 请求均设置超时并校验 TLS。

### `RELAY_RANDOM_DELAY_MINUTES`

- 必填：否
- 敏感：否
- 获取或设置：按调度需要设置；0 关闭延迟。
- 填写格式：0–60 的整数分钟，默认 20；每日确定性随机延迟，仅正式签到等待。

### `RELAY_RETRY_TIMES`

- 必填：否
- 敏感：否
- 获取或设置：按调度需要设置。
- 填写格式：0–3 的整数，默认 3；仅暂时网络错误、HTTP 429 或服务端错误重试，不因鉴权错误、人机验证、未启用而重试。

### `RELAY_RETRY_INTERVAL_MINUTES`

- 必填：否
- 敏感：否
- 获取或设置：按调度需要设置。
- 填写格式：1–60 的整数分钟，默认 30；跨天停止本轮重试。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：按需在青龙配置通知脚本选择列表，设置后替代默认列表；本脚本未列入默认列表。
- 填写格式：用逗号、分号、空白或换行分隔；匹配目录编号 c7b19578064eea37、脚本相对路径、文件名或文件名通配符；* 选择全部，空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：已有青龙 notify.py 或 sendNotify.js 所在目录；也会尝试导入 notify.send 及青龙标准脚本目录。
- 填写格式：本地目录路径，仅用于可选通知集成；脚本业务无需该目录或其他仓库。

## 多账号

每个非空行一个独立站点账号，同站多账号也各占一行；同账号配套凭据集中于同一 JSON 对象；账号依次独立执行，任一失败整体非零退出。禁用账号和未选账号明确跳过，无可执行账号按配置错误退出。

## 副作用与风险

- 正式签到调用站点签到接口，可能增加账号额度及签到记录
- 密码模式登录会建立服务端登录会话
- 启用通知时通过现有青龙通知配置发送脱敏任务总结
