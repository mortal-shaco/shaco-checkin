## 脚本功能

- 读取阴阳师官网原画页面，保留首个 tab-cont 内六个链接的第三个原画链接选择规则。
- 默认仅核验并列出素材；显式开启后保存原画，保留数字路径命名与原画目录默认值，修复未知文件名及同名碰撞。
- 通过任务开关读取全部官网 CG 视频分组，保存标题命名的 MP4 视频并记录 downloaded_videos.txt 标题历史。
- 校验已有素材文件格式并跳过下载；视频新下载数量限制与默认两秒间隔均保留。
- 独立实现带超时和 HTTPS 重定向校验的 HTTP 请求；检查状态码、页面结构、素材格式、大小及已知响应长度；原子落盘且不覆盖已有文件。
- 每种素材及每个下载项独立处理，任一失败即整体非零退出；输出中文分阶段耗时、子任务统计和唯一 TASK_SUMMARY JSON。
- 提供无账号、无网络、无文件写入的断网预演，覆盖原画和视频解析。
- 所有结果发送脱敏青龙通知；预演输出通知摘要且不调用通知服务，通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

当前脚本无需必选参数。

### 可选参数

### `YYS_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：无需账号。在青龙环境变量中选择原画、CG视频或两者。
- 填写格式：images（默认）、videos 或 images,videos

### `YYS_DOWNLOAD`

- 必填：否
- 敏感：否
- 获取或设置：无需从官网获取。确认下载目录与磁盘空间后自行显式开启。
- 填写格式：1 开启下载；0 默认仅解析并列出素材；兼容 true/false、yes/no、on/off

### `YYS_IMAGE_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自行选择有写入权限的原画保存目录。
- 填写格式：目录路径，默认 ./yys原画

### `YYS_VIDEO_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自行选择有写入权限的视频保存目录，标题历史也保存在该目录。
- 填写格式：目录路径，默认 ./yys视频

### `YYS_VIDEO_LIMIT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置本次成功下载的新视频数量上限。
- 填写格式：非负整数，默认 0 表示全部；已有文件不计入上限

### `YYS_VIDEO_INTERVAL`

- 必填：否
- 敏感：否
- 获取或设置：自行设置每个新视频成功下载后的等待时间。
- 填写格式：0 至 3600 的秒数，默认 2

### `YYS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置断网预演开关；无需任何凭据。
- 填写格式：1 使用内置页面样本且不联网、不写素材、不调用通知服务；默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，自行设置。
- 填写格式：默认 1；0、false、no、off 关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：选填青龙自带 notify.py 所在目录；未设置则自动发现 notify 模块及青龙常用目录。
- 填写格式：目录路径；通知模块不可用不改变任务退出码
