# 威锋网签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/feng.js`
- 青龙命令：`node scripts/feng.js`
- 建议 Cron：`16 10 * * *`
- 发布哈希：`c73bd1b06df81caa424470883b8b7c86172c9a93b365b944afe5ff070275bf41`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 使用原始登录请求体和 X-Running-Env 登录威锋网，兼容原 chavy_login_feng 会话格式。
- 使用内置加密库生成与上游一致的 AES-CBC 请求签名，无需安装第三方业务依赖。
- 每日签到，业务码 0 判定成功，1021 判定已经签到；其他响应失败闭合。
- 支持换行多账号、独立失败处理及整体退出码。
- 官方返回昵称、用户名、显示名或公开 UID 时输出原值，抑制凭据及手机号。
- 提供完全断网的参数和签名预演、逐阶段脱敏日志、账号与任务统计及唯一 TASK_SUMMARY 记录。
- 按全局开关及通知选择清单调用青龙 sendNotify.js，通知不可用不影响业务结果。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FENG_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录本人威锋 App，使用本人授权抓包工具获取 POST https://api.wfdata.club/v1/auth/signin 的原始请求体和 X-Running-Env 请求头；将两者组合为单行 JSON。不要分享凭据；不要复制 Cookie、签名或访问令牌。可将原会话捕获脚本保存的 chavy_login_feng 对象原样导出到此变量，无需私有文件。
- 填写格式：每个非空行一个 JSON 对象，body 为原始请求体字符串，headers 为包含 X-Running-Env 字符串的对象；其他捕获字段不使用。JSON 字符串中的换行需转义；请求体不按 & 或 @ 拆分。

### 可选参数

### `chavy_login_feng`

- 必填：否
- 敏感：是
- 获取或设置：旧会话键的可选环境变量兼容入口，由本人原会话捕获记录导出；优先配置 FENG_ACCOUNTS。脚本不读取 box.dat。
- 填写格式：与 FENG_ACCOUNTS 相同；仅当 FENG_ACCOUNTS 为空或未设置时使用。

### `FENG_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1，正式运行时删除或设置为 0。
- 填写格式：1 表示断网预演；其余值为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要通知时填入本脚本目录编号、路径或文件名；设置后替换默认清单。
- 填写格式：逗号、分号、空白或换行分隔；支持 a4a2af6a3c46bf58、feng/feng.js、feng.js、candidate.js、实际文件名及 * 通配符；空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填入青龙 sendNotify.js 所在目录；未设置时检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径；通知缺失或失败不改变业务退出码。预演调用本地通知时禁止网络及外部程序。

## 多账号

每个非空行一个账号会话 JSON；同一账号请求体与运行环境头保存在同一对象，不拆分凭据文本。逐账号独立执行，任一账号失败则整体非零退出。
