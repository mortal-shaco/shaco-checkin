# 什么值得买签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/smzdm_checkin.js`
- 青龙命令：`node scripts/smzdm_checkin.js`
- 建议 Cron：`58 0 * * *`
- 发布哈希：`91cd8c77fdb589abd96ea3f32532249724e55bcb2ff7fbdec8ffd8e218b7df08`
- 许可证：`MIT`

## 脚本功能

- 校验账号的 sk 与 sess 配套凭据
- 执行什么值得买每日签到并识别今日已签到状态
- 查询签到奖励与连续签到状态
- 满足条件时领取连续签到额外奖励
- 查询并显示接口可取得的账号身份、等级、金币和碎银概览
- 统计当月经验变动
- 支持逐行多账号独立处理与失败汇总
- 提供完全断网的离线预演
- 输出时间轴日志、兼容结果记录和单行 TASK_SUMMARY JSON
- 按青龙通知策略发送脱敏汇总
- 展示签到天数、补签卡、普通奖励和礼包明细
- 查询值会员总经验、等级经验及有效期
- 通过显式任务开关查询两处会员转盘活动并各执行一次抽奖
- 可显式启用原上游未默认运行的生活频道转盘入口
- 仅抽奖模式兼容逐行 SMZDM_COOKIE，无需签到 sk
- 保留原抽奖独立调度说明及请求间等待
- 可显式选择上游 Robot Token 签到流程，严格验证获取、签到及普通奖励响应
- 兼容旧 Cookie 与配套 sk 环境变量，不使用共享默认 sk
- 按青龙、PushPlus、Server酱顺序发送脱敏汇总并验证回退推送结果
- 通过显式开关执行好价点值与好文点赞，每类最多七条且逐项验证业务结果
- 互动前后查询账号身份、签到状态、积分、金币、碎银及未读消息，并展示资产变化
- 查询互动前后总经验并展示最近二十条经验记录，提示记录可能延迟
- 显式网页 Cookie 签到无需 sk，已签到跳过写入，写入后重新核对账号身份、签到状态和天数
- 网页模式展示官方账号身份、积分、经验、金币、碎银、威望、等级及签到天数
- 通过独立显式模式保留原固定活动单次 POST 抽奖，不与既有动态会员转盘混跑
- 兼容逐行 SMZDM_COOKIE_LIST 并保留原固定活动每日 15:00:45 调度说明
- 固定活动严格核验 HTTP、业务码和结果字段，失败不重试写入

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SMZDM_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：登录本人什么值得买客户端，从本人签到请求取得 sk；在开发者工具网络请求中复制本人完整 Cookie，至少含 sess。仅抽奖或网页签到可省略 sk。不要分享凭据。
- 填写格式：每个非空行一个账号，格式 sk|完整 Cookie；仅在第一个 | 分割。网页或仅抽奖模式使用 |完整 Cookie。

### 可选参数

### `SMZDM_COOKIE_LIST`

- 必填：否
- 敏感：是
- 获取或设置：兼容原固定抽奖变量；从本人已登录什么值得买网页请求头复制完整 Cookie。
- 填写格式：每个非空行一个完整 Cookie，必须含 sess；固定活动模式下优先于其他旧 Cookie 变量。

### `SMZDM_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容入口；从本人已登录网页或客户端请求头获取完整 Cookie。
- 填写格式：每个非空行一个完整 Cookie，至少含 sess；客户端签到另配同顺序 SMZDM_SK，或 Cookie 内带 sk。

### `SMZDM_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：旧复数变量兼容入口；从本人已登录网页或客户端请求头获取完整 Cookie。
- 填写格式：每个非空行一个完整 Cookie；可用 # 开头的注释行；客户端签到另配配套 sk。

### `SMZDM_SK`

- 必填：否
- 敏感：是
- 获取或设置：从本人客户端签到请求取得 sk，与旧 Cookie 变量的账号逐行对应；不使用他人或共享默认值。
- 填写格式：每个非空行一个 sk；需要 sk 时行数须与旧 Cookie 账号数相同。

### `SMZDM_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：按需要在青龙环境中选择；默认 checkin，不自动执行转盘或固定活动。
- 填写格式：checkin：签到；lottery：既有会员转盘；all：签到和既有会员转盘；upstream-lottery：仅原固定活动一次抽奖。固定活动原调度为 45 0 15 * * *，会员转盘原独立调度为 20 8 * * *，需在相应任务环境中选择模式。

### `SMZDM_TOKEN_MODE`

- 必填：否
- 敏感：否
- 获取或设置：保留默认 sess；需要原 Robot Token 或网页 Cookie 签到时显式选择。
- 填写格式：sess、robot 或 web；默认 sess。网页模式无需 sk。

### `SMZDM_INTERACTION`

- 必填：否
- 敏感：否
- 获取或设置：仅希望执行点赞或点值时开启；默认不互动。
- 填写格式：none、value、article 或 both；默认 none，每类最多七条，原互动调度 29 0-23/8 * * * 可自定义。

### `SMZDM_LOTTERY_LIFE`

- 必填：否
- 敏感：否
- 获取或设置：显式启用原生活频道入口；仅影响 lottery 或 all，不影响固定活动模式。
- 填写格式：1、true、yes、on 启用；默认关闭。

### `SMZDM_USER_AGENT_APP`

- 必填：否
- 敏感：否
- 获取或设置：可从本人什么值得买请求头复制客户端 User-Agent；不要填入凭据或设备标识。
- 填写格式：可选请求头字符串；未配置时使用各模式既有客户端配置。

### `SMZDM_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：验证配置时设为 1，完全离线，不调用任何联网通知组件。
- 填写格式：1、true、yes、on 启用；默认正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可指定青龙已有 sendNotify.js 所在目录；也会查找青龙标准脚本目录。
- 填写格式：可选目录；组件缺失或发送失败只记录通知状态，不改变业务退出码。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在本人 PushPlus 账户取得推送令牌，仅用于青龙通知不可用或失败时回退。
- 填写格式：可选推送令牌，受 QINGLONG_NOTIFY 控制。

### `SENDKEY`

- 必填：否
- 敏感：是
- 获取或设置：在本人 Server酱账户取得 SendKey，仅用于前两种通知不可用或失败时回退。
- 填写格式：可选推送密钥，受 QINGLONG_NOTIFY 控制。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号；配套 sk 与完整 Cookie 合并为 SMZDM_ACCOUNT，仅在首个 | 分割。旧 Cookie 变量逐行兼容，不用 & 或 @ 分隔账号；独立处理所有账号，任一账号失败整体非零退出。

## 副作用与风险

- 在什么值得买账号上执行每日签到并改变当日签到状态
- 满足条件时领取连续签到额外奖励并改变账号奖励状态
- 显式选择 lottery 或 all 后提交转盘抽奖，可能消耗抽奖机会或活动资产并获得奖励
- 显式启用 value 或 both 后对好价提交点值，改变账号投票状态
- 显式启用 article 或 both 后对好文提交点赞，改变账号点赞状态
- 显式选择 upstream-lottery 后对原固定活动提交一次抽奖，可能消耗机会或活动资产并获得奖励
