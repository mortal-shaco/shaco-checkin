# 什么值得买签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/smzdm_checkin.js`
- 青龙命令：`node scripts/smzdm_checkin.js`
- 建议 Cron：`5 1 * * *`
- 发布哈希：`dae84dc4839f86bdcbbcdf2301cabe258fcec418345962daf167cfb92714fae9`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 校验同一账号的 sk 与 sess 配套凭据，并兼容旧环境变量
- 执行什么值得买每日客户端签到并识别今日已签到状态
- 显式 dual 模式依次执行客户端签到和网页签到状态核验
- 查询普通签到奖励、连续签到状态，并在满足条件时领取额外奖励
- 查询并展示官方接口可取得的账号身份、签到天数、补签卡、等级、积分、经验、金币和碎银
- 统计最近三页中的当月经验，并查询值会员经验、等级经验和有效期
- 显式 web 模式使用网页 Cookie 签到，写入前后均核验账号身份和签到状态
- 显式 lottery 或 all 模式查询会员转盘并各执行一次抽奖
- 显式开关可增加生活频道转盘，保留请求间等待且不自动重试写入
- 显式 upstream-lottery 模式保留固定活动的独立单次 POST 抽奖和原调度说明
- 显式 value、article 或 both 模式执行好价点值或好文点赞，每类最多七条
- 互动前后查询账号资产、未读消息、总经验和最近二十条经验记录
- 可显式启用最长等待时间受限的随机启动延迟，默认关闭且预演不等待
- 支持逐行多账号独立处理，并在任一账号失败时返回非零退出码
- 提供完全断网的离线预演，不访问业务接口、文本接口或通知接口
- 输出时间轴日志、兼容结果记录和且仅一条 TASK_SUMMARY JSON
- 按青龙通知策略发送脱敏汇总，并保留 PushPlus 与 Server酱回退通道

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SMZDM_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：登录本人什么值得买客户端，在本人授权的 HTTPS 调试环境中查看签到请求，取得配套的 sk 与完整 Cookie；网页或仅抽奖模式可从本人已登录网页请求头复制完整 Cookie。不得公开这些值。
- 填写格式：每个非空行一个账号，写成 sk|完整 Cookie，仅在第一个竖线处分割，Cookie 必须包含 sess；网页或仅抽奖模式可写成 |完整 Cookie，不得用 & 或 @ 分隔账号。

### 可选参数

### `SMZDM_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：按需要选择任务动作；不配置时只执行每日签到流程，高副作用任务不会默认开启。
- 填写格式：可填 checkin、lottery、all 或 upstream-lottery，默认 checkin；后三者涉及抽奖时应先核对活动规则。

### `SMZDM_TOKEN_MODE`

- 必填：否
- 敏感：否
- 获取或设置：按凭据来源和所需签到通道选择；不确定时保持默认值。
- 填写格式：可填 sess、robot、web 或 dual，默认 sess；dual 会依次执行客户端签到与网页状态核验。

### `SMZDM_INTERACTION`

- 必填：否
- 敏感：否
- 获取或设置：仅在明确希望改变好价点值或好文点赞状态时设置。
- 填写格式：可填 none、value、article 或 both，默认 none；每类最多处理七条。

### `SMZDM_LOTTERY_LIFE`

- 必填：否
- 敏感：否
- 获取或设置：仅在确认生活频道转盘仍开放且愿意消耗抽奖机会时启用。
- 填写格式：填 1、true、yes 或 on 表示启用，默认关闭，只对 lottery 或 all 生效。

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：需要错峰运行时手动设置；为保持已发布维护版行为并避免任务意外阻塞，默认关闭。
- 填写格式：填 1、true、yes 或 on 表示在正式执行前随机等待；离线预演只检查配置而不等待。

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：仅在启用 RANDOM_SIGNIN 时按允许的最长等待时间设置。
- 填写格式：填写 0 到 86400 的整数秒数，默认 3600 秒。

### `SMZDM_USER_AGENT_APP`

- 必填：否
- 敏感：是
- 获取或设置：可从本人什么值得买客户端请求头取得；通常无需配置，且可能包含设备信息，应按敏感信息保管。
- 填写格式：填写完整的客户端 User-Agent 字符串，不得包含 Cookie 或 Token。

### `SMZDM_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，从本人已登录的什么值得买请求头取得完整 Cookie；建议迁移到 SMZDM_ACCOUNT。
- 填写格式：每个非空行一个完整 Cookie，必须包含 sess；签到还需同顺序的 SMZDM_SK 或 Cookie 自带本人 sk。

### `SMZDM_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，从本人已登录的什么值得买请求头取得完整 Cookie；建议迁移到 SMZDM_ACCOUNT。
- 填写格式：每个非空行一个完整 Cookie，不得用 & 或 @ 分隔；签到还需配套本人 sk。

### `SMZDM_COOKIE_LIST`

- 必填：否
- 敏感：是
- 获取或设置：固定活动旧版兼容变量，从本人已登录的什么值得买请求头取得完整 Cookie；建议迁移到 SMZDM_ACCOUNT。
- 填写格式：每个非空行一个完整 Cookie，不得用 & 或 @ 分隔账号。

### `SMZDM_SK`

- 必填：否
- 敏感：是
- 获取或设置：仅配合旧 Cookie 变量使用，从与该 Cookie 相同账号的客户端签到请求中取得 sk。
- 填写格式：每个非空行一个本人 sk，行数和顺序必须与 Cookie 账号严格一致；不得使用上游共享固定值。

### `SMZDM_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试配置时手动设置，无需从服务端获取。
- 填写格式：填 1、true、yes 或 on 表示完全断网预演，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：由青龙环境统一配置，用于筛选需要通知的脚本。
- 填写格式：用逗号、分号、空白或换行分隔目录编号、脚本路径、文件名或通配符；星号表示全部，显式空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：当通知脚本不在青龙标准目录时，填写包含 sendNotify.js 的本地目录。
- 填写格式：填写本机绝对目录路径；通知组件不可用或发送失败不会改变业务退出码。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在本人 PushPlus 账户中创建推送令牌，仅在需要该通知回退通道时配置。
- 填写格式：填写单个 PushPlus 推送令牌；只向对应的 HTTPS 通知接口发送。

### `SENDKEY`

- 必填：否
- 敏感：是
- 获取或设置：在本人 Server酱账户中取得 SendKey，仅在需要该通知回退通道时配置。
- 填写格式：填写单个 Server酱 SendKey；只向对应的 HTTPS 通知接口发送。

## 多账号

每个非空行代表一个账号；同一账号的 sk 与 Cookie 合并写入 SMZDM_ACCOUNT，并只在第一个竖线处分割。各账号独立处理，任一账号失败时进程整体返回非零状态。

## 副作用与风险

- 在什么值得买账号上执行每日签到并改变当日签到状态
- 满足条件时领取连续签到额外奖励并改变账号奖励状态
- 显式选择 lottery、all 或 upstream-lottery 后提交抽奖，可能消耗抽奖机会或活动资产并获得奖励
- 显式选择 value 或 both 后对好价提交点值并改变账号投票状态
- 显式选择 article 或 both 后对好文提交点赞并改变账号点赞状态
