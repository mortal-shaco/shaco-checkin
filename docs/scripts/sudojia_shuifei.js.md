## 脚本功能

- 查询官方昵称与剩余签到次数，隐藏手机号及凭据
- 按剩余次数签到，已签到时跳过并保留连续签到天数展示
- 查询当前积分
- 支持每行一个账号独立执行和失败退出码
- 提供完全断网预演、分阶段日志与结构化汇总
- 通过青龙通知模块发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SHUI_FEI_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在微信公众号水费易打开个人中心，抓取 m.ipaiyun.cn 的个人中心请求，取得请求头 Cookie 和请求正文 memberId，必须属于同一账号。
- 填写格式：每行 Cookie#memberId，仅在首个 # 处分割；不使用 & 或 @ 分隔账号。

### 可选参数

### `SHUI_FEI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 可断网预演；不设置则正式执行。
- 填写格式：1 表示预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：默认开启通知；设为 0、false、no 或 off 关闭。
- 填写格式：默认 1

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 sendNotify.js 所在目录；未设置则搜索青龙标准脚本目录。
- 填写格式：本地目录路径

## 参数获取方法

## 多账号

每个非空行一个账号，Cookie 与 memberId 使用首个 # 连接；逐账号执行，任一账号失败则整体非零退出。
