# 机场自动登录签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/aitport.js`
- 青龙命令：`node scripts/aitport.js`
- 建议 Cron：`1 8 * * *`
- 发布哈希：`fa63efbcd571eb8254dfa3a7089cbc7c97504f79185f132873da11924cd1a58e`
- 许可证：`GPL-3.0`

## 脚本功能

- 自动使用邮箱密码登录，兼容上游授权字段 auth_data 和 token。
- 每日签到并识别官方今日已签到提示；仅成功 HTTP 响应与明确业务确认可判为完成。
- 展示官方返回的奖励流量 MB 与累计签到流量 GB；未返回时明确标记，不伪造零值。
- 官方返回非敏感昵称、用户名、显示名称或公开 UID 时直接展示，便于核对账号；屏蔽凭据与手机号。
- 支持每行一个账号及旧版单账号变量，逐账号隔离失败并汇总退出状态。
- 保留可选 PushPlus HTML 卡片，新增遵循全局开关与脚本名单的青龙通知，通知失败保留业务退出码。
- 完全断网预演，含配置错误、账号步骤、统计及通知模拟；不加载通知工具。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON 记录。
- 独立实现固定 HTTPS 接口请求，不依赖上游仓库；包含 15 秒完整请求超时、响应大小上限和重定向拒绝。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AITPORT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人在 https://flzt.top 注册的邮箱和登录密码；在青龙环境变量中填写。该变量为维护版规范入口；旧单账号可继续仅使用 USER_EMAIL 与 USER_PASSWORD 兼容输入。
- 填写格式：每行一个账号，格式为邮箱|密码；只在第一个竖线处分割，密码中的后续竖线和空格原样保留。空行忽略，不使用 & 或 @ 分隔账号；设置本变量后优先使用，不回退旧变量。

### 可选参数

### `USER_EMAIL`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容输入：本人在机场网站注册的登录邮箱；与 USER_PASSWORD 配套，且仅在未设置 AITPORT_ACCOUNTS 时生效。
- 填写格式：单个登录邮箱，不支持将多个账号拼接到此变量。

### `USER_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容输入：本人机场登录密码，与 USER_EMAIL 配套；不从脚本或他人日志获取。
- 填写格式：单个密码，保留空格和竖线；不含换行。

### `AITPORT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1 表示完全断网预演；其他值为正式执行。预演不登录、不签到、不调用通知模块或通知服务，配置错误仍非零退出。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从 PushPlus 官网 https://www.pushplus.plus 的本人账户获取推送令牌；保留上游可选 HTML 卡片通知。
- 填写格式：单个推送令牌，独立于机场账号凭据。设置后汇总通知全部账号，受 QINGLONG_NOTIFY 全局关闭控制；预演不发送。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 be4fa480e7c5151e、实际脚本文件名或脚本相对路径；未设置时自动模式没有默认入选项。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 和 ? 文件名通配符，* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。业务运行不依赖该工具。
- 填写格式：本地目录路径。依次尝试指定目录和 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py，最后尝试 Python 的 notify.send；通知进程超时为 15 秒，失败只记录脱敏状态。

## 多账号

AITPORT_ACCOUNTS 每个非空行一个账号，邮箱和密码仅按第一个 | 分割；逐个独立登录、签到与统计，任一账号失败则整体非零退出，其余账号继续执行。兼容旧版单账号变量，凭据不写入日志或通知。

## 副作用与风险

- 正式运行时使用凭据登录并建立服务端登录会话。
- 正式运行时提交每日签到，可能增加账号流量。
- 启用通知时通过青龙通知工具或 PushPlus 发送脱敏账号统计；断网预演不发送。
