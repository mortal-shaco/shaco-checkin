# Rousi 签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/rousi_checkin.js`
- 青龙命令：`node scripts/rousi_checkin.js`
- 建议 Cron：`37 0 * * *`
- 发布哈希：`d195f93453cc7ffa05757861c03a397201d1cd647296b6767f83164c8545bf81`
- 许可证：`MIT`

## 脚本功能

- 普通模式每日签到，并按服务端今日日期识别已签到，避免重复操作
- 读取积分余额，保留站点自定义积分名称
- 展示分享率、当前魔力值及累计上传下载量
- 展示连续签到、已返回签到日期累计天数、本次奖励及连续签到奖励
- 兼容 Token、Bearer 前缀、Cookie、小写变量和编号变量的逐行多账号认证
- 可选 PushPlus HTTPS 汇总通知，保留渠道参数兼容
- 成功、部分失败、失败、配置错误均尝试青龙脱敏通知，预演仅模拟通知
- 完全断网预演、带阶段耗时的时间轴日志、账号与任务统计、单行 TASK_SUMMARY 输出

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ROUSI_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://rousi.pro/，打开浏览器开发者工具的网络面板，查看站内 API 请求头 Authorization，复制 Bearer 后的值；不要分享凭据。
- 填写格式：规范凭据变量，每个非空行一个账号 Token，可带 Bearer 前缀；禁止用 & 或 @ 分隔账号。已有兼容变量也能独立提供凭据，无需同时配置。

### 可选参数

### `ROUSI_COOKIE`

- 必填：否
- 敏感：是

- 填写格式：旧版凭据兼容输入，每个非空行一个完整 Cookie；不拆分 Cookie 内的 &、@、分号或等号。Token 与 Cookie 为可替换认证方式，无需配对，同一账号请只选一种。
