## 脚本功能

- 使用本人 Cookie 向服务 /api/user/sign_in 发起 POST 签到，仅 HTTP 200 且 JSON success 严格为 true 时确认成功。
- 支持按行配置多账号及旧版 config.json accounts/base_url/email 配置，账号之间隔离 Cookie 和会话。
- 可选使用公开 Python 包 cloudscraper 处理兼容挑战，未安装时使用 requests；不依赖浏览器或私有工作流。
- 支持原有显式启用的 SMTP SSL 邮件报告及青龙选择式通知，失败不改变业务退出码。
- 提供完全断网预演、公开账号身份显示、分阶段脱敏日志、账号及任务统计和单行 TASK_SUMMARY。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ANYROUTER_COOKIES`

- 必填：是
- 敏感：是
- 获取或设置：登录本人 AnyRouter 服务站点，在浏览器开发者工具 Network 中查看 /api/user/sign_in 请求的 Request Headers，复制 Cookie 值；过期后重新登录获取。兼容原 accounts 配置时可由配置文件提供。
- 填写格式：每个非空行一个完整 Cookie；不带 Cookie: 前缀；不以 &、@ 或分号拆分账号，Cookie 内等号及分号原样保留。

### `ANYROUTER_BASE_URL`

- 必填：是
- 敏感：否
- 获取或设置：从本人实际登录的服务站点地址栏获取可信 HTTPS 根地址，确认该域名可以接收本人凭据；兼容 config.json 的 base_url。已移除上游默认第三方代理地址。
- 填写格式：https://可信站点域名，可有端口，不含路径、查询、用户名或密码。

### 可选参数

### `ANYROUTER_CONFIG`

- 必填：否
- 敏感：否
- 获取或设置：可指定已有 JSON 配置文件；未设置时兼容脚本同目录 config.json，无文件时使用环境变量。不要把含 Cookie 或 SMTP 密码的配置提交到公开仓库。
- 填写格式：JSON 文件路径；accounts 为对象数组，每项含 cookie，可保留 name；base_url 为 HTTPS 根地址；email 可含 enabled、smtp_server、smtp_port、smtp_user、smtp_pass、recipient。同名环境配置优先。

### `ANYROUTER_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无网络检查时设置为 1，正常运行省略或设为 0。
- 填写格式：1/true/yes/on 表示断网预演；不请求服务、不发送邮件，不视为真实签到成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙设置本轮需要通知的脚本选择器。未设置时本脚本没有默认通知选择。
- 填写格式：逗号、分号或空白分隔；支持 catalog-id、脚本路径、文件名或文件名通配符；* 表示全部，空值禁用全部自动通知；显式启停优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：若 notify.py 不在 Python 导入路径或青龙标准脚本目录，可指定其所在目录。
- 填写格式：含青龙 notify.py 的目录；依次尝试 import notify、指定目录、/ql/data/scripts、/ql/scripts。
