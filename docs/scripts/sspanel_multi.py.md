# SSPanel 多站点签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sspanel_multi.py`
- 青龙命令：`python3 scripts/sspanel_multi.py`
- 建议 Cron：`41 10 * * *`
- 发布哈希：`b24442f7d82c9593d8bab02032145aed2448a6723ae8a5efe67a3ea712f77ed6`
- 许可证：`GPL-3.0`

## 脚本功能

- 支持多站点、多账号邮箱密码登录及每日签到
- 保留两次站点预热访问及默认十秒等待
- 兼容旧环境变量 websites、user_list、pwd_list 以及当前目录 site、users、pwd 配置文件；新变量优先，其次完整本地配置，最后旧变量
- 使用会话 Cookie、正确表单编码、系统证书校验、同源重定向限制及请求超时
- 登录 ret 明确成功后才签到；签到 ret 成功或明确今日已签到才算成功
- 显示官方非秘密昵称、用户名或公开用户标识，屏蔽凭据及手机号
- 支持完全断网预演、逐账号错误隔离和失败非零退出
- 打印阶段时间轴、逐账号及最终统计、唯一 TASK_SUMMARY 结构化记录
- 支持青龙通知全局开关、选择列表及脱敏汇总，通知错误保留业务退出码
- 兼容 editXY 主题，签到后读取并脱敏展示用户等级、到期时间及剩余流量；字段缺失或查询不可用时明确跳过，不改变已验证签到结果
- 保留 Server酱、酷推、Qmsg、Telegram、Pushplus 五种可选通知渠道，均受通知总开关及名单控制，独立校验通知业务结果
- 保留云函数入口 main_handler(event, context)，返回包含业务退出码的结果

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SSPANEL_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在各自 SSPanel 站点注册或登录，从地址栏获取 HTTPS 根地址，使用该站点的注册邮箱和登录密码，无需抓包。根地址不要包含 /auth/login 或 /user。旧配置可兼容替代，推荐迁移到本变量。
- 填写格式：每个非空行一个账号：HTTPS站点|邮箱|密码。只按前两个竖线分割，密码内后续竖线和空格保留。账号之间仅用换行。

### 可选参数

### `websites`

- 必填：否
- 敏感：否
- 获取或设置：旧变量兼容，从站点地址栏获取 HTTPS 根地址，与 user_list、pwd_list 同时逐行配置。新变量未设置且无本地配置文件时生效。
- 填写格式：每行一个地址，旧三组变量行数必须一致，不允许中间空行。

### `user_list`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容，填写对应站点的注册邮箱，与 websites、pwd_list 逐行对应。
- 填写格式：每行一个邮箱。

### `pwd_list`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容，填写对应站点邮箱的登录密码，与 websites、user_list 逐行对应。
- 填写格式：每行一个密码，空格和特殊字符保留。

### `SSPANEL_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量或本地测试环境中设置。
- 填写格式：1、true、yes、on 启用完全断网预演，默认关闭；预演不算真实签到成功。

### `SSPANEL_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选，在青龙环境变量中设置请求超时。
- 填写格式：1 至 120 秒，默认 20。

### `SSPANEL_WARMUP_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：可选，按站点连接保护需求设置两次预热请求之间的等待时间。
- 填写格式：0 至 60 秒，默认 10；不绕过交互式验证码。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，在 auto 模式中替换默认通知列表。
- 填写格式：逗号、分号、空白或换行分隔目录标识、脚本相对路径、文件名或文件名通配符；* 表示全部；空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写现有青龙通知模块的目录。优先导入 notify.send，其次在此目录、/ql/data/scripts、/ql/scripts 查找 notify.py，实际运行可回退至 sendNotify.js。
- 填写格式：通知模块所在目录；签到本身仅使用标准库，不依赖青龙文件。断网预演禁止通知联网及外部通知进程，投递不可用时仅记录状态。

### `SendKey`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Server酱账号的发送密钥页取得。
- 填写格式：单个密钥，受通知总开关和名单控制。

### `ktkey`

- 必填：否
- 敏感：是
- 获取或设置：可选：从酷推管理页面取得发送密钥。
- 填写格式：单个密钥，受通知总开关和名单控制。

### `QmsgKey`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Qmsg 管理页面取得消息密钥。
- 填写格式：单个密钥，受通知总开关和名单控制。

### `tele_bot_token`

- 必填：否
- 敏感：是
- 获取或设置：可选：通过 Telegram 的 BotFather 创建机器人并取得令牌。
- 填写格式：机器人令牌，需同时配置 tele_user_id。

### `tele_user_id`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Telegram 机器人的会话更新中取得自己的会话编号。
- 填写格式：与 tele_bot_token 配套的会话编号，仅用于通知。

### `tele_api_url`

- 必填：否
- 敏感：否
- 获取或设置：可选：默认官方 https://api.telegram.org；代理须自行管理并使用 HTTPS。
- 填写格式：无内嵌凭据的 HTTPS 地址，仅用于 Telegram 通知。

### `push_token`

- 必填：否
- 敏感：是
- 获取或设置：可选：从 Pushplus 账号的令牌页面取得。
- 填写格式：单个推送令牌，受通知总开关和名单控制。

## 多账号

每个非空行一个账号，用前两个竖线分隔站点、邮箱和密码，密码剩余内容保留。账号独立执行，任一失败整体非零退出。旧三组配置必须等长且逐行对应，不再静默截断。
