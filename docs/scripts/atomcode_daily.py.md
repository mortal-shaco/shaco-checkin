## 脚本功能

- 查询当前免费套餐有效期和额度使用情况；以可解析到期时间优先判断有效性
- 无有效套餐时按 Max、Pro、Lite 顺序尝试领取，已有套餐跳过；领取后再次查询核验有效套餐
- 访问令牌即将到期或遇到 HTTP 401/403 时续期并重试一次，兼容轮换续期令牌
- 逐行多账号、--only N 筛选与 --query 仅查询模式
- 兼容单账号环境变量及显式 JSON/TOML 凭据文件；可选安全保存令牌状态
- 官方返回非敏感用户名、昵称或公开标识时原样展示；输出额度数字与脱敏步骤统计
- 青龙通知选择开关、配置错误通知、逐账号及任务汇总与单行 TASK_SUMMARY
- 完全断网预演，无第三方依赖的独立 HTTP 实现、超时、TLS 校验及禁止重定向

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ATOMCODE_TOKENS`

- 必填：是
- 敏感：是
- 获取或设置：登录本人官方 AtomCode/AtomGit 客户端，在本地 auth.json 或 auth.toml 中查看 tokens 下的 access_token、refresh_token 及到期字段，直接填入青龙环境变量；不要打印或分享凭据。
- 填写格式：每个非空行一个账号；推荐 备注|{"access_token":"访问令牌","refresh_token":"续期令牌","expires_at":"到期时间"}；兼容 备注|access_token[|refresh_token[|expires_at[|created_at|expires_in]]]。首个竖线后为完整 JSON 或旧格式字段；不使用 & 或 @ 分隔账号。到期时间支持秒、毫秒或日期时间；created_at 与 expires_in 用于推算到期时间。允许仅提供续期令牌。

### 可选参数

### `ATOMCODE_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：同 ATOMCODE_TOKENS；仅无多账号输入时使用的旧单账号别名。
- 填写格式：单个访问令牌，可带 Bearer 前缀

### `ATOMCODE_REFRESH_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：同 ATOMCODE_TOKENS；配套旧单账号变量。
- 填写格式：单个续期令牌

### `ATOMCODE_EXPIRES_AT`

- 必填：否
- 敏感：否
- 获取或设置：从本人官方登录令牌数据获取，配套旧单账号变量。
- 填写格式：秒、毫秒时间戳或日期时间

### `ATOMCODE_AUTH_FILE`

- 必填：否
- 敏感：是
- 获取或设置：可选：将本人导出的官方 JSON/TOML 凭据文件放入受保护目录并指定路径；无需安装官方客户端或其他仓库。TOML 读取需要 Python 3.11+。
- 填写格式：显式本地文件路径；支持单对象、对象数组或 accounts 数组，与逐行账号输入合并；预演不读取

### `ATOMCODE_STATE_FILE`

- 必填：否
- 敏感：是
- 获取或设置：可选：指定受保护且可写的状态文件，用于跨次保存续期令牌。默认不写文件；目录需已存在，禁止提交或公开该文件。
- 填写格式：可选 JSON 路径；原子写入，权限 0600；预演不读写

### `ATOMCODE_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：需要代理时由本人配置可信代理；日志不会输出地址。
- 填写格式：代理 URL，默认使用系统代理设置

### `ATOMCODE_BROKER_BASE`

- 必填：否
- 敏感：否
- 获取或设置：默认使用上游 https://acs.atomgit.com；仅在确认官方迁移后修改，令牌会发往此地址。
- 填写格式：不含用户名密码的 HTTPS 基址

### `ATOMCODE_CODINGPLAN_API_BASE`

- 必填：否
- 敏感：否
- 获取或设置：默认使用上游 https://api.gitcode.com/api/v5；仅在确认官方迁移后修改，令牌会发往此地址。
- 填写格式：不含用户名密码的 HTTPS 基址

### `ATOMCODE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置；禁止全部网络、通知外发和文件读写。
- 填写格式：1 启用，默认关闭

### `ATOMCODE_NO_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：兼容原脚本的关闭通知开关，也可使用 --no-notify。
- 填写格式：1 关闭通知

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中选择允许通知的脚本。
- 填写格式：逗号、分号、空白或换行分隔；支持目录相对路径、文件名及通配符、目录编号 e10a36a978f215b9；* 全部，空值关闭列表选择

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在青龙通知模块不在默认目录时指定可信本地目录。
- 填写格式：包含 notify.py 或 sendNotify.js 的目录
