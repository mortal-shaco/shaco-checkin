# 头歌平台课堂签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/educoder.py`
- 青龙命令：`python3 scripts/educoder.py`
- 建议 Cron：`54 8,10,14,16 * * 1-5`
- 发布哈希：`afe5c251704dfd356453f77cf08368f2d01dcc9596a81b7b48cdd0eebde4d16d`
- 许可证：`GPL-3.0`

## 脚本功能

- 登录头歌（Educoder）后按课程 ID 执行课堂考勤签到，或只读查询考勤历史。
- 识别登录响应中的 user_id 与签到响应中的 success；无进行中考勤视为已完成。
- 显示官方返回的姓名、学校与公开 UID；不输出密码、Cookie 或原始响应。
- 支持逐行多账号、可选短时等待考勤开始、完全断网预演、超时控制、时间轴日志与单行 TASK_SUMMARY。
- 通过青龙 notify.py 或 sendNotify.js 发送脱敏任务汇总，遵守全局开关与脚本清单。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `EDUCODER_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：打开 https://www.educoder.net 使用日常登录名与密码。登录名可为学号、手机号或用户名，以头歌账号页显示为准。勿把真实密码写入仓库或示例。
- 填写格式：每个非空行一个账号：登录名#密码 或 登录名#密码#课程ID；仅在首个 # 处分割登录名，再在剩余部分首个 # 处分割密码与可选课程 ID。以 # 开头的行视为注释。

### 可选参数

### `EDUCODER_COURSE_ID`

- 必填：否
- 敏感：否
- 获取或设置：登录头歌后进入目标课程，从课程页面 URL 或课程信息中复制数字课程 ID；账号行未写课程 ID 时必须设置本变量。
- 填写格式：正整数字符串，例如 123456。

### `EDUCODER_USER`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名：填写头歌登录名；仅当 EDUCODER_ACCOUNTS 为空且同时提供 EDUCODER_PASSWORD 时生效。别名 EDUCODER_LOGIN 同等可用。
- 填写格式：单个登录名字符串。

### `EDUCODER_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写头歌登录密码；仅当 EDUCODER_ACCOUNTS 为空且同时提供 EDUCODER_USER 时生效。别名 EDUCODER_PASSWD 同等可用。
- 填写格式：单个密码字符串。

### `EDUCODER_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：选择本轮任务动作；默认执行课堂签到。
- 填写格式：sign（默认，提交进行中考勤）或 history（只读查询考勤历史）。

### `EDUCODER_WAIT_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：课堂签到尚未开始时，可选短时轮询等待；替代上游交互式无限等待。默认 0 表示只尝试一次。
- 填写格式：整数秒，范围 0 到 600。

### `EDUCODER_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置单次 HTTPS 请求超时；默认 20 秒。
- 填写格式：数字秒，范围 5 到 60。

### `EDUCODER_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：用于首次配置检查与完全断网预演；不代表真实业务成功。
- 填写格式：1、true、yes 或 on 启用；不访问业务接口。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行选择需要推送的脚本；设置后替代默认通知清单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；支持 56a92f26b6487e35、scripts/educoder_signin.py；* 选择全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：指定已安装青龙通知模块所在目录，否则依次发现可导入的 notify、/ql/data/scripts、/ql/scripts。
- 填写格式：目录路径，包含 notify.py 或 sendNotify.js。

## 多账号

每个非空行一个账号，格式为 登录名#密码 或 登录名#密码#课程ID。各账号独立执行，任一账号失败时整体非零退出。

## 副作用与风险

- 正式执行签到动作时向头歌提交课堂考勤签到，可能改变该课程的考勤记录。
- 登录会创建会话 Cookie；查询历史为只读，不改变考勤状态。
- 通知启用且助手可用时发送脱敏任务汇总；无网络预演不投递外部通知。
