# 精易论坛签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/jingyiluntan_sign.py`
- 青龙命令：`python3 scripts/jingyiluntan_sign.py`
- 建议 Cron：`2 2 * * *`
- 发布哈希：`3782534af710de22762805e6182806e6139259a50b2381b50ce2b9dd3bb5b808`
- 许可证：`GPL-3.0`

## 脚本功能

- 读取登录页面与表单令牌，显示官方返回的昵称
- 每日签到并区分成功和今日已签到
- 显式开启后按上游流程读取热门帖、逐帖评分 +1 和显示积分，保持两秒间隔
- 评分附言优先从一言读取文字、作者及出处，按策略格式注明出处；所有提供方失败回退本地文字
- 多账号独立执行、超时和明确业务成功校验
- 完全断网预演、脱敏时间轴日志和单行 TASK_SUMMARY 结构化统计
- 成功、部分失败、失败、配置错误及预演均生成脱敏通知摘要；预演仅模拟通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JYLT_Cookie`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录精易论坛 https://bbs.125.la，打开开发者工具的网络面板，选择本站已登录请求，复制请求头 Cookie 的完整值。会话过期后重新登录获取；不要复制请求头名称或向他人公开。
- 填写格式：每个非空行一个账号的完整 Cookie；保留分号及其中的等号，不用 & 或 @ 分隔账号。

### 可选参数

### `JYLT_RATE`

- 必填：否
- 敏感：否
- 获取或设置：需要延续上游热门帖评分功能时手动设为 1；默认 0，避免自动消耗评分额度或更改帖子评分。
- 填写格式：1 开启热门帖逐帖 +1 评分，0 关闭；评分失败或额度受限时停止该账号评分并返回失败。

### `JYLT_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可自行填写评分附言的本地备用文字；不要填写凭据或个人敏感信息。优先使用一言及出处，提供方异常时回退本地文字。
- 填写格式：归一化后不超过 280 字；空值或超长时使用内置文字。

### `JYLT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设为 1，正式运行时移除或设为 0。
- 填写格式：1 完全断网模拟所有请求和通知，0 正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写本机青龙 notify.py 或 sendNotify.js 所在目录；默认尝试导入 notify 和青龙标准目录。
- 填写格式：本地通知模块目录；脚本业务不依赖此目录。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
