- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_98d86c7c.js`
- 青龙命令：`node scripts/task_98d86c7c.js`
- 建议 Cron：`48 10 * * *`
- 发布哈希：`fb3de12cdc8d54a423f2582c1cbd0caeed69023ef212a8572d2c891bc1890534`
- 许可证：`GPL-3.0`

## 脚本功能

- 验证 BDUSS 登录状态并通过 HTTPS 获取 tbs 校验值
- 读取官方接口返回的关注贴吧列表并逐吧签到，保留每次签到前五秒间隔
- 识别业务码 0 的签到成功和 1101 的重复签到，业务码 2150040 触发验证码停止当前账号后续签到
- 打印官方响应提供的非敏感账号名称或公开 UID，隐藏登录凭据、校验值及手机号
- 支持每行一个账号、账号隔离和任一账号失败时非零退出
- 支持完全断网演练、阶段耗时、账号与子任务统计及单行 TASK_SUMMARY 汇总
- 正式执行通过青龙通知模块发送脱敏结果，配置错误和部分失败也通知，支持全局开关与脚本选择器
- 显式选择客户端模式后，使用关联源码支持的客户端签名、分页关注列表和签到排名；分页不完整或业务失败时拒绝假成功。
- 保留同账号 STOKEN 网页兜底能力和单账号命令行参数；兼容单独 BDUSS 并支持每行组合凭据。
- 显式配置最多五轮安全重试，重试前刷新 TBS 并等待60至90秒；默认网页单轮流程和每次签到前五秒间隔保持不变。
- 兼容 SCKEY 并新增 PUSHPLUS_TOKEN，通过 HTTPS 发送脱敏结果，以业务码200验证受理，通知失败保留业务退出码。
- 依据官方关注列表跳过今日已签到项目，签到响应提供排名和累计签到天数时显示。
- 兼容原 accounts/push 配置结构的环境 JSON 迁移，保留启用开关和按账号分组的 Server酱、PushDeer 通知，并提供独立可选全局通知密钥。
- 逐吧显示官方关注列表快照中的等级与经验值，已签到条目同样展示；字段未返回时明确标注，不额外请求或改变签到结果。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BDUSS`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录百度贴吧，打开开发者工具，在应用或存储面板的 tieba.baidu.com Cookie 中复制 BDUSS 字段的值，保存到青龙环境变量。失效时重新登录获取。仅填写自己的登录凭据，勿公开或写入日志。
- 填写格式：每个非空行一个账号，填写 BDUSS 原值或 BDUSS原值|STOKEN原值；只在第一个 | 处分割，后续内容属于 STOKEN。单独 BDUSS 的旧配置保持有效，不支持 &&、& 或 @ 分隔账号。兼容 --bduss、--stoken 命令行，但建议使用环境变量避免终端历史泄漏。

### 可选参数

### `TIEBA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量或运行环境中设置。
- 填写格式：1、true、yes 或 on 启用完全断网演练，默认正式执行。演练验证配置并模拟流程，不读取真实关注吧或执行签到，通知摘要仅本地输出。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中配置需要通知的脚本选择器。
- 填写格式：auto 模式下，未设置时本脚本默认通知；设置后替换默认列表。支持目录内相对脚本路径、实际文件名、文件名 * 通配符和目录编号 98d86c7c8da22e52，以逗号、分号、空白或换行分隔，* 匹配全部，空值关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 或 sendNotify.js 所在目录。默认也检查脚本目录、/ql/data/scripts、/ql/scripts 及 Python 可导入的 notify.send。
- 填写格式：本地通知模块目录路径，仅用于可选通知集成。脚本的签到 HTTP 行为由 Node.js 标准库独立实现。

### `STOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在浏览器登录同一个贴吧账号，从开发者工具的 Cookie 存储复制 STOKEN 字段；失效后重新登录获取。
- 填写格式：仅单账号兼容输入；多账号必须在 BDUSS 每行中组合。命令行 --stoken 优先于此变量。客户端模式失败时用于网页兜底，不替代 BDUSS。

### `TIEBA_SIGN_MODE`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置，可按需要选择客户端签到。
- 填写格式：web 或 client，默认 web 保留维护版网页接口；client 使用关联源码的签名分页列表与客户端签到，配置同账号 STOKEN 后可网页兜底。

### `TIEBA_MAX_ROUNDS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置；需要原入口的多轮能力时设为5。
- 填写格式：1至5的整数，默认1保持维护版行为。网络错误或缺失业务码最多尝试指定次数，每次重试刷新 TBS 并等待60至90秒；明确业务失败不盲目重试，验证码停止当前账号。每次签到前至少等待5秒。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：登录 PushPlus 官方控制台，复制自己的推送令牌并保存在青龙环境变量。
- 填写格式：可选单个令牌，优先于 SCKEY；仅在正式执行且通知规则允许时通过 HTTPS 推送脱敏汇总，受理必须返回数值业务码200。通知失败不改变业务退出码。

### `SCKEY`

- 必填：否
- 敏感：是
- 获取或设置：登录 PushPlus 官方控制台获取自己的推送令牌；此名称兼容上游配置。
- 填写格式：可选 PushPlus 令牌兼容别名，不是账号凭据，PUSHPLUS_TOKEN 未配置时使用。

### `TIEBA_CONFIG`

- 必填：否
- 敏感：是
- 获取或设置：旧配置迁移：将自己原 config.json 的完整 JSON 内容保存到此环境变量，勿公开。BDUSS/STOKEN 从登录后的贴吧开发者工具 Cookie 存储获取。
- 填写格式：可选兼容输入，替代 BDUSS：对象含 accounts 数组和 push 数组；账号字段 enable（布尔）、bduss、可选 stoken 和 push（通知分组名数组）；通知字段 name、type（serverchan 或 pushdeer）、key。enable=false 不运行。不得同时设置 BDUSS，推荐迁移到 BDUSS 每行一个账号。

### `TIEBA_SERVERCHAN_KEY`

- 必填：否
- 敏感：是
- 获取或设置：登录 Server酱官方控制台获取自己的 SendKey，保存在青龙环境变量。
- 填写格式：可选全局 Server酱通知密钥，受通知总开关和脚本选择器约束；使用 HTTPS，明确受理后才报告通知成功。

### `TIEBA_PUSHDEER_KEY`

- 必填：否
- 敏感：是
- 获取或设置：在 PushDeer 官方客户端中获取自己的推送 Key，保存在青龙环境变量。
- 填写格式：可选全局 PushDeer 通知密钥，受通知总开关和脚本选择器约束；使用 HTTPS，明确受理后才报告通知成功。

## 多账号

每个非空行一个账号，BDUSS 原值后可用第一个 | 连接同账号 STOKEN；后续字段文字完整保留。各账号独立执行，任一账号失败整体非零退出；验证码停止当前账号剩余签到。单账号兼容 STOKEN 环境变量，多账号禁止共享。

## 副作用与风险

- 对当前账号关注的贴吧执行每日签到，可能获得服务端签到奖励并更新签到记录
- 正式执行且通知开启时，通过可用青龙通知组件及已配置的 PushPlus 向配置渠道发送脱敏汇总。
- 正式运行且通知规则允许时，向显式配置的 Server酱和 PushDeer 通道发送脱敏汇总。
