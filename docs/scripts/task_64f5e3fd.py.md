## 脚本功能

- 使用学号、密码、学校与 openid 登录工软校园统一身份，并本地 OCR 识别登录验证码
- 获取微信服务大厅与健康填报 token 后拉取当日「学生每日健康填报」表单并提交
- 保留上游默认选项：校内、正常体温、无不适、未被隔离、第三针、绿码、未出校及省市区/姓名/学院字段
- 展示配置中的姓名作为公开身份以便核对账号
- 支持每行一个账号的多账号独立处理，任一账号失败时非零退出
- 支持完全断网预演、请求超时、有限重试、时间轴日志、脱敏青龙通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `GRXY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：准备工软校园（xy.4009955.com / 微信工软校园）学号与密码；学校名称与学院按系统登记填写；openid 从微信端登录相关请求参数或本地调试抓包中获取；姓名与省市区按本人填报信息填写。仅写入青龙环境变量，不要公开或提交到仓库。
- 填写格式：每个非空行一个账号：学号|密码|学校|openid|姓名|学院|省|市|区。从行尾固定解析后七段，中间整段作为密码（密码可含竖线）；不要用 & 或 @ 分隔账号；以 # 开头的行为注释。

### 可选参数

### `GRXY_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置单次 HTTP 请求超时；留空使用 20 秒。
- 填写格式：5 至 60 之间的秒数

### `GRXY_MAX_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：验证码识别失败或登录链路偶发错误时的最大重试次数；留空使用 5。
- 填写格式：1 至 10 之间的整数

### `GRXY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用；预演不访问业务接口，也不加载 OCR。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启完全断网预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试导入 notify 和青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径
