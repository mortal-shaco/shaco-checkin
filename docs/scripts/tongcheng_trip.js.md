# 同程旅行签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tongcheng_trip.js`
- 青龙命令：`node scripts/tongcheng_trip.js`
- 建议 Cron：`5 12 * * *`
- 发布哈希：`8fb9693662af3e560cde17876abbaec3b28098acd96491d4df26234d4504123e`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每天 12:05 查询签到状态与里程，未签到时签到，已签到时跳过重复签到。
- 查询福利浏览任务列表；显式开启后启动任务、等待、完成并领取奖励，完成步骤最多尝试三次。
- 复核签到状态，汇总本月签到天数、今日里程与当前里程，必要字段缺失时失败。
- 支持请求头 JSON 逐行多账号及旧变量兼容，账号独立执行，官方返回明确公开昵称或用户名时显示供核对。
- 提供断网预演、超时与响应大小限制、逐阶段日志、账号统计、唯一单行结构化汇总及青龙脱敏通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TONGCHENG_TRIP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人授权设备打开同程旅行 APP → 领福利，用抓包工具捕获 https://app.17u.cn/welfarecenter/index/signIndex 请求。将请求头复制为 JSON 对象，必须包含 phone、apptoken、device，保留版本及 User-Agent 等必要头；三项来自同一账号有效登录。不要复制响应或分享凭据，无需原仓库或持久化文件。
- 填写格式：每个非空行一个完整请求头 JSON 对象，值为字符串，头名称不区分大小写。不同账号只用换行分隔，不用 & 或 @。

### 可选参数

### `tongcheng_trip_signheader`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容入口，获取方式同规范变量；仅 TONGCHENG_TRIP_ACCOUNTS 未设置时读取，不拼接两个变量，不读取 box.dat。
- 填写格式：每个非空行一个账号请求头 JSON 对象。

### `TONGCHENG_TRIP_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：可选；了解浏览任务会启动、上报完成并领奖后，显式开启。默认关闭自动模拟浏览和领奖，仍执行签到及任务列表查询。每项等待上限 300 秒，超限失败且不启动任务。
- 填写格式：1、true、yes、on 开启；默认 0。

### `TONGCHENG_TRIP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时开启，仍提供占位请求头；仅模拟本地响应，不请求业务或通知网络。
- 填写格式：1、true、yes、on 开启；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选；设置后替换入选名单。可填目录编号 0a730847ceb97039、脚本相对路径、文件名 tongcheng-trip.js、实际安装文件名或文件名通配符。显式全局开关优先。
- 填写格式：逗号、分号或空白分隔；* 匹配全部；空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选；填写青龙 sendNotify.js 所在目录。否则依次查找 /ql/data/scripts/sendNotify.js、/ql/scripts/sendNotify.js；不下载或安装组件。
- 填写格式：本机通知组件目录路径。

## 多账号

每个非空行一个完整请求头 JSON 对象，将同账号的 phone、apptoken、device 合并保存。账号独立执行，单账号失败不阻止后续账号，任一失败整体非零退出。

## 副作用与风险

- 未签到时提交每日签到，由平台发放相应里程。
- 仅显式开启浏览任务时提交启动、浏览完成上报并领取奖励。
- 符合全局开关与入选策略时通过青龙组件发送脱敏通知，离线模式不发送。
