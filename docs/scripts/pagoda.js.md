# 百果园小程序签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/pagoda.js`
- 青龙命令：`node scripts/pagoda.js`
- 建议 Cron：`34 1 * * *`
- 发布哈希：`2b341cdbbc3d4267f22eaaed08fb7b92470ebc391bcd0b968a00a3c1a5799665`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 按原请求 URL、查询参数和请求头执行百果园小程序每日签到，保留每日 00:10 计划。
- 严格识别成功和重复签到业务码，网络、接口、响应及配置错误均失败闭合。
- 支持多账号逐行独立处理及旧 chavy_sign_pagoda 会话参数兼容。
- 提供原会话抓包获取说明，固定允许的 HTTPS 签到地址，禁止重定向及自动重试。
- 支持完全断网预演、分阶段脱敏日志、官方非敏感账号身份展示及单行结构化汇总。
- 按通知开关和脚本选择，通过可选青龙 sendNotify.js 发送脱敏汇总，通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `PAGODA_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在自己设备的受信任抓包工具中打开百果园小程序并进入签到页，找到 wx-mini.pagoda.com.cn 的 /api/v1/wxmini/signIn/customer 请求，复制完整 URL（保留所有查询参数）及实际请求头。将二者组成单行 JSON；会话失效时重新采集。无需猜测鉴权字段，不上传抓包内容。
- 填写格式：每个非空行一个账号 JSON 对象，字段 url 为完整 HTTPS 签到地址，headers 为请求头名称到字符串值的对象；同一账号的 URL、Cookie、Token 等请求头放在同一个对象中。只支持 GET，不用 & 或 @ 分隔账号。

### 可选参数

### `chavy_sign_pagoda`

- 必填：否
- 敏感：是
- 获取或设置：可从旧版脚本持久化存储中手工取出同名会话 JSON，或按主变量的抓包步骤获取；仅主变量未设置时使用，不再读取 box.dat。
- 填写格式：与 PAGODA_ACCOUNTS 相同，每个非空行一个完整会话 JSON。

### `PAGODA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中自行设置。
- 填写格式：1 表示完全断网预演，只校验配置并模拟通知；其他值执行正式签到。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：按需在青龙环境变量中指定通知脚本列表；设置后替换默认选择，未设置时本脚本不在默认通知名单中。
- 填写格式：以逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；本脚本可用 93a6cb1dedb6401b 或 pagoda.js；* 表示全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如已有青龙 sendNotify.js，可设置其所在目录；未设置时依次查找 /ql/data/scripts 和 /ql/scripts。脚本自身签到无需通知模块。
- 填写格式：现有通知模块所在目录；不会下载、安装或引导外部程序。

## 多账号

每个非空行一个账号的完整 JSON；同一账号的 url 和 headers 合并存储，逐行独立处理，任一账号失败或配置错误时整体非零退出。
