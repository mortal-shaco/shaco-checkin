# 甄稀冰淇淋每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_zxice.js`
- 青龙命令：`node scripts/sudojia_zxice.js`
- 建议 Cron：`34 2 * * *`
- 发布哈希：`d0205fe1ea64b94caad278719298368e0eb27e733b4b42baa742d3c859dc9c36`
- 许可证：`GPL-3.0`

## 脚本功能

- 校验账号登录状态并展示官方返回的非敏感昵称
- 查询今日签到状态，已签到时避免重复操作
- 每日签到并展示接口确认的奶滴奖励
- 查询当前奶滴值
- 支持每行一个账号，独立处理并汇总失败退出码
- 完全断网预演、分阶段时间轴日志、账号统计和单行 TASK_SUMMARY 汇总
- 通过青龙 sendNotify.js 发送脱敏结果通知，支持全局开关；完全断网预演生成本地通知摘要

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ZX_ICE_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录甄稀冰淇淋微信小程序，使用抓包工具查看本人发往 msmarket.msx.digitalyili.com 的请求，复制请求头 access-token 的值。失效后重新登录并获取；不要复制整个请求头或向他人提供凭据。
- 填写格式：每个非空行填写一个账号的 access-token 原值；不使用 & 或 @ 分隔账号。

### 可选参数

### `ZX_ICE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置；用于完全断网预演。
- 填写格式：1 开启预演，其他值执行正式任务。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置全局通知开关。
- 填写格式：默认 1；0、false、no、off 关闭，不区分大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已配置好的青龙 sendNotify.js 所在目录；未设置时查找青龙标准脚本目录。
- 填写格式：本地目录路径；只用于通知，业务请求不依赖此目录。

## 多账号

每行一个非空账号凭据，按顺序独立运行；任何账号失败均以非零状态退出。
