## 脚本功能

- 登录福州 OJ（qoj.fzoi.top）后执行每日签到，读取连续签到天数与今日 RP、硬币摘要。
- 自动从登录页提取 CSRF _token，不再使用上游硬编码令牌。
- 识别登录业务码 ok、账号或密码错误、banned；签到 HTTP 200 为成功，403 为今日已签到。
- 显示 OJ 用户名作为公开身份；不输出 Token、Cookie 或原始响应。
- 支持逐行多账号与单账号别名，完全断网预演、超时控制、时间轴日志与单行 TASK_SUMMARY。
- 通过青龙 notify.py 或 sendNotify.js 发送脱敏任务汇总，遵守全局开关与脚本清单。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FZQOJ_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://qoj.fzoi.top ，打开「更改个人信息」页面，复制显示的 Token；用户名使用本站注册用户名。勿把 Token 当作公开示例或写入仓库。
- 填写格式：每个非空行一个账号：用户名|Token；仅在首个竖线处分割，后续字符完整保留。无竖线时兼容上游空格写法：用户名 Token。

### 可选参数

### `FZQOJ_USER`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名：填写本站用户名；仅当 FZQOJ_ACCOUNTS 为空且同时提供 FZQOJ_TOKEN 时生效。
- 填写格式：单个用户名字符串。

### `FZQOJ_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：从「更改个人信息」页面复制 Token；仅当 FZQOJ_ACCOUNTS 为空且同时提供 FZQOJ_USER 时生效。
- 填写格式：单个 Token 字符串。

### `FZQOJ_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置单次 HTTPS 请求超时；默认 15 秒。
- 填写格式：数字秒，范围 5 到 60。

### `FZQOJ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：用于首次配置检查与完全断网预演；不代表真实业务成功。
- 填写格式：1、true、yes 或 on 启用；不访问业务接口。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行选择需要推送的脚本；设置后替代默认通知清单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；支持 ed4d6d4d632e033e、scripts/fzqoj_checkin.py；* 选择全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：指定已安装青龙通知模块所在目录，否则依次发现可导入的 notify、/ql/data/scripts、/ql/scripts。
- 填写格式：目录路径，包含 notify.py 或 sendNotify.js。
