# 微助教课堂签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/asynccheckin.py`
- 青龙命令：`python3 scripts/asynccheckin.py`
- 建议 Cron：`*/3 7-22 * * 1-5`
- 发布哈希：`bfd3d2091bf67676330d493adc96fe636b69184d3ac0f55815e82ece6d0288e9`
- 许可证：`GPL-3.0`

## 脚本功能

- 查询进行中的微助教课堂签到并提交普通签到
- 按响应中的 Rank / repeat 识别签到成功或已签到
- 读取并展示官方返回的公开姓名
- 可选地理位置签到（须同时配置经纬度，无硬编码默认坐标）
- 可选短时轮询等待进行中签到，替代上游长驻守护循环
- 二维码签到在无头定时环境明确跳过并提示需人工扫码
- 换行多账号与 WZJ_OPENID 兼容别名
- 请求超时、签到前延时、断网预演、脱敏时间轴日志与单行 TASK_SUMMARY
- 青龙通知开关、脚本选择与 Python/JavaScript 通知发现链

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TEACHERMATE_OPENID`

- 必填：是
- 敏感：是
- 获取或设置：用微信打开微助教学生端，在浏览器开发者工具或抓包结果中复制带 openid= 的链接，或只保留纯 openid 字符串；参考上游 README 与 yun-mu/wzj-sign-in-weixin 的获取说明。不要把该值发给他人或写入公开仓库。
- 填写格式：每个非空行一个账号；可为纯 openid、含 openid= 的链接，或 备注#openid（仅在第一个 # 处分割）。不使用 &、@ 分隔账号。

### 可选参数

### `WZJ_OPENID`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名；未设置 TEACHERMATE_OPENID 时按相同方式获取并填写。
- 填写格式：与 TEACHERMATE_OPENID 相同，每行一个账号。

### `TEACHERMATE_LAT`

- 必填：否
- 敏感：否
- 获取或设置：仅在课堂要求地理位置签到且确认需要传坐标时自行填写；须与 TEACHERMATE_LON 同时配置。上游硬编码西十二默认坐标已移除。
- 填写格式：纬度数字，范围 -90 到 90；提交时会加微小随机抖动。

### `TEACHERMATE_LON`

- 必填：否
- 敏感：否
- 获取或设置：仅在课堂要求地理位置签到且确认需要传坐标时自行填写；须与 TEACHERMATE_LAT 同时配置。
- 填写格式：经度数字，范围 -180 到 180；提交时会加微小随机抖动。

### `TEACHERMATE_DELAY_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：发现进行中普通签到后、提交前的延时；对应上游 DELAY_TO_CHECKIN，默认 6 秒。
- 填写格式：0 到 120 的数字秒，默认 6。

### `TEACHERMATE_WAIT_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：当前无进行中签到时最多短时轮询等待秒数；用于替代上游长驻守护，默认 0 只查一次。
- 填写格式：0 到 600 的整数秒，默认 0。

### `TEACHERMATE_POLL_INTERVAL`

- 必填：否
- 敏感：否
- 获取或设置：启用短时等待时的轮询间隔；对应上游约 30 秒检测节奏。
- 填写格式：5 到 300 的数字秒，默认 30。

### `TEACHERMATE_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况自行调整单次 HTTPS 请求超时；不填使用默认 15 秒。
- 填写格式：5 到 60 之间的数字秒，默认 15。

### `TEACHERMATE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在测试环境自行开启；正式执行时删除或设为 0。
- 填写格式：1/true/yes/on 开启完全断网预演；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式下需要替换默认通知名单时自行设置。
- 填写格式：逗号、分号或空白分隔；可匹配 catalogId、脚本路径、文件名或通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录。
- 填写格式：目录路径；失败后继续尝试 /ql/data/scripts 与 /ql/scripts；通知失败不改变业务退出码。

## 多账号

每个非空行一个 openid 账号；可用 备注#openid，仅在第一个 # 处分割。账号独立处理，任一账号失败则整体非零退出。
