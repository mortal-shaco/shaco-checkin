## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NDNU_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人微信中打开宁德师范学院第二课堂（dekt.ndnu.edu.cn）并保持登录，于浏览器或抓包工具中复制请求 Cookie 里的 SESSION 单个值（不要整段 Cookie、不要分享）。照片可将本人签到用 JPG/PNG 转为 Base64 后附在同一行；也可先用上游 make_img 思路本地转码后只把 Base64 填入环境变量。本脚本不再使用 mitmproxy 或系统代理抓包。
- 填写格式：每个非空行一个账号：SESSION 或 SESSION|照片Base64。仅按首个竖线分割，后续内容保留在照片字段。不使用 &、@ 分隔账号。# 开头行忽略。可选前缀 SESSION=。

### 可选参数

### `NDNU_SESSION`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容输入；未设置 NDNU_ACCOUNTS 时使用。获取方式与 NDNU_ACCOUNTS 相同，建议合并到规范变量。
- 填写格式：与 NDNU_ACCOUNTS 相同：每行 SESSION 或 SESSION|照片Base64。

### `NDNU_IMG_BASE64`

- 必填：否
- 敏感：是
- 获取或设置：可选。账号行未附带照片时使用的共用签到照片 Base64。将本人 JPG/PNG 等图片内容做 Base64 编码后填入；上传时 type 固定为 17，与上游 img.json 一致。
- 填写格式：纯 Base64 字符串，不含 data: 前缀；勿把凭据发给任何在线转码服务。

### `NDNU_LOCATIONS`

- 必填：否
- 敏感：否
- 获取或设置：可选。课程地点名称到坐标的映射；未设置时使用内置校园地点（求是楼、操场、讲堂群、第一食堂、图书馆、体育馆、求真楼、逸夫实训楼）。若课程返回地点不在列表中，请按实际坐标补充。
- 填写格式：JSON 对象，如 {"求是楼":[26.661232,119.58768]}，值为 [纬度,经度]。

### `NDNU_TASK`

- 必填：否
- 敏感：否
- 获取或设置：可选。控制本轮执行签到、签退或两者。
- 填写格式：all（默认，签到+签退）/ sign（仅签到）/ signout（仅签退）。

### `NDNU_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选。单次 HTTP 超时秒数。
- 填写格式：3–120 之间的数字，默认 20。

### `NDNU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验证配置时设置为 1。
- 填写格式：1、true、yes、on 启用完全断网预演；0、false、no、off 或空值关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中将本任务加入通知名单；存在该变量时替换默认名单。
- 填写格式：逗号、分号或空白分隔；支持 1b92bf9b58ea5e07、scripts/ndnu_checkin.py、ndnu_checkin.py、文件名通配符及 *；空值关闭全部名单通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定本人青龙 notify.py 或 sendNotify.js 所在目录；也自动查找青龙标准目录。
- 填写格式：目录路径；优先 Python 通知，兼容 JavaScript 通知。通知缺失、超时或失败保留业务退出码。

## 多账号

每个非空行一个账号。规范变量 NDNU_ACCOUNTS 填写 SESSION，或 SESSION|照片Base64（仅按首个竖线分割）。未设置时兼容 NDNU_SESSION。共用照片可放 NDNU_IMG_BASE64。账号独立处理，任一失败则进程非零退出。
