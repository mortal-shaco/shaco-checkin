# 班级魔法自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_7be4b090.py`
- 青龙命令：`python3 scripts/task_7be4b090.py`
- 建议 Cron：`44 8 * * 1-5`
- 发布哈希：`72dd637dc269d7e7ae88ce5b5943f33870825ba650a23c6520803bc46d8766b3`
- 许可证：`GPL-3.0`

## 脚本功能

- 使用班级魔法学生端 Cookie 查询指定班级进行中的签到任务
- 自动识别 GPS 定位签到与扫码签到入口并提交打卡
- 支持经纬度微偏移、多账号分行配置与短重试
- 展示可选用户备注或页面公开身份，输出脱敏时间轴日志与 TASK_SUMMARY
- 支持完全断网预演并通过青龙 notify 发送脱敏汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BJMF_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：打开 https://k8n.cn/student/login 登录班级魔法学生端，按教程 https://github.com/JasonYANG170/AutoCheckBJMF/wiki/ 抓包任意已登录请求的 Cookie。需要 remember_student_59ba36addc2b2f9401580f014c7f58ea4e30989d 字段；可在同行加入 username=备注 便于区分账号。Cookie 变更是最常见失败原因。
- 填写格式：每个非空行一个账号。推荐：username=<备注>;remember_student_59ba36addc2b2f9401580f014c7f58ea4e30989d=<令牌>。也可只填 remember_student 键值对或纯令牌值。不使用 & 或 @ 分隔账号。

### `BJMF_CLASS_ID`

- 必填：是
- 敏感：否
- 获取或设置：按上游教程抓包获取班级 ID（课程/班级标识），填写到本变量；全班账号通常共用。
- 填写格式：字母数字、下划线或短横线，长度 1..64。

### `BJMF_LAT`

- 必填：是
- 敏感：否
- 获取或设置：课堂签到定位纬度。可用腾讯坐标拾取 https://lbs.qq.com/getPoint/ ，建议至少 8 位小数以便微偏移。
- 填写格式：十进制度数，例如 39.12345678。

### `BJMF_LNG`

- 必填：是
- 敏感：否
- 获取或设置：课堂签到定位经度。可用腾讯坐标拾取工具获取。
- 填写格式：十进制度数，例如 116.12345678。

### 可选参数

### `BJMF_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名。未设置 BJMF_COOKIE 时读取本变量。
- 填写格式：与 BJMF_COOKIE 相同：每行一个账号 Cookie。

### `BJMF_ACC`

- 必填：否
- 敏感：否
- 获取或设置：海拔/精度字段，对应上游 acc；没有可留空。
- 填写格式：字符串或数字，可空。

### `BJMF_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：验证配置时设为 1，不发起任何网络请求或签到提交。
- 填写格式：1/true/yes/on 开启断网预演；0/false/no/off 真实执行。默认 0。

### `BJMF_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：网络较慢时可适当增大。
- 填写格式：整数秒，默认 20，范围 5..120。

### `BJMF_GPS_OFFSET`

- 必填：否
- 敏感：否
- 获取或设置：默认开启与上游一致的经纬度微偏移，降低多人同坐标冲突；设为 0 可关闭。
- 填写格式：1/true/yes/on 或 0/false/no/off。默认 1。

### `BJMF_RETRY`

- 必填：否
- 敏感：否
- 获取或设置：列表页或签到失败时的额外短重试次数。青龙环境不使用上游 5/15 分钟长等待。
- 填写格式：整数，默认 1，范围 0..3。

### `BJMF_RETRY_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：短重试间隔秒数。
- 填写格式：整数秒，默认 3，范围 0..30。

### `ClassID`

- 必填：否
- 敏感：否
- 获取或设置：兼容上游/注释中的 ClassID 别名；优先使用 BJMF_CLASS_ID。
- 填写格式：与 BJMF_CLASS_ID 相同。
