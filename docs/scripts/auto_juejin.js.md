# 掘金每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/auto_juejin.js`
- 青龙命令：`node scripts/auto_juejin.js`
- 建议 Cron：`36 10 * * *`
- 发布哈希：`532facb50319f8d1ced494cba1d3d19e91de39ea5d89e9a6a4be9c09621dc8fd`
- 许可证：`MIT`

## 脚本功能

- 查询今日签到状态，未签到时执行签到并再次核验
- 读取连续签到天数、累计签到天数和当前矿石余额
- 读取累计幸运值
- 显式开启后使用有效抽奖历史记录沾喜气
- 显式开启后查询免费次数，仅在次数为正时抽奖一次并显示奖品
- 每行一个账号独立执行，失败汇总并非零退出
- 完全断网预演、带时间戳的分阶段日志、账号和任务统计、单行结构化汇总
- 按青龙通知开关和脚本名单发送脱敏摘要，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JUEJIN_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录掘金网页版，打开浏览器开发者工具的网络面板，从本人 api.juejin.cn 已登录请求的请求头复制完整 Cookie。过期后重新登录获取，不要向他人发送请求或凭据。
- 填写格式：每个非空行一个账号的完整 Cookie，使用键值对，保留分号及后续内容，不添加 Cookie: 前缀，不用 & 或 @ 分隔账号。

### 可选参数

### `JUEJIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时设置为 1。预演不投递可能联网的通知，记录脱敏摘要与通知计划。
- 填写格式：1、true、yes、on 开启，0、false、no、off 关闭，默认关闭。

### `JUEJIN_DIP_LUCKY`

- 必填：否
- 敏感：否
- 获取或设置：需要沾喜气时显式设置为 1，同时提供有效历史记录 ID。
- 填写格式：布尔开关，默认 0，对所有账号生效。

### `JUEJIN_LOTTERY_HISTORY_ID`

- 必填：否
- 敏感：是
- 获取或设置：在掘金网页版本人执行沾喜气时，从网络请求参数中获取有效 lottery_history_id。开启沾喜气时必填，不沿用上游固定记录。
- 填写格式：十进制数字字符串，共享的目标抽奖历史记录标识，无需与登录凭据合并。

### `JUEJIN_FREE_LOTTERY`

- 必填：否
- 敏感：否
- 获取或设置：接受抽奖副作用时显式设置为 1。只在官方免费次数为正时抽奖一次；接口未提供强制免费参数，并发可能消耗矿石，请勿并发执行。
- 填写格式：布尔开关，默认 0，对所有账号生效。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式下填写需要通知的脚本标识。可使用当前目录标识 9e33a705da89cfd6、文件名 auto_juejin.js、实际文件名、脚本相对路径或通配符。
- 填写格式：逗号、分号、空白或换行分隔，支持 * 和 ?，* 匹配全部，空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块位于自定义目录时填写该目录。不填时依次寻找 /ql/data/scripts/sendNotify.js 和 /ql/scripts/sendNotify.js。通知不可用不改变业务退出码。
- 填写格式：可选目录路径，目录中应存在导出 sendNotify 函数的 sendNotify.js。

## 副作用与风险

- 未签到时完成每日签到并触发平台签到奖励
- 显式开启后沾喜气并改变平台幸运值相关状态
- 显式开启后执行一次抽奖并改变抽奖次数、奖品及幸运值；并发情况下可能消耗矿石
- 开启并匹配通知条件时通过青龙通知模块发送任务摘要
