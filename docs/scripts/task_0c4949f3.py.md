## 脚本功能

- 米游社指定分区米游币打卡和任务积分状态查询，默认原神、星穹铁道、绝区零分区
- 原神、崩坏：星穹铁道、绝区零、崩坏3角色查询、每日签到、已签识别及奖励展示；默认启用前三款
- 米游社网页凭据有效性检查，显式授权后通过 passport 接口续期，失败回退旧接口
- 库街区鸣潮和战双帕弥什全部绑定角色每日补给签到、已签识别及奖励查询
- 微博登录身份查询、分页获取全部关注超话并签到、验签失败时获取 st 重试
- run 默认签到；test 仅查询现有凭据有效性，不续期
- 每行一个账号的多账号配置、模块独立开关、完全离线预演、失败闭合退出
- 时间轴日志、模块任务和账号统计、唯一 TASK_SUMMARY 单行 JSON、按全局和脚本选择开关调用青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `QL_CHECKIN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：仅获取本人账号凭据。米游社：在本人登录的米游社客户端请求中取得同账号 stoken、stuid、mid 和 x-rpc-device_id；从官方签到网页的请求 Cookie 取得 cookie_token、account_id。v2 stoken 必须配 mid；扫码登录签发的 stoken 可能没有米游币权限，可使用官方短信登录后取得的凭据。库街区：在本人官方客户端已登录请求头中取得 token、devcode、distinct_id，user_id 可由官方 mineV2 查询。微博：登录 https://m.weibo.cn 后，在浏览器开发者工具的网络面板复制本人请求的 Cookie，必须包含 SUB，可包含 XSRF-TOKEN。凭据仅保存为青龙私密环境变量，不向日志粘贴。
- 填写格式：每个非空行是一个完整 JSON 对象，一个对象表示一个账号，可包含 mihoyo、kuro、weibo 中已授权的模块；各平台凭据独立，不要求不同平台使用相同身份。模块内字段保留原 config.json 名称，enabled 为布尔开关，省略模块即关闭。mihoyo 必填 stoken、stuid、device_id；可选 mid、cookie_token、account_id、bbs_checkin（默认 true）、bbs_gids（默认 ["2","6","8"]）、game_sign（默认 ["genshin","honkaisr","zzz"]，另支持 honkai3rd）；v2 stoken 必填 mid。kuro 必填 token、devcode、distinct_id，可选 user_id、games（默认 ["wuwa","pgr"]）。weibo 必填 cookie。所有凭据和标识使用字符串，游戏和分区选项使用字符串数组，不拆分 Cookie 内的等号、分号、& 或 @。

### 可选参数

### `QL_CHECKIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置为 1。
- 填写格式：1、true、yes、on 开启，默认 0；不会请求官方服务或通知服务。

### `QL_CHECKIN_REFRESH_AUTH`

- 必填：否
- 敏感：否
- 获取或设置：只有接受米游社续期会导致旧 cookie_token 失效时才设置为 1。
- 填写格式：默认 0；开启后保留 passport 接口优先、旧接口回退的续期链，刷新结果只保存在本次进程内存。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写本脚本目录标识 0c4949f3b1b01793、脚本文件名或青龙 scripts 相对路径；支持文件名通配符。
- 填写格式：逗号、分号、空白或换行分隔；* 匹配全部；显式空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 notify.py 所在目录。
- 填写格式：目录路径。依次发现可导入 notify.send、此目录、/ql/data/scripts/notify.py、/ql/scripts/notify.py；投递超时 25 秒。

## 多账号

QL_CHECKIN_ACCOUNTS 每个非空行一个 JSON 账号对象；账号逐一独立运行，模块失败后继续其他模块及账号，任何账号失败整体非零退出。
