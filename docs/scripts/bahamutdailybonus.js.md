# 巴哈姆特每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/bahamutdailybonus.js`
- 青龙命令：`node scripts/bahamutdailybonus.js`
- 建议 Cron：`15 10 * * *`
- 发布哈希：`fd0ede8a6aa1d337a5f436befd216bc8189a9f6fe219e8c16abc296f6f7f9f9f`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 账号密码登录及可选两步验证，官方账号标识和昵称按返回值显示，凭据不输出
- 主站每日签到及连续签到天数，识别官方今日已签到结果
- 已加入公会逐个签到及公会结果统计，保留默认开启
- 可选双倍签到广告奖励，保留默认关闭及 30 秒等待
- 显式开启动画疯每日答题，沿用 blackXblue 当日答案文章来源，缺失或歧义时拒绝提交
- 保留每天 08:00 定时，兼容原 ND_BAHA 字段配置
- 每行一个账号，隔离会话，单账号失败不阻断其他账号
- 无网络预演、请求超时、响应大小限制及明确业务成功检查
- 脱敏阶段日志、逐账号统计、单行 TASK_SUMMARY 以及青龙统一通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BAHAMUT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人巴哈姆特官网注册账号及密码；启用两步验证时使用账号安全设置中保存的 Base32 密钥作为 totp，未启用留空。仅存入青龙私有环境变量。
- 填写格式：每个非空行一个 JSON 对象，uid、pwd 为必填字符串，totp 为可选字符串。用 JSON 转义保存密码中的特殊字符，不用 & 或 @ 分隔账号。

### 可选参数

### `ND_BAHA`

- 必填：否
- 敏感：是
- 获取或设置：可将原 BoxJs 的 ND_BAHA 对象复制到私有环境变量，新配置使用 BAHAMUT_ACCOUNTS；不读取原私有文件。
- 填写格式：兼容单账号 JSON 对象 ID、PW、TOTP 及可选布尔值 ADS、GUILD、ANSWER；规范账号变量存在时优先使用规范变量。

### `BAHAMUT_GUILD`

- 必填：否
- 敏感：否
- 获取或设置：按是否需要已加入公会的每日签到设置。
- 填写格式：默认 1；接受 1/0、true/false、yes/no、on/off，显式设置优先于兼容配置。

### `BAHAMUT_ADS`

- 必填：否
- 敏感：否
- 获取或设置：按是否领取主站双倍签到广告奖励设置。
- 填写格式：默认 0，开启为 1，领取前按上游要求等待 30 秒。

### `BAHAMUT_ANSWER`

- 必填：否
- 敏感：否
- 获取或设置：了解每天一次答题机会及第三方文章可能提供错误答案后自行开启。
- 填写格式：默认 0，开启为 1；兼容 ND_BAHA.ANSWER。

### `BAHAMUT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设为 1。
- 填写格式：默认 0；1 为完全断网预演，不生成会话、不等待广告、不提交业务操作。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写通知脚本选择列表，设置后替换默认选择。
- 填写格式：逗号、分号、空白或换行分隔，支持脚本目录相对路径、文件名、文件名通配符或目录编号 62449b894277f9fb；* 全选，空字符串全关闭；auto 且未配置列表时不发送。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自定义青龙通知模块位置时填写包含 sendNotify.js 的目录。
- 填写格式：可选目录；默认查找 /ql/data/scripts/sendNotify.js 和 /ql/scripts/sendNotify.js。预演在禁止网络的隔离进程中尝试通知。

## 多账号

每个非空行一个完整账号 JSON；同账号 uid、pwd、totp 放在同一对象，字段内容不再按分隔符拆开。账号独立校验及执行，任一失败整体非零退出。

## 副作用与风险

- 登录创建服务端会话
- 主站签到并领取其奖励
- 开启公会任务时为已加入公会签到并增加贡献度
- 开启广告奖励时记录广告开始和完成并领取双倍签到奖励
- 显式开启答题时提交答案并消耗当日答题机会，正确时领取奖励
- 通知开关及选择匹配时通过青龙通知模块发送脱敏汇总
