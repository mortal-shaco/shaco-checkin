## 脚本功能

- 从每个账号配置的远程纯文本地址读取并校验待提交 URL。
- 按百度普通收录接口的单批上限分批提交 URL，并核对 HTTP 状态、JSON 结构、业务错误码、确认数量和剩余额度。
- 支持多账号逐行独立处理，以及按账号或全局显式配置重复提交次数。
- 提供不执行百度读取和提交请求的断网预演、时间轴日志、逐账号统计、单行结构化总结和脱敏青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BAIDU_SUBMIT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在百度搜索资源平台添加并验证站点，进入该站点的普通收录资源提交接口页面取得推送准入密钥；同时准备一个返回 UTF-8、每行一个待提交网址的 HTTP 或 HTTPS 文本地址。每个账号写成一行 JSON，站点、密钥和列表地址必须属于同一账号。
- 填写格式：每个非空行一个 JSON 对象：{"site":"站点完整地址","token":"推送准入密钥","data_url":"URL 列表地址"}；可在对象中增加 1 到 100 的整数 times。

### 可选参数

### `BAIDU_SUBMIT_TIMES`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；用于统一设置每批 URL 的显式提交次数，账号 JSON 中的 times 会覆盖它。为避免意外重复提交，默认值为 1。
- 填写格式：1 到 100 的整数，默认 1。

### `BAIDU_HTTP_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；按网络状况设置单次 HTTP 请求超时。
- 填写格式：3 到 60 的整数秒数，默认 15。

### `BAIDU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；在首次配置或变更后设为 1，可只校验配置和执行计划，不发起业务 HTTP 请求。
- 填写格式：启用值为 1、true、yes 或 on；默认不启用。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；需要只通知部分脚本时填写本脚本目录、文件名、通配符或目录编号。设置为空值会关闭全部脚本通知。
- 填写格式：可用逗号、分号、空白或换行分隔；本脚本可用 0acdab575fbc0e9e、candidate.py、ck_baidu.py 或 * 匹配。
