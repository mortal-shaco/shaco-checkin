## 脚本功能

- 兼容原账号密码命令行参数，支持每行一个账号的环境配置与独立会话。
- 使用天翼官方登录页面公钥进行 RSA 加密登录，不依赖其他仓库或应用。
- 每日签到并显示空间奖励，识别接口返回的已签到状态。
- 执行签到活动及相册活动两次抽奖，校验明确奖品，逐项报告结果。
- 显示官方响应中的非敏感昵称、用户名、显示名称或公开身份；手机号和凭据不输出。
- 支持完全断网预演、分阶段时间轴、账号及任务统计和唯一结构化汇总。
- 支持青龙通知开关、脚本选择及 Python 或 JavaScript 通知发送器；通知失败不覆盖业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CLOUD189_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用天翼云盘官方客户端的登录账号和密码；在青龙环境变量中添加，账号需先完成官方注册及必要验证。需要验证码或风控处理时先在官方客户端登录，本脚本不绕过验证。
- 填写格式：每个非空行一个账号，格式为 账号|密码；仅在首个竖线处分割，密码中的后续竖线原样保留；空行忽略，不使用 & 或 @ 分隔账号。优先使用环境变量；兼容原 --username 与 --password 配套命令行参数，但不可同时配置环境账号。

### 可选参数

### `CLOUD189_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要不联网检查配置时设为 1；正式执行留空或设为 0。
- 填写格式：1、true、yes、on 开启；预演不登录、不抽奖、不调用任何通知发送器。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：按需填写要发送通知的脚本选择器；设置后替换默认选择，空值禁用全部。
- 填写格式：逗号、分号、空白或换行分隔；支持目录编号 9973f7e502796463、脚本相对路径、文件名及通配符，* 选中全部；全局禁用优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写本机青龙 notify.py 或 sendNotify.js 所在目录；也自动尝试脚本目录及青龙标准脚本目录。
- 填写格式：本机目录路径；不下载、不安装通知模块；通知正文仅含脱敏统计。
