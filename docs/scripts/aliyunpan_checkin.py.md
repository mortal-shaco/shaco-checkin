# 阿里云盘签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/aliyunpan_checkin.py`
- 青龙命令：`python3 scripts/aliyunpan_checkin.py`
- 建议 Cron：`47 1 * * *`
- 发布哈希：`d297589ed30069bb2aff77a3127190145100976a2910581999049105b54cb939`
- 许可证：`GPL-3.0`

## 脚本功能

- 刷新阿里云盘登录凭据并识别 refresh_token 轮换，全程不输出凭据。
- 输出官方返回的安全昵称、用户名、显示名称或公开 UID，并过滤手机号、令牌和设备标识。
- 查询账号身份与存储容量；只读查询失败时仍继续签到和领奖，但最终以非零状态报告。
- 执行每日签到并严格校验 HTTP 状态、业务成功标志、本月累计签到天数和签到明细。
- 逐日显示签到、已领奖、待领奖状态以及经过脱敏的奖励名称和说明。
- 默认领取当日奖励；可显式关闭，或显式补领本月全部已签到未领奖励，单日领奖失败不阻断后续日期。
- 可选注册带 ECDSA 签名的设备会话；默认关闭，只有正式启用时才导入 ecdsa。
- 支持规范变量及 refreshToken、ALI_REFRESH_TOKEN 旧变量别名，并按换行独立处理多账号。
- 支持正式执行前随机延迟、新旧延迟参数兼容和轮换令牌的显式安全文件持久化。
- 支持完全断网预演、青龙脱敏总结通知、分账号分阶段时间轴日志、原机器汇总和唯一 TASK_SUMMARY 记录。
- 支持可选 HTTPS PushPlus 推送；青龙通知不可用时仍可独立推送，通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ALIYUN_REFRESH_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录阿里云盘网页版，打开浏览器开发者工具，在 Application 的 Local Storage 中查看当前站点 token 项，只复制 refresh_token 字段；不要复制整段 JSON，也不要公开该值。
- 填写格式：每个非空行填写一个账号的 refresh_token；只用换行分隔账号，不使用 &、@ 或其他分隔符。

### 可选参数

### `refreshToken`

- 必填：否
- 敏感：是
- 获取或设置：旧版变量兼容入口；获取方式与 ALIYUN_REFRESH_TOKEN 相同。仅在规范变量未设置时读取。
- 填写格式：每个非空行一个 refresh_token，只使用换行分隔。

### `ALI_REFRESH_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：sudojia 上游脚本的旧变量兼容入口；获取方式与 ALIYUN_REFRESH_TOKEN 相同。仅在前两个变量均未设置时读取。
- 填写格式：每个非空行一个 refresh_token；原脚本的 & 分隔方式不再接受。

### `ALIYUN_CLAIM_REWARD`

- 必填：否
- 敏感：否
- 获取或设置：由用户按需设置；默认领取当日奖励，关闭后只签到和查询明细。
- 填写格式：1、true、yes、on 表示开启；0、false、no、off 表示关闭。默认 1。

### `ALIYUN_CLAIM_ALL_REWARDS`

- 必填：否
- 敏感：否
- 获取或设置：由用户按需显式设置；用于补领本月所有已签到但未领取的奖励。
- 填写格式：布尔值，默认 0；仅在 ALIYUN_CLAIM_REWARD 开启时生效。

### `ENABLE_DEVICE_SESSION`

- 必填：否
- 敏感：否
- 获取或设置：普通签到无需设置；仅在服务端要求设备会话时由用户显式开启。
- 填写格式：布尔值，默认 0；正式开启时需要从公共包仓库安装 ecdsa。

### `ALIYUN_MAX_DELAY_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：由用户设置正式执行前的最大随机延迟秒数。
- 填写格式：非负整数，默认 0；预演不等待。

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：旧版随机延迟变量，仅在 ALIYUN_MAX_DELAY_SECONDS 未设置时读取。
- 填写格式：非负整数秒数。

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：旧版随机延迟开关；显式关闭时取消随机延迟。
- 填写格式：布尔值。

### `ALIYUN_PERSIST_ROTATED_TOKENS`

- 必填：否
- 敏感：否
- 获取或设置：仅在需要把服务端轮换后的 refresh_token 安全写入文件时显式开启。
- 填写格式：布尔值，默认 0。

### `ALIYUN_TOKEN_OUTPUT_FILE`

- 必填：否
- 敏感：否
- 获取或设置：由用户选择已有父目录下的私有绝对路径；只有显式开启令牌持久化时才需要。
- 填写格式：绝对文件路径；脚本以原子替换方式写入并设置为 0600 权限，每行对应一个账号。

### `ALIYUN_DRIVE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试或导入核验时设置为 1，可完全断网预演请求、领奖、通知和凭据持久化。
- 填写格式：布尔值，正式执行默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要限定通知脚本时设置；可匹配目录 ID 9c6fa7a75879fa8b、规范路径 scripts/aliyunpan_checkin.py 或文件名。
- 填写格式：使用逗号、分号、空白或换行分隔选择器，支持文件名通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知组件不在标准目录时，可填写包含 notify.py 的目录。
- 填写格式：本机绝对目录路径；不设置时依次尝试 Python 导入、/ql/data/scripts/notify.py 和 /ql/scripts/notify.py。

### `ALIYUN_PUSH_PLUS`

- 必填：否
- 敏感：是
- 获取或设置：从 PushPlus 官网账户获取推送令牌，存入青龙私密环境变量；不设置时只使用青龙通知。
- 填写格式：单个推送令牌；仅正式执行且通知策略允许时发送脱敏总结。

## 多账号

每个非空行仅放一个账号的 refresh_token；各账号独立处理并继续执行，任一账号或其必需子任务失败时进程整体非零退出。

## 副作用与风险

- 执行账号每日签到。
- 默认领取当日奖励；显式开启全量模式后补领其他已签到且未领取的奖励。
- ENABLE_DEVICE_SESSION=1 时向服务端注册临时设备会话。
- ALIYUN_PERSIST_ROTATED_TOKENS=1 且发生令牌轮换时，原子写入用户指定的 0600 权限凭据文件。
- 正式执行且通知策略允许时，通过青龙 notify.py 发送不含凭据和原始响应的任务总结。
- ALIYUN_PUSH_PLUS 已配置且通知策略允许时，向 PushPlus 发送脱敏任务总结。
