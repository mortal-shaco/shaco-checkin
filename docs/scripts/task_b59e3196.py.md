## 脚本功能

- 每日零点为本人指定的原神国服角色签到，保留默认活动、区服、请求接口及配套签名版本。
- 从官方角色列表核对 UID 与区服，显示官方返回的昵称和公开游戏 UID。
- 查询当天签到状态，已签到时跳过重复提交；执行后再查 is_sign，验证成功才报告业务完成。
- 查询累计签到天数与当日奖励，保留并启用上游已有信息查询能力。
- 每行一个账号，逐账号隔离错误，任一失败则非零退出。
- 独立标准库 HTTP 实现，超时、限制响应长度、拒绝重定向和严格业务字段校验；不依赖私有仓库。
- 完全离线预演仅校验配置，不访问服务或通知渠道，不把预演视为业务成功。
- 按全局开关及脚本选择配置青龙通知，投递不可用时保留业务退出码；输出时间轴、阶段耗时、账号统计和唯一结构化任务汇总。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MYS_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录米游社官方原神签到页，在浏览器开发者工具的网络面板查看本人签到请求。复制完整 Cookie 请求头值，并从请求的 uid、region 字段核对游戏 UID 和区服；UID 也可在游戏个人资料查看。不要复制请求到公开日志，不要提交或分享 Cookie。凭据过期时重新登录获取。仅适用于本人原神国服角色，账号和角色必须对应。
- 填写格式：每个非空行一个账号：UID,区服|完整Cookie；省略逗号与区服时默认为 cn_gf01。仅在首个 | 拆分，后续 Cookie 原样保留；不能使用 &、@ 分隔账号。Cookie 需包含官方已登录请求实际使用的全部字段，不猜测或替换字段。

### 可选参数

### `MYS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线预演设为 1；正式执行设为 0 或不配置。
- 填写格式：1、true、yes、on 开启；0、false、no、off 关闭。

### `MYS_ACT_ID`

- 必填：否
- 敏感：否
- 获取或设置：默认保留上游原神签到活动标识 e202009291139501；仅在官方同一签到活动请求证实变更时配置。
- 填写格式：活动标识，仅允许字母、数字、下划线和短横线。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式下配置需要通知的脚本，替换默认选择列表；本任务默认未列入。可填写本任务目录编号 b59e31965541a4fa、脚本文件名或相对路径；支持文件名通配符和 *。
- 填写格式：以逗号、分号或空白分隔；空值关闭全部自动选择。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙现有 notify.py 或 sendNotify.js 所在目录。默认尝试导入 notify.send，再查找 /ql/data/scripts 与 /ql/scripts。
- 填写格式：本机通知模块目录路径；不需要额外仓库或下载引导。
