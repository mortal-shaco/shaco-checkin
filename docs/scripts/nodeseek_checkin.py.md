## 脚本功能

- NodeSeek 每日签到
- 已签到状态识别
- 近 N 天签到鸡腿收益统计
- 可选随机奖励模式与多账号错峰执行
- 多账号独立处理与脱敏汇总通知
- 断网预演配置验证

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NODESEEK_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://www.nodeseek.com 后打开浏览器开发者工具 → Network，刷新页面，选择同站请求，复制 Request Headers 中完整的 cookie 值（不含 Cookie: 前缀）。请勿分享或写入公开仓库。
- 填写格式：每个非空行一个账号的完整 Cookie；Cookie 内的 &、@、; 保持原样，不用它们分隔账号

### 可选参数

### `NODESEEK_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演时手动设置为 1
- 填写格式：1/true/yes/on 启用

### `NS_RANDOM`

- 必填：否
- 敏感：否
- 获取或设置：按是否使用 NodeSeek 随机签到奖励模式设置
- 填写格式：布尔值，默认 true

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：如需多账号在时间窗口内错峰执行则设为 true；默认关闭，避免强制长等待
- 填写格式：布尔值，默认 false

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：自定义错峰时间窗口上限
- 填写格式：0..86400 整数秒，默认 3600

### `NS_STATS_DAYS`

- 必填：否
- 敏感：否
- 获取或设置：自定义近 N 天签到鸡腿收益统计窗口
- 填写格式：1..365 整数天，默认 30

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本白名单启用通知时设置；空值表示全部禁用
- 填写格式：catalog-id、脚本路径、文件名或 glob，可用逗号/分号/空白/换行分隔；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认路径时，设为 notify.py 或 sendNotify.js 所在目录
- 填写格式：本地目录绝对路径

## 多账号

NODESEEK_COOKIE 中每个非空行是一个独立账号；逐账号执行，任一账号失败时进程整体非零退出
