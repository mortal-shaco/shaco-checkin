# 爱上ASMR每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/a3asmr.js`
- 青龙命令：`node scripts/a3asmr.js`
- 建议 Cron：`15 9 * * *`
- 发布哈希：`6bb83ca656512945101d667db6933f8b8715f52e2351e244bee9a2527c39d274`
- 许可证：`MIT`

## 脚本功能

- 使用登录 Cookie 访问签到页并提取 WordPress REST nonce 后提交每日签到
- 识别签到成功、今日已签到（页面状态或接口文案）等业务结果
- 支持每行一个账号，可选备注标签，独立汇总结果
- 展示页面中可解析的非敏感昵称或公开 UID，隐藏 Cookie、nonce 与原始响应
- 完全断网预演、超时与响应大小限制、时间轴日志与单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `A3ASMR_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://www.a3asmr.com/ 后，打开开发者工具网络面板，选择发往本站的已登录请求，复制请求头 Cookie 的完整值；不要复制响应 Set-Cookie，也不要将凭据发给他人。登录失效后重新获取。
- 填写格式：每个非空行一个账号。整行可为完整 Cookie，或「备注|Cookie」；仅在首个竖线处拆分，后续 Cookie 原文保留。Cookie 内分号与等号原样保留，不使用 & 或 @ 分隔账号。

### 可选参数

### `A3ASMR_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：按本人实际可访问的站点入口填写；不填则使用默认官方域名。
- 填写格式：站点根地址，默认 https://www.a3asmr.com；末尾斜杠可有可无。

### `A3ASMR_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置请求超时；不设置时使用 20000 毫秒。
- 填写格式：1000 至 60000 的整数毫秒值。

### `A3ASMR_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在测试环境自行开启；正式执行时删除或设为 0。
- 填写格式：1/true/yes/on 开启完全断网预演；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式下需要替换默认通知名单时自行设置。
- 填写格式：逗号、分号或空白分隔；可匹配 catalogId、scripts/a3asmr_checkin.js、a3asmr_checkin.js、当前文件名或通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录。
- 填写格式：目录路径；失败后继续尝试 /ql/data/scripts 与 /ql/scripts；通知失败不改变业务退出码。
