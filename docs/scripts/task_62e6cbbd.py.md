## 脚本功能

- 按账号提交学校 OA 实习单日签到（经度、纬度、地址与学生 ID）
- 多账号换行配置，学生 ID 与 Token 合并到同一账号行
- 完全断网预演、超时请求、业务成功判定与失败闭合退出
- 时间轴日志、账号阶段统计、脱敏通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `OA_SGIN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在学校 OA 实习微信小程序或网页登录本人账号，打开开发者工具网络面板，找到 internshipSignIn 相关请求，复制请求头 X-Access-Token，并确认本人 probationaryworkplacementstudentid（实习学生 ID）。凭据仅写入青龙环境变量，不要分享抓包。
- 填写格式：每个非空行一个账号：studentId#X-Access-Token；仅在第一个井号处分割，后续 Token 原文保留。空行和以井号开头的注释行忽略。

### `OA_SGIN_LONGITUDE`

- 必填：是
- 敏感：否
- 获取或设置：填写本人真实实习地点经度；可与手机地图或上游 Wiki 获取方式一致，须与现场打卡位置相符。
- 填写格式：十进制度数，范围 -180 到 180

### `OA_SGIN_LATITUDE`

- 必填：是
- 敏感：否
- 获取或设置：填写本人真实实习地点纬度；须与现场打卡位置相符。
- 填写格式：十进制度数，范围 -90 到 90

### `OA_SGIN_SIGNADDRESS`

- 必填：是
- 敏感：否
- 获取或设置：填写本人真实实习签到地址文本，与学校 OA 要求的地址描述一致。
- 填写格式：非空地址字符串，最长 200 字符

### 可选参数

### `OA_SGIN_DATE`

- 必填：否
- 敏感：否
- 获取或设置：可选单日覆盖；默认使用运行当天本地日期。维护版已移除上游日期区间批量补签。
- 填写格式：YYYY-MM-DD 单日；不支持区间

### `OA_SGIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：完全断网预演时设置为 1；只校验配置与流程，不发起网络请求，不声明真实签到成功。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试导入 notify 和青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径
