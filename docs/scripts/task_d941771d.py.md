## 脚本功能

- 通过学校 HTTPS 统一认证表单登录，支持本人官方 Cookie 认证；认证页面变化、加密或验证码不受支持时失败闭合
- 查询今日待签到任务；默认仅查询，空列表只报告无待签到任务，不伪称已经签到
- 显式开启后按本人真实位置提交首个待签到任务，要求本人设备扩展值；通过业务成功标志、业务码及待签到列表复查核验
- 按换行 JSON 配置独立处理多个账号，任一失败非零退出
- 完全断网预演、带时间戳的阶段日志、账号与子任务统计及唯一 TASK_SUMMARY 记录
- 显示官方返回的非敏感账号身份；不输出凭据、原始响应或设备值
- 正式模式支持青龙通知与全局开关，通知失败保持原业务退出码；断网预演生成摘要

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CPDAILY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人学校官方今日校园客户端进入签到页面，使用本人授权的网络调试工具获取请求。推荐从发往 neuq.cpdaily.com 的请求取得完整 Cookie；也可填写本校统一认证 username/password（仅支持原上游表单流程，遇加密或验证码必须改用本人 Cookie，绝不降级明文 HTTP）。提交时另从本人 submitSign 请求取得 Cpdaily-Extension 填入 extension，longitude/latitude/position 必须填写实际位置。不得复用上游固定设备值。账号信息只保存在青龙环境变量，不上传或公开。
- 填写格式：每个非空行一个 JSON 对象，账号之间仅换行。认证字段二选一：cookie 字符串，或 username/password 字符串对。CPDAILY_SUBMIT=1 时还需 longitude（-180 到 180 的数字）、latitude（-90 到 90 的数字）、position（位置文字）、extension（本人官方请求头 ASCII 字符串）。可选 isMalposition 为整数 0 或 1，默认 0；为 1 时必须填写真实 abnormalReason。不支持照片上传。JSON 可安全容纳密码及 Cookie 中的等号、&、@，无需拆分。

### 可选参数

### `CPDAILY_SUBMIT`

- 必填：否
- 敏感：否
- 获取或设置：自行决定是否允许签到写入；默认仅查询。先在学校官方客户端核验任务和实际位置。
- 填写格式：0 或 1，默认 0；1 时每轮只提交第一个待签到任务，保留上游任务选择范围

### `CPDAILY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 进行完全断网预演。
- 填写格式：0 或 1，默认 0；预演只检查账号参数，生成通知摘要但不发送网络通知，不代表真实签到成功

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：设置需要自动通知的脚本名单；默认未列入通知名单。
- 填写格式：逗号、分号或空白分隔的目录编号、脚本文件名或通配符；本脚本编号 d941771d29760d88，文件名 candidate.py；* 为全部，空值禁用全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写本机青龙 notify.py 或 sendNotify.js 所在目录；也会查找青龙标准目录及可导入的 notify.send。业务本身不依赖通知模块。
- 填写格式：本机目录路径，不填写时使用标准发现方式
