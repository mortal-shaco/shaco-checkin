## 脚本功能

- 使用多看阅读 Cookie 执行每日签到。
- 查询当前书豆总额、到期批次和到期日期。
- 通过显式 delay 任务延期接口标记为可延期的书豆批次。
- 通过显式 free 任务查询并领取今日限免书籍。
- 通过显式 gift 任务检查并领取体验任务奖励。
- 通过显式 add_draw 和 draw 任务添加抽奖机会并执行抽奖。
- 通过显式 download 任务领取下载任务奖励，并设置安全循环上限。
- 通过显式 task 任务领取五类其他活动奖励。
- 支持多账号独立执行、逐阶段统计、青龙通知和单行 TASK_SUMMARY 汇总。
- 支持完全断网的配置预演，不访问多看接口或修改账号状态。
- 每日签到，保留上游时间戳与设备字段校验算法。
- 查询当前书豆总量、各批次数量、到期日期和可延期状态。
- 可选延长符合条件的书豆有效期。
- 可选领取频道限免图书，仅提交零价格请求。
- 可选消耗已有机会参加上游抽奖活动，最多六次且失败即停止。
- 多账号独立处理、凭据格式检查、无网络预演、请求超时和明确业务成功核验。
- 显示官方返回的非敏感昵称、用户名、显示名称或公开用户编号。
- 脱敏时间轴、阶段与账号统计、唯一单行结构化任务汇总以及青龙通知。
- 规范任务每日 02:28；旧多看 02:05 定时任务如需保留原 Cron，请将命令改为 python3 scripts/yuxian158_check_duokan.py。

## 环境变量与参数

先配置必选参数再运行；条目注明的兼容变量可以替代规范变量。缺少任一必选参数及其全部兼容变量时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `DUOKAN_COOKIE`

- 必填：是（也可设置 `DUOKAN`）
- 敏感：是
- 获取或设置：登录多看阅读网页后，在浏览器开发者工具的网络面板中打开 www.duokan.com 请求，复制自己的完整 Cookie；必须包含 device_id 和有效登录会话字段。不要把该值分享给他人。 规范变量与所列旧变量任选其一；只保留旧变量也可运行。
- 填写格式：每行一个账号；每行是以分号分隔的 Cookie 字段，字段采用 名称=值，解析时只按每个字段的第一个等号分割。

### 可选参数

### `DUOKAN_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需选择要执行的任务；默认只执行签到和书豆查询，具有额外副作用的任务必须显式启用。
- 填写格式：用英文逗号分隔且不得重复：sign,info,free,gift,add_draw,draw,download,task,delay。

### `DUOKAN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置单次请求超时秒数，通常保留默认值即可。
- 填写格式：1 至 60 的整数，默认 15。

### `DUOKAN_MAX_REWARDS`

- 必填：否
- 敏感：否
- 获取或设置：用于限制体验奖励机会数和下载奖励循环次数，避免异常接口导致过量请求。
- 填写格式：1 至 200 的整数，默认 20。

### `DUOKAN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 可进行完全断网的配置预演；预演只检查参数和任务计划，不代表线上业务成功。
- 填写格式：1 表示开启；0、false、no 或 off 表示关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要只通知部分脚本时填写脚本选择器；设置后将替换默认选择范围，空值表示全部关闭。
- 填写格式：可用逗号、分号、空白或换行分隔；支持 df7ef61ae68efc75、scripts/duokan_reading.py、duokan_reading.py、candidate.py、通配符或 *。

### `DUOKAN`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容输入；获取方式同 DUOKAN_COOKIE。原脚本通过私有 utils.get_data 读取 DUOKAN 账号列表，本版本不依赖该配置文件；请导出其中 cookie 字段。规范变量有值时优先使用规范变量。
- 填写格式：每行一个完整 Cookie；也接受上游账号列表的 JSON 数组，每项含 cookie 字段。

### `DUOKAN_FREE`

- 必填：否
- 敏感：否
- 获取或设置：明确希望领取频道限免图书时设为 1。仅提交价格为零的原始领书请求，不回退到付费购买。
- 填写格式：默认 0；1 开启、0 关闭。

### `DUOKAN_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：明确希望延长可延期书豆有效期时设为 1；只处理书豆查询返回 delay 为 1 的批次。
- 填写格式：默认 0；1 开启、0 关闭。

### `DUOKAN_DRAW`

- 必填：否
- 敏感：否
- 获取或设置：明确同意消耗已有抽奖机会时设为 1。沿用上游活动编号，每个账号最多尝试六次，任一次失败立即停止；不会增加或伪造机会。旧活动可能已失效，失败不会视为完成。
- 填写格式：默认 0；1 开启、0 关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙 notify.py 所在目录；还会查找可导入的 notify 模块、/ql/data/scripts/notify.py 和 /ql/scripts/notify.py。只用于通知，业务逻辑不依赖外部仓库。
- 填写格式：本机通知模块目录路径。

## 多账号

DUOKAN_COOKIE 每个非空行对应一个账号；各账号独立解析和执行，任一账号或任一所选任务失败时进程返回非零退出码。 兼容 DUOKAN 逐行 Cookie 或旧 JSON 列表，DUOKAN_COOKIE 优先。旧 DUOKAN_DELAY/FREE/DRAW=1 仅追加相应任务。

## 副作用与风险

- 默认 sign 任务会提交每日签到并改变账号签到状态。
- 显式 free 任务会创建价格为零的书籍订单并把限免书加入账号。
- 显式 gift、download 和 task 任务会领取活动奖励并改变书豆或活动任务状态。
- 显式 add_draw 任务会增加抽奖机会，显式 draw 任务会执行抽奖并可能消耗机会。
- 显式 delay 任务会延期符合条件的书豆到期批次。
- 每日签到改变签到状态并可能获得书豆。
- 开启 DUOKAN_FREE 时领取图书并改变书架或购买记录。
- 开启 DUOKAN_DELAY 时修改可延期书豆批次的有效期。
- 开启 DUOKAN_DRAW 时消耗已有抽奖机会并可能领取活动奖励。
- 真实模式且通知启用时，通过青龙通知模块发送脱敏任务总结。
