# Discuz 论坛日常维护

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/forum_download.py`
- 青龙命令：`python3 scripts/forum_download.py`
- 建议 Cron：`20 8 * * *`
- 发布哈希：`f7c36f3c4bb0ef72d1c9bdaec2387d373c870a5be4607ac71ed9f274c0339751`
- 许可证：`GPL-3.0`

## 脚本功能

- 读取指定版块的主题列表，并按上游顺序读取前三个帖子的附件；下载显式启用，不保存文件，间隔两秒。
- 访问论坛首页并验证登录状态，不把首页访问成功推断为奖励到账。
- 提供 dsu_paulsign 和 qiandao.php 两种显式签到开关，保留原端点、方法、签到参数和已签到判断。
- 独立解析 Discuz 积分页面并显示可验证的积分项目，替代私有 get_coin 导入；页面不兼容时明确失败。
- 官方首页返回用户名时显示该非敏感身份，账号日志不输出 Cookie、表单令牌、地址参数或原始响应。
- 多账号独立运行、请求超时、同站重定向限制、明确业务成功检查、断网预演、脱敏通知和单行结构化任务汇总。
- 显式 work 动作访问打工插件，最多点击八次，遇间隔限制停止点击，再领取奖励；只接受 messagetext 中明确成功或今日已完成提示。
- 保留默认 visit,credits、账号 JSON 参数及每日 08:20 计划；与现有动作在同一规范脚本运行。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FORUM_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录自己的论坛，在浏览器开发者工具网络面板复制同站请求的完整 Cookie；url 填 HTTPS 根地址，可含安装子目录；下载所需 fid 从版块地址取得。
- 填写格式：每个非空行一个 JSON 对象，必填 url、cookie，可选 name、fid；不按分号、& 或 @ 拆分 Cookie。

### 可选参数

### `FORUM_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需选择动作，两个签到入口择一；完整打工流程可选 visit,work,credits。
- 填写格式：逗号分隔 visit、credits、download、sign、sign_plus、work；默认 visit,credits。

### `FORUM_ALLOW_DOWNLOAD`

- 必填：否
- 敏感：否
- 获取或设置：确认下载可能消耗积分后显式开启。
- 填写格式：1 开启；默认 0。

### `FORUM_ALLOW_WORK`

- 必填：否
- 敏感：否
- 获取或设置：确认站点安装 np_cliworkdz 并允许广告点击及领取奖励后显式开启。
- 填写格式：1 开启；默认 0；work 动作必须开启。

### `FORUM_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：开启无网络参数和流程预演，不代表真实业务成功。
- 填写格式：1 开启；默认 0；不访问论坛或发送网络通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙已有 notify.py 发送脱敏总结；预演仅打印通知内容。
- 填写格式：默认 1；0、false、no、off 关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可指定青龙 notify.py 所在目录；默认尝试导入 notify 及 /ql/data/scripts、/ql/scripts。
- 填写格式：可选本地目录；通知失败保留业务退出码。

## 副作用与风险

- 启用 sign 或 sign_plus 时提交每日签到并可能获得签到奖励。
- 首页访问及页面读取可能增加论坛访问统计或触发站点每日访问奖励。
- 显式启用 download 后附件请求可能消耗论坛积分、增加下载次数或触发下载奖励。
- 显式开启 work 后提交广告点击和领取奖励，可能改变积分、任务状态及广告点击统计。
