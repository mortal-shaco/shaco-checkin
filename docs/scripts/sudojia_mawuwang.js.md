- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）

- 建议 Cron：`13 0 * * *`

- 许可证：`GPL-3.0`

## 脚本功能

- 校验登录凭据
- 读取官方返回的非敏感昵称或用户名以核对账号
- 每日查询签到状态，已签到时跳过重复提交，未签到时执行签到
- 查询当前积分、即将过期积分和过期时间
- 按行配置多账号，独立运行并汇总失败退出码
- 完全断网预演，验证参数并演示全部任务阶段
- 通过青龙发送脱敏结果通知，包含积分和签到结果；通知失败不改变业务退出码
- 时间轴日志、逐账号和总体统计及单行 TASK_SUMMARY 结构化汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MAWUW_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：微信登录馬伍旺饮料厂小程序，通过本人授权抓包查看 https://webapi.qmai.cn/web/seller/oauth/flash-sale-login 响应，取 token 与 user.id。失效时重新登录获取，不分享响应。
- 填写格式：每个非空行填写 token#id，仅在第一个 # 分割；其后内容完整保留，不以 & 或 @ 分隔账号。

### 可选参数

### `MAWUW_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 开启完全断网预演。
- 填写格式：1 为预演，其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙 sendNotify.js 所在目录；否则自动检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：目录路径，不包含文件名。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

每个非空行一个账号，token 和 id 用第一个 # 连接；逐账号独立运行，任何账号失败时整体非零退出。
