# 百度站点提交

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/baidu.py`
- 青龙命令：`python3 scripts/baidu.py`
- 建议 Cron：`36 2 * * *`
- 发布哈希：`1e0f4f5610f83503ed177024921c98b998d4752f576e03515fdad888fd86fda0`
- 许可证：`MIT`

## 脚本功能

- 下载并校验本站 UTF-8 URL 清单
- 调用百度站点提交接口并核验 success 与 remain，输出成功条数和剩余配额
- 支持显式设置重复提交次数，默认仅提交一次
- 按行配置多个站点，逐账号隔离错误并汇总业务退出码
- 完全离线预演、分阶段时间轴日志和唯一 TASK_SUMMARY 结构化结果
- 通过青龙通知发送脱敏结果，支持全局关闭，通知故障不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BAIDU`

- 必填：是
- 敏感：是
- 获取或设置：登录百度搜索资源平台，验证自己拥有的站点，在普通收录的 API 提交页面复制含 site 和 token 的提交地址；使用 HTTPS 的 data.zz.baidu.com/urls 地址。自行托管公开的 UTF-8 URL 文本清单，仅包含该站点 URL。不得公开或记录提交令牌。
- 填写格式：每个非空行是一个 JSON 对象，必填 data_url（HTTPS 文本清单地址）、submit_url（含唯一 site 和 token 的百度 HTTPS 接口地址），可选 times（1 至 100 的整数，默认 1）。不使用 & 或 @ 分隔账号；接口地址内部的 & 保持原样。

### 可选参数

### `BAIDU_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 即可完全离线预演。
- 填写格式：1、true、yes、on 开启，其他值关闭，默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当通知文件位于自定义目录时填写该目录；自动兼容可导入的 notify.send 和青龙标准脚本目录。
- 填写格式：含 notify.py 的目录绝对路径；可留空。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

BAIDU 每个非空行对应一个站点账号 JSON 对象，同一站点的清单地址、含令牌提交地址和次数合并在此对象中。各账号独立处理，任一账号失败整体非零退出。
