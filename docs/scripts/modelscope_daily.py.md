# ModelScope 魔搭每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/modelscope_daily.py`
- 青龙命令：`python3 scripts/modelscope_daily.py`
- 建议 Cron：`0 9 * * *`
- 发布哈希：`2a95265bfabf2f6b927222ad0786b58ba5d804bd7b5bd8d2206d70b513e25cc9`
- 许可证：`MIT`

## 脚本功能

- 国内站与国际站每日登录签到，保留每天 9 点定时；国内站查询当日魔粒账单，国际站按官方登录接口业务成功确认，明确提示无账单回读。
- 国内站按北京时间筛选 EARN 类型、daily_active 与 aliyun_bindlogin 规则；保留签到前、签到后及延迟回读，区分今日已领取与签到到账，并显示到账数量和账单标题。
- 查询可用及总魔粒余额、今日推理调用用量；保留辅助查询失败提示和不阻断签到主任务的边界。
- 显示官方返回的昵称、用户名或公开 UID，保留自定义账号备注；不输出凭据、手机号或原始响应。
- 规范多账号与四种旧凭据变量兼容，保留 --query、--only N、--no-notify；--query 仍调用可能触发签到的登录信息接口。
- 自带标准库 HTTPS 请求、超时、响应大小限制、代理与 TLS 校验；拒绝重定向，区分 401 凭据失效与 403 风控。
- 完全断网预演、逐账号隔离、部分失败非零退出、带时间戳的阶段日志和每次恰好一条 TASK_SUMMARY 结构化汇总。
- 青龙 notify.py 或 sendNotify.js 通知发现及 PushPlus、Bark、企业微信、钉钉兼容渠道，遵守统一清单与开关，通知失败保留业务退出码；预演仅生成通知摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MODELSCOPE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：分别登录国内站 https://modelscope.cn 或国际站 https://www.modelscope.ai；按 F12，在应用或存储的 Cookie 中复制对应站点 m_session_id 的值。不是个人中心的 API Token；国内、国际凭据不可互换。
- 填写格式：每个非空行一个账号：cn:备注|会话值 或 intl:备注|会话值。备注可留空，写作 cn:|会话值；只在首个 | 处分割，后续字符完整保留。此变量非空时优先于所有旧凭据变量。

### 可选参数

### `MODELSCOPE_CN_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧版：在国内站登录后，从开发者工具的 Cookie 中取得 m_session_id 值。规范配置优先使用 MODELSCOPE_ACCOUNTS。
- 填写格式：每个非空行一个账号，格式为 备注|会话值 或仅会话值；仅在首个 | 处分割，不再使用 & 或 @ 分隔账号。

### `MODELSCOPE_INTL_TOKENS`

- 填写格式：每个非空行一个账号，格式为 备注|会话值 或仅会话值；仅在首个 | 处分割，不再使用 & 或 @ 分隔账号。

### `MODELSCOPE_CN_TOKEN`

## 多账号

每个非空行一个账号，规范变量使用 cn:备注|会话值 或 intl:备注|会话值；备注可为空，只在首个 | 处分割。规范变量非空则优先，否则按国内、国际顺序读取旧变量。各账号独立执行，任一账号失败或到账未确认时整体非零退出；--only N 使用该配置顺序选择账号。
