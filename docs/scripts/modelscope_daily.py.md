# ModelScope 魔搭每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/modelscope_daily.py`
- 青龙命令：`python3 scripts/modelscope_daily.py`
- 建议 Cron：`30 0 * * *`
- 发布哈希：`59f9403ceae2737dbd646c739bb5eb6600b43bc4d24d54d5c955d89c51c5299d`
- 许可证：`MIT`

## 脚本功能

- 国内站和国际站按各自会话值每日签到，保留两站同任务运行能力
- 国内站以北京时间当日魔粒账单确认签到到账，重复签到显示今日已领取
- 国际站以登录接口的明确业务成功结果确认签到触发
- 查询魔粒可用余额、总余额和今日推理用量
- 支持按账号序号选择运行及旧版查询模式
- 支持代理、国内站账单延时核验及旧版环境变量
- 支持逐行多账号、无网络预演、时间轴日志和结构化结果汇总
- 运行结束发送脱敏青龙通知，并兼容已配置的旧版推送渠道

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MODELSCOPE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录对应的 ModelScope 国内站或国际站，在浏览器开发者工具的 Cookie 中找到 m_session_id；每行填写一个账号。也兼容下方旧版站点变量。
- 填写格式：每行 cn:备注|m_session_id 或 intl:备注|m_session_id；备注可留空，凭据中的后续竖线保留

### 可选参数

### `MODELSCOPE_CN_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：旧版国内站多账号兼容变量：登录 modelscope.cn 后从浏览器 Cookie 取得 m_session_id；仅在统一账号变量为空时读取。
- 填写格式：每行 备注|m_session_id，备注可省略

### `MODELSCOPE_INTL_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：旧版国际站多账号兼容变量：登录 modelscope.ai 后从浏览器 Cookie 取得 m_session_id；仅在统一账号变量为空时读取。
- 填写格式：每行 备注|m_session_id，备注可省略

### `MODELSCOPE_CN_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版国内站单账号兼容变量：登录国内站后从浏览器 Cookie 取得 m_session_id；仅在该站多账号变量为空时读取。
- 填写格式：单个 m_session_id 值

### `MODELSCOPE_INTL_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版国际站单账号兼容变量：登录国际站后从浏览器 Cookie 取得 m_session_id；仅在该站多账号变量为空时读取。
- 填写格式：单个 m_session_id 值

### `MODELSCOPE_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：如需代理，由用户自行配置可用的 HTTPS 代理地址；地址中可能含认证信息。
- 填写格式：HTTPS 代理地址

### `MODELSCOPE_VERIFY_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：国内站签到后账单尚未到账时的重查等待时间，默认 2 秒。
- 填写格式：0 至 30 的整数秒数

### `MODELSCOPE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设置为 1 可检查账号配置并预演日志，不发送任何网络请求。
- 填写格式：1 表示无网络预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可指定需要通知的脚本；设置后替换默认选择，空值关闭全部通知。
- 填写格式：目录标识、脚本名或通配符；逗号、分号或空白分隔

### `MODELSCOPE_NO_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：旧版通知关闭开关。
- 填写格式：1 表示关闭通知

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：自定义青龙 notify.py 所在目录；通常无需设置。
- 填写格式：本地目录路径

### `PLUSPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：如继续使用旧版 PushPlus 推送，在自己的 PushPlus 账户中获取令牌。
- 填写格式：PushPlus 令牌

### `BARK_URL`

- 必填：否
- 敏感：是
- 获取或设置：如继续使用旧版 Bark 推送，在自己的 Bark 客户端中获取 HTTPS 推送地址。
- 填写格式：HTTPS 推送地址

### `WECOM_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：如继续使用旧版企业微信推送，在自己的群机器人设置中获取 Webhook 地址。
- 填写格式：HTTPS Webhook 地址

### `QYWX_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版企业微信兼容变量：在自己的群机器人设置中获取 Webhook 密钥。
- 填写格式：Webhook 密钥或 HTTPS 地址

### `DINGTALK_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：如继续使用旧版钉钉推送，在自己的群机器人设置中获取 Webhook 地址。
- 填写格式：HTTPS Webhook 地址

## 多账号

每个非空行对应一个账号；统一变量中先写国内站 cn 或国际站 intl，再写备注和会话值。账号逐个处理，任一账号失败时进程以非零码退出。
