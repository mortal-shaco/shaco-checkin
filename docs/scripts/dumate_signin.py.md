# 百度搭子每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/dumate_signin.py`
- 青龙命令：`python3 scripts/dumate_signin.py`
- 建议 Cron：`24 9 * * *`
- 发布哈希：`6911960321bef6da2da25317e921fb9445ed2c96b5280b481fa875bc9e70dd4c`
- 许可证：`MIT`

## 脚本功能

- 查询百度搭子登录积分状态（累计积分、已签天数、今日是否已发放）
- 未领取时调用领取接口完成每日登录积分签到，并核验业务成功或今日已签
- 展示累计积分等非凭据状态信息，隐藏 Cookie、csrftoken 与原始响应
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `DUMATE_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录百度智能云控制台或百度搭子（千帆桌面端）后，打开浏览器开发者工具，在发往 console.bce.baidu.com 的请求中复制完整 Cookie（建议包含 bce-user-info），写入青龙环境变量。不要把 Cookie 发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号的 Cookie 字符串。账号之间只用换行分隔，不使用 &、@ 或 &&。

### 可选参数

### `COOKIE_DUMATE`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容别名；未设置 DUMATE_COOKIE 时可读此变量。优先使用规范变量 DUMATE_COOKIE。
- 填写格式：与 DUMATE_COOKIE 相同：每行一个账号 Cookie。

### `BAIDU_DUMATE_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容别名；未设置 DUMATE_COOKIE 与 COOKIE_DUMATE 时可读此变量。优先使用规范变量 DUMATE_COOKIE。
- 填写格式：与 DUMATE_COOKIE 相同：每行一个账号 Cookie。

### `DUMATE_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 90 的整数秒；默认 20。

### `DUMATE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。

## 多账号

DUMATE_COOKIE 每个非空行一个账号 Cookie。账号逐个独立查询签到状态并领取登录积分；任一账号失败则整体非零退出。不使用 &、@ 或 && 分隔账号。
