# 维咔VikACG签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/vikacg_checkin.py`
- 青龙命令：`python3 scripts/vikacg_checkin.py`
- 建议 Cron：`59 9 * * *`
- 发布哈希：`7eb941708dca785e26fc581d12d0f0604778e913a1798ccd7f2ea7b34bd035e2`
- 许可证：`MIT`

## 脚本功能

- 邮箱密码登录换取双 Token，完整保留浏览器特征请求头
- 复用绑定设备指纹的本地缓存，过期优先续期后账密重登，401 后恢复认证并仅重试一次
- 每日钱包积分签到，严格校验 HTTP 200 与业务 success；HTTP 409 且含已签关键词才认定已完成
- 展示官方非敏感昵称、连续签到天数、累计次数及积分余额
- 保留每日 08:23 定时、站点覆盖、超时、显式代理与直连/全局代理兜底、网络与挑战页有限重试
- 每行多账号独立处理，任一账号失败整体非零退出
- 完全断网预演，中文时间轴日志、账号与任务统计及唯一单行 JSON 汇总
- 统一青龙通知开关与脚本选择，所有结果生成脱敏摘要，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `VIKACG_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在维咔官网注册并设置登录密码，使用本人登录邮箱和密码；青龙环境变量编辑器中每行填写一组。
- 填写格式：每个非空行一个邮箱#密码，仅按首个 # 分割，密码内后续 #、&、@ 原样保留；禁止使用 & 分隔账号。

### 可选参数

### `VIKACG_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网核验时在青龙环境变量中设置。
- 填写格式：1 或 true 启用，默认关闭；预演不调用接口、通知或缓存。

### `VIKACG_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况在青龙环境变量中设置。
- 填写格式：1 至 120 的整数秒，默认 30。

### `VIKACG_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：从维咔官方发布渠道确认当前站点，备用域名需自行核实。
- 填写格式：默认 https://www.vikacg.cc，仅允许不含凭据、路径或查询参数的 HTTPS 站点。

### `VIKACG_PROXY`

- 必填：否
- 敏感：是
- 获取或设置：从本人代理服务配置取得，按需设置。
- 填写格式：代理地址；不设置或 none/direct/off/0/false 时直连并强制 IPv4，连接异常时使用全局代理兜底；显式代理失败后直连兜底。

### `VIKACG_INSECURE`

- 必填：否
- 敏感：否
- 获取或设置：仅在明确了解自签代理风险时自行配置。
- 填写格式：默认 false 校验 TLS；true 显式关闭校验。

- 敏感：否
- 获取或设置：需要排查登录态来源时设置。
