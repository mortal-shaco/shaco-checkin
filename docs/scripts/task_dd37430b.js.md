## 脚本功能

- 使用邮箱和密码登录 Cafe123，并校验业务成功码与有效会话。
- 沿用原登录与签到地址、POST 方法及登录表单字段，执行每日签到并校验业务成功码。
- 每行一个账号，账号独立执行，任一账号失败时整体返回非零。
- 沿用每天 14:11:30 的六字段调度，由青龙每次启动执行一轮。
- 完全离线预演、带阶段耗时的脱敏日志、官方非敏感身份展示及单行任务汇总。
- 根据青龙全局开关与脚本选择器发送脱敏通知，通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CAFE123_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://cafe123.cn/auth/login 注册或登录本人账号，使用登录邮箱与密码。无需抓取或输出会话。若网站要求验证码或其他凭据，本版本将失败闭合，需依据官方接口补充契约。
- 填写格式：每个非空行填写邮箱|密码，仅在第一个 | 处分隔，密码中的后续 | 原样保留。不支持凭据内换行。

### 可选参数

### `CAFE123_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时设置为 1，正式签到时取消。
- 填写格式：1 表示完全断网预演，校验账号格式并模拟登录与签到，通知只生成摘要。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中填写需要通知的脚本选择器。默认未列入通知名单。
- 填写格式：支持目录编号 dd37430b249399f1、脚本文件名、scripts/文件名及文件名 * 通配符，逗号、分号或空白分隔。* 选择全部，空值全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙通知模块所在目录；默认查找 /ql/data/scripts 和 /ql/scripts，也尝试 Python 的 notify.send。
- 填写格式：本机目录路径，其中包含 sendNotify.js 或 notify.py，仅用于通知，不参与业务请求。

## 多账号

每个非空行一个账号，顺序独立登录和签到。账号会话仅保留于本次进程。任一账号配置错误或业务失败时整体退出码为非零，其他账号继续处理。

## 副作用与风险

- 正式运行登录时创建或更新服务端登录会话，沿用 remember_me=week。
