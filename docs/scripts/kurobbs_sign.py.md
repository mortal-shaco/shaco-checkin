# 鸣潮·库街区 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/kurobbs_sign.py`
- 青龙命令：`python3 scripts/kurobbs_sign.py`
- 建议 Cron：`16 1 * * *`
- 发布哈希：`ba8b69f916ffd74d402b05c53fde344f1866a6b4e18e46b9bf1b813733d06960`
- 许可证：`MIT`

## 脚本功能

- 查询社区每日任务完成进度
- 查询鸣潮默认绑定角色并展示官方公开身份
- 库街区每日签到及连续天数、累计天数和奖励展示
- 鸣潮每日签到、已签到识别及签到后状态核验
- 展示当月普通签到奖励和响应提供的限时循环签到奖励
- 浏览鸣潮今州茶馆帖子并核验进度
- 显式开启后点赞不同帖子并核验进度，不取消原有点赞
- 显式开启后提交帖子分享进度并核验完成，不发布文字
- 逐行多账号及旧单账号变量兼容
- 完全断网预演、时间轴日志、脱敏统计和青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KUROBBS_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录官方库街区 App，用本人授权的抓包工具读取 api.kurobbs.com 请求头 token；从角色查询 queryUserId 或签到 userId 获取社区 UID，不能用游戏角色 UID。请勿公开凭据或抓包。
- 填写格式：每个非空行一个账号：社区UID|Token，仅在第一个 | 分隔，保留 Token 后续内容。社区 UID 为数字。

### 可选参数

### `kurobbs`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容输入：官方库街区 App 请求头 token；仅在 KUROBBS_ACCOUNTS 未配置时与 kuro_uid 配对。
- 填写格式：单账号 Token，不支持旧式账号分隔符

### `kuro_uid`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容输入：从本人官方请求的 queryUserId 或 userId 获取社区 UID。
- 填写格式：单账号数字社区 UID，与 kurobbs 配对

### `KUROBBS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设为 1，断网预演不会调用业务或通知网络。
- 填写格式：1 开启；0 关闭，默认 0

### `KUROBBS_LIKE`

- 必填：否
- 敏感：否
- 获取或设置：明确同意脚本点赞他人帖子后设为 1；不会取消已有点赞。
- 填写格式：1 开启；0 关闭，默认 0

### `KUROBBS_SHARE`

- 必填：否
- 敏感：否
- 获取或设置：明确同意提交帖子分享任务进度后设为 1；不发布分享文字。
- 填写格式：1 开启；0 关闭，默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：青龙现有 notify.py 所在目录；未配置时尝试导入 notify 和青龙标准目录，不需私人仓库。
- 填写格式：通知模块目录路径

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号，社区UID|Token；只分割第一个 |。账号独立执行，任一账号或配置失败时整体非零退出。旧变量仅兼容一个账号。
