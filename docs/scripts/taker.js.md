# Taker每日挖矿

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/taker.js`
- 青龙命令：`node scripts/taker.js`
- 建议 Cron：`26 8 * * *`
- 发布哈希：`84876a1d9e42b389aa7b6104790116563666bd50c4f3685ae23adc69b0016671`
- 许可证：`MIT`

## 脚本功能

- 使用钱包私钥本地签名，完成 Taker lightmining API 的 nonce 获取、登录与用户信息查询。
- 展示官方返回的 Twitter/X 绑定名（twName）、userId、累计奖励与钱包地址，便于核对账号。
- 查询挖矿冷却窗口；已在 24 小时内挖过则记为已完成，可挖时调用 startMining 并链上合约 active() 激活。
- 支持每行一个私钥及可选地址核对；兼容 TAKER_WALLETS；可选邀请码与自定义 RPC。
- 网络或业务失败可按配置重试；账号失败隔离并汇总退出状态。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验私钥格式、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TAKER_PRIVATE_KEY`

- 必填：是
- 敏感：是
- 获取或设置：使用本人在 https://earn.taker.xyz/ 注册并已绑定 X/Twitter 的钱包私钥；确保钱包有足够 TAKER 余额支付链上 active()。勿使用他人私钥，勿将私钥写入公开仓库、日志或通知。
- 填写格式：每个非空行一个账号私钥，64 位十六进制，可带或不带 0x。可选「地址|私钥」，只在首个竖线处拆分并核对地址。不使用 & 或 @ 分隔账号。

### 可选参数

### `TAKER_WALLETS`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：仅当未设置 TAKER_PRIVATE_KEY 时读取；获取方式与 TAKER_PRIVATE_KEY 相同（对应上游 wallets.json 多钱包配置）。
- 填写格式：与 TAKER_PRIVATE_KEY 相同；每行一个私钥，或「地址|私钥」。

### `TAKER_INVITE_CODE`

- 必填：否
- 敏感：否
- 获取或设置：如需在登录时附带邀请码，填写本人邀请码；未设置时不发送邀请码（已移除上游硬编码邀请码）。
- 填写格式：非空字符串；留空或不设置表示不附带 invitationCode。

### `TAKER_RPC_URL`

- 必填：否
- 敏感：否
- 获取或设置：需要更换 Taker 主网 RPC 时手动设置。
- 填写格式：HTTPS RPC URL；缺省为 https://rpc-mainnet.taker.xyz/

### `TAKER_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不请求 API/RPC、不投递真实通知。

### `TAKER_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP/RPC 超时时间时手动设置。
- 填写格式：1000 至 120000 的整数毫秒；缺省或非法值使用 20000。

### `TAKER_MAX_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：需要调整网络或业务失败重试次数时手动设置。
- 填写格式：0 至 5 的整数；缺省或非法值使用 3。重试间隔约 3 秒。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 e6b938e23e5d9750、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

TAKER_PRIVATE_KEY（或兼容别名 TAKER_WALLETS）每个非空行一个钱包；可选地址前缀仅按第一个竖线分割。账号逐个独立登录与挖矿统计，任一账号失败则整体非零退出，其余账号继续执行。
