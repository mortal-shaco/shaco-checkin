# IT之家签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ithome.js`
- 青龙命令：`node scripts/ithome.js`
- 建议 Cron：`36 1 * * *`
- 发布哈希：`fce25e1a7f0c8baedd272da49832656f00932e956e7c0f27c1b4fb115b8102da`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每日签到，识别明确成功及今日已签到状态
- 查询并显示连续签到天数、累计签到天数和金币数量
- 从签到页请求参数手动获取凭据，兼容旧变量名
- 逐行多账号独立执行与失败非零退出
- 完全断网预演、本地签名验证、脱敏时间轴及单行结构化汇总
- 官方返回非敏感昵称、用户名、显示名称或公开 UID 时显示身份
- 按通知开关与脚本选择列表发送青龙脱敏总结；离线预演仅生成通知预览

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ITHOME_USER_HASH`

- 必填：是
- 敏感：是
- 获取或设置：登录 IT之家 App 并进入签到页，在本人授权的 HTTPS 抓包中找到 napi.ithome.com/api/usersign/getsigninfo 请求，提取 userHash 参数并 URL 解码一次，填入青龙环境变量；不要公开分享。
- 填写格式：每个非空行仅填一个账号的 userHash；不要填整个请求链接，也不要使用 & 或 @ 分隔账号。

### 可选参数

### `senku_ithome_userHash`

- 必填：否
- 敏感：是
- 获取或设置：旧版凭据变量兼容入口；仅当 ITHOME_USER_HASH 未设置时使用，获取方法相同。
- 填写格式：每行一个已解码的 userHash；不读取旧 box.dat 文件。

### `ITHOME_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置，预演时使用。
- 填写格式：1 为完全断网预演；其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中指定接收通知的脚本；未设置或空值时 auto 不发送。
- 填写格式：逗号、分号或空白分隔；支持目录编号 2d56412ced04fdd3、ithome.js、实际文件名、相对路径及 * 通配符；* 选中全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：需要时设置青龙 sendNotify.js 所在目录；默认检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机通知模块目录；通知失败不改变业务退出码。
