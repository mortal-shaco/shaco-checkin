# 奥拉星每日任务与积分

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/aolaxing.py`
- 青龙命令：`python3 scripts/aolaxing.py`
- 建议 Cron：`38 0 * * *`
- 发布哈希：`08315768d7e7119be58d8cc0170e95dd1de83f25bce1ff518898cebedaba9959`
- 许可证：`MIT`

## 脚本功能

- 查询每日任务列表、今日任务总数及完成数。
- 按显式指定任务 ID 执行未完成任务，执行后重新读取列表核验已完成状态；已完成任务不重复执行。
- 查询当前积分、累计获得积分和累计签到次数。
- 官方响应返回昵称、用户名、显示名称或公开 UID 时显示非敏感身份；抑制手机号和凭据。
- 逐行多账号、上游配置键名兼容、断网预演、独立 HTTPS 请求、超时和失败非零退出。
- 时间轴阶段日志、账号与任务统计、单行机器汇总和青龙脱敏通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AOLAXING_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录百田网奥拉星积分商城，在浏览器开发者工具网络面板查找 service.100bt.com/creditmall 请求，复制请求头 Cookie 完整值。请勿复制到日志或公开仓库。
- 填写格式：每行一个账号的完整 Cookie；不按 &、@ 或分号拆分账号。

### 可选参数

### `AOLAXING`

- 必填：否
- 敏感：是
- 获取或设置：兼容上游配置键名，将原 config.json 中 AOLAXING 数组复制为此环境变量；仅在 AOLAXING_COOKIE 未设置时使用。不读取本地私有配置文件。
- 填写格式：JSON 数组，每项为包含 cookie 字段的对象。

### `AOLAXING_TASK_IDS`

- 必填：否
- 敏感：否
- 获取或设置：在浏览器网络面板查看每日任务列表返回的 taskID，并人工审阅任务实际行为后填写。默认留空，仅查询；多个账号使用相同任务选择。
- 填写格式：逗号分隔的不重复数字任务 ID。仅执行列表中未完成的指定任务。

### `AOLAXING_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设为 1，不调用业务接口或通知网络；在线运行留空或设为 0。
- 填写格式：1 开启；0、false、no、off 关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙已有 notify.py 所在目录；也会查找 Python notify 模块及青龙标准脚本目录。仅通知依赖青龙，业务独立运行。
- 填写格式：本机通知模块目录路径。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行对应一个账号，整行保留；逐账号独立处理，任何账号失败则整体非零退出。兼容变量 AOLAXING 使用原 JSON 数组。
