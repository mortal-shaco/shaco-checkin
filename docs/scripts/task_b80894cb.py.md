## 脚本功能

- TJUPT 站点账号密码登录
- 每日签到页访问与「今日已签到」识别
- 豆瓣海报匹配验证码后提交签到
- 公开用户名展示以便核对账号
- 多账号逐行独立处理与失败汇总
- 完全断网预演、时间轴日志与单行 TASK_SUMMARY
- 青龙脱敏通知及全局通知开关

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TJUPT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人在 https://www.tjupt.org/ 注册并可用的站点用户名与密码。在青龙环境变量中配置，切勿写入公开仓库或日志。
- 填写格式：每个非空行一个账号，格式为 username|password；仅按第一个 | 分割，密码中后续 | 原样保留；支持空行与 # 开头注释；不要用 & 或 @ 分隔账号

### 可选参数

### `TJUPT_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名；仅当 TJUPT_ACCOUNTS 为空时与 TJUPT_PASSWORD 成对使用
- 填写格式：单个站点用户名，不含分隔符换行

### `TJUPT_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名；仅当 TJUPT_ACCOUNTS 为空时与 TJUPT_USERNAME 成对使用
- 填写格式：对应用户名的站点密码

### `TJUPT_BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：需要改用官方镜像或备用根地址时设置；默认即可访问官网时无需填写
- 填写格式：HTTPS 站点根地址，默认 https://www.tjupt.org/，不得含凭据

### `TJUPT_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自定义单次 HTTPS 请求超时秒数
- 填写格式：5 到 60 的数字秒，默认 20

### `TJUPT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要完全断网预演、只校验配置时手动设置为 1
- 填写格式：1/true/yes/on 启用预演；默认实际执行

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本白名单启用通知时设置；空值表示全部禁用
- 填写格式：catalog-id、脚本路径、文件名或 glob，可用逗号/分号/空白/换行分隔；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅当青龙通知脚本不在默认路径时，设为 notify.py 或 sendNotify.js 所在目录
- 填写格式：本地目录绝对路径
