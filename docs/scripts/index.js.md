## 脚本功能

- 通过官方收藏页跳转获取并原样显示公开 UID，也支持手动指定公开 UID
- 分页获取全部公开收藏，校验明确业务成功、总数稳定、无重复以及分页完整性
- 读取每个作品全部原图页；图片页查询与图片下载分别限制为三个并发任务
- 以标题加作品 ID 建目录、标题加页码命名图片，保留规范候选保存路径及旧目录兼容检查
- 跳过已有有效图片，修复无效普通图片文件；原子创建下载结果以避免并发覆盖
- 原图仅接受 HTTPS 图片域，隔离账号 Cookie，校验图片类型、文件头、大小和完整性，设置请求超时
- 支持逐行多账号、旧版 cookie/output/proxy 配置和完全断网预演，逐账号隔离失败
- 按编号阶段打印带时间戳的脱敏结果及耗时、账号和任务统计，保留收藏成功日志并输出唯一单行 TASK_SUMMARY
- 调用青龙通知组件发送脱敏总结，支持全局通知开关；预演禁止外部投递，通知失败或缺失不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `PIXIV_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录本人 Pixiv 账号，在浏览器开发者工具的网络面板中复制 www.pixiv.net 请求的完整 Cookie；公开 UID 从个人主页网址 /users/ 后获取，也可留空由官方收藏跳转获取。兼容当前工作目录 config.json 的 cookie 字段。
- 填写格式：每行一个账号：公开UID|完整Cookie；只按第一个 | 拆分，后续 Cookie 内容保留；UID 留空时使用 |完整Cookie。禁止用 & 或 @ 分隔账号。

### 可选参数

### `PIXIV_OUTPUT`

- 必填：否
- 敏感：否
- 获取或设置：自行指定本地可写图片目录；正式下载必须明确设置本变量或当前工作目录 config.json 的 output 字段。预演无需设置。
- 填写格式：目录路径；新图片保存为 标题_作品ID/标题_页码.扩展名，兼容检查旧版 标题/标题_页码.扩展名。

### `PIXIV_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设为 1 开启完全断网预演；不创建下载目录或图片文件。
- 填写格式：1 为预演，其他值为正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：使用青龙已有通知配置；默认开启，可主动关闭。预演调用可用通知组件时阻断网络，不进行外部投递。
- 填写格式：0、false、no、off 关闭，大小写不敏感；其他值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，指定青龙 sendNotify.js 所在目录；未设置时依次检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地通知组件目录路径。

## 多账号

每个非空行表示一个独立账号，按第一个 | 分隔公开 UID 与完整 Cookie；账号顺序处理，任一账号失败使整体非零退出。旧版 config.json 单账号 cookie/output/proxy 继续兼容；代理使用 host、port、protocol 等 axios 代理字段，无默认代理。
