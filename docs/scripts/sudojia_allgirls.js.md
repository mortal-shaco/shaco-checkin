# 所有女生会员签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_allgirls.js`
- 青龙命令：`node scripts/sudojia_allgirls.js`
- 建议 Cron：`33 2 * * *`
- 发布哈希：`f23f02fec7fe0742d7128134b6dc7cb36a629eeb6e8505824b21a889b9f89a59`
- 许可证：`GPL-3.0`

## 脚本功能

- 获取并显示官方昵称
- 查询每日签到状态，已签到时避免重复请求
- 未签到时执行签到并复查已签到状态
- 查询当前积分
- 支持逐行多账号、请求超时与账号独立失败统计
- 支持完全断网预演、青龙通知和单行结构化汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ALL_GIRLS_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录所有女生会员服务中心微信小程序，在本人授权的抓包工具中查找主机 7.wawo.cc 的请求，复制请求头 AccessToken 的完整值；失效后重新登录获取。不要复制整个请求头或分享令牌。
- 填写格式：每个非空行一个账号的 AccessToken；不使用 & 或 @ 分隔账号。

### 可选参数

### `ALL_GIRLS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置，断网预演时设为 1。
- 填写格式：1 为预演，其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写青龙 sendNotify.js 所在目录；未设置时查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录绝对路径。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
