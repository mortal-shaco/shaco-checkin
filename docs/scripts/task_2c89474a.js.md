## 脚本功能

- 使用 HayFrp 用户名密码登录官方 API，并以 csrf token 完成每日签到领流量。
- 识别当日已签到（业务 status=403）为已完成，展示签到增量流量与总流量。
- 可选 Discord Webhook 推送脱敏签到摘要；默认关闭。
- 支持每行一个账号及可选备注前缀，账号失败隔离并汇总退出状态。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验账号格式与 API/Webhook 协议、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。
- 兼容归档官方身份 displayName 回退及旧青龙通知选择器，已有身份字段优先级保持原样。
- 保留最多三次请求尝试、429 等待与账号间 1500 毫秒间隔，只允许 HTTPS。
- 单一规范部署路径 scripts/task_2c89474a.js，保留 Node.js CommonJS 与原登录、签到、可选 Discord、最终青龙通知顺序。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HAYFRP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人 HayFrp 控制台账号密码（https://console.hayfrp.com 可登录验证的同一组凭据）。勿填写他人账号或日志中的敏感信息。
- 填写格式：每个非空行一个账号，格式「用户名,密码」，只在第一个逗号处拆分（密码可含逗号）。可选备注前缀「备注|用户名,密码」，只在首个竖线处拆分。不使用 & 或 @ 分隔账号。

### 可选参数

### `HAYFRP_API_URL`

- 必填：否
- 敏感：否
- 获取或设置：一般无需更改；仅当官方更换 API 根地址时手动设置。可参考 HayFrp-Team/Learn 文档。
- 填写格式：合法 HTTPS API 根地址，禁止 HTTP 和 URL 内嵌用户名密码；默认 https://api.hayfrp.com。自定义 HTTPS 保留端口和路径，每次向根地址追加 /user，不跟随重定向。

### `HAYFRP_WEBHOOK_URL`

- 必填：否
- 敏感：是
- 获取或设置：可选。Discord 频道设置 → 整合 → 创建 Webhook → 复制 URL。不需要 Discord 推送时留空或填 disabled。
- 填写格式：合法 HTTPS Webhook 地址，禁止 HTTP 和 URL 内嵌用户名密码；空值或 disabled 关闭。仅显式配置后投递，预演无投递。

### `HAYFRP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不访问 HayFrp、不签到、不投递真实通知或 Webhook。

### `HAYFRP_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：推荐 1000 至 60000 的整数毫秒；默认 20000。保留两版 parseInt 十进制解析，解析结果越界或无效则回退默认。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写当前或旧目录 ID、脚本名及 scripts 相对路径，支持 2c89474a11ce9592 和 81b701d12d5b39f2。
- 填写格式：逗号、分号或空白分隔，大小写不敏感，支持 * 与 ? 通配。旧 task_81b701d1 及规范 task_2c89474a 的文件名和路径均可选择。全局开关未设置且名单未设置时保留现有前置策略关闭通知；显式空名单关闭通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。
