## 脚本功能

- 执行影视飓风会员每日签到，显示服务端返回的签到奖励标题。
- 识别原接口今日已签到业务码 1000030071，作为已完成处理；仅业务码 0 且 success 严格为 true 时认定新签到成功。
- 保留原小程序请求 URL、GET 方法、查询参数、请求头及 Extra-Data 会话结构；为请求设置超时和响应大小限制，拒绝重定向，避免自动重试造成不确定的重复签到。
- 兼容 ACCESS_TOKEN、SESSION_ID 单账号参数及脚本同目录 .env 凭据读取，进程环境优先；不在导入阶段读取凭据。
- 支持每行一个账号的规范组合变量，账号独立处理并汇总失败退出码。
- 提供完全断网预演，完成参数校验和请求构造，不把预演记作真实签到成功。
- 返回公开昵称、用户名、显示名或公开 UID 时显示该身份，过滤凭据及手机号；失败时不打印服务端原始响应或异常原文。
- 提供带时间戳的编号阶段、每账号与全任务统计、单行 TASK_SUMMARY JSON，以及受青龙全局开关和脚本选择器控制的脱敏通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MEDIASTORM_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录微信影视飓风会员小程序，使用本人授权的 HTTPS 抓包工具查看签到请求 checkinV2.json：查询参数 access_token 为第一项，Extra-Data 请求头 JSON 的 sid 为第二项。同一行必须取自同一账号同一次会话；失效后重新登录抓取，勿分享抓包。此变量为规范凭据入口；未设置时才兼容旧参数。
- 填写格式：每个非空行一个账号：access_token|sid；只按第一个 | 分割，不使用 & 或 @ 分隔账号；两项不能为空或含首尾空白及控制字符。

### 可选参数

### `ACCESS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版单账号兼容参数：取自上述签到请求 URL 的 access_token 查询参数；必须与 SESSION_ID 配套，且仅在未设置 MEDIASTORM_ACCOUNTS 时生效。
- 填写格式：单个账号的访问令牌，不含参数名或 URL。

### `SESSION_ID`

- 必填：否
- 敏感：是
- 获取或设置：旧版单账号兼容参数：取自同一签到请求 Extra-Data JSON 的 sid；必须与 ACCESS_TOKEN 配套，且仅在未设置 MEDIASTORM_ACCOUNTS 时生效。
- 填写格式：单个账号的会话值，不含字段名或整个请求头。

### `MEDIASTORM_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地预演或青龙环境变量中设置为 1；不调用业务接口、文本提供方及通知模块。
- 填写格式：1、true、yes、on 启用；其他值为正式模式，默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择列表；设置后替换默认列表，支持当前目录编号 e559f6b278de9d78、脚本相对路径、文件名、文件名通配符。当前任务无默认启用名单，auto 下未设置则不发送。
- 填写格式：逗号、分号、空白或换行分隔；* 选择全部；空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选青龙通知组件目录；可放置已配置的 notify.py 或 sendNotify.js。也会尝试导入 notify.send，以及 /ql/data/scripts 和 /ql/scripts 标准目录。业务运行不依赖通知组件。
- 填写格式：本机目录路径；JavaScript 通知兼容方式需要已有 Node.js，脚本不会下载或安装。
