# 百度贴吧签到

- 管理状态：`上架`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tieba_checkin.py`
- 青龙命令：`python3 scripts/tieba_checkin.py`
- 建议 Cron：`23 8 * * *`
- 发布哈希：`2db577380e0d0f1f5cf940b40cceca8bfcd21e2d140e284552f9cc943f4a7d4e`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 保留登录验证和 TBS 获取、读取关注贴吧、识别当日已签到项目、为未签到贴吧逐吧签到，沿用明确成功码和已签到判断。
- 直接显示官方接口返回的昵称、用户名或公开 UID，方便核对账号。
- 显式开启后通过 APP 成长接口验证登录、取得独立 TBS，并执行成长任务每日签到，要求业务码明确为 0。
- 显式开启后查询当前成长值、贴贝余额、当前等级及距离下一等级所需成长值，保留上游等级差值算法。
- 沿用 TIEBA_COOKIE，兼容 TIE_BA_COOKIE 的完整 Cookie 或 BDUSS 单值，每行一个账号；成长字段在同一账号 Cookie 中提供。
- 保留规范任务每日 08:23 计划、逐吧详情开关与可配置请求间隔；成长任务默认关闭。
- 完全断网预演校验账号必要字段、不加载通知组件、不产生账号副作用，并展示脱敏通知汇总。
- 正式执行、配置失败、部分失败或成功后尝试青龙脱敏通知，支持全局关闭，通知失败保持业务退出码。
- 输出逐阶段时间轴、账号及任务统计、最终状态和恰好一个单行 TASK_SUMMARY 结构化汇总。
- 逐吧流程和成长任务独立处理，任一任务或账号失败返回非零退出码；HTTP 有超时、响应大小限制及同主机 HTTPS 重定向限制。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TIEBA_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在百度贴吧网站登录本人账号，从浏览器开发者工具请求头复制完整 Cookie，或其中 BDUSS 的值；开启成长任务时，从本人贴吧 APP 发往 tieba.baidu.com 的请求取得同一账号的 BDUSS 和 CUID。可改用兼容变量 TIE_BA_COOKIE。
- 填写格式：每个非空行一个账号；支持 BDUSS 单值或完整 Cookie。成长任务要求同一行含 BDUSS=值; CUID=值，字段值按首个等号分割，后续等号保留；不能按 & 或 @ 分账号。

### 可选参数

### `TIE_BA_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容入口，获取方式同 TIEBA_COOKIE；TIEBA_COOKIE 非空时优先使用它。
- 填写格式：每个非空行一个完整 Cookie 或 BDUSS 单值；成长任务需包含 BDUSS 与 CUID。

### `TIEBA_GROWTH_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需手动设置；默认关闭。只有明确开启并具有同账号 BDUSS 与 CUID 时提交成长任务，启用后字段缺失计为账号失败，逐吧签到仍独立执行。
- 填写格式：1、true、yes、on 开启，其他值关闭。

### `TIEBA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设为 1 开启完全断网配置预演。
- 填写格式：1、true、yes、on 开启；默认关闭。

### `TIEBA_VERBOSE`

- 必填：否
- 敏感：否
- 获取或设置：手动开启逐吧名称及结果日志，默认关闭。
- 填写格式：1、true、yes、on 开启。

### `TIEBA_DELAY_MS`

- 必填：否
- 敏感：否
- 获取或设置：按需设置逐吧请求间隔，默认 1200 毫秒。
- 填写格式：整数毫秒；限制在 500 至 10000；格式错误沿用默认值。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关，默认开启。断网预演仅生成并展示脱敏通知汇总，不加载可能联网的通知组件。
- 填写格式：0、false、no、off 关闭，其他值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙 notify.py 所在目录；自动尝试导入 notify.send 及标准青龙目录。
- 填写格式：本地目录路径；仅作为可选通知组件位置，业务功能不依赖此文件。

## 多账号

每个非空行一个账号，整行保留为 Cookie；重复行去重，不按 & 或 @ 拆分。账号独立执行，任一账号失败则进程非零退出。

## 副作用与风险

- 正式执行时提交关注贴吧签到，改变对应贴吧当日签到状态及可能产生签到奖励。
- 仅显式开启成长任务且 Cookie 同时含 BDUSS 和 CUID 时提交 APP 成长每日签到，改变当日成长签到状态及可能产生的成长奖励。
- 正式执行且通知开启、青龙组件可用时发送脱敏任务汇总通知。
