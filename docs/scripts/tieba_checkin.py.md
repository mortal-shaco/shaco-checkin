# 百度贴吧签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tieba_checkin.py`
- 青龙命令：`python3 scripts/tieba_checkin.py`
- 建议 Cron：`39 2 * * *`
- 发布哈希：`33af7386fbc75e4a16817200fa5d0f16077440198fbf7713f74ada9bf355191c`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 验证百度贴吧登录状态并取得签到所需 TBS；官方接口返回昵称、用户名、显示名称或公开 UID 时直接显示该非敏感身份。
- 读取账号关注的贴吧列表，识别当日已签到项目，并对未签到贴吧逐项执行签到。
- 可选显示逐吧详情并配置签到请求间隔，使用每日 08:23 的青龙计划。
- 显式开启后执行贴吧 APP 成长任务每日签到，并查询成长值、贴贝余额、当前等级及距离下一等级所需成长值；该功能默认关闭。
- 兼容 TIEBA_COOKIE 与旧变量 TIE_BA_COOKIE，支持每行一个账号独立处理，任一账号失败时整体返回非零状态。
- 提供完全断网预演，只校验账号必要字段，不加载通知组件、不发送网络请求且不产生账号副作用。
- 在成功、部分失败、失败、配置错误或预演后生成脱敏汇总，并按全局开关与脚本选择规则处理青龙通知。
- 输出任务横幅、开始与完成时间、运行模式、账号数、编号阶段、脱敏逐步结果、账号统计、任务统计、最终状态及唯一一行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TIEBA_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录本人百度贴吧网页后，在浏览器开发者工具的本人请求中复制完整 Cookie；也可只填写其中的 BDUSS 值。请勿使用他人凭据。启用成长任务时，同一行 Cookie 还必须包含本人贴吧 APP 请求中的 CUID。
- 填写格式：每个非空行一个账号。单行可为纯 BDUSS 值，或形如 BDUSS=值; 其他字段=值 的完整 Cookie；整行只按 Cookie 字段解析，不使用 &、@ 等符号分隔账号。

### 可选参数

### `TIE_BA_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，获取方式与 TIEBA_COOKIE 相同；仅在未设置 TIEBA_COOKIE 时读取。
- 填写格式：每个非空行一个账号，格式与 TIEBA_COOKIE 相同。

### `TIEBA_GROWTH_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；仅在确实需要贴吧 APP 成长每日签到及成长信息查询时手动开启。
- 填写格式：1、true、yes 或 on 表示开启；默认关闭。

### `TIEBA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；用于完全断网的配置预演。
- 填写格式：1、true、yes 或 on 表示开启。

### `TIEBA_VERBOSE`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；需要在日志中显示贴吧名称等逐项详情时手动开启。
- 填写格式：1、true、yes 或 on 表示开启；默认关闭。

### `TIEBA_DELAY_MS`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；用于设置相邻贴吧签到请求之间的间隔。
- 填写格式：整数毫秒，允许范围 500 至 10000，默认 1200。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本选择规则，无需账号侧获取；设置后替换默认选择。
- 填写格式：使用逗号、分号、空白或换行分隔目录标识、脚本路径、文件名或通配符；* 表示全部，显式空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在青龙通知组件不位于标准目录时填写其所在目录。
- 填写格式：包含 notify.py 或 sendNotify.js 的本地目录路径。

## 多账号

TIEBA_COOKIE 中每个非空行对应一个账号，各账号独立校验和执行；任一账号或已开启的账号子任务失败时，进程整体返回非零退出码。

## 副作用与风险

- 正式执行时提交关注贴吧签到，改变对应贴吧当日签到状态，并可能获得签到奖励。
- 仅在显式开启成长任务且同一账号 Cookie 同时包含 BDUSS 和 CUID 时，提交贴吧 APP 成长每日签到，改变当日成长签到状态并可能获得成长奖励。
- 正式执行且通知规则允许、青龙通知组件可用时，发送不含凭据和原始响应的任务汇总通知。
