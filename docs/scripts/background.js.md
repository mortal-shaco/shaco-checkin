# 薄荷公益站每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/background.js`
- 青龙命令：`node scripts/background.js`
- 建议 Cron：`4 8 * * *`
- 发布哈希：`e5e03c536eaa6123f5f969ad5f0b82cd1f15d8cf5cab568ccc77b64ef99f18e1`
- 许可证：`MIT`

## 脚本功能

- 使用薄荷公益站 Cookie 调用用户信息与签到状态接口，校验登录并展示官方用户名或公开 linux_do_id。
- 在可签到时提交每日抽奖签到，展示奖项标签、获得额度、余额与今日排名；识别今日已签。
- 读取签到历史并展示连续签到天数与累计额度（只读），奖项等级文案与上游一致。
- 支持每行一个账号及可选备注前缀，账号失败隔离并汇总退出状态。
- 按青龙全局开关与脚本名单发送脱敏通知，通知失败保留业务退出码。
- 完全断网预演：校验 Cookie 格式、模拟阶段与通知摘要，不发起业务或通知网络请求。
- 提供中文时间轴日志、编号阶段、耗时、逐账号与全局统计，以及唯一单行 TASK_SUMMARY JSON。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BOHE_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：使用本人账号登录 https://up.x666.me ，在浏览器开发者工具→应用/网络中复制发往本站请求的 Cookie（至少包含 server_session_58ffd1cb；可附带 auth_token）。勿使用他人 Cookie 或日志中的敏感信息。
- 填写格式：每个非空行一个账号的完整 Cookie 字符串。可选备注前缀「备注|Cookie」，只在首个竖线处拆分。不使用 & 或 @ 分隔账号。

### 可选参数

### `BOHE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；其他值或未设置表示正式执行。预演不访问站点、不签到、不投递真实通知。

### `BOHE_TIMEOUT_MS`

- 必填：否
- 敏感：否
- 获取或设置：需要调整单次 HTTP 超时时间时手动设置。
- 填写格式：1000 至 60000 的整数毫秒；缺省或非法值使用 20000。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在青龙通知名单中填入 5d8ba0f271781047、实际脚本文件名或 scripts 相对路径；未设置时默认对本任务发送通知。
- 填写格式：逗号、分号、空白或换行分隔的选择器；支持 * 与 ? 通配；* 表示全部；显式空值关闭全部青龙通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知工具不在默认目录时，填写本机 sendNotify.js 或 notify.py 所在目录。
- 填写格式：本地目录路径。依次尝试指定目录与 /ql/data/scripts、/ql/scripts 下的 sendNotify.js，再尝试 notify.py；通知失败只记录脱敏状态。

## 多账号

BOHE_COOKIE 每个非空行一个账号；可选备注仅按第一个竖线分割。账号逐个独立查询、签到与统计，任一账号失败则整体非零退出，其余账号继续执行。
