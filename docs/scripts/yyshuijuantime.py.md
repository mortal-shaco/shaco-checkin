# 阴阳师绘卷时间获取

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/yyshuijuantime.py`
- 青龙命令：`python3 scripts/yyshuijuantime.py`
- 建议 Cron：`39 2 * * *`
- 发布哈希：`381977e2482a91ef02239804ed1e706b8ab04df83bb9e5f358696c499b6a8c7a`
- 许可证：`MIT`

## 脚本功能

- 每天读取阴阳师官网最新五条维护更新公告
- 支持原有三种正文容器，并保留嵌套正文内容
- 提取追忆绘卷活动名称、维护后开始日期及结束时间，支持跨年并验证日期
- 保留原 JSON 字段及同名同开始日期去重的活动历史
- 报告活动时间与已结束活动状态
- 通过青龙通知模块发送脱敏运行摘要，支持全局通知开关
- 无网络、无文件读写的内置公告预演
- 带时间戳的分阶段日志和单行结构化任务统计，失败非零退出

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `YYS_HUIJUAN_OUTPUT`

- 必填：是
- 敏感：否
- 获取或设置：在青龙环境变量中自行填写授权写入的 JSON 绝对路径。无需登录、抓包或账号凭据。兼容原数据时填写原脚本目录下的 config/yys_huijuan_time.json 绝对路径。请使用独立文件，已有文件须符合原脚本数据结构。
- 填写格式：以 .json 结尾的绝对文件路径；每次运行使用一个路径，不按账号拆分

### 可选参数

### `YYS_HUIJUAN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试时在青龙环境变量中设置为 1；正式运行删除该变量或设置为 0。
- 填写格式：1、true、yes、on 启用断网预演；默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局通知开关；默认开启，使用青龙已有 notify.py 通知配置。
- 填写格式：默认 1；0、false、no、off 关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写青龙 notify.py 所在目录；否则尝试可导入的 notify 模块及 /ql/data/scripts、/ql/scripts。通知失败不改变业务退出码。
- 填写格式：可选绝对目录路径
