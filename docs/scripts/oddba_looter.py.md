# ODDBA社区签到与任务领取

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/oddba_looter.py`
- 青龙命令：`python3 scripts/oddba_looter.py`
- 建议 Cron：`21 0,12 * * *`

- 许可证：`MIT`

## 脚本功能

- 登录 sns.oddba.cn 并校验页头登录态
- 执行每日签到；今日已签到视为已完成成功
- 领取已解锁的累签宝箱奖励
- 领取每日任务中可领取且未领取的奖励
- 支持每行一个「用户名|密码」的多账号独立处理，任一账号失败时整体非零退出
- 提供完全断网预演、时间轴脱敏日志、账号与任务统计及单行 TASK_SUMMARY
- 按青龙全局开关发送脱敏通知，通知故障不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ODDBA_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://sns.oddba.cn/ 注册并确认可登录后，将用户名与密码写入青龙环境变量。每个账号单独占一行。
- 填写格式：每行一个账号，格式为 用户名|密码；仅在首个竖线处分割，密码中可含竖线。不要用 &、@ 或其他符号分隔账号。

### 可选参数

### `ODDBA_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：单账号兼容别名。仅当未设置 ODDBA_ACCOUNTS 时生效，须与 ODDBA_PASSWORD 成对使用。
- 填写格式：sns.oddba.cn 登录用户名。

### `ODDBA_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：单账号兼容别名。仅当未设置 ODDBA_ACCOUNTS 时生效，须与 ODDBA_USERNAME 成对使用。
- 填写格式：与用户名配套的登录密码。

### `ODDBA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要在完全断网条件下检查配置与流程时设置。
- 填写格式：设为 1、true、yes 或 on 启用预演。

### `ODDBA_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络状况设置单次 HTTPS 超时；不填写时为 30 秒。
- 填写格式：5 至 120 之间的秒数。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 QINGLONG_NOTIFY=auto 时填写要通知的脚本选择器。
- 填写格式：可用逗号、分号、空白或换行分隔；支持 d4d9e489b3cac0c4、candidate.py、output/candidate.py、oddba_looter.py、通配符或 *。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙 notify.py 不在默认位置时，填写其所在目录。
- 填写格式：包含 notify.py 的本地目录路径。
