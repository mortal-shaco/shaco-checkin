# 羿文教育积分签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/yiwenjiaoyu.py`
- 青龙命令：`python3 scripts/yiwenjiaoyu.py`
- 建议 Cron：`52 8 * * *`
- 发布哈希：`9ecd1daf80d3262254a1cb4d799c2ce1ff84504db563298fc022d516f06cb025`
- 许可证：`MIT`

## 脚本功能

- 使用手机号与 MD5 密码登录羿文教育 proxyweb.yiwenjy.com
- 执行每日积分签到；识别今日已签到
- 查询当前积分并脱敏展示积分数值
- 官方响应若返回公开身份则直接展示；否则使用账号序号；不输出手机号
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `YIWEN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在羿文教育官网或 App 注册并确认可用手机号密码登录。将手机号与明文登录密码写入青龙环境变量；不要把凭据发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号，写成「手机号|密码」，仅在首个竖线处拆分，密码中后续竖线原样保留。不使用换行以外的符号分隔账号。

### 可选参数

### `YIWEN_PHONE`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：未设置 YIWEN_ACCOUNTS 时，与 YIWEN_PASSWORD 组合为单账号。新部署请优先使用 YIWEN_ACCOUNTS。
- 填写格式：单个登录手机号；须与 YIWEN_PASSWORD 同时提供。

### `YIWEN_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：未设置 YIWEN_ACCOUNTS 时，与 YIWEN_PHONE 组合为单账号。脚本按上游逻辑对明文密码做 MD5 后提交；勿写入日志或通知。
- 填写格式：对应账号的明文登录密码。

### `YIWEN_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTPS 超时秒数。
- 填写格式：5 至 90 的整数秒；默认 20。

### `YIWEN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。可填 878c77e4feb4d89e、脚本文件名或 scripts 相对路径。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。不是业务依赖。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。
