# 微博超话网页签到评论

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/weibo_checkin.py`
- 青龙命令：`python3 scripts/weibo_checkin.py`
- 建议 Cron：`28 8 * * *`
- 发布哈希：`9459b31730d9632df56af0eee2f2aca657af3c4c00004b081d508db024bfad66`
- 许可证：`MIT`

## 脚本功能

- 使用网页 Cookie 校验登录态后，按名称解析超话并执行每日签到
- 识别签到成功与今日已签到（幂等），未确认结果记失败
- 可选开启评论：对超话最新帖发表主楼/楼中楼/混合评论，文案优先取一言并本地回退
- 支持每行一个 Cookie 多账号，共享超话列表，独立汇总结果
- 官方评论响应中的非敏感昵称或公开 UID 原样展示，隐藏 Cookie 与原始响应
- 完全断网预演、请求超时与大小限制、时间轴日志与单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WEIBO_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 weibo.com 后打开开发者工具网络面板，复制发往 weibo.com 的已登录请求头 Cookie 完整值；需含登录态字段（如 SUB、XSRF-TOKEN），不要复制响应 Set-Cookie，也不要将凭据发给他人。登录失效或 ALF 过期后重新获取。
- 填写格式：每个非空行一个账号。整行可为完整 Cookie，或「备注|Cookie」；仅在首个竖线处拆分，后续 Cookie 原文保留。Cookie 内分号与等号原样保留，不使用 & 或 @ 分隔账号。

### `WEIBO_SUPERTOPICS`

- 必填：是
- 敏感：否
- 获取或设置：填写本人关注并希望每日签到的超话名称（不含“超话”后缀亦可，脚本会按名称搜索解析）。
- 填写格式：多个超话用英文逗号、中文逗号或换行分隔，例如：小米,数码

### 可选参数

### `WEIBO_WEB_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧名兼容输入；优先使用 WEIBO_COOKIE。获取方式相同。
- 填写格式：与 WEIBO_COOKIE 相同，每行一个账号。

### `WEIBO_ENABLE_COMMENT`

- 必填：否
- 敏感：否
- 获取或设置：需要在签到后对超话最新帖自动评论时自行开启；默认关闭以避免意外发帖。
- 填写格式：1/true/yes/on 开启；默认关闭。

### `WEIBO_COMMENT_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：开启评论后，设置每个超话发表的评论条数；防风控建议不超过 5。
- 填写格式：整数 1–5，默认 1。

### `WEIBO_REPLY_MODE`

- 必填：否
- 敏感：否
- 获取或设置：开启评论后选择主楼或楼中楼策略。
- 填写格式：new=主楼评论；reply=楼中楼；mixed=交替；默认 new。

### `WEIBO_FALLBACK_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：评论开启时，一言服务失败或 dry-run 使用的本地评论文案；可按需自定义。
- 填写格式：不超过 280 字的纯文本；默认使用内置本地文案。

### `WEIBO_DELAY_MIN`

- 必填：否
- 敏感：否
- 获取或设置：可选：两次请求间随机间隔下限（秒）。
- 填写格式：非负数字，默认 5。

### `WEIBO_DELAY_MAX`

- 必填：否
- 敏感：否
- 获取或设置：可选：两次请求间随机间隔上限（秒）。
- 填写格式：非负数字，默认 15；不得小于下限。

### `WEIBO_JITTER_MINUTES`

- 必填：否
- 敏感：否
- 获取或设置：可选：启动前随机延迟分钟数上限，用于错开整点；默认 0 关闭。
- 填写格式：0–60 的数字，默认 0。

### `WEIBO_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：可选：网络层失败重试次数。
- 填写格式：整数 1–5，默认 3。

### `WEIBO_RETRY_BACKOFF`

- 必填：否
- 敏感：否
- 获取或设置：可选：重试退避基数（秒），指数退避。
- 填写格式：数字，默认 4。

### `WEIBO_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次 HTTP 超时秒数。
- 填写格式：数字，默认 25。

### `WEIBO_WEB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在测试环境自行开启；正式执行时删除或设为 0。
- 填写格式：1/true/yes/on 开启完全断网预演；默认关闭。兼容 WEIBO_DRY_RUN。

### `WEIBO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：WEIBO_WEB_DRY_RUN 的兼容别名。
- 填写格式：与 WEIBO_WEB_DRY_RUN 相同。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式下需要替换默认通知名单时自行设置。
- 填写格式：逗号、分号或空白分隔；可匹配 catalogId、scripts 相对路径、文件名或通配符；* 全选，空值全关。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 所在目录。
- 填写格式：目录路径；失败后继续尝试 /ql/data/scripts 与 /ql/scripts；通知失败不改变业务退出码。

## 多账号

每个非空行一个账号 Cookie；可选备注|Cookie，仅拆首个竖线。超话列表由 WEIBO_SUPERTOPICS 共享。账号独立执行，任一失败或配置错误则整体非零退出。
