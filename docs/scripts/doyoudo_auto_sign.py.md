# Doyoudo每日签到发言

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/doyoudo_auto_sign.py`
- 青龙命令：`python3 scripts/doyoudo_auto_sign.py`
- 建议 Cron：`59 8 * * *`
- 发布哈希：`8a8dc1c97b0d04fe7afcf6e2a6d95d53155d62081d024508db39836d75e84507`
- 许可证：`MIT`

## 脚本功能

- 登录 Doyoudo 后执行每日签到，读取坚持天数、本次奖励与雪糕数量。
- 登录后自动发言获取积分；文案优先使用一言随机文本并按策略署名，失败或断网预演回落本地短句。
- 读取公开用户名、雪糕与金币摘要以便核对账号；不输出密码、Token、dyd-token 或原始响应。
- 本地按 CryptoJS 兼容 AES 生成 dyd-token，不再依赖 localhost 加密服务。
- 支持逐行多账号、动作开关、完全断网预演、超时控制、时间轴日志与单行 TASK_SUMMARY。
- 通过青龙 notify.py 或 sendNotify.js 发送脱敏任务汇总，遵守全局开关与脚本清单。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `DOYOUDO_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://www.doyoudo.com 注册或登录后，使用本人账号与登录密码。勿把真实凭据写入仓库、日志或示例。
- 填写格式：每个非空行一个账号：用户名|密码；仅在首个竖线处分割，后续字符完整保留为密码。

### 可选参数

### `DOYOUDO_USERNAME`

- 必填：否
- 敏感：否
- 获取或设置：兼容单账号别名：填写 Doyoudo 登录用户名；仅当 DOYOUDO_ACCOUNTS 为空且同时提供 DOYOUDO_PASSWORD 时生效。
- 填写格式：单个用户名字符串。

### `DOYOUDO_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：填写 Doyoudo 登录密码；仅当 DOYOUDO_ACCOUNTS 为空且同时提供 DOYOUDO_USERNAME 时生效。
- 填写格式：单个密码字符串。

### `DOYOUDO_ACTIONS`

- 必填：否
- 敏感：否
- 获取或设置：可选：选择本轮执行的动作；默认与上游一致为签到、发言、读取个人信息。
- 填写格式：逗号、分号或空白分隔：sign、say、info；默认 sign,say,info。

### `DOYOUDO_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可选：发言在一言不可用或断网预演时使用的本地正文；不设置则使用内置短句列表。
- 填写格式：不超过 280 字的公开发言文本；不会发送给一言接口。

### `DOYOUDO_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置单次 HTTPS 请求超时；默认 15 秒。
- 填写格式：数字秒，范围 5 到 60。

### `DOYOUDO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：用于首次配置检查与完全断网预演；不代表真实业务成功。
- 填写格式：1、true、yes 或 on 启用；不访问业务接口与一言。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：自行选择需要推送的脚本；设置后替代默认通知清单。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；支持 aa8ce405ac3abf85、scripts/doyoudo_auto_sign.py；* 选择全部，空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：指定已安装青龙通知模块所在目录，否则依次发现可导入的 notify、/ql/data/scripts、/ql/scripts。
- 填写格式：目录路径，包含 notify.py 或 sendNotify.js。

## 副作用与风险

- 正式执行时向 Doyoudo 提交登录会话与每日签到，可能增加坚持天数与雪糕。
- 启用 say 动作时向社区发布发言内容，可能消耗或获取积分相关状态。
- 通知启用且助手可用时发送脱敏任务汇总；无网络预演不投递外部通知，也不请求一言。
