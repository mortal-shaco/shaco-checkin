# 网易云全能打卡

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/netease_task.py`
- 青龙命令：`python3 scripts/netease_task.py`
- 建议 Cron：`53 1 * * *`
- 发布哈希：`e24b76bcb0e7df479cb84cb08b29487d324ee5e6265dca9c6270dfa031e3a949`
- 许可证：`MIT`

## 脚本功能

- 确认登录并显示官方昵称、用户名或公开用户编号
- 手机端与网页端每日签到，识别今日已签到并显示返回积分
- 可选通过官方 weapi 执行网页签到
- 云贝签到、连签奖励领取、已完成云贝任务奖励领取及余额查询
- 黑胶乐签打卡、VIP 每日成长任务逐项奖励领取、批量成长值领取及按任务编号备用领取
- 查询 VIP 等级、成长值和昨日新增成长值
- 显式开启时通过四个榜单获取歌曲并提交最多三百首模拟播放记录，按三百首确认成功
- 查询账号等级与累计听歌数量
- 每行多账号、旧 Cookie 变量和 MUSIC_U 变量兼容
- 青龙通知、PushPlus 与 Server酱顺序备用及独立 Bark 通知
- 完全断网预演、分阶段时间轴日志、逐账号统计及单行结构化汇总

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `NETEASE_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录网易云音乐网页版，在浏览器开发者工具的站点 Cookie 中复制同一账号的完整 Cookie，至少保留 MUSIC_U 与 __csrf；在青龙环境变量中每行填写一个账号。
- 填写格式：每行一份完整 Cookie；字段以分号分隔，字段值中的等号原样保留；可有空行、井号开头注释或整行引号。

### `NETEASE_API_BASE`

- 必填：是
- 敏感：否
- 获取或设置：正式运行前填写自己信任且兼容网易云音乐接口的 HTTPS 服务地址；该服务会接收 Cookie，断网预演不需要。
- 填写格式：不含账号密码、查询参数和片段的 HTTPS 基础地址。

### 可选参数

### `NETEASE_COOKIES`

- 必填：否
- 敏感：是
- 获取或设置：与 NETEASE_COOKIE 相同；旧版多账号变量，设置后优先读取。
- 填写格式：每行一份完整 Cookie，不使用 & 或 @ 分隔账号。

### `NETEASE_MUSIC_U`

- 必填：否
- 敏感：是
- 获取或设置：登录网易云音乐网页版，在开发者工具的 Cookie 中复制 MUSIC_U 字段值；仅在两个完整 Cookie 变量均未设置时使用。
- 填写格式：每行一个 MUSIC_U 值；为兼容上游输入，完整 Cookie 仍为首选。

### `NETEASE_SCROBBLE`

- 必填：否
- 敏感：否
- 获取或设置：如明确需要模拟听歌，在青龙环境变量中设为 1；默认关闭。
- 填写格式：仅 1 开启。

### `NETEASE_WEB_SIGN_WEAPI`

- 必填：否
- 敏感：否
- 获取或设置：如需把原有网页签到切换为网易云官方 weapi，在青龙环境变量中设为 1。
- 填写格式：仅 1 开启，默认沿用兼容接口。

### `NETEASE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设为 1，可进行完全断网预演。
- 填写格式：仅 1 开启。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要限制自动通知脚本时填写脚本名、相对路径或目录标识；设置为空表示自动模式下不通知。
- 填写格式：多个选择器可用逗号、分号或空白分隔，支持星号通配。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知模块位于非标准目录时填写其所在目录。
- 填写格式：包含 notify.py 的目录路径。

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在 PushPlus 官网个人中心获取推送凭据；仅在青龙通知不可用时作为备用渠道。
- 填写格式：单个推送凭据。

### `SENDKEY`

- 必填：否
- 敏感：是
- 获取或设置：登录 Server酱 官网获取 SendKey；仅在青龙和 PushPlus 均不可用时使用。
- 填写格式：单个 SendKey。

### `BARK_URL`

- 必填：否
- 敏感：是
- 获取或设置：从自己使用的 Bark 服务取得完整 HTTPS 推送地址；此渠道按原有行为独立发送。
- 填写格式：完整 HTTPS 地址，不含查询参数。

## 多账号

每个非空行填写同一账号的完整 Cookie；空行和井号开头的注释会跳过。各账号独立处理，任何账号失败则进程非零退出。
