# 安徽工业大学晚寝签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ahut.py`
- 青龙命令：`python3 scripts/ahut.py`
- 建议 Cron：`20 21 * * *`
- 发布哈希：`a7629c69d6a51460875144943007c502fddcb2f4087450eea3b933318a663abb`
- 许可证：`MIT`

## 脚本功能

- 安徽工业大学智慧考勤晚寝签到：OAuth 登录、动态任务、微信环境校验、时间窗口、宿舍定位与签到提交
- 官方返回姓名等非秘密身份时直接展示以便核对账号
- 多账号按行处理；规范变量 AHUT_ACCOUNTS，兼容 STUDENT_IDS/PASSWORDS
- 完全断网预演 AHUT_DRY_RUN、HTTPS 超时、业务成功/已签到判定
- 脱敏时间轴日志、账号与任务统计、单行 TASK_SUMMARY 与青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AHUT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用安徽工业大学智慧考勤（xskq.ahut.edu.cn）学号与登录密码。在青龙环境变量中按每行一个账号填写；不要把真实凭据写入公开仓库或分享给他人。
- 填写格式：每行一个账号，格式：学号|密码；仅按第一个竖线分割，密码中可含竖线；账号之间只用换行分隔，不使用 & 或 @

### 可选参数

### `STUDENT_IDS`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：未配置 AHUT_ACCOUNTS 时填写学号列表；须与 PASSWORDS 数量对齐。维护版不再提供默认密码。
- 填写格式：学号文本；多个可用换行、分号或逗号分隔

### `PASSWORDS`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：与 STUDENT_IDS 配套填写密码；已配置 AHUT_ACCOUNTS 时忽略。必须显式填写，无默认密码。
- 填写格式：密码文本；多个与 STUDENT_IDS 顺序对齐，可用换行、分号或逗号分隔；若仅填一个密码则复用到全部学号

### `AHUT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置；只校验配置并模拟六步流程，不登录、不定位、不提交签到、不真实发送通知。
- 填写格式：1、true、yes、on 开启完全断网预演；默认关闭

### `AHUT_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次 HTTPS 请求超时秒数。
- 填写格式：3 到 120 的数字；默认 20

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录；失败不改变业务退出码。
- 填写格式：目录路径；还会尝试 /ql/data/scripts 与 /ql/scripts
