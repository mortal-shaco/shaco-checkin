# 森空岛每日任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/skland_daily.py`
- 青龙命令：`python3 scripts/skland_daily.py`
- 建议 Cron：`33 1 * * *`
- 发布哈希：`4d0dc70ab35fe6d918045e693b91344a25b41a07a248d43af79c49203334c016`
- 许可证：`MIT`

## 脚本功能

- 通行证 Token、森空岛 cred/token 和手机号密码登录，保留官方授权换取及请求签名
- 自动获取临时设备标识或使用用户指定标识
- 获取版区及今日检票状态、版区筛选、每日检票及避免重复检票
- 配置数量的帖子浏览、显式开启的点赞和分享任务，保留帖子分页
- 保留 --dry-run、--actions、--zones、--version 命令行参数及旧序号账号输入
- 多账号独立执行、HTTP 超时、禁止重定向、业务码核验和失败闭合退出
- 完全断网配置预演、时间轴阶段日志、账号及任务统计、单行 TASK_SUMMARY JSON、脱敏通知
- 显式 attendance 动作获取明日方舟所有绑定角色，逐角色签名签到并展示奖励名称与数量
- 游戏角色官方昵称与公开 UID 原样展示，单角色失败继续其他角色，任一失败整体非零退出
- 显式 endfield 动作获取终末地全部绑定角色，逐角色空请求体签名签到，按资源映射展示奖励名称与数量
- 终末地官方角色昵称和返回的公开 UID 原样展示；单角色或绑定记录失败继续其余角色，任何失败导致账号及进程失败
- 保留归档全部账号变量、短信码登录、显式 send-code、可选刷新与游戏筛选
- 保留旧加密数美设备协议、校时与进程内缓存；规范入口依旧使用原设备实现
- 显式受限文件读取、账号合并去重、Hermes 日志及成功正文静默、通知标题和代理选项
- 青龙通知可发现位置回退，兼容当前与归档选择器；通知及 TASK_SUMMARY 保留

## 环境变量与参数

先配置必选参数再运行；条目注明的兼容变量可以替代规范变量。缺少任一必选参数及其全部兼容变量时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SKLAND_TOKEN`

- 必填：是（也可设置 `SKYLAND_TOKEN`、`SKLAND_ACCOUNTS`、`SKYLAND_TOKENS`、`TOKEN`、`SKYLAND_TOKEN_FILE`）
- 敏感：是
- 获取或设置：登录本人官方鹰角通行证，在浏览器开发者工具中查看登录响应的 token，或使用官方通行证 web-api 响应的 data.content；也可从本人森空岛客户端授权响应获得成对的 cred、token。账密登录请填写本人手机号与密码的单行 JSON。不要共享凭据。 本变量是可替代账号入口；与其他入口按兼容规则合并去重。
- 填写格式：每个非空行一个账号：通行证 Token、cred:token、含 cred/token 的单行 JSON、含 data.content 的官方响应 JSON，或含 phone/password 的单行 JSON；冒号仅在第一处分割，不使用 &、@、分号或逗号分隔账号。 同时兼容单行 JSON token、phone/code、did；send-code 只需 phone。

### 可选参数

### `SKLAND_PHONE`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧输入，填写本人鹰角通行证手机号，建议迁移至 SKLAND_TOKEN 单行 JSON。
- 填写格式：与 SKLAND_PASSWORD 成对设置，一个账号；不能用作多账号分隔输入。

### `SKLAND_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧输入，填写本人鹰角通行证密码，建议迁移至 SKLAND_TOKEN 单行 JSON。
- 填写格式：与 SKLAND_PHONE 成对设置。

### `SKLAND_TOKEN_N`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧序号输入，获取方式同 SKLAND_TOKEN；N 替换为数字。
- 填写格式：每个序号变量仍按非空行解析账号。 按数字序号排序；不完整账密对记录账号失败，其余账号继续。

### `SKLAND_PHONE_N`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧序号输入，填写本人鹰角通行证手机号；N 替换为数字。
- 填写格式：与同序号 SKLAND_PASSWORD_N 成对设置。 按数字序号排序；不完整账密对记录账号失败，其余账号继续。

### `SKLAND_PASSWORD_N`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧序号输入，填写本人鹰角通行证密码；N 替换为数字。
- 填写格式：与同序号 SKLAND_PHONE_N 成对设置。 按数字序号排序；不完整账密对记录账号失败，其余账号继续。

### `SKLAND_DID`

- 必填：否
- 敏感：是
- 获取或设置：从本人森空岛官方客户端请求头获取 dId；不填写时沿用维护版本的临时设备标识注册功能，值仅保存在内存。
- 填写格式：单个设备标识，不输出到日志。

### `SKLAND_ACTIONS`

- 必填：否
- 敏感：否
- 获取或设置：按需要选择任务，默认 checkin,view；like、share、attendance、endfield 须显式添加。
- 填写格式：逗号分隔 checkin、view、like、share、attendance、endfield；attendance 仅明日方舟，endfield 仅终末地；原源游戏签到可设置 attendance,endfield。

### `SKLAND_ZONE_IDS`

- 必填：否
- 敏感：否
- 获取或设置：从官方版区列表接口读取 gameId，不设置时处理全部社区版区。
- 填写格式：逗号分隔版区编号；只筛选社区动作，不筛选游戏签到角色。

### `SKLAND_VIEW_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：按需要配置每个版区的浏览数量，默认 5。
- 填写格式：非负整数。

### `SKLAND_LIKE_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：按需要配置每个版区的点赞数量，默认 10，只有显式选择 like 才生效。
- 填写格式：非负整数。

### `SKLAND_SHARE_COUNT`

- 必填：否
- 敏感：否
- 获取或设置：按需要配置每个版区的分享任务计数，默认 1，只有显式选择 share 才生效。
- 填写格式：非负整数；接口只计数，不发布文本。

### `SKYLAND_TYPE`

- 必填：否
- 敏感：否
- 获取或设置：仅在 SKLAND_ACTION 未设置且有 SKLAND_ACCOUNTS/TOKEN 输入时采用旧动作；其余入口保持原无业务效果。
- 填写格式：sign 或 send-code；不支持 add_account，不保存凭据。

### `SKLAND_NOTIFY_URL`

- 必填：否
- 敏感：是
- 获取或设置：可选本人维护的 HTTPS 通知服务地址，正式运行发送脱敏摘要；与青龙通知模块兼容。
- 填写格式：HTTPS 地址，禁止重定向和 URL 用户名密码；不得填写账号凭据。

### `SKLAND_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1，也支持 --dry-run 参数。
- 填写格式：1、true、yes、on 启用完全断网预演，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写青龙 notify.py 所在目录；可省略以自动查找 notify 模块及青龙标准目录。
- 填写格式：目录路径；通知模块不可用、超时或失败时保留业务退出码。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

### `SKYLAND_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在自己的浏览器登录鹰角网络官方账号页面 https://user.hypergryph.com/ ，再访问 https://web-api.hypergryph.com/account/info/hg 获取响应 content 中的账号 Token。若官方登录流程变化，从本人已登录客户端的授权请求获取 token；不要公开响应、Token 或 Cookie。 本变量是可替代账号入口；与其他入口按兼容规则合并去重。
- 填写格式：每个非空行一个完整账号 Token；禁止用逗号、& 或 @ 分隔多个账号。

### `SKYLAND_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置为 1 开启完全断网预演。
- 填写格式：1、true、yes、on 开启，默认 0。

### `SKLAND_ACCOUNTS`

- 必填：否
- 敏感：是
- 获取或设置：登录森空岛官网后，在同一浏览器访问 https://web-api.skland.com/account/info/hg，复制 data.content 的鹰角通行证；也可使用本人手机号与密码，或通过显式 send-code 动作获取短信验证码。不要分享接口响应。 本变量是可替代账号入口；与其他入口按兼容规则合并去重。
- 填写格式：每个非空行一个账号：通行证原文、含 data.content 的单行 JSON，或单行 JSON 对象，字段 token；也可字段 phone 与 password，或 phone 与 code；可在同一 JSON 添加 did（由本人官方登录请求的 dId 头获取）。send-code 动作仅需 phone。账号不能使用逗号、& 或 @ 分隔。

### `TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版通行证环境变量兼容入口，获取方法同 SKLAND_ACCOUNTS；仅在规范变量为空时采用。 本变量是可替代账号入口；与其他入口按兼容规则合并去重。
- 填写格式：每个非空行一个通行证或单行 JSON；旧版逗号分隔需改为换行。

### `SKLAND_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：显式设为 sign 开启游戏签到；显式设为 send-code 仅发送验证码；不设置时保持社区任务。
- 填写格式：sign/send-code；send-code 与 SKLAND_ACTIONS/--actions 不能并用。

### `SKLAND_GAMES`

- 必填：否
- 敏感：否
- 获取或设置：筛选显式开启的游戏动作；本变量自身不启用游戏签到。
- 填写格式：arknights,endfield，或其中任意一个；逗号仅用于游戏选项。

### `SKLAND_REFRESH`

- 必填：否
- 敏感：否
- 获取或设置：需要主动刷新签名令牌时设置，默认关闭。
- 填写格式：1 开启；0、false、no、off 关闭。

### `SKYLAND_TOKENS`

- 必填：否
- 敏感：是
- 获取或设置：本人登录 https://www.skland.com/ 后，在同一浏览器打开 https://web-api.skland.com/account/info/hg ，取官方响应 data.content。请只保存自己的凭据，不公开响应。账号需在森空岛绑定游戏角色。 本变量是可替代账号入口；与其他入口按兼容规则合并去重。
- 填写格式：每个非空行一个完整鹰角登录 token；也接受每行一个包含 data.content 的官方 JSON。禁止使用逗号、& 或 @ 分隔账号。

### `SKYLAND_TOKEN_FILE`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容输入：自行创建并保护本地凭据文件，填入其路径；可与 SKYLAND_TOKENS 合并去重，也兼容仅从文件读取。脚本不创建或修改此文件。
- 填写格式：当前工作目录内的普通文件路径，支持 ~ 和 # 注释；上限 1 MiB；必须同时 SKYLAND_READ_FILE=1；预演不读取。

### `SKYLAND_MODE`

- 必填：否
- 敏感：否
- 获取或设置：按执行环境选填；自动模式根据可发现的青龙通知模块选择日志输出流。
- 填写格式：auto（默认）、qinglong 或 hermes。

### `SKYLAND_SILENT_OK`

- 必填：否
- 敏感：否
- 获取或设置：希望全部成功时抑制 Hermes 投递正文可设为 on；统计记录仍保留。
- 填写格式：on 启用；默认 off。

### `USE_PROXY`

- 必填：否
- 敏感：否
- 获取或设置：仅需使用自己配置的系统代理时设为 on。
- 填写格式：默认 off，忽略系统代理；on 使用系统代理。

### `NOTIFY_TITLE`

- 必填：否
- 敏感：否
- 获取或设置：可选填写通知标题，不得填入凭据。
- 填写格式：默认“森空岛自动签到”。

### `EXIT_WHEN_FAIL`

- 必填：否
- 敏感：否
- 获取或设置：仅为旧配置兼容保留；任意账号失败始终非零退出，无需设置此变量。
- 填写格式：旧版 on/off 输入不再允许失败返回零。

### `SKYLAND_READ_FILE`

- 必填：否
- 敏感：否
- 获取或设置：仅需要读取自己保护的当前目录内凭据文件时显式设置；预演仍不读文件。
- 填写格式：1/true/yes/on 开启；默认 0，其他有效关闭值 false/no/off。

## 副作用与风险

- 未配置 SKLAND_DID 时向上游设备服务注册临时设备标识
- 账密或通行证登录时换取授权和账号会话凭据
- 版区每日检票改变签到状态
- 浏览帖子可能增加任务浏览进度
- 显式启用 like 时点赞帖子
- 显式启用 share 时增加分享任务计数，不发布文案
- 正式运行时向已配置的青龙或自有通知渠道发送脱敏摘要
- 显式开启 attendance 时为明日方舟绑定角色签到并领取游戏奖励
- 显式开启 endfield 时为终末地绑定角色签到并领取游戏奖励
- 显式 send-code 向账号手机号发送登录短信验证码，不登录或签到
- 显式 SKLAND_REFRESH 开启时刷新签名令牌，仅内存保存
- 显式 SKYLAND_READ_FILE 开启且非预演时只读当前目录内的指定凭据文件
- 旧设备协议向数美发送模拟浏览器指纹；SKYLAND_TOKEN 在游戏正式运行前读取服务器时间用于校准
