# 极氪每日签到与奖励领取

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/zeekr_egern.js`
- 青龙命令：`node scripts/zeekr_egern.js`
- 建议 Cron：`14 0 * * *`
- 发布哈希：`81e9f4f539ca6cc2b590f77f91367271ebf6a372de7d6953b59cd1b29c306c1c`
- 许可证：`Apache-2.0`

## 脚本功能

- 每日签到与连续签到状态处理
- 阅读任务文章及任务进度复查
- 显式启用的社区点赞及三页广场帖子查找
- 显式步数上报、固定值或范围及每日固定随机策略
- 碎片批量领取、失败逐项重试及缺失结果检测
- 七日连签奖励、碳能量球与极值领取
- all、sign、claim 任务切换及场次标签
- 领取轮询、入账观察、失败次数与窗口限制
- 网页与可选原生签名头、可选页面上下文及阅读停留
- iTunes 版本查询与本地版本回退
- 换行多账号、旧凭据别名与同账号配套字段隔离
- 断网预演、凭据有效期检查、请求超时与业务响应验证
- 脱敏分阶段日志、公开账号身份、逐账号统计与结构化汇总
- 按青龙全局开关和脚本列表发送任务结果通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ZEEKR_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：在本人极氪 App 或官网登录后，使用本人授权的抓包工具获取发往 api-gw-toc.zeekrlife.com 的 Authorization 请求头。配套 device_id 和原生签名字段必须来自同一账号，可一并放入该行 JSON。到期或认证失败后重新获取，勿公开抓包。
- 填写格式：每个非空行一个账号，填 Bearer JWT 或裸 JWT；也可每行 JSON，包含 authorization、可选 device_id、可选 app_secret。只按换行分隔账号。

## 多账号

ZEEKR_TOKEN 每个非空行一个账号，单行凭据可为 Bearer JWT 或含同账号 authorization、device_id、app_secret 的 JSON。仅按换行分账号，不按其他符号拆分。每个账号独立执行，任一失败整体非零退出。
