# PSY 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/daily_checkin.py`
- 青龙命令：`python3 scripts/daily_checkin.py`
- 建议 Cron：`21 8 * * *`
- 发布哈希：`acddadb83702bf0192e41103c8a7d52513350f2042a5fb776767ccd6ccc7ad94`
- 许可证：`MIT`

## 脚本功能

- PSY 会员使用 Bearer 访问令牌完成每日签到
- 签到前读取 /users/me 校验令牌，并展示官方返回的公开用户名、钱包地址或 UID
- 业务 code=0 视为签到成功；已签到类文案视为今日已完成
- 多账号按行处理；规范变量 PSY_ACCOUNTS，兼容 PSY_TOKEN
- 完全断网预演 PSY_DRY_RUN、HTTPS 超时、账号间隔与业务成功判定
- 脱敏时间轴日志、账号与任务统计、单行 TASK_SUMMARY 与青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `PSY_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://psy.xyz/ 使用钱包登录后，从浏览器开发者工具网络请求的 Authorization: Bearer 头，或登录接口返回的 data.token 取得访问令牌。每个非空行一个账号。推荐「钱包地址|访问令牌」；亦可整行只填令牌。不要填写私钥，也不要把真实令牌写入公开仓库、日志或通知。
- 填写格式：每行一个账号：钱包地址|访问令牌（仅在第一个 | 处分割，令牌可含 |）或仅访问令牌；账号之间只用换行分隔，不使用 & 或 @

### 可选参数

### `PSY_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：仅当 PSY_ACCOUNTS 为空时生效，可填单个访问令牌或「钱包地址|访问令牌」。
- 填写格式：单个访问令牌，或 钱包地址|访问令牌

### `PSY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线检查时设置；只校验账号行格式并模拟读取用户/签到阶段，不访问网络、不改动签到状态、不真实发送通知。
- 填写格式：1、true、yes、on 开启完全断网预演；默认关闭

### `PSY_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次 HTTPS 请求超时秒数。兼容上游名 REQUEST_TIMEOUT。
- 填写格式：5 到 120 的数字；默认 30

### `PSY_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：可选：多账号之间的间隔秒数。兼容上游名 BATCH_DELAY。
- 填写格式：0 到 60 的数字；默认 2

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录；失败不改变业务退出码。
- 填写格式：目录路径；还会尝试 /ql/data/scripts 与 /ql/scripts
