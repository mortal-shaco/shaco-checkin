# 领克App每日签到分享

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/lynkco_qinglong_single.py`
- 青龙命令：`python3 scripts/lynkco_qinglong_single.py`
- 建议 Cron：`51 9 * * *`
- 发布哈希：`08dc0af421d4792223ff88980f6e15ec2239653d6334f0b1986c66820a42e40f`
- 许可证：`MIT`

## 脚本功能

- AppCode优先续期、HMAC签名兜底及静态令牌回退
- 今日签到状态查询、自动签到及签到后复查，已签到跳过
- 连续签到天数与签到卡查询，任务及分享前后能量体积分查询
- 五页动态文章查找及上游备用文章，可选按详情时间择新
- 文章分享两步链及完整三步链回退，严格核验分享积分增加
- 可选任务列表、成长值及官方身份查询，新增状态查询模式
- 多账号独立处理、官方非秘密身份展示、任一账号失败非零退出
- 青龙及可选Bark脱敏摘要通知，支持全局开关与选择清单，通知失败保留业务退出码
- 完全断网预演、分阶段日志及账号统计，兼容机器输出并追加单行TASK_SUMMARY
- 旧账号变量、显式只读JSON配置及签名参数兼容，无私有模块依赖
- 显式分享链接解析及编号、分类一致性检查，支持文章、动态、活动、商品和专题
- 可选签到后分享前等待，保留维护版默认零额外等待
- 显式分享目标使用原有签名、简化链与完整链回退，并继续严格核验积分增加

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LYNKCO_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：从本人领克App登录或续期请求响应获取centerTokenDto.token、refreshToken，从同账号请求获取deviceId。在青龙环境变量中按行填写，勿公开抓包内容。
- 填写格式：每个非空行一个JSON对象，包含token，或同账号refreshToken和deviceId；可同时包含token用于续期失败回退。不使用&或@分账号。

### `LYNKCO_APP_SECRETS`

- 必填：是
- 敏感：是
- 获取或设置：从本人有权访问的App配置或原生网关请求中获取签名配置，在青龙环境变量中填写。
- 填写格式：JSON对象，必填nativeAppKey、nativeAppSecret；每日分享或续期需glDevId；AppCode优先续期还需nativeAppCode。兼容独立签名变量与显式只读配置文件。

### 可选参数

### `LYNKCO_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧输入，从本人App登录响应获取token，优先使用LYNKCO_ACCOUNTS。
- 填写格式：每行一个令牌，按账号行号配对。

### `LYNKCO_REFRESH_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧输入，从本人App登录响应获取refreshToken。
- 填写格式：每行一个续期令牌，按行配对deviceId。

### `LYNKCO_DEVICE_ID`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧输入，从本人同账号请求获取deviceId。
- 填写格式：每行一个设备标识，不跨账号广播。

### `LYNKCO_ENV_FILE`

- 必填：否
- 敏感：是
- 获取或设置：可选兼容本人已有配置，脚本本身无需配置文件。
- 填写格式：显式只读JSON文件路径，含secrets及可选单账号user。多账号不读取user，不回写。

### `LYNKCO_NATIVE_APP_KEY`

- 必填：否
- 敏感：是
- 获取或设置：从本人合法获取的App签名配置读取。
- 填写格式：非空字符串，对应nativeAppKey。

### `LYNKCO_NATIVE_APP_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：从本人合法获取的App签名配置读取。
- 填写格式：非空字符串，对应nativeAppSecret。

### `LYNKCO_NATIVE_APP_CODE`

- 必填：否
- 敏感：是
- 获取或设置：从本人App原生网关Authorization头获取AppCode。
- 填写格式：非空字符串，对应nativeAppCode。

### `LYNKCO_LOGIN_APP_CODE`

### `LYNKCO_NATIVE_GL_DEV_ID`

- 必填：否
- 敏感：是
- 获取或设置：从本人App原生请求的gl_dev_id获取。

### `LYNKCO_CA_KEY`

- 必填：否
- 敏感：是
- 获取或设置：从本人合法获取的App配置读取。
- 填写格式：非空字符串，原生签名键的兼容别名。

### `LYNKCO_CA_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：从本人合法获取的App配置读取。
- 填写格式：非空字符串，原生签名密钥的兼容别名。

### `LYNKCO_APP_CODE`

- 必填：否

- 敏感：是

### `LYNKCO_DRY_RUN`

- 必填：否
- 敏感：否

- 填写格式：1启用完全断网预演，默认0。

### `LYNKCO_TASK_MODE`

- 必填：否
- 敏感：否
- 获取或设置：根据本人任务需求选择模式。

### `LYNKCO_DO_SHARE`

- 必填：否

- 必填：否

### `LYNKCO_ARTICLE_ID`

- 必填：否
- 敏感：否

- 填写格式：可选文章编号，默认分页查询，查询不可用时使用原有备用文章。

### `LYNKCO_CONTENT_ID`

- 必填：否
- 敏感：否
- 获取或设置：从本人App完整分享请求的contentId获取，不凭空构造。

### `LYNKCO_SHARE_URL`

- 必填：否
- 敏感：是
- 获取或设置：从本人App复制分享链接，分享码视为敏感信息。
- 填写格式：可选https://h5.lynkco.com官方分享链接；支持文章、动态、活动、商品、专题；不接受片段或其他域名。

### `LYNKCO_BUSINESS_NO`

- 必填：否
- 敏感：否

- 填写格式：可选目标编号；与链接编号一致；优先于LYNKCO_ARTICLE_ID。

### `LYNKCO_FIRST_CLASSIFICATION`

- 填写格式：文章、动态、活动、商品或专题；默认从链接推断，无链接默认文章。

### `LYNKCO_SECOND_CLASSIFICATION`

### `LYNKCO_SHARE_DELAY_SECONDS`

## 多账号

每个非空行填写一个账号JSON对象。同账号续期令牌与设备标识放在同一对象中，账号独立处理，任一账号失败时整体非零退出；兼容旧变量按行配对。

## 副作用与风险

- 每日模式执行签到并领取服务端奖励，已签到时跳过
- 每日模式默认上报文章分享，服务端可能增加积分，可用LYNKCO_DO_SHARE关闭
- 配置刷新令牌时续期可能改变服务端登录状态，不写本地凭据文件
- 发送脱敏青龙通知及可选Bark推送；全局可关闭，预演禁止联网
- 显式配置非文章目标时上报对应内容分享，服务端可能增加积分
