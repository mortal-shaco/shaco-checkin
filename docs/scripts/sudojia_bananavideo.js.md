# 香蕉视频每日任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_bananavideo.js`
- 青龙命令：`node scripts/sudojia_bananavideo.js`
- 建议 Cron：`19 0 * * *`
- 发布哈希：`390ddb8634db0953715a9695be667190be5a1928789c14ac48bcc94fc6391903`
- 许可证：`GPL-3.0`

## 脚本功能

- 每日 01:10 执行登录、账号昵称查询、签到、广告任务、长视频下载任务登记、观看十个视频、二维码任务登记及金币查询。
- 显式启用后可添加五个随机视频收藏；移除上游清空全部收藏的危险行为。
- 显式启用后可发布评论：独立 HTTPS 一言文本提供方、作者与来源署名、空白规范化、二百八十字符上限及本地回退。
- 每行一账号、首个分隔符解析、会话隔离、有限重试、请求超时和严格业务成功校验。
- 完全断网预演、分阶段脱敏日志、账号与任务统计、单行 TASK_SUMMARY 及青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BANANA_ACCOUNT`

- 必填：是
- 敏感：是
- 获取或设置：在香蕉视频 APP 注册或登录，使用本人绑定的手机号和设置的登录密码；忘记密码请先在 APP 重置。无需抓包。
- 填写格式：每个非空行一个账号：手机号#密码；仅按第一个 # 分割，密码中的后续 #、&、@ 原样保留；手机号为十一位数字。

### 可选参数

### `BANANA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 进行完全断网预演。
- 填写格式：0 或 1，默认 0

### `BANANA_FAVORITE`

- 必填：否
- 敏感：否
- 获取或设置：确认愿意添加五个随机视频收藏后设为 1；不会删除已有或新增收藏。
- 填写格式：0 或 1，默认 0

### `BANANA_COMMENT`

- 必填：否
- 敏感：否
- 获取或设置：确认愿意公开发布随机视频评论后设为 1；文本优先使用一言并署名，任何获取失败均回退本地文本。
- 填写格式：0 或 1，默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写青龙 sendNotify.js 所在目录；未设置时检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：可选本地目录

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 副作用与风险

- 每日签到及任务奖励可能增加金币。

- 仅显式启用时添加随机视频收藏。
- 仅显式启用时公开发布评论。
- 登录创建服务端会话；启用通知时发送脱敏结果通知。
