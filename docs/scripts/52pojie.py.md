# 吾爱破解每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/52pojie.py`
- 青龙命令：`python3 scripts/52pojie.py`
- 建议 Cron：`25 6 * * *`
- 发布哈希：`9d3766fa6d591d751146a68d816901e5e269196fd2de68bdb43f9bd457ba382c`
- 许可证：`Apache-2.0`

## 脚本功能

- 每天 06:25 自动申请并领取吾爱破解每日签到任务（任务编号 2），保留原有会话准备流程。
- PJ52_COOKIE 按行多账号、兼容整段 URL 编码，保留凭据值中的等号，隔离各账号会话。
- 标准库独立 HTTP 客户端、会话 Cookie 管理、HTTPS 同站跳转限制、超时和响应大小限制。
- 仅以官方明确成功或已完成文案确认结果，登录失效、未知响应和模糊任务状态失败退出。
- 官方页面提供公开账号昵称时展示原值；敏感字段、手机号和原始响应不输出。
- 完全断网预演、中文时间轴日志、逐账号及总任务统计、单行 TASK_SUMMARY JSON 汇总。
- 正式运行在成功、部分失败、失败和配置错误后按通知开关尝试青龙脱敏通知；离线预演只显示通知预览。通知失败保留业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `PJ52_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录吾爱破解 https://www.52pojie.cn，打开开发者工具的网络面板，复制已登录请求的 Cookie 请求头；须同时包含 htVC_2132_saltkey 和 htVC_2132_auth。过期后重新登录获取，不要分享凭据。
- 填写格式：每个非空行一个账号：htVC_2132_saltkey=<该账号值>; htVC_2132_auth=<该账号值>。同账号字段合并在一行，仅在首个等号切分字段，保留值中的等号；支持整段经过 URL 编码的 Cookie；不再用 & 或 @ 分隔账号。

### 可选参数

### `PJ52_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置为 1 开启离线预演，默认 0。
- 填写格式：0/1、true/false、yes/no 或 on/off。预演只校验配置，不校验真实登录状态，不发送网络通知。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，auto 模式下设置以替换默认通知选择，空值禁用全部；强制开启或关闭时优先使用全局开关。
- 填写格式：逗号、分号或空白分隔的目录标识、脚本相对路径、文件名或文件名通配符；支持 *；本脚本可选 11b4c2ed42746ce1、52pojie.py、candidate.py。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填入已有青龙 notify.py 或 sendNotify.js 所在目录；自动兼容 notify.send、/ql/data/scripts 和 /ql/scripts。
- 填写格式：本机已有通知模块目录；不下载或安装程序，不作为签到依赖。
