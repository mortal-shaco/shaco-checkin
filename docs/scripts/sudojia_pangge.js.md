- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_pangge.js`

- 建议 Cron：`7 1 * * *`

- 许可证：`GPL-3.0`

## 脚本功能

- 校验登录状态并显示官方返回的非敏感昵称
- 查询签到状态、连续签到天数和累计签到天数
- 未签到时执行每日签到并再次查询确认，已签到时跳过
- 查询当前账号积分
- 支持换行多账号及独立失败统计
- 提供完全断网预演、分阶段日志及单行结构化汇总
- 通过青龙发送脱敏结果通知，支持全局关闭

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `PANG_GE_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录微信胖哥俩肉蟹煲小程序，在本人授权抓包中找到 saash5.namek.com.cn 请求，复制请求头 token 的值；失效时重新登录获取。
- 填写格式：每个非空行填写一个账号的完整 token，不使用 & 或 @ 分隔账号。

### 可选参数

### `PANG_GE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 开启完全断网预演，正式执行时移除或设为 0。
- 填写格式：1 或 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写青龙 sendNotify.js 所在目录；未设置则自动查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机目录路径

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
