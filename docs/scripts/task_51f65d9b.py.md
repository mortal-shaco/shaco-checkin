## 脚本功能

- 每日向百度知道移动端签到接口提交签到。
- 按上游习惯在每日 10:30 运行（cron 30 10 * * *）。
- 完整 Cookie 按行配置多账号，各账号独立执行。
- 完全断网预演、分阶段脱敏日志和单行结构化统计。
- 若接口返回昵称、用户名、显示名称或公开 UID，直接显示以便核对账号。
- 正式运行可通过青龙通知助手发送成功、部分失败、失败、配置错误或预演摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `BD_ZHIDAO_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录本人百度知道（zhidao.baidu.com），在浏览器开发者工具网络面板中打开本站请求，复制完整 Cookie 请求头值（不含 Cookie: 前缀），仅存入青龙环境变量，勿公开。
- 填写格式：每个非空行一个账号的完整 Cookie；保留分号与等号；不以 &、@ 或其他符号分隔账号。

### 可选参数

### `BD_ZHIDAO_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设为 1；不发 HTTP 请求、不执行签到、不调用外部通知助手。
- 填写格式：1、true、yes、on 启用，默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选；设置后仅列表中的脚本默认发送通知。空值表示全部关闭。
- 填写格式：可用 catalog-id、脚本路径、文件名或 glob；以逗号、分号、空白或换行分隔；* 表示全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填青龙通知模块目录；默认先导入 notify.send，再查找 /ql/data/scripts/notify.py 与 /ql/scripts/notify.py。
- 填写格式：包含 notify.py 的本地目录；通知不可用或失败不影响业务退出码。
