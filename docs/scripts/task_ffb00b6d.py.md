## 脚本功能

- 通过学号及明文或 MD5 密码登录，显示官方返回的非敏感姓名
- 获取当前签到任务、检查微信配置并读取宿舍信息
- 显式启用后执行晚寝签到，保留上游请求签名、签到摘要与今日已签到识别
- 只读请求最多重试四次，令牌过期最多重新登录三次；签到响应不明时停止且不盲目重复提交
- 支持逐行多账号和兼容 JSON 配置文件，账号独立失败并聚合退出码
- 完全断网预演、分阶段脱敏日志、账号及任务统计和唯一 TASK_SUMMARY 结构化汇总
- 正式运行通过青龙通知发送脱敏总结，支持全局开关与脚本选择，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AHUT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人安徽工业大学考勤系统学号及本人设置的密码。请从学校官方考勤入口核对登录；脚本不提供默认密码、不保存配置。若使用 MD5 密码，可在本人授权的浏览器开发者工具中核对官方登录请求的 password 字段，切勿分享请求内容。
- 填写格式：每个非空行一个账号：学号|密码，仅在第一个 | 处分割，保留密码后续字符及空格。也可每行一个 JSON 对象，字段为 student_Id、password、is_encrypted（0 或 1）。签到时还须包含 latitude、longitude、locationAccuracy（米），从本人设备当前真实定位获取，不可填写宿舍坐标冒充实际位置。JSON 可用转义表示特殊字符。

### 可选参数

### `AHUT_ACTION`

- 必填：否
- 敏感：否
- 获取或设置：默认 query，仅登录并读取签到任务、微信配置及宿舍信息；本人决定提交时显式设置 sign。
- 填写格式：query 或 sign；sign 会登记访问记录并签到，北京时间 21:20 前拒绝执行，实际开放时间仍以官方返回为准。

### `AHUT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时设置为 1；正式运行设置为 0。
- 填写格式：1/true/yes/on 开启；0/false/no/off 关闭，默认 0。断网模式不调用业务接口或青龙通知模块。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选设置需要通知的脚本选择列表；未设置时本脚本默认入选。
- 填写格式：以逗号、分号或空白分隔，支持目录编号 ffb00b6d41f1e89f、脚本路径、文件名和文件名通配符；* 选择全部；空值关闭全部；QINGLONG_NOTIFY 显式开关优先。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写青龙受信任通知模块所在目录；不需要额外仓库或程序即可执行业务。
- 填写格式：包含 notify.py 的目录；亦尝试 import notify 以及 /ql/data/scripts/notify.py、/ql/scripts/notify.py。

## 多账号

每个非空行一个账号，依次独立处理；学号与密码按第一个 | 分割，后续字符保留；复杂账号每行一个 JSON 对象。同账号凭据与真实定位写在同一个对象内，任一账号失败则整体非零退出。可选兼容 -f/--file 指定 JSON 用户数组或包含 users 数组的对象；未设置环境变量时读取同目录 users.json。指定文件优先。不交互、不保存密码。
