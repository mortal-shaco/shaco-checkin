## 脚本功能

- 保留原脚本 WorkBuddy 与 Trae 两平台的独立账号任务，支持 --workbuddy-only、--trae-only 选择执行范围。
- 查询 WorkBuddy 签到状态、活动周期、连续签到天数与积分余额，展示套餐、奖励及购买积分构成。
- 执行签到并回查确认成功，识别今日已签到以避免重复领取。
- 查询 Trae 签到状态与可用积分，领取后回查并优先以余额差计算本次所得。
- Trae 凭据临期或认证失败时通过官方接口刷新，仅在本次进程内使用。
- 支持 --status-only 只查询，以及环境变量或 --dry-run 完全离线预演。
- 保留每日北京时间 08:45、11:45、14:45、17:45、20:45、23:45 运行时刻，由青龙配置调度。
- 逐账号隔离执行，输出官方返回的非敏感身份、脱敏时间轴、统计与单行机器汇总。
- 在成功、部分失败、失败、配置错误和预演结束时按全局开关调用青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AICREDIT_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人官方 WorkBuddy 或 Trae 登录会话中查看签到请求的鉴权头与设备字段，或查看本人官方登录授权响应。WorkBuddy 的 Bearer 值填入 access_token，X-User-Id、X-Domain、X-Enterprise-Id 分别填入 uid、domain、enterprise_id。Trae 的 Cloud-IDE-JWT 值填入 accessToken，授权响应 RefreshToken、UserID 与 TokenExpireAt 分别填入 refreshToken、userId 与 expiresAt，x-device-id 填入 deviceId。凭据过期后重新授权并更新青龙变量。
- 填写格式：每个非空行一个 JSON 对象。platform 为 workbuddy 时必填 access_token，兼容 accessToken、token 字段，选填 uid、domain、enterprise_id、api_base。platform 为 trae 时必填 accessToken、refreshToken、userId、deviceId，选填 claimDeviceId、expiresAt（秒时间戳）、fingerprint（brand、type、os）。不同平台分别填写独立账号行，默认执行全部已启用账号，enabled=false 可禁用。

### 可选参数

### `AICREDIT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置为 1 开启完全离线预演。
- 填写格式：1 开启，0 关闭，默认 0。

### `WORKBUDDY_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：手动设置单次请求超时，对两个平台均生效。
- 填写格式：5 至 120 秒的整数，默认 20。

### `WORKBUDDY_RETRIES`

- 必填：否
- 敏感：否
- 获取或设置：手动设置网络和临时服务端错误的重试次数。
- 填写格式：0 至 5 的整数，默认 2。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：手动填写需要通知的脚本选择器，设置后替换默认名单。
- 填写格式：支持目录相对路径、文件名、文件名通配符与目录编号 ed929736b882170c，以逗号、分号或空白分隔；* 匹配全部，空值关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已由青龙提供的 notify.py 所在目录；默认尝试导入 notify.send、/ql/data/scripts/notify.py、/ql/scripts/notify.py。
