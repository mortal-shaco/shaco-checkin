# 51CTO博客每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/51cto_sign.js`
- 青龙命令：`node scripts/51cto_sign.js`
- 建议 Cron：`17 2 * * *`
- 发布哈希：`aa9a3cbefc3d430220969034c3f61c9bf36e002a1bd2c10e3151e78db496009f`
- 许可证：`GPL-3.0`

## 脚本功能

- 账号密码登录并同步博客会话
- 获取签到Token并沿用原始MD5接口签名
- 查询每日签到状态，已经签到时避免重复提交
- 未签到时执行签到并重新查询验证完成
- 每行一个账号，兼容单行旧式用户名@密码
- 完全断网预演、阶段日志、账号及任务统计和结构化汇总
- 青龙通知及全局开关，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ICTO_BLOG_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在51CTO官网注册或使用已有账号的登录用户名和密码；验证码或额外验证须先人工处理，无需抓取Cookie。
- 填写格式：每个非空行一个账号，推荐用户名|密码；在首个竖线拆分，后续密码原样保留。兼容不含竖线的用户名@密码，在首个@拆分；邮箱用户名须使用竖线。旧版&多账号配置必须迁移为换行。

### 可选参数

### `ICTO_BLOG_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：由用户设置，预演时填1。
- 填写格式：1开启完全断网预演；其他值为真实运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙面板按需设置，默认开启。
- 填写格式：0、false、no、off关闭通知，其他值开启。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：填写已有青龙sendNotify.js所在目录，不需另一个项目仓库。
- 填写格式：可选本地目录；同时自动查找青龙标准脚本目录和当前目录。

## 多账号

每个非空行一个账号，配套用户名和密码合并；独立处理，任一账号失败则整体非零退出。
