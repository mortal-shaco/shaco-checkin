## 脚本功能

- 向 V次元（bbs.66ccff.cc）提交每日签到，识别官方成功或今日已签到结果
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 正式执行结束后发送脱敏青龙通知，通知不可用不改变业务退出码；预演仅输出通知摘要
- 官方响应返回昵称、用户名或公开 UID 时直接显示以便核对账号

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TYBBS_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 https://bbs.66ccff.cc（V次元）后，打开开发者工具 → 网络面板，选中同站已登录请求，复制完整 Cookie 请求头值（不含 Cookie: 前缀）。通常需包含 wordpress_logged_in_* 或 wordpress_sec_* 等登录字段。不要把 Cookie 写入公开仓库、日志或通知。
- 填写格式：每个非空行一个账号的完整 Cookie；Cookie 字段以分号分隔，保留字段值中的 &、@ 和等号。不使用 & 或 @ 分隔账号。

### 可选参数

### `BBS_COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：上游兼容别名；仅当 TYBBS_COOKIE 为空时读取。获取方式与字段要求同 TYBBS_COOKIE。上游 GitHub Actions 示例仅粘贴 wordpress_sec_*=值，本维护版建议使用完整 Cookie。
- 填写格式：与 TYBBS_COOKIE 相同；每个非空行一个完整 Cookie。

### `TYBBS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要断网验证配置与执行计划时手动设置；正式执行时删除或设为 0。
- 填写格式：1、true、yes、on 表示完全断网预演；0、false、no、off 或未设置表示正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。可填 0d4996a9f8a038f6、脚本文件名或 scripts 相对路径。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。不是业务依赖。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。
