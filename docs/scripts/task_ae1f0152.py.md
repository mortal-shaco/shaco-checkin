# 天翼云盘签到与抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_ae1f0152.py`
- 青龙命令：`python3 scripts/task_ae1f0152.py`
- 建议 Cron：`45 10 * * *`

- 许可证：`GPL-3.0`

## 脚本功能

- 使用天翼云盘账号密码及官方登录页公钥完成加密登录
- 每日签到并检查空间奖励及是否已签到
- 签到抽奖并核验奖励说明
- 相册任务抽奖并核验奖励说明
- 可独立选择签到及两类抽奖任务，默认保留上游全部任务
- 每行一个账号，独立会话，单账号失败不阻塞其他账号
- 完全断网预演与失败闭合的业务判定
- 展示官方返回的非敏感账号身份，提供分阶段日志、账号统计和唯一结构化任务汇总
- 实际运行通过青龙通知模块发送脱敏结果，通知异常保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TY189_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用本人天翼云盘登录账号与密码；先在天翼云盘官方客户端或官网确认密码登录正常。账号登录遇到验证码或风控时先在官方端处理，不绕过校验。配置到青龙环境变量，不写入脚本或日志。
- 填写格式：每个非空行一个账号：登录账号|密码；仅按首个 | 分隔，后续 | 属于密码；保留密码空格。不可用 & 或 @ 分隔账号。

### 可选参数

### `TY189_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：可选任务开关，默认执行上游全部三项；相册抽奖不修改备份设置，也不上传相片。
- 填写格式：逗号分隔 sign,draw,photos，可选择子集；分别代表每日签到、签到抽奖、相册任务抽奖，按此顺序执行。

### `TY189_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验收时设为 1；实际运行时设为 0 或不设置。
- 填写格式：1 为完全断网预演（通知也只模拟），0 为实际执行；默认 0。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选通知选择列表；设置后替换默认列表，空值关闭全部通知。
- 填写格式：用逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；* 选择全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录；也会查找可导入的 notify 模块及青龙标准脚本目录。通知失败不改变业务退出码。
- 填写格式：本机通知模块目录路径，不是外部仓库依赖。

## 多账号

每个非空行一个账号，账号与密码在同一行以首个 | 分隔；各账号会话隔离并独立处理，任一账号失败则进程非零退出。
