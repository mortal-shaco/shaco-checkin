# 京东每日签到领京豆

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/daily_sign.py`
- 青龙命令：`python3 scripts/daily_sign.py`
- 建议 Cron：`40 8 * * *`
- 发布哈希：`c3c190181684d9c630fe8c74a87b74c5891fd0a80a151e5525ed83e752d79590`
- 许可证：`MIT`

## 脚本功能

- 每日调用京东 signBeanAct 接口领取京豆签到奖励。
- JD_COOKIE 按行配置多账号，各账号独立执行。
- 显示接口返回的非敏感昵称、用户名、显示名称或公开 UID。
- 完全断网预演、分阶段脱敏日志、账号与任务统计及单行 TASK_SUMMARY。
- 正式运行通过青龙通知助手发送成功、部分失败、失败、配置错误或预演摘要；预演只输出摘要。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `JD_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：打开京东网页并登录本人账号，按 F12 打开开发者工具，切换到手机模式后刷新；在网络面板找到 m.jd.com 相关请求，复制完整 Cookie 请求头值（需含 pt_key 与 pt_pin，不含 Cookie: 前缀）。仅存入青龙环境变量，勿公开。
- 填写格式：每个非空行一个账号的完整 Cookie；保留分号与等号；不以 & 或 @ 分隔账号。

### 可选参数

### `JD_BEAN_SIGN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：首次配置或联调时设为 1；不访问京东接口，不发送外部通知。
- 填写格式：1、true、yes、on 启用；默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、scripts/相对路径、文件名或通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录；默认尝试导入 notify 及 /ql/data/scripts、/ql/scripts。
- 填写格式：包含 notify.py 的本地目录；通知不可用或失败不影响业务退出码。
