# 魔盒 CityBox 签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/citybox.js`
- 青龙命令：`node scripts/citybox.js`
- 建议 Cron：`15 0 * * *`
- 发布哈希：`f40e6173d635b9c36ae0eaa7357932b89adc8423a1885b1927a1a27aba52f03a`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 每日签到，保留每天 00:10 的调度
- 兼容抓包请求头及旧 BoxJS 同名环境变量，不依赖私有文件或外部仓库
- 逐行多账号独立执行、超时限制、失败闭合及非零退出
- 显式开启原期限内活动查询、剩余次数核对、抽奖及最多四次限流退避
- 展示官方昵称、用户名、显示名或公开 UID，隐藏手机号、凭据和原始响应
- 完全断网预演、阶段时间轴、每账号统计及单行结构化汇总
- 通过青龙发送脱敏结果，遵守通知开关及选择器，通知失败不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CITYBOX_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用自己授权的抓包工具打开 CityBox 小程序签到页面，复制 https://api.icitybox.cn/api/user/get_user_info 请求头，保留全部认证与签名字段。也可复制旧 BoxJS 的 boxapp_citybox_har 值；不要公开抓包内容。
- 填写格式：每个非空行一个 JSON 对象，结构为 {"headers":{请求头字段:字符串值}}，同一账号配套凭据全部放在 headers 内，不用 & 或 @ 分隔账号。

### 可选参数

### `boxapp_citybox_har`

- 必填：否
- 敏感：是
- 获取或设置：兼容旧 BoxJS 的同名配置值；仅未设置 CITYBOX_ACCOUNTS 时读取同名环境变量，不再读写 box.dat。
- 填写格式：每行一个包含 headers 的 JSON 对象，与规范变量相同。

### `CITYBOX_DRAW`

- 必填：否
- 敏感：否
- 获取或设置：有意消耗活动机会时显式开启，默认关闭。
- 填写格式：0 或 1；1 在北京时间 2026-09-20 及之前查询并抽奖；签到失败不抽奖。

### `CITYBOX_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置以执行断网预演。
- 填写格式：1 为预演；其他值为正式模式；预演不验证真实业务。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写允许自动通知的脚本选择器；默认未选中任何脚本，强制开关优先。
- 填写格式：逗号、分号或空白分隔；支持 08faf258eda0d905、citybox/citybox.js、citybox.js、candidate.js 和文件名通配符 *；* 选中全部，空值关闭自动通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写本机青龙 sendNotify.js 所在目录；默认查找 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本机目录路径；预演不加载通知模块，通知失败保持业务退出码。

## 多账号

每个非空行一个账号 JSON 对象，同一账号的所有请求头合并在 headers 中；逐个独立处理，任一账号失败整体非零退出。
