# 芬享汇每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/fxh.js`
- 青龙命令：`node scripts/fxh.js`
- 建议 Cron：`18 1 * * *`
- 发布哈希：`06b96db2a66fc3c040d716fd500a3e76a00c885b7aeedae55da74d62d564a073`
- 许可证：`MIT`

## 脚本功能

- 每日查询当前积分
- 每日执行芬享汇签到，显示可解析的奖励积分与已签到状态
- 官方返回非敏感昵称、用户名、显示名称或公开 UID 时直接展示
- 逐行多账号独立执行和失败退出
- 完全断网预演、时间轴日志、账号及任务统计、单行 TASK_SUMMARY 汇总
- 实际执行通过青龙通知模块发送脱敏总结；预演只模拟通知，不联网

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `fxhOpenId`

- 必填：是
- 敏感：是
- 获取或设置：打开芬享汇微信小程序，用自己的合法抓包工具查看 scrm.ocheng.me/v2/api/member/info 请求的 miniProgramOpenId 参数，或签到请求路径中的 OpenId。仅复制自己的 OpenId，不要复制整条请求、Cookie 或手机号。
- 填写格式：每个非空行一个 OpenId，允许字母、数字、下划线和短横线；保留上游变量名，不再支持 @ 分隔。

### 可选参数

### `FXH_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置。
- 填写格式：1 表示完全断网预演；其他值表示实际执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置，默认启用。
- 填写格式：0、false、no、off 关闭通知，不区分大小写。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙现有通知模块所在目录；默认查找 /ql/data/scripts 与 /ql/scripts。
- 填写格式：包含 sendNotify.js 或 notify.py 的目录，不是业务依赖。

## 多账号

fxhOpenId 每个非空行一个账号，逐个独立执行；任一账号失败整体非零退出，不使用 @ 或 & 分隔。
