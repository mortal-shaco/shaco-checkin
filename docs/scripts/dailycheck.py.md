# 电子科大返校疫情健康打卡

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/dailycheck.py`
- 青龙命令：`python3 scripts/dailycheck.py`
- 建议 Cron：`33 9 * * *`
- 发布哈希：`0deb2f84f5ba1cddbfc9137e2c446f9126e439a4bf18cdc3325fa7757ba97ae4`
- 许可证：`Apache-2.0`

## 脚本功能

- 使用 sessionId 调用 getLoginUser 换取 Cookie，或直接使用已有 Cookie
- 查询当日返校疫情健康登记状态（appliedTimes）
- 未登记时提交健康状况、体温区间、位置与健康码颜色
- 复查询核验已登记成功
- 展示官方返回的非秘密账号身份或用户配置的显示名
- 换行多账号独立执行、完全断网预演、时间轴脱敏日志与 TASK_SUMMARY
- 青龙通知发送脱敏总结，支持全局开关，通知失败不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WEB_DAILY_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在本人微信登录电子科技大学相关小程序后，从 jzsz.uestc.edu.cn 已授权业务请求中复制 Cookie；或复制登录 sessionId（UUID）。可选在凭据后用 | 附加仅用于日志的显示名。不要把凭据发给他人或写入公开仓库。
- 填写格式：每个非空行一个账号：sessionId 或 Cookie；可选 |显示名。仅按首个 | 分割；账号只用换行分隔。

### 可选参数

### `WEB_DAILY_LOCATION`

- 必填：否
- 敏感：否
- 获取或设置：按本人真实返校/居住位置填写；默认与上游示例校园地址一致，若不住校请覆盖。
- 填写格式：文本地址，默认「四川省成都市郫都区西源大道2006号电子科技大学」。

### `WEB_DAILY_HEALTH_CONDITION`

- 必填：否
- 敏感：否
- 获取或设置：按当日真实健康状况填写；默认与上游一致。
- 填写格式：文本，默认「正常」。

### `WEB_DAILY_HEALTH_COLOR`

- 必填：否
- 敏感：否
- 获取或设置：按当日健康码颜色填写；默认与上游一致。
- 填写格式：文本，默认「绿色」。

### `WEB_DAILY_TEMP_MORNING`

- 必填：否
- 敏感：否
- 获取或设置：按实际上午体温区间填写；默认与上游一致。
- 填写格式：文本，默认「36°C~36.5°C」。

### `WEB_DAILY_TEMP_MIDDAY`

- 必填：否
- 敏感：否
- 获取或设置：按实际昨日午间体温区间填写；默认与上游一致。
- 填写格式：文本，默认「36°C~36.5°C」。

### `WEB_DAILY_TEMP_EVENING`

- 必填：否
- 敏感：否
- 获取或设置：按实际昨日晚间体温区间填写；默认与上游一致。
- 填写格式：文本，默认「36°C~36.5°C」。

### `WEB_DAILY_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1，无需从服务获取。
- 填写格式：1、true、yes、on 开启完全断网预演，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：listed-only 模式下配置允许通知的脚本选择器。
- 填写格式：catalog-id、路径、文件名或通配；* 表示全部；空值禁用全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录。
- 填写格式：目录路径。
