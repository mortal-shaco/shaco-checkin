# EMOS 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/emos_sign.py`
- 青龙命令：`python3 scripts/emos_sign.py`
- 建议 Cron：`30 8 * * *`
- 发布哈希：`dff85c0996086003c529d6e5e978f94be43cb07f1710f1e590928df2e01301b0`
- 许可证：`MIT`

## 脚本功能

- 查询今日签到状态，已完成时跳过重复签到。
- 使用本人 Token 执行每日签到，并通过重新查询 is_sign 确认业务完成；限流、冲突及 HTTP 200 不能单独视为成功。
- 查询并完整显示接口提供的非凭据公开账号名称或公开编号，同时隐藏手机号和凭据。
- 显示签到接口返回的获得积分、连续签到天数和签到排名等数值。
- 保留 EMOS_TOKENS 与 EMOS_TOKEN 参数兼容、两个官方域名的读取回退和随机本地签到短句。
- 签到文案优先从一言获取，按策略保留作者和作品署名；接口、网络、超时、超长、解析及缺失文本异常均回退本地文案，且不向供应商发送账号凭据。
- 支持换行多账号、完全断网预演、逐账号阶段日志、单条结构化汇总及青龙脱敏通知；通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `EMOS_TOKENS`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://emos.best 后，在浏览器开发者工具的网络面板查看本人 /api/sign/check 或 /api/user 请求；复制 Authorization 请求头中 Bearer 后的完整 Token，保存到青龙环境变量。不要分享抓包或请求头。
- 填写格式：每个非空行一个完整 Token，不加 Bearer 前缀，不使用逗号、分号、& 或 @ 分隔账号；Token 内部内容原样保留。

### 可选参数

### `EMOS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，获取方式同 EMOS_TOKENS；建议迁移到规范变量。
- 填写格式：单个 Token 或每个非空行一个 Token；仅当 EMOS_TOKENS 为空时使用。

### `EMOS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置；验证或首次配置时设为 1。
- 填写格式：1、true、yes、on 启用完全断网预演；0、false、no、off 执行真实签到，默认 0。

### `EMOS_BASE`

- 必填：否
- 敏感：否
- 获取或设置：可选，按实际可用的官方域名设置；不需要额外凭据。
- 填写格式：仅允许 https://emos.best 或 https://api.emos.best，允许末尾斜杠；默认依次使用这两个地址。自定义地址不在白名单时停止执行，防止凭据外送。

### `EMOS_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：可选，手动填写公开的签到短句；不要填写任何个人隐私或凭据。
- 填写格式：一言失败时的本地回退文案，合并空白后不超过 280 个字符；为空或过长时随机使用上游内置短句。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选，在青龙环境变量中填写需要通知的脚本选择列表。
- 填写格式：逗号、分号或空白分隔的目录编号、脚本相对路径、文件名或文件名通配符；支持本任务编号、emos_sign.py、candidate.py 和 *。设置为空关闭自动选择；未设置时默认不在通知名单。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已配置好的青龙 notify.py 或 sendNotify.js 所在目录；不是业务运行依赖。
- 填写格式：本地通知适配器目录；同时支持导入 notify.send，以及 /ql/data/scripts 和 /ql/scripts 下的标准通知文件。

## 多账号

每个非空行一个账号的完整 Token，账号独立处理；规范变量 EMOS_TOKENS 优先，EMOS_TOKEN 仅作兼容输入。任一账号失败时整体非零退出。不要用逗号、分号、& 或 @ 分隔账号。
