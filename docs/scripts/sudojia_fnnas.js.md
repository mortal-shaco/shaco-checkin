# 飞牛私有云签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_fnnas.js`
- 青龙命令：`node scripts/sudojia_fnnas.js`
- 建议 Cron：`54 1 * * *`
- 发布哈希：`1fdf5637f860e003d670a3b6a2d230cf37e25a62b218fa1681a9b4c6370a1232`
- 许可证：`GPL-3.0`

## 脚本功能

- 读取并显示本站返回的账号昵称和公开 UID，抑制手机号及凭据输出
- 每日签到，识别明确的今日已签到状态；执行后重新读取页面验证结果
- 查询最近、本月、连续、累计打卡次数或时间、累计和最近奖励、当前打卡等级
- 查询积分、牛值、飞牛币和登录天数
- 每行一个账号，逐账号隔离异常并汇总退出状态
- 完全断网预演、分阶段日志、账号统计及单行 TASK_SUMMARY 结构化汇总
- 正式执行成功、部分失败、失败和配置错误均尝试发送青龙脱敏通知；预演生成摘要并记录不发送状态

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FN_NAS_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://club.fnnas.com，在浏览器开发者工具的网络面板选择本站已登录请求，复制请求头 Cookie。必须包含 pvRK_2132_auth 和 pvRK_2132_saltkey；过期后重新登录获取，勿公开分享。
- 填写格式：每个非空行填写一个账号的完整 Cookie；同账号字段用分号保留，不使用 & 或 @ 分隔账号。

### 可选参数

### `FN_NAS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中手动设置，断网预演时设为 1。
- 填写格式：1 表示断网预演，其他值表示正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如使用自定义青龙通知模块，填写现有 sendNotify.js 所在目录；不设置时查找青龙标准目录。
- 填写格式：本地目录路径，仅用于可选通知，不参与业务请求。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

每行一个账号的完整 Cookie，忽略空行；各账号独立处理，任一失败则整体非零退出。
