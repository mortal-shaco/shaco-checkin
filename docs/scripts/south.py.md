## 脚本功能

- 通过独立 HTTP 客户端完成 SouthPlus 日常与周常任务申请、完成和奖励结算。
- 支持完整 Cookie、浏览器 Cookie 对象 JSON 数组及旧版 COOKIE 入口。
- 支持合并用户名密码多账号登录与旧版单账号入口；可选公开 ddddocr 和 Pillow 包，在内存中通过双识别器和多图像预处理识别验证码。
- 保留每日 9 点定时和默认一小时内随机延迟；可配置站点、浏览器标识与请求超时。
- 校验登录、申请冷却及明确业务成功标记；未知状态失败闭合，不绕过浏览器验证。
- 提供断网预演、脱敏分阶段日志、逐账号统计、单行 TASK_SUMMARY 和青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `SOUTHPLUS_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在所选 SouthPlus 站点登录并完成浏览器验证，在开发者工具网络面板的站内请求中复制 Cookie 请求头。密码登录可用 SOUTHPLUS_ACCOUNTS 替代此规范入口。
- 填写格式：每个非空行一个账号的完整 Cookie；也接受单行浏览器 Cookie 对象 JSON 数组，数组表示一个账号。不以 & 或 @ 分隔账号。

### 可选参数

### `COOKIE`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容入口；获取方式与 SOUTHPLUS_COOKIE 相同，仅规范变量为空时使用。
- 填写格式：与 SOUTHPLUS_COOKIE 相同。

### `SOUTHPLUS_ACCOUNTS`

- 必填：否
- 敏感：是
- 获取或设置：使用本人注册的用户名和密码；存在 Cookie 时不启用密码模式。
- 填写格式：每个非空行一个用户名|密码，仅在首个 | 分割，保留密码中的后续 |。用户名不能包含 | 或换行。

### `SOUTHPLUS_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：旧版单账号入口，填写本人用户名，配合 SOUTHPLUS_PASSWORD；优先级低于 Cookie 和合并密码变量。
- 填写格式：单个用户名。

### `SOUTHPLUS_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：填写与 SOUTHPLUS_USERNAME 属于同一账号的密码；推荐改用合并变量 SOUTHPLUS_ACCOUNTS。
- 填写格式：单账号密码。

### `SOUTHPLUS_SITE`

- 必填：否
- 敏感：否
- 获取或设置：默认 https://www.south-plus.net；仅在确认官方镜像可信后手动设置，Cookie 只发送到此站点，跨站跳转被拒绝。
- 填写格式：HTTPS 站点根地址，不含凭据、路径、查询或片段。

### `SOUTHPLUS_USER_AGENT`

- 必填：否
- 敏感：否
- 获取或设置：从获取 Cookie 的同一个浏览器开发者工具复制 User-Agent 请求头。
- 填写格式：单行浏览器标识；默认沿用上游 Chrome/150 浏览器标识。

### `SOUTHPLUS_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设置为 1 进行断网预演，包含通知预演，不执行随机等待。
- 填写格式：1/true/yes/on 开启，0/false/no/off 关闭，默认关闭。

### `SOUTHPLUS_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置，默认 20 秒。
- 填写格式：1 至 120 的整数，控制每次 HTTP 请求超时。

### `RANDOM_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：沿用上游随机签到开关，默认 true。
- 填写格式：1/true/yes/on 或 0/false/no/off。

### `MAX_RANDOM_DELAY`

- 必填：否
- 敏感：否
- 获取或设置：沿用上游随机延迟上限，默认 3600 秒；设为 0 可关闭等待。
- 填写格式：0 至 86400 的整数，单位秒。

### `SOUTHPLUS_CAPTCHA_RETRY_LIMIT`

- 必填：否
- 敏感：否
- 获取或设置：密码登录需要验证码时使用；可通过公开包管理器手动安装 ddddocr 与 Pillow。脚本不下载或安装任何模型。
- 填写格式：0 至 10 的整数，默认 3；0 关闭识别；不再支持无限重试 -1。

### `SOUTHPLUS_CAPTCHA_RETRY_BACKOFF`

- 必填：否
- 敏感：否
- 获取或设置：调整验证码被拒绝后的等待间隔，默认 2 秒。
- 填写格式：0 至 10 的整数；按尝试次数递增但最多等待 10 秒。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：auto 模式下配置通知脚本选择器；未配置或空值均不发送本脚本通知。
- 填写格式：逗号、分号或空白分隔；支持目录标识 c346af04eb70ab9b、south.py、candidate.py、脚本相对路径和文件名通配符；* 表示全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙已配置通知模块所在目录；也会检查标准青龙路径及可导入的 notify 模块。
- 填写格式：包含 notify.py 或 sendNotify.js 的本地目录；模块缺失或发送失败不改变业务退出码。

## 多账号

每个非空行一个账号。规范入口为 SOUTHPLUS_COOKIE；密码模式使用 SOUTHPLUS_ACCOUNTS，每行用户名|密码，只在首个 | 分割。Cookie、旧版 COOKIE、合并密码、旧版单账号密码依次取首个可用入口。账号独立执行，任一失败整体非零退出。
