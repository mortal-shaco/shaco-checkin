# 霸王茶姬签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/bwcj.py`
- 青龙命令：`python3 scripts/bwcj.py`
- 建议 Cron：`31 9,18 * * *`
- 发布哈希：`cf0c19dcb1d4f324dbe0a197122d579610828432c15c846d871599e0e95671d3`
- 许可证：`MIT`

## 脚本功能

- 读取并展示官方非秘密账号身份，禁止输出手机号和凭据。
- 读取积分流水获取签到用户 ID，支持同账号手动补充用户 ID 并核验一致性。
- 查询新版签到天数，使用上游签名算法执行新版签到并核验业务状态和奖励明细。
- 显式开启旧版签到后查询旧版活动及连续天数并执行旧版签到。
- 保留每天 9 点和 18 点定时及 bwcjCookie 变量名，换行多账号独立执行。
- 完全断网预演、脱敏分阶段日志、账号及任务统计、唯一 TASK_SUMMARY 结构化记录。
- 青龙通知发送脱敏总结，支持全局开关，通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `bwcjCookie`

- 必填：是
- 敏感：是
- 获取或设置：在本人微信霸王茶姬小程序登录后，从本人授权的业务请求头获取 Qm-User-Token；可选 customerId 从积分流水接口 data.data 项获取，仅在流水为空时补充。不要使用手机号或设备标识代替。
- 填写格式：每个非空行一个 Token，或 Token|customerId；仅在首个 | 分割。同账号配套字段，账号仅用换行分隔，不支持原 @ 分隔。

### 可选参数

### `BWCJ_TASKS`

- 必填：否
- 敏感：否
- 获取或设置：按需选择；默认新版签到，旧版需显式开启。
- 填写格式：new、old 或 new,old；默认 new。

### `BWCJ_ACTIVITY_ID`

- 必填：否
- 敏感：否
- 获取或设置：从本人小程序新版签到请求中的 activityId 获取；默认保留上游历史值，活动失效时核对当前请求。
- 填写格式：数字字符串，默认 947079313798000641。

### `BWCJ_STORE_ID`

- 必填：否
- 敏感：否
- 获取或设置：从本人小程序签到请求中的 storeId 或 store_id 获取。
- 填写格式：正整数，默认 49006。

### `BWCJ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1，无需从服务获取。
- 填写格式：1、true、yes、on 开启完全断网预演，默认关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙 notify.py 所在目录；默认尝试导入 notify 及青龙标准目录。
- 填写格式：目录路径。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号；同账号 Token 与可选 customerId 使用首个 | 分割。各账号独立处理，任一失败整体非零退出。
