# 厚工坊签到与任务

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_hgf.js`
- 青龙命令：`node scripts/sudojia_hgf.js`
- 建议 Cron：`44 1 * * *`
- 发布哈希：`c7157dc2b55a1875b3ffca48ff5240a2429a2009ed63fabece924fb8362e5b6f`
- 许可证：`GPL-3.0`

## 脚本功能

- 每日自动签到，显示接口返回的数字酒币奖励。
- 浏览小阿头条并领取任务奖励。
- 保留每天 05:33 的执行计划，签到日期按北京时间计算。
- 每行一个账号，逐账号隔离失败，提供超时和严格业务成功判断。
- 显示官方返回的非敏感账号身份；不输出凭据或接口原始响应。
- 支持完全断网预演、分阶段时间轴日志、账号及子任务统计和单行 TASK_SUMMARY 汇总。
- 通过青龙 sendNotify.js 发送脱敏通知，支持全局开关；预演通知禁止网络投递，通知失败不改变业务退出码。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `HGF_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：登录微信厚工坊商城小程序（#小程序://厚工坊商城/aWVCNOaniBxf4Pk），通过本人设备的抓包工具查看发往 https://api.hgf1862.com 的请求头 sessionid；仅复制该字段的完整值，不填请求头名称或完整 Cookie。失效后重新登录获取。
- 填写格式：每个非空行一个账号的 sessionid；仅按换行分隔，不使用 & 或 @；空行忽略。

### 可选参数

### `HGF_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 启用断网预演。
- 填写格式：1 为预演，其他值为正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如青龙通知模块不在标准目录，填写已有 sendNotify.js 所在目录；不下载或安装通知模块。
- 填写格式：本机通知模块目录路径，可省略。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号，独立执行签到及浏览领奖；任一账号任一步骤失败则整体非零退出。
