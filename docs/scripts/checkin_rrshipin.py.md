- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/checkin_rrshipin.py`
- 青龙命令：`python3 scripts/checkin_rrshipin.py`
- 建议 Cron：`14 10 * * *`
- 发布哈希：`c06676339f15ffd7bb4bb2a38bcddd957f879a604c793275f9f72b0009899465`
- 许可证：`GPL-3.0-only`

## 脚本功能

- 查询并显示官方返回的账号昵称，过滤其中的凭据和手机号等敏感内容
- 查询签到前和任务结束后的积分
- 每日签到，区分奖励领取成功与今日已领取
- 查询每日任务列表和任务编号
- 通过显式任务编号白名单依次激活任务并领取奖励，只有激活成功才继续领取
- 每行一个账号并独立处理，任何失败均非零退出
- 完全断网预演、带时间戳的分阶段日志及单行结构化任务汇总
- 按青龙通知开关和脚本名单发送脱敏统计，通知模块缺失或失败时保持业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `COOKIE_RRShiPin`

- 必填：是
- 敏感：是
- 获取或设置：登录人人视频，开启本机抓包并打开签到页；找到 https://api.qwdjapp.com/activity/index/integral 请求头，复制同一账号的 clientVersion、clientType、token、aliId、st 五个字段。不要分享抓包记录。
- 填写格式：每个非空行一个账号：clientVersion=<版本>; clientType=<类型>; token=<令牌>; aliId=<设备字段>; st=<会话字段>;。字段只在第一个等号处分割，保留值中后续等号；不使用 &&、& 或 @ 分隔账号。

### 可选参数

### `RRSHIPIN_TASK_IDS`

- 必填：否
- 敏感：否
- 获取或设置：先运行默认流程查看任务编号，结合人人视频任务页核对用途和副作用后，仅填写明确授权激活和领奖的编号。
- 填写格式：逗号分隔的数字任务编号；默认空，仅签到及查询，不激活额外任务。编号必须出现在当前账号的官方任务列表中。

### `RRSHIPIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：本地预演时设置为 1。
- 填写格式：1、true、yes、on 表示断网预演，默认 0；通知也仅模拟，不验证真实账号或业务成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按名单通知时配置本脚本目录编号、脚本相对路径、文件名或文件名通配符。
- 填写格式：逗号、分号、空白或换行分隔；支持 64eaa3a0cf186a0f、checkin/checkIn_RRShiPin.py、checkIn_RRShiPin.py、candidate.py 或 *；设置后替换默认名单，空值禁用全部。未提供默认名单，auto 未选择时跳过。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如青龙通知模块不在标准位置，填写现有 notify.py 或 sendNotify.js 所在目录。
- 填写格式：本地目录路径；依次查找可导入的 notify.send、指定目录及 /ql/data/scripts、/ql/scripts 下的通知模块。通知模块是可选集成，不参与业务 HTTP 实现。

## 多账号

每个非空行一个账号，同一账号五个请求头字段组合在 COOKIE_RRShiPin 中；逐个独立执行，任一账号配置或业务失败则整体非零退出。
