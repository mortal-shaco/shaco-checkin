- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/pingmesignin.js`
- 青龙命令：`node scripts/pingmesignin.js`
- 建议 Cron：`0 16 * * *`
- 发布哈希：`d8c4256d97f8830f0af74f8c0d4104586d2f1b31ca54a7b4848367a579bb9b13`

## 脚本功能

- 查询运行前与运行后 Coins 余额
- 每日签到并严格检查业务成功码
- 通过显式开关领取最多 5 次视频奖励，保留原等待间隔
- 兼容 pingme_capture_v3 抓参格式并重建原始参数 UTC 时间与 MD5 签名
- 每行一个账号，失败隔离并汇总退出状态
- 完全离线预演、阶段时间轴、逐账号统计与单行 TASK_SUMMARY 汇总
- 展示官方返回的非敏感昵称、用户名、显示名称或公开 UID
- 按青龙全局开关和选择器发送脱敏合并通知，通知失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `pingme_capture_v3`

- 必填：是
- 敏感：是
- 获取或设置：登录本人 PingMe，通过可信本地抓包工具捕获 https://api.pingmeapp.net/app/queryBalanceAndBonus 请求。将完整请求头存入 headers，将原始查询字符串按 & 分项且每项只在首个 = 分割，保持值的原始编码，存入 paramsRaw。保留全部认证字段，旧 sign 与 signDate 会自动更新。抓参仅存于私有环境变量，不上传或打印。
- 填写格式：每个非空行一个完整 JSON 对象，包含非空 headers 和 paramsRaw 对象，字段值为字符串或数字。兼容旧版单账号格式化 JSON。账号之间仅换行，同一账号所有凭据放在同一个对象中。

### 可选参数

### `PINGME_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：可选。沿用上游应用签名常量，如自行核实官方应用签名协议变化，可填写相应签名密钥。
- 填写格式：单个字符串，未设置时保持上游签名行为。

### `PINGME_VIDEO_ENABLED`

- 必填：否
- 敏感：否
- 获取或设置：确认服务规则允许后手动设置为 1，启用上游视频奖励领取。
- 填写格式：1、true、yes、on 开启，默认关闭。开启后最多 5 次，首次等待 1.5 秒，后续等待 8 秒，失败停止后续视频请求。

### `PINGME_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验证时手动设置为 1。
- 填写格式：1、true、yes、on 开启完全离线预演，跳过所有业务请求与实际通知投递。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：填写需要通知的脚本选择器，可使用本脚本目录编号 6807cb14d5312bb8 或 PingMeSignin.js。
- 填写格式：逗号、分号、空白或换行分隔。支持目录编号、脚本相对路径、文件名及文件名通配符，* 表示全部。设置为空表示自动模式全部关闭，未设置时默认不选中。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙通知模块 sendNotify.js 所在目录。未设置时查找脚本同目录及 /ql/data/scripts、/ql/scripts。
- 填写格式：目录路径，只用于可选通知模块，不承载业务实现。

## 多账号

每个非空行一个账号 JSON，同一账号的 headers 与 paramsRaw 放在同一对象；兼容旧版单账号格式化 JSON。逐账号独立执行，任一账号配置或业务失败均以非零退出。
