## 脚本功能

- 建立独立 Cookie 会话并使用邮箱密码登录 HTM 面板
- 每日签到并识别今日已签到，明确校验业务结果
- 支持换行多账号、逐账号失败隔离及旧版 EMAIL/PASSWORD/BASE_URL 单账号参数
- 支持普通分隔格式及逐行 JSON 账号格式，保留密码内分隔符
- 使用标准库实现 HTTP，启用证书校验、同源重定向限制、超时与响应大小限制
- 官方响应提供安全的非凭据昵称或公开身份时显示以便核对账号
- 完全断网预演，青龙通知开关与清单选择、脱敏统计和单行 TASK_SUMMARY 输出
- 保留每日计划及产品专属发布路径 scripts/airport_sg_checkin.py

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AIRPORT_SG_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人机场官网注册并确认账号可正常登录；面板根地址取自浏览器地址栏。邮箱和密码使用该站注册信息。仅适用于 user-login.htm 登录及 sg_sign.htm 签到的 HTM 面板，不支持验证码或二步验证。
- 填写格式：每个非空行一个账号：HTTPS面板根地址|邮箱|密码；仅按前两个 | 切分，密码内后续 |、&、@ 原样保留。也兼容每行一个包含 url、email、password 字符串的 JSON 对象（别名 base_url/BASE_URL、EMAIL、passwd/PASSWORD）。仅换行分账号，不使用 & 或 @ 分账号。

### 可选参数

### `EMAIL`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容：本人机场注册邮箱。仅在 AIRPORT_SG_ACCOUNTS 无非空行时，与 PASSWORD、BASE_URL 配套使用。
- 填写格式：单账号邮箱

### `PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容：本人机场登录密码，与 EMAIL、BASE_URL 配套使用。
- 填写格式：单账号密码

### `BASE_URL`

- 必填：否
- 敏感：否
- 获取或设置：旧版兼容：本人机场官网地址栏中的 HTTPS 面板根地址，与 EMAIL、PASSWORD 配套使用。
- 填写格式：HTTPS 根地址，不含登录路径、账号密码、查询参数或片段

### `AIRPORT_SG_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时设置为 1；默认 0。预演不请求面板或通知服务。
- 填写格式：1/0、true/false、yes/no、on/off

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：通知自动选择清单；未设置或空值默认不发送，星号选择全部。可使用目录相对路径、文件名、通配符或目录编号 8a735e8a8b20c238。
- 填写格式：以逗号、分号、空白或换行分隔，例如 scripts/airport_sg_checkin.py

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填已配置的青龙 notify.py 所在目录；默认尝试导入 notify 及脚本目录、/ql/data/scripts、/ql/scripts。
- 填写格式：本机通知模块目录路径

## 多账号

每个非空行一个账号；同一账号的面板地址、邮箱、密码在一行组合；仅按前两个字段分隔符切分以保留密码内容。单账号配置错误不阻断后续账号；任一账号失败整体非零退出。
