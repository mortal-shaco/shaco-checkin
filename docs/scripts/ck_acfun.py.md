# AcFun每日签到与可选互动

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ck_acfun.py`
- 青龙命令：`python3 scripts/ck_acfun.py`
- 建议 Cron：`20 0 * * *`
- 发布哈希：`86e6648da0ecf7f63c216dfefebbf88070b97d5134d090c18334deb19217b68b`
- 许可证：`MIT`

## 脚本功能

- 独立实现手机号密码登录及多账号处理，不依赖原仓库工具。
- 保留每天 7:31 调度，默认签到与等级、香蕉余额查询。
- 按需获取排行榜视频和互动令牌。
- 显式启用点赞后取消，两步分别检查业务结果。
- 显式启用公开弹幕，动态提取视频和分区，一言优先并保留作者、来源署名，失败回退本地文本。
- 显式启用对排行榜视频投一根香蕉。
- 官方返回的非秘密昵称、用户名和公开用户标识直接显示。
- 支持完全断网预演、分阶段脱敏日志、账号及任务统计和单行结构化汇总。
- 正式执行的成功、部分失败、失败及配置错误均尝试青龙通知，通知不可用或失败保留业务退出码；断网预演模拟通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ACFUN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 AcFun 官方网站或客户端确认自己的登录手机号和密码，在青龙环境变量中填写；仅用于自己的账号。登录需要验证码时需自行在官方客户端处理，脚本不绕过验证。
- 填写格式：每个非空行一个账号：手机号|密码。只按第一个 | 分割，密码中的后续 |、&、@ 和空格完整保留。

### 可选参数

### `ACFUN`

- 必填：否
- 敏感：是
- 获取或设置：兼容原配置 ACFUN 中的 phone 和 password，手动将账号数据填入环境变量，不再读取私有配置文件；优先使用 ACFUN_ACCOUNTS。
- 填写格式：每个非空行 手机号|密码，或旧账号数组的 JSON，每项包含字符串 phone 和 password。

### `ACFUN_ACTIONS`

- 必填：否
- 敏感：否
- 获取或设置：按需在青龙设置任务开关。默认 sign,info；like、danmu、banana 均须主动启用。
- 填写格式：逗号分隔的任务名，不重复：sign 签到，info 信息查询，like 点赞后取消，danmu 公开弹幕，banana 投一根香蕉。

### `ACFUN_DANMU_FALLBACK`

- 必填：否
- 敏感：否
- 获取或设置：启用弹幕时可在青龙填写公开备用文本，不要填入任何秘密。默认：欣赏作品，感谢分享。
- 填写格式：归一化空白后 1 至 280 个字符，一言网络、超时、HTTP、大小、JSON、正文或长度异常时使用。

### `ACFUN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙设为 1 进行完全断网预演；正式运行设为 0。
- 填写格式：1 启用；0、false、no、off 或空值关闭。预演也不调用通知插件。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如青龙通知模块不在默认位置，可填写已有 notify.py 所在目录；通知模块是可选集成，缺失不影响业务退出码。
- 填写格式：本地目录路径，不是下载地址。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号，手机号与密码在同一行，只在第一个 | 分割；逐账号独立处理，任一账号失败则整体非零退出。兼容 ACFUN 的旧 JSON 账号数组。
