# 塔斯汀每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/tastin_checkin.py`
- 青龙命令：`python3 scripts/tastin_checkin.py`
- 建议 Cron：`4 11 * * *`
- 发布哈希：`4bdf1f35f585b5e5e8a3c0d8b0e3756bc8c17d394f520300bf4f9596c8dbee4c`
- 许可证：`MIT`

## 脚本功能

- 验证本人凭据并查询当前积分
- 自动获取会员手机号并展示官方返回的非敏感账号身份
- 优先从 banner 发现签到活动，保留连续 30 个 ID 的有效期探测与原 ID 回退
- 每日签到、今日已签到识别与最多三次重试
- 展示连续签到天数、奖励、优惠券内容及有效期、奖励积分和签到后积分
- 支持只读积分与活动名称、签到开关及活动时间查询
- 兼容旧命令行和只读配置，不再自动保存凭据
- 逐行多账号独立执行、失败整体非零退出
- 完全离线预演、时间轴日志、阶段耗时、账号统计及唯一单行 TASK_SUMMARY 汇总
- 青龙脱敏通知、通知选择与全局开关，发送失败保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `TASTIN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：本人登录微信塔斯汀小程序后，用自行授权的 HTTPS 调试工具查看 sss-web.tastientech.com 请求头 user-token。可从签到请求体取得 memberPhone，留空时自动获取；过期后重新获取。
- 填写格式：每个非空行一个账号：user-token 或 user-token|memberPhone；仅在首个 | 分隔，右侧完整保留，不用 & 或 @ 分隔账号。

### 可选参数

### `TASTIN_SHOP_ID`

- 必填：否
- 敏感：否
- 获取或设置：查看本人请求头 gray-shop-id 或请求体 shopId；默认保留上游门店。
- 填写格式：正整数，默认 28416。

### `TASTIN_VERSION`

- 必填：否
- 敏感：否
- 获取或设置：查看本人小程序请求头 version。
- 填写格式：版本字符串，默认 3.78.0。

### `TASTIN_ACTIVITY_ID`

- 必填：否
- 敏感：否
- 获取或设置：查看本人签到请求体 activityId；先使用 banner，再从此 ID 起探测 30 个活动，最后回退此 ID。
- 填写格式：正整数，默认 74。

### `TASTIN_STATUS`

- 必填：否
- 敏感：否
- 获取或设置：自行设置，等价于 --status。
- 填写格式：1 只读查询积分与活动；默认签到。

### `TASTIN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置。
- 填写格式：1、true、yes、on 开启完全离线预演；包括通知，不加载外部通知组件。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：青龙全局配置；替换默认通知任务选择，强制开关优先。
- 填写格式：逗号、分号或空白分隔目录编号、文件名、scripts 相对路径或通配符；* 为全部，空值关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可设置青龙已有 notify.py 或 sendNotify.js 所在目录；也自动尝试导入 notify 与标准青龙脚本目录。
- 填写格式：可选本机目录；业务功能不依赖通知文件。

## 多账号

每个非空行一个账号，首个 | 左侧为 user-token，右侧完整保留为可选 memberPhone。账号独立处理，任一账号失败整体非零退出。兼容旧 --token、--phone、--shop-id、--status 与只读 config.json；命令行 token 优先，其次环境账号，再读旧配置。
