- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/comicai_ai_cookie.py`
- 青龙命令：`python3 scripts/comicai_ai_cookie.py`
- 建议 Cron：`46 1 * * *`
- 发布哈希：`7bc9effea735009d6ba475228b6558b43353fe9cf6f56cfb9edbdd24b6a58f0e`
- 许可证：`GPL-3.0`

## 脚本功能

- 可选 Cookie 登录页访问，保留原流程但不将页面 HTTP 200 当作认证成功
- 查询签到前积分并展示签到成功响应中的签到后积分
- 每日签到与已签到业务码识别
- 展示接口返回的非敏感昵称、用户名、显示名称或公开 UID
- 逐行多账号及旧环境变量兼容，账号独立执行且任一失败整体失败
- 完全断网预演及配置校验
- 分阶段时间轴日志、账号及子任务统计、单行 TASK_SUMMARY JSON
- 向青龙 notify.py 发送脱敏总结，通知不可用或失败时保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `COMICAI_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录 ComicAI 网页，从浏览器开发者工具网络面板读取 api.comicai.ai 请求的 Token 请求头；如需要兼容访问登录页，另取 comicai.ai 请求的 Cookie 请求头。仅保存在本人青龙环境中。
- 填写格式：每个非空行一个 JSON 对象，token 为必填非空字符串，cookie 为可选字符串；JSON 转义可保留凭据中的分隔符。设置规范变量后不读取旧变量。

### 可选参数

### `comicai_Token`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容入口，从本人登录后的 ComicAI API 请求头读取 Token。
- 填写格式：仅当 COMICAI_ACCOUNTS 未设置时生效；每个非空行一个 Token，不使用 & 或 @ 分隔账号。

### `comicai_Cookie`

- 必填：否
- 敏感：是
- 获取或设置：旧变量兼容入口，从本人登录后的 ComicAI 网页请求头读取 Cookie。
- 填写格式：仅当规范变量未设置时生效；每个非空行一个完整 Cookie，行数必须与旧 Token 变量一致；可以不设置。

### `COMICAI_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中自行设置以预演配置。
- 填写格式：1 启用完全断网预演，默认 0；预演不调用业务接口，不表示真实签到成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙中自行设置全局通知开关，默认启用。
- 填写格式：0、false、no、off 关闭通知，默认 1；通知失败不改变业务退出码。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：如已有青龙 notify.py 不在常规目录，可填写其所在目录，无需安装额外应用。
- 填写格式：本地目录路径；依次尝试导入 notify、指定目录及 /ql/data/scripts、/ql/scripts 的 notify.py。

## 多账号

每个非空行一个账号 JSON 对象，同账号 Token 和可选 Cookie 放在同一对象内；账号独立执行，任一账号失败整体非零退出。兼容变量按非空行对应，不允许 & 或 @ 分隔账号。
