# 赛马娘官网每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/uma.py`
- 青龙命令：`python3 scripts/uma.py`
- 建议 Cron：`8 10 * * *`
- 发布哈希：`67a21feed918da5d0f8c970ae71e1e8cc68d17730654e9a6f26fbe5e4a68d7ca`
- 许可证：`MIT`

## 脚本功能

- 检查今日签到状态，已签到时避免重复提交，未签到时执行并复查状态
- 查询本月签到总天数与最近签到时间，正确处理跨年和月份边界
- 按本月签到次数查询每日奖励和累计签到奖励
- 查询可用与总积分，以及接口返回的已用和即将到期积分
- 按行配置多账号，单个账号失败后继续处理其他账号
- 断网预演、分阶段脱敏日志、账号统计、任务统计及单行结构化汇总
- 按全局开关和脚本选择策略发送青龙脱敏通知，通知异常不改变业务退出码
- 展示官方响应中明确标注的非凭据昵称、用户名、显示名或公开用户编号

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `UMA_COOKIES`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 https://uma.komoejoy.com/ 并打开签到活动页；开发者工具网络面板中找到 l11-activity-web-hk.komoejoy.com 的签到请求，复制 Cookie 请求头值，不要复制响应或将凭据发给他人。失效时重新登录获取。
- 填写格式：每行一个账号的完整 Cookie 请求头；保留 site、joy_jct、DedeUserID、SESSDATA 中存在的字段。分号分隔字段，每个字段只按首个等号拆分，保留值内的等号。不使用 & 或 @ 分隔账号。

### 可选参数

### `UMA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：手动设置为 1 开启断网预演，默认 0 为正式执行。
- 填写格式：1/0、true/false、yes/no 或 on/off；其他值报配置错误。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要通知本任务时设置为 792bd50268357a67 或 uma.py；设置后替换默认选择列表。
- 填写格式：逗号、分号或空白分隔目录编号、脚本相对路径、文件名或文件名通配符；* 选择全部，空值关闭全部。默认列出模式中本脚本未被选择。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写现有青龙 notify.py 或 sendNotify.js 所在目录；也会尝试导入 notify.send 和青龙标准脚本目录。
- 填写格式：通知模块目录路径；不是业务运行依赖。

UMA_COOKIES 每个非空行对应一个账号；逐个独立执行，任一账号配置或业务失败则进程非零退出。
