## 脚本功能

- 使用学号密码登录昆明医科大学学工 SPCP 疫情防控系统
- 打开每日健康填报页并识别当日已登记或非填报时段
- 读取表单学籍与地址默认值，按上游健康问卷选项提交登记，并以「提交成功」确认
- 展示官方返回的姓名作为公开身份，隐藏密码、身份证、手机号与原始响应
- 多账号逐行配置、独立执行及任一失败非零退出
- 完全断网预演、编号阶段与耗时、账号及子任务统计、单行 TASK_SUMMARY
- 按青龙通知策略发送脱敏汇总，通知不可用不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `KMMU_EPIDEMIC_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用昆明医科大学学工账号（通常为学号）登录 https://xg.kmmu.edu.cn/SPCP/Web/ 确认可打开疫情防控填报页。将学号与密码写入青龙环境变量；不要把凭据发给他人或写入公开仓库、日志、通知。
- 填写格式：每个非空行一个账号，写成「学号|密码」，仅在首个竖线处拆分，密码中后续竖线原样保留。不使用换行以外的符号分隔账号。

### 可选参数

### `KMMU_EPIDEMIC_USERNAME`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：未设置 KMMU_EPIDEMIC_ACCOUNTS 时，与 KMMU_EPIDEMIC_PASSWORD 组合为单账号。新部署请优先使用 KMMU_EPIDEMIC_ACCOUNTS。
- 填写格式：单个学号或学工登录名；须与 KMMU_EPIDEMIC_PASSWORD 同时提供。

### `KMMU_EPIDEMIC_PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容单账号别名：未设置 KMMU_EPIDEMIC_ACCOUNTS 时，与 KMMU_EPIDEMIC_USERNAME 组合为单账号。新部署请优先使用 KMMU_EPIDEMIC_ACCOUNTS。
- 填写格式：对应账号的登录密码；勿写入日志或通知。

### `KMMU_EPIDEMIC_UA`

- 必填：否
- 敏感：否
- 获取或设置：可选自定义浏览器 User-Agent；默认使用接近易班客户端的移动 UA。
- 填写格式：完整 User-Agent 字符串。

### `KMMU_EPIDEMIC_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况调整单次 HTTP 超时秒数。
- 填写格式：5 至 90 的数字秒；默认 20。

### `KMMU_EPIDEMIC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用。
- 填写格式：设为 1、true、yes 或 on 时启用完全断网预演。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。可填 8f8ad2c581f7a3a7、脚本文件名或 scripts 相对路径。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定本地青龙 notify.py 所在目录；也支持导入 notify.send 和青龙标准目录。不是业务依赖。
- 填写格式：已存在的本地通知组件目录，不会下载或安装组件。
