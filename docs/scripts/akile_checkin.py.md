## 脚本功能

- AK 币签到，先查今日流水以避免重复提交，提交后复核实际流水。
- 查询余额、今日所得、连续天数与累计签到收益，分页校准及增量同步。
- 显式开启 Token 保活，验证新凭据后唯一匹配回写青龙多行变量。
- 支持 --check-only 只读查询、08:45 合集调用和每天 22:00 独立定时。
- 多账号独立执行、完全断网预演、脱敏日志、官方公开身份展示、合集 JSON 与单行任务汇总。
- 按通知开关发送脱敏总结，通知故障保留业务退出码；缺参及未确认结果失败闭合。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `AKILE_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://akile.ai/console/ak-coin-shop，浏览器开发者工具→应用→本地存储→https://akile.ai，复制 akile-token 原始 JWT。
- 填写格式：每个非空行一个完整 JWT，包含有效 exp；不加 Bearer，不用 & 或 @ 分隔账号。

### 可选参数

### `AKILE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：预演时手动设为 1。
- 填写格式：1 开启断网预演，默认 0。

### `AKILE_REFRESH_TOKEN`

- 必填：否
- 敏感：否
- 获取或设置：需要保活时手动开启，并先配置青龙应用凭证。
- 填写格式：1 开启刷新及回写，默认 0；仅查询模式不刷新。

### `CLIENT_ID`

- 必填：否
- 敏感：是
- 获取或设置：青龙系统设置→应用设置创建应用并授予环境变量权限；开启保活时必填。
- 填写格式：青龙应用标识。

### `CLIENT_SECRET`

- 必填：否
- 敏感：是
- 获取或设置：与 CLIENT_ID 同一青龙应用的密钥；开启保活时必填。
- 填写格式：青龙应用密钥。

### `AKILE_STATE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：按需指定可写统计文件路径。
- 填写格式：默认同目录 state.json；保存时保留其他分区，禁止符号链接。

### `DAILY_ALL_CHILD`

- 必填：否
- 敏感：否
- 获取或设置：合集调用时设为 1。
- 填写格式：1 输出兼容的 __DAILY_ALL_RESULT__ JSON。

### `DAILY_ALL_DISABLED`

- 必填：否
- 敏感：否
- 获取或设置：需要停用时配置。
- 填写格式：包含 akile、akile_checkin 或 akilecloud 时跳过；用逗号、分号、竖线或换行列出服务。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：在青龙环境变量中设置通知开关。
- 填写格式：默认 1；0、false、no、off 关闭；预演只模拟通知。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：使用自定义青龙通知目录时填写。
- 填写格式：包含 notify.py 或 sendNotify.js 的目录；通知不可用不改变业务退出码。
