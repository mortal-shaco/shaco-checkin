# 厦门大学畅课自动签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/auto_checkin.py`
- 青龙命令：`python3 scripts/auto_checkin.py`
- 建议 Cron：`*/2 8-18 * * 1-5`
- 发布哈希：`e6182aeb1505e114566c657039fa136d5d8ee8e44c7c01047772c52edebea928`
- 许可证：`MIT`

## 脚本功能

- 厦门大学畅课（Tronclass）CAS 登录与可选 Cookie 复用
- 拉取本学期课程并扫描进行中的点名
- 数字签到（详情取码 + 课表日期接口备用通道）
- GPS 签到（双探针三角定位并回查本人签到状态）
- 签到门控（已签超过全班 1/4 或超过 20 人再签，含超时与临近结束保底）
- 多账号按行处理与断网预演
- 脱敏时间轴日志、TASK_SUMMARY 与青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `XMU_AC_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用厦门大学统一身份认证学号与密码。在青龙环境变量中按每行一个账号填写；不要把真实凭据写入公开仓库或分享给他人。
- 填写格式：每行一个账号，格式：学号|密码；仅按第一个竖线分割，密码中可含竖线；账号之间只用换行分隔，不使用 & 或 @

### 可选参数

### `STUDENT_ID`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：未配置 XMU_AC_ACCOUNTS 时，可填写学号；多账号时与 PASSWORD 按行一一对应。
- 填写格式：学号文本；多账号时每行一个学号

### `PASSWORD`

- 必填：否
- 敏感：是
- 获取或设置：兼容别名：与 STUDENT_ID 配套填写统一身份认证密码；已配置 XMU_AC_ACCOUNTS 时忽略本变量。
- 填写格式：密码文本；多账号时每行一个密码，与 STUDENT_ID 行数一致

### `XMU_AC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 进入完全断网预演：只校验配置与请求构造，不登录、不扫描、不提交签到。
- 填写格式：1、true、yes、on 表示开启预演

### `XMU_AC_CHECKIN_GATE`

- 必填：否
- 敏感：否
- 获取或设置：可选：是否启用签到门控（等班里已签超过 1/4 或超过 20 人再签）。默认开启，与上游一致。
- 填写格式：1/true/yes/on 开启；0/false/no/off 关闭

### `XMU_AC_INTERVAL`

- 必填：否
- 敏感：否
- 获取或设置：可选：有界轮询时的扫描间隔秒数，默认 15。仅当 XMU_AC_POLL_SECONDS>0 时生效。
- 填写格式：1 到 600 的整数秒

### `XMU_AC_POLL_SECONDS`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次任务内有界轮询秒数。默认 0 表示扫描一轮后退出，适合青龙分钟级 cron；上课时段可设为 3600 等以在本轮内等待门控。
- 填写格式：0 到 86400 的整数秒

### `XMU_AC_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：可选：单次 HTTP 请求超时秒数，默认 15。
- 填写格式：3 到 120 的数字

### `XMU_AC_PERSIST_COOKIE`

- 必填：否
- 敏感：否
- 获取或设置：可选：是否将登录 Cookie 持久化到本地会话文件以便复用。默认开启；设为 0 可关闭。
- 填写格式：1/true/yes/on 开启；0/false/no/off 关闭

### `XMU_AC_SESSION_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：Cookie 会话文件目录；默认写在脚本同级 .xmu_ac_sessions/。文件名经学号摘要脱敏，仍需妥善保管。
- 填写格式：可写目录的绝对路径

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定青龙 notify.py 或 sendNotify.js 所在目录。
- 填写格式：目录路径；失败后继续尝试 /ql/data/scripts 与 /ql/scripts；通知失败不改变业务退出码
