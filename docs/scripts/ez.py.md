# M-SEC 每日签到与积分查询

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ez.py`
- 青龙命令：`python3 scripts/ez.py`
- 建议 Cron：`44 9 * * *`
- 发布哈希：`eba8fb9b05d24ae0cd60a5123af24199aaea2679c83cbbb4921d2106f3c9367d`
- 许可证：`MIT`

## 脚本功能

- M-SEC 每日签到与重复签到确认，限流时按上游间隔重试确认；严格核对 HTTP 状态和业务码
- 查询当前积分与累计积分；查询失败按失败统计，不能仅凭签到成功返回零
- 每行一个账号 JSON；兼容上游 user* JSON 配置、旧 Authorization= 配置及 Authorization/authorization 字段
- 优先使用已有 Authorization；显式启用后支持密码加云码识别登录、Token 失效重登及可选安全写回
- 显式启用本地积分历史记录，保留上游积分字段与更新时间格式
- 保留全局或账号级飞书及 Lark 机器人通知、命令行覆盖和环境变量兼容；增加青龙统一脱敏通知
- 默认由青龙每日 08:00 单次调度；可选 --daemon 保留启动执行一次及每日 08:00 常驻调度，支持 --tz 时区
- 断网预演、账号独立处理、阶段耗时统计、业务失败非零退出，以及每轮恰好一条 TASK_SUMMARY 汇总
- 展示官方返回的非秘密昵称、用户名、显示名称或公开 UID，并隐藏手机号和所有已知凭据

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `EZ_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：登录 https://msec.nsfocus.com 后，在浏览器开发者工具网络面板查看本人签到或积分请求的 Authorization 请求头，原样复制完整值。每个账号写一行 JSON；配套密码、用户名和云码令牌可写入同一对象。不要向他人发送凭据。
- 填写格式：每个非空行一个 JSON 对象，字段 Authorization（兼容 authorization）；可选 username、password、CAPTCHA_TOKEN、LARK_WEBHOOK、FEISHU_WEBHOOK。密码登录时 Authorization 可空，但必须显式开启 EZ_PASSWORD_LOGIN 并提供全部登录字段。凭据包含特殊字符时按 JSON 转义，不用 & 或 @ 分隔账号。

### 可选参数

### `EZ_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：验证配置时设为 1。
- 填写格式：1 为断网预演，默认正式执行；预演不调用登录、验证码、签到、积分、通知网络接口，不写业务文件。

### `EZ_PASSWORD_LOGIN`

- 必填：否
- 敏感：否
- 获取或设置：需要密码登录或 Token 失效自动重登时显式设置，可能消耗云码识别额度。
- 填写格式：默认关闭；1 开启。需要账号对象的 username、password、CAPTCHA_TOKEN。每次登录只尝试一次识别，账号登录间隔至少 10 秒。

### `CAPTCHA_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：在云码验证码识别服务个人控制台获取 API 令牌。推荐放入对应 EZ_ACCOUNTS 账号对象；此变量仅作为可选全局兼容输入。
- 填写格式：非空令牌；账号内字段优先于兼容配置和全局变量。识别仅向 api.jfbym.com 的 HTTPS 接口提交令牌及验证码图片，不提交 M-SEC 密码或 Authorization。HTTPS 可用性未联网核验，不回退 HTTP。

### `EZ_SAVE_TOKEN`

- 必填：否
- 敏感：否
- 获取或设置：确需保存刷新后的 Token 时显式设置，默认不写回。
- 填写格式：1 开启；仅用于 --config-file 指定的 user* JSON 配置，username 必须唯一；不支持环境变量账号写回。写回文件权限为仅所有者可读写。

### `EZ_SAVE_STATE`

- 必填：否
- 敏感：否
- 获取或设置：需要本地积分历史时显式设置。
- 填写格式：1 开启，默认关闭；按上游结构记录当前积分、累计积分和更新时间，不保存 Token。

### `EZ_STATE_FILE`

- 必填：否
- 敏感：否
- 获取或设置：启用积分历史时选填自己可写的文件路径。
- 填写格式：默认 points_state.json；父目录须存在；写入文件权限为仅所有者可读写。

### `LARK_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：在 Lark 群自定义机器人设置中获取 Webhook；也兼容 --lark、lark=、兼容配置全局字段及账号对象字段。
- 填写格式：可选机器人令牌或 https://open.larksuite.com/open-apis/bot/v2/hook/ 开头的地址；命令行优先。只发送对应账号的脱敏统计。

### `FEISHU_WEBHOOK`

- 必填：否
- 敏感：是
- 获取或设置：在飞书群自定义机器人设置中获取 Webhook；也兼容 --feishu、feishu=、兼容配置全局字段及账号对象字段。
- 填写格式：可选机器人令牌或 https://open.feishu.cn/open-apis/bot/v2/hook/ 开头的地址；命令行优先。只发送对应账号的脱敏统计。

### `TZ`

- 必填：否
- 敏感：否
- 获取或设置：按部署所在地选填时区，也可使用 --tz。
- 填写格式：默认 Asia/Shanghai；使用系统时区数据库支持的时区名；青龙任务本身也应使用同一时区。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要替换默认通知脚本列表时设置。
- 填写格式：默认选中本脚本的目录编号；设置后覆盖默认值。支持目录编号、脚本相对路径、文件名或文件名通配符，用逗号、分号、空白或换行分隔；* 选中全部，空值关闭全部。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：通知模块不在青龙标准路径或 Python 导入路径时，填写已有模块所在目录。
- 填写格式：可选目录，查找 notify.py 或 sendNotify.js；同时探测 /ql/data/scripts 和 /ql/scripts；缺失时记录通知不可用并保留业务退出码。

## 多账号

EZ_ACCOUNTS 每个非空行一个账号 JSON 对象；同账号配套凭据合并在对象内。逐账号隔离处理，任一账号失败则整体非零退出。未配置该变量时兼容 --config-file 的 user* 多账号对象或旧 Authorization= 单账号配置；不按 & 或 @ 拆分。

## 副作用与风险

- 执行 M-SEC 签到，更新当日签到状态并可能增加积分
- 显式开启密码登录时创建或刷新登录会话，并向云码提交验证码图片和识别令牌，可能消耗付费额度
- 显式开启 EZ_SAVE_TOKEN 时改写本人兼容配置中的 Authorization
- 显式开启 EZ_SAVE_STATE 时创建或更新本地积分历史文件
- 正式执行时按通知开关向青龙已配置渠道发送脱敏汇总；配置机器人时另向飞书或 Lark 发送脱敏汇总
