# 青龙备份与阿里云盘签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/qinglong_backup.py`
- 青龙命令：`python3 scripts/qinglong_backup.py`
- 建议 Cron：`11 1 * * *`
- 发布哈希：`66954ce7bf90e8a9c5c403db59fdad877ebc9e3f3c772e58534107de44bc3e4a`
- 许可证：`MIT`

## 脚本功能

- 按青龙计划任务每日 02:00 自动运行，并保留上游的任务名称与计划。
- 将青龙数据目录中的顶层业务目录打包为带时间戳的 tar.gz 备份，并支持配置排除目录。
- 使用脚本内置 HTTP 客户端刷新阿里云盘授权、逐级创建云盘目录并分片上传备份。
- 分别限制本地与每个云盘账号的备份保留数量，且仅清理 qinglong_时间戳.tar.gz 规范文件。
- 默认执行阿里云盘签到并校验 signInCount，也可通过任务动作开关只运行备份或签到。
- 支持每行一个 refresh_token 的多账号独立处理，并在官方响应提供时显示昵称、用户名或公开 UID。
- 提供完全断网且不修改文件的 QLBK_DRY_RUN 预演模式。
- 输出分阶段时间轴、逐账号统计、最终统计和唯一一行 TASK_SUMMARY JSON，并按青龙通知策略发送脱敏总结。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ALIYUNDRIVE_REFRESH_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录本人阿里云盘官方网页或客户端，在本人授权会话的令牌刷新响应中取得 refresh_token；仅保存到青龙环境变量，禁止分享。旧变量 ALI_REFRESH_TOKEN、ALIYUN_TOKEN 仅作为可选兼容输入。
- 填写格式：每个账号一个非空行，每行仅填写该账号的 refresh_token；不得使用 &、@ 或其他符号拼接账号。

### 可选参数

### `ALI_REFRESH_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容凭据变量；建议迁移到必需的规范变量 ALIYUNDRIVE_REFRESH_TOKEN。
- 填写格式：与 ALIYUNDRIVE_REFRESH_TOKEN 相同，每个账号一个非空行。

### `ALIYUN_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容凭据变量；建议迁移到必需的规范变量 ALIYUNDRIVE_REFRESH_TOKEN。
- 填写格式：与 ALIYUNDRIVE_REFRESH_TOKEN 相同，每个账号一个非空行。

### `QLBK_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：导入或修改配置后先启用，用于执行完全断网且不产生副作用的预演。
- 填写格式：1/0、true/false、yes/no 或 on/off。

### `QLBK_ACTIONS`

- 必填：否
- 敏感：否
- 获取或设置：按需填写要执行的动作；不填写时默认同时备份和签到，兼容旧变量 EXEC_SIGN_IN。
- 填写格式：逗号、分号或空白分隔的 backup、sign_in，例如 backup,sign_in。

### `EXEC_SIGN_IN`

- 必填：否
- 敏感：否
- 获取或设置：旧版兼容开关；仅在未设置 QLBK_ACTIONS 时生效。
- 填写格式：True 或 False，也接受 1/0、yes/no、on/off。

### `QLBK_SOURCE_PATH`

- 必填：否
- 敏感：否
- 获取或设置：填写需要备份的青龙数据目录；通常无需设置，脚本优先使用 /ql/data，否则使用 /ql。
- 填写格式：本机绝对目录路径。

### `QLBK_BACKUPS_PATH`

- 必填：否
- 敏感：否
- 获取或设置：填写本地备份目录；默认 backups，并相对于备份源目录解析。
- 填写格式：安全的相对目录；外部绝对目录还需显式启用 QLBK_ALLOW_EXTERNAL_BACKUP_PATH。

### `QLBK_ALLOW_EXTERNAL_BACKUP_PATH`

- 必填：否
- 敏感：否
- 获取或设置：仅在明确需要把备份写到源目录外部时启用。
- 填写格式：1/0、true/false、yes/no 或 on/off。

### `QLBK_UPLOAD_PATH`

- 必填：否
- 敏感：否
- 获取或设置：填写阿里云盘中的目标目录；不存在时脚本会逐级创建，默认 backups。
- 填写格式：不含 . 或 .. 的云盘相对目录，例如 backups/qinglong。

### `QLBK_EXCLUDE_NAMES`

- 必填：否
- 敏感：否
- 获取或设置：填写备份源下不应打包的顶层目录名；不填写时沿用上游默认排除项。
- 填写格式：逗号、分号、空白分隔，或 JSON 字符串数组。

### `QLBK_MAX_FLIES`

- 必填：否
- 敏感：否
- 获取或设置：填写要保留的本地规范备份数量；变量名沿用上游拼写，默认 5。
- 填写格式：1 到 10000 的整数。

### `QLBK_CLOUD_MAX_FLIES`

- 必填：否
- 敏感：否
- 获取或设置：填写每个账号云盘中要保留的规范备份数量；默认 100，且不得小于本地保留数。
- 填写格式：1 到 10000 的整数。

### `QLBK_HTTP_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：网络较慢时可调整单次接口或分片请求超时，默认 20 秒。
- 填写格式：3 到 120 的整数秒数。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要限定通知脚本时填写；设置后替换默认选择，空值关闭全部通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalogId、脚本路径、文件名或通配模式。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本不在标准位置时，填写同时包含 notify.py 或 sendNotify.js 的目录。
- 填写格式：本机绝对目录路径。

## 多账号

ALIYUNDRIVE_REFRESH_TOKEN 每个非空行代表一个账号；账号独立认证、签到、上传和清理，任一账号失败时进程整体返回非零退出码。

## 副作用与风险

- 在本地备份目录创建青龙数据压缩包。
- 在阿里云盘创建目标目录并上传备份文件。
- 将超过保留数量的本地规范旧备份删除。
- 将超过保留数量的云端规范旧备份移入阿里云盘回收站。
- 在启用 sign_in 动作时执行阿里云盘签到，但不领取签到奖励。
- 在通知开关允许且非断网预演时发送脱敏任务总结。
