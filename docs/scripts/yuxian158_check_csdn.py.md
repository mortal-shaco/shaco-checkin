# CSDN每日签到与可选抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/yuxian158_check_csdn.py`
- 青龙命令：`python3 scripts/yuxian158_check_csdn.py`
- 建议 Cron：`36 1 * * *`
- 发布哈希：`d283398aca9aa9411633038f2c803a31c7784808463080f48901723ae541feac`
- 许可证：`MIT`

## 脚本功能

- 使用 CSDN 登录 Cookie 执行每日签到，并对 HTTP 状态、业务代码和结果说明进行明确成功校验。
- 通过 CSDN_DRAW 显式选择是否在签到后执行抽奖，默认不消耗抽奖机会。
- 支持每行一个账号并逐账号隔离失败，任一账号失败时整体返回非零退出码。
- 提供完全断网的预演模式，用于校验参数格式、账号数量和任务规划。
- 输出带时间戳的分阶段脱敏日志、账号统计、总统计和单行 TASK_SUMMARY JSON。
- 按青龙全局开关和脚本选择规则发送脱敏任务通知，通知失败不覆盖业务退出码。
- 当官方响应提供昵称、用户名、显示名称或公开 UID 时，原样显示可公开账号身份。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CSDN_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：浏览器登录 CSDN 后，打开开发者工具网络面板，从发往 CSDN 的已登录请求中复制完整 Cookie 请求头；不要将其写入日志或公开仓库。
- 填写格式：每个非空行一个账号；行内为分号分隔的名称=值字段，字段只在第一个等号处分割。

### 可选参数

### `csdn_cookie`

- 必填：否
- 敏感：是
- 获取或设置：旧版兼容变量，获取方式与 CSDN_COOKIE 相同；仅在未设置 CSDN_COOKIE 时读取。
- 填写格式：每个非空行一个账号；不得与 CSDN_COOKIE 混合配置。

### `CSDN_DRAW`

- 必填：否
- 敏感：否
- 获取或设置：如需在签到后执行抽奖，将该变量设为 1；抽奖可能消耗抽奖机会，因此默认关闭。
- 填写格式：1/0、true/false、yes/no 或 on/off。

### `CSDN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试配置和任务规划时设为 1；该模式不会发出网络请求。
- 填写格式：1/0、true/false、yes/no 或 on/off。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要仅让部分脚本通知时，填写目录标识、产品专属路径、文件名或文件名通配符。
- 填写格式：多个选择器用逗号、分号、空白或换行分隔；* 代表全部；显式空值代表全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本不在标准目录时，填写包含 notify.py 或 sendNotify.js 的目录。
- 填写格式：青龙容器内的绝对目录路径。

CSDN_COOKIE 每个非空行表示一个账号；各账号独立处理，任一账号失败时整个进程返回非零退出码。

## 副作用与风险

- 正式执行时为每个有效账号发起 CSDN 每日签到。
- 启用 CSDN_DRAW 时发起一次抽奖，可能消耗账号的抽奖机会。
- 按通知配置向青龙通知渠道发送不含凭据和原始响应的任务摘要。
