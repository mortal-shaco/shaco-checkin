# OPPO商城每日签到与任务领奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_opposhop.js`
- 青龙命令：`node scripts/sudojia_opposhop.js`
- 建议 Cron：`12 0 * * *`
- 发布哈希：`e9d59a758346682c273928baaa7184e0cd9ebc2997029e7772f847a6f0cbc953`
- 许可证：`GPL-3.0`

## 脚本功能

- 从活动页面 DSL 自动发现签到和任务活动 ID
- 核验登录与会员信息，显示官方会员名称
- 每日签到并重新查询验证签到状态，识别今日已签到
- 查询连续签到天数
- 读取任务列表，按显式任务 ID 白名单完成任务并领奖，始终排除黑卡和购物类型
- 手动确认当月固定奖励 ID 后可领取 3、5、10、15 天累计奖励
- 每行多账号独立执行，任一失败整体非零退出
- 无网络预演、分阶段日志、账号及任务统计、单行结构化总结、青龙通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `OPPOSHOP_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 OPPO商城 APP 开启抓包，进入我的－签到任务，从 https://hd.opposhop.cn/api/cn/oapi/users/web/member/check?unpaid=0 请求获取同一账号的 User-Agent 和 Cookie。不要公开抓包结果。
- 填写格式：每个非空行一个账号：User-Agent|Cookie；仅按第一个竖线分割，后续 Cookie 原样保留；不支持 & 或 @ 分隔账号。

### 可选参数

### `OPPOSHOP_TASK_IDS`

- 必填：否
- 敏感：否
- 获取或设置：从官方任务列表确认任务 ID 及其副作用，只填自己同意执行的任务；黑卡和购物类型 6 始终跳过。默认空值，仅读取任务列表。
- 填写格式：英文逗号分隔的数字任务 ID

### `OPPOSHOP_CUMULATIVE_REWARDS`

- 必填：否
- 敏感：否
- 获取或设置：手动核实当前活动奖励 ID 1327、1328、1329、1330 分别对应累计 3、5、10、15 天后设为 1；默认 0，避免跨活动误领。
- 填写格式：0 或 1

### `OPPOSHOP_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：设为 1 启用完全断网的参数与流程预演；预演通知仅生成总结，不加载联网通知模块。
- 填写格式：0 或 1

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：默认启用青龙通知；设为 0、false、no 或 off 可关闭。
- 填写格式：默认 1

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选：填写青龙 sendNotify.js 所在目录；未设置时检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录绝对路径

## 多账号

每行一个账号，格式为 User-Agent|Cookie；仅在第一个竖线处分割。同一账号配套凭据必须来自同一次登录。任一账号失败则进程非零退出。
