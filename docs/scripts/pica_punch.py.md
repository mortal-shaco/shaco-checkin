## 脚本功能

- 使用邮箱或用户名与密码登录哔咔漫画官方 API
- 登录后提交每日打卡并区分打卡成功与今日已打卡
- 查询并展示官方返回的非凭据公开身份（名称、用户名或 UID），未返回时使用账号序号
- 可选 HTTP(S) 代理访问业务接口
- 支持每行一个账号的多账号独立处理，任一账号失败时非零退出
- 支持完全断网预演、请求超时、时间轴日志、脱敏通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `PICA_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：使用哔咔漫画（Picacomic）注册或登录时的邮箱/用户名与明文密码。仅写入青龙环境变量，不要分享或提交到公开仓库。
- 填写格式：每个非空行一个账号：邮箱或用户名|密码；仅在第一个竖线处分割，密码中后续竖线保留。空行和以 # 开头的注释行忽略。

### 可选参数

### `PICA_PROXY`

- 必填：否
- 敏感：否
- 获取或设置：可选；当青龙主机无法直连 picaapi.picacomic.com 时配置可用的 HTTP(S) 代理。
- 填写格式：完整代理 URL，例如 http://127.0.0.1:7890

### `PICA_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置单次 HTTPS 请求超时；留空使用 20 秒。
- 填写格式：5 至 60 之间的秒数

### `PICA_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用；预演不访问业务接口，也不声明真实打卡成功。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启完全断网预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试导入 notify 和青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径
