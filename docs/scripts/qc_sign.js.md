# 青瓷签到与会话保活

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/qc_sign.js`
- 青龙命令：`node scripts/qc_sign.js`
- 建议 Cron：`25 * * * *`
- 发布哈希：`16825012341ba009defae42c736f7f7e796ff8ba8aa6a5d1bf1d06c2b2a17263`
- 许可证：`MIT`

## 脚本功能

- 按小时刷新微信活动会话，合并官方 Set-Cookie 并以仅本人可读写的权限保存续期 Cookie
- 支持多个账号及多款青瓷游戏，兼容原游戏默认值和参数覆盖方式
- 查询今日签到及累计签到天数，已签到时不重复提交，未签到时提交并复查官方状态
- 仅显式开启后按官方当前角色资料绑定并重试签到
- 独立账号错误隔离、超时及响应大小限制，任一失败整体非零退出
- 完全离线预演、时间轴分阶段日志、账号及任务统计、单行结构化汇总
- 按青龙全局开关和任务选择清单发送脱敏结果通知，通知不可用时保留业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `QC_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在微信打开青瓷官方游戏活动页并完成角色绑定，抓取 api.qingcigame.com 请求头的完整 Cookie（含 PHPSESSID），同时记录活动 URL 中的 app_id、page_id。通行证账号密码不能替代微信活动会话；超过约两小时未保活或会话失效时需重新抓取。
- 填写格式：每个非空行一个账号；完整 Cookie，或 游戏编号,页面编号|完整Cookie；只拆第一个竖线，后续内容原样保留。默认游戏 39、页面 1。

### 可选参数

### `QC_APP_ID`

- 必填：否
- 敏感：否
- 获取或设置：从微信官方活动页面 URL 的 app_id 获取；默认 39（最强蜗牛）。
- 填写格式：数字；优先级：QC_ARGUMENT、账号行前缀、旧 qc_app、本项、默认值。

### `QC_PAGE_ID`

- 必填：否
- 敏感：否
- 获取或设置：从同一官方活动页面 URL 的 page_id 获取；默认 1。
- 填写格式：数字；优先级与 QC_APP_ID 相同。

### `QC_ARGUMENT`

- 必填：否
- 敏感：否
- 获取或设置：兼容原 Surge argument 的游戏覆盖方式，填写官方活动页参数。
- 填写格式：app_id=数字&page_id=数字；覆盖所有账号的目标游戏，仅填写确需覆盖的字段。

### `qc_ck`

- 必填：否
- 敏感：是
- 获取或设置：旧 qc_ck 会话可作为兼容输入；建议迁移到 QC_ACCOUNTS。优先使用非空 QC_ACCOUNTS。
- 填写格式：含 PHPSESSID 的完整 Cookie，每个非空行一个账号。

### `qc_app`

- 必填：否
- 敏感：否
- 获取或设置：可手工迁移原捕获存档中的游戏编号和页面编号。
- 填写格式：游戏编号|页面编号；默认由 QC_APP_ID、QC_PAGE_ID 提供；可被账号前缀和 QC_ARGUMENT 覆盖。

### `QC_ALLOW_BIND`

- 必填：否
- 敏感：否
- 获取或设置：默认不自动修改绑定；优先在官方页面手动绑定。仅在明确需要按官方当前角色资料绑定时开启。
- 填写格式：1 开启；其余值关闭。仅在签到接口明确提示绑定角色且官方资料完整时调用绑定接口。

### `QC_STATE_FILE`

- 必填：否
- 敏感：是
- 获取或设置：可选设置本机会话缓存绝对路径；默认脚本同目录 .qc-session-state.json。缓存包含会话，勿上传或分享；目录须可写且受保护。
- 填写格式：绝对文件路径；自动写入权限 0600，不接受权限宽松的已有缓存；更新原始 Cookie 后使用新会话。

### `QC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线验证时设置为 1，不发送业务请求、不读写缓存、不加载通知模块。
- 填写格式：1 离线预演，其余值执行真实任务；预演成功不代表真实签到成功。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选设置通知任务选择清单，替换本任务默认选择；显式开启全局开关时强制发送。
- 填写格式：逗号、分号或空白分隔；支持目录编号 17218a3f4a2a30a6、scripts/qc_sign.js、文件名及含 * 的文件名模式；* 全部，空值全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知文件不在默认 /ql/data/scripts 或 /ql/scripts 时，指定可信通知模块所在目录；另支持 Python 的 notify.send。
- 填写格式：本机目录路径，包含 sendNotify.js 或 notify.py；不是业务依赖。

## 多账号

每个非空行一个账号；可用 游戏编号,页面编号|完整Cookie 将游戏信息与同账号会话合并，只拆分第一个竖线，不用 &、@ 或其他符号分隔账号。逐账号独立执行，任一账号失败则整体非零退出。
