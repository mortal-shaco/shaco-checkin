# 老板电器服务微商城

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_laoban.js`
- 青龙命令：`node scripts/sudojia_laoban.js`
- 建议 Cron：`6 1 * * *`
- 发布哈希：`17601b584fbd45c2fcc65c13fd47570599ddde5b6d80e1d2b4f0cd6efbadf9e4`
- 许可证：`GPL-3.0`

## 脚本功能

- 查询并显示官方账号昵称，不输出手机号或凭据
- 按中国标准时间检查每日签到状态，未签到时签到并复查
- 查询累计签到天数，领取可领取的连续签到积分奖励
- 执行商品与资讯各三次浏览，并复查积分任务完成状态
- 保留秒杀任务状态检查及上游停用提示，不调用未经验证的秒杀接口
- 同步并查询当前积分
- 每行多账号独立执行、超时及业务成功校验、失败非零退出
- 完全断网预演、时间轴日志、账号与任务统计、单行结构化汇总和青龙脱敏通知

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `LAOBAN_OPENID`

- 必填：是
- 敏感：是
- 获取或设置：登录老板电器服务微商城微信小程序，在本人授权的抓包环境中查看 https://vip.foxech.com 请求正文，复制 openid 字段值；不是请求头。不得分享凭据。
- 填写格式：每行一个账号的 openid，仅填写字段值，不带引号或请求正文；不使用 & 或 @ 分隔。

### 可选参数

### `LAOBAN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：青龙环境变量中设置为 1 即启用完全断网预演。
- 填写格式：1 表示预演；未设置时正式运行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可填写青龙 sendNotify.js 所在目录；未设置时依次检查 /ql/data/scripts 和 /ql/scripts。
- 填写格式：本地目录路径；仅用于可选通知，不参与业务请求。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
