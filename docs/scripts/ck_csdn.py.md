# CSDN签到与可选抽奖

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/ck_csdn.py`
- 青龙命令：`python3 scripts/ck_csdn.py`
- 建议 Cron：`28 1 * * *`
- 发布哈希：`161d9580a41bb0e7ea7a89338fb4c97b2db1c8e76b6877869d0dbc5a22ccd419`
- 许可证：`MIT`

## 脚本功能

- 每日签到，保留上游每天 10:30 的执行时间
- 通过 CSDN_DRAW 显式启用签到后的抽奖
- 每行一个 Cookie 的多账号独立处理，保留 Cookie 值中的等号
- 显示官方响应中的昵称、用户名、显示名称或公开 UID，抑制手机号等敏感字段
- 完全离线预演、请求超时、响应大小限制、禁止重定向转发凭据和明确业务成功校验
- 按账号和编号阶段记录脱敏结果、耗时和统计，输出唯一 TASK_SUMMARY JSON
- 通过青龙 notify.py 通知正式运行的成功、部分失败、失败与配置错误；预演生成摘要并记录离线跳过，通知故障不改变业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `CSDN_COOKIE`

- 必填：是
- 敏感：是
- 获取或设置：在浏览器登录 CSDN，打开开发者工具网络面板，从发往 me.csdn.net 的已登录请求中复制 Cookie 请求头值；勿公开或提交凭据。
- 填写格式：每个非空行一个账号的完整 Cookie，字段用分号分隔，字段仅按第一个等号切分，保留值中的后续等号；不含 Cookie: 前缀，不使用 & 或 @ 分隔账号。

### 可选参数

### `CSDN_DRAW`

- 必填：否
- 敏感：否
- 获取或设置：按需在青龙环境变量中设置；抽奖可能消耗机会，默认关闭。
- 填写格式：默认 0；1、true、yes、on 开启，0、false、no、off 关闭。

### `CSDN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：离线预演时设置为 1；正式执行时设置为 0 或不设置。
- 填写格式：默认 0；1、true、yes、on 开启，0、false、no、off 关闭。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选指定可信的青龙 notify.py 所在目录；也支持导入 notify 或使用青龙标准脚本目录。
- 填写格式：本地目录路径；仅用于可选通知，不是业务依赖。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。
