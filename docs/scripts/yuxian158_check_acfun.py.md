- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）

- 建议 Cron：`44 2 * * *`
- 发布哈希：`0d1091647c5f29e627578fa0826e48fa7eabbb3e87e61aabe59f77c69f0a4095`

## 脚本功能

- 使用 AcFun 手机号和密码登录，并在官方响应提供时显示非敏感昵称、用户名或公开 UID。
- 默认执行每日签到；点赞、取消点赞、分享任务上报、投香蕉和发布弹幕均需显式选择。
- 点赞、取消点赞和投香蕉可使用指定稿件，也可选择每日榜单首个稿件；弹幕仅允许使用明确指定的稿件、视频和分区。
- 发布弹幕时优先从一言 HTTPS 接口获取文案并保留作者及来源，所有声明的远端失败情形都会回退到本地文案。
- 支持规范逐行多账号，并兼容旧版 ACF 逐行或 JSON 参数。
- 提供完全断网预演、分账号分阶段时间轴日志、脱敏统计、单行 TASK_SUMMARY JSON 和青龙通知。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `ACFUN_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：填写 AcFun 登录手机号和对应密码；每个账号独占一行，请仅保存在青龙环境变量中。旧版 ACF 变量可作为可选兼容输入。
- 填写格式：每行 手机号|密码；只按第一个竖线分割，因此密码中的后续竖线会被保留。

### 可选参数

### `ACF`

- 必填：否
- 敏感：是
- 获取或设置：仅供旧版任务迁移；内容仍来自本人 AcFun 登录手机号和密码。设置 ACFUN_ACCOUNTS 后会优先使用新变量。
- 填写格式：可使用每行 手机号|密码，或由 phone 和 password 字段组成的 JSON 对象或对象数组。

### `ACFUN_ACTIONS`

- 必填：否
- 敏感：否
- 获取或设置：按需要显式选择动作；为避免默认修改内容互动状态，默认只签到。
- 填写格式：逗号分隔，可选 sign,like,unlike,share,banana,danmu；默认 sign。

### `ACFUN_CONTENT_ID`

- 必填：否
- 敏感：否
- 获取或设置：从目标 AcFun 视频页面地址取得稿件编号；点赞、取消点赞、投香蕉或弹幕时必填。点赞、取消点赞和投香蕉也可填写 rank 以选取每日榜单首项。
- 填写格式：十进制稿件编号；部分互动也支持固定值 rank。

### `ACFUN_VIDEO_ID`

- 必填：否
- 敏感：否
- 获取或设置：从目标稿件的具体视频分集信息取得；仅发布弹幕时必填。
- 填写格式：十进制视频编号。

### `ACFUN_SUBCHANNEL_ID`

- 必填：否
- 敏感：否
- 获取或设置：从目标稿件所属分区信息取得；仅发布弹幕时必填。
- 填写格式：十进制分区编号。

### `ACFUN_SUBCHANNEL_NAME`

- 必填：否
- 敏感：否
- 获取或设置：填写目标稿件页面显示的分区名称；仅发布弹幕时必填。
- 填写格式：非空中文或文本分区名称。

### `ACFUN_LOCAL_TEXT`

- 必填：否
- 敏感：否
- 获取或设置：自行设置随机文案服务不可用时发布的本地弹幕文本。
- 填写格式：去除多余空白后不超过 280 个字符。

### `ACFUN_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：测试配置时设为 1；预演不会发起任何网络请求，也不会修改账号状态。
- 填写格式：1 表示完全断网预演，0 表示正式执行。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要限制通知脚本时填写目录编号、产品专属发布路径、文件名或通配符；设置为空值会关闭全部脚本通知。
- 填写格式：逗号、分号、空白或换行分隔；本任务可用 f3d4c9cbaf4b9ce7、scripts/ck_acfun_daily.py 或 ck_acfun_daily.py。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知脚本不在标准目录时，填写包含 notify.py 或 sendNotify.js 的目录。
- 填写格式：青龙容器内的绝对目录路径。

## 多账号

ACFUN_ACCOUNTS 每个非空行表示一个账号，按第一个竖线拆分手机号和密码；账号独立执行，任一账号失败时进程整体返回非零状态。
