# M-SEC 每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/task_f37fb5e9.py`
- 青龙命令：`python3 scripts/task_f37fb5e9.py`
- 建议 Cron：`6 8 * * *`
- 发布哈希：`bab5ab940f21b624efeecef9f2eacbc2225aa78838f46a849c31783c80459984`
- 许可证：`MIT`

## 脚本功能

- 使用 Authorization 令牌或用户名密码登录 M-SEC 并完成每日签到
- 密码登录时优先本地 OCR 识别验证码，可选云码 API 回退
- 令牌失效且配置了密码时自动重新登录后继续签到
- 区分签到成功与今日已签到，并查询当前/累计积分
- 展示配置中的用户名作为公开身份，未配置时使用账号序号
- 支持每行一个账号的多账号独立处理，任一账号失败时非零退出
- 支持完全断网预演、请求超时、时间轴日志、脱敏通知与单行 TASK_SUMMARY

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `MSEC_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在 https://msec.nsfocus.com 登录后，从浏览器开发者工具网络请求的 Authorization 头复制令牌；或使用注册用户名与明文密码。仅写入青龙环境变量，不要分享或提交到公开仓库。密码登录需要本地 OCR（ddddocr/Pillow/numpy，可选安装）或配置 MSEC_CAPTCHA_TOKEN。
- 填写格式：每个非空行一个账号：Authorization令牌；或 用户名|密码；或 用户名|密码|Authorization令牌。仅在第一个竖线处分割用户名，其余保留为密码或密码|令牌。空行和以 # 开头的注释行忽略。

### 可选参数

### `MSEC_CAPTCHA_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：可选。在云码（jfbym）平台获取 API Token；仅在密码登录且本地 OCR 不可用或识别失败时使用。纯令牌账号可不配置。
- 填写格式：云码 API Token 字符串

### `MSEC_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按网络情况设置单次 HTTPS 请求超时；留空使用 20 秒。
- 填写格式：5 至 60 之间的秒数

### `MSEC_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：需要验证配置与执行路径但禁止联网时启用；预演不访问业务接口，也不声明真实签到成功。
- 填写格式：布尔值，默认 0；1、true、yes、on 开启完全断网预演

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认名单，只为匹配的脚本开启通知。
- 填写格式：用逗号、分号、空白或换行分隔 catalog ID、相对路径、文件名或通配符；* 表示全部，空值表示全部关闭

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选填写已有青龙 notify.py 或 sendNotify.js 所在目录；未填写时尝试导入 notify 和青龙标准脚本目录。
- 填写格式：已有通知模块所在目录路径

## 多账号

MSEC_ACCOUNTS 中每个非空行代表一个账号，格式为令牌、用户名|密码或用户名|密码|令牌；仅在第一个竖线处分割。脚本逐账号独立处理，任一账号失败时进程非零退出。
