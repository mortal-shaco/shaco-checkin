# 万能福利吧每日签到

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/wnflb.js`
- 青龙命令：`node scripts/wnflb.js`
- 建议 Cron：`0 45 11 * * *`
- 发布哈希：`80b8350c4ffd9a03aac1eab69869bd4099a3f7808d7d9e4effc5040785dbdc6c`
- 许可证：`MIT`

## 脚本功能

- 读取签到页中的签到前积分和非敏感账号身份。
- 提交万能福利吧每日签到，并明确识别签到成功或今日已完成。
- 签到后回查累计签到天数、连续签到天数和当前积分。
- 支持每行一个账号的多账号独立执行与汇总统计。
- 支持完全断网预演、青龙通知选择和单行机器可读任务汇总。

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WNFLB_COOKIE_LIST`

- 必填：是
- 敏感：是
- 获取或设置：登录万能福利吧网页后，打开浏览器开发者工具的网络面板并刷新页面，在发往 www.wnflb2023.com 的请求头中复制完整 Cookie。每行填写一个账号，严禁上传或公开分享。
- 填写格式：每行一个完整 Cookie，例如由若干名称=值片段组成；不使用 &、@ 或其他字符分隔账号。

### 可选参数

### `WNFLB_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：无需获取；设为 1、true、yes 或 on 时启用完全断网预演。
- 填写格式：布尔开关；预演模式不请求业务站点，也不调用通知模块。

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：需要按脚本选择通知时填写；可使用目录 ID 0958709b5f55078a、文件名 wnflb.js、candidate.js 或通配符 *。
- 填写格式：多个选择器可用逗号、分号、空白或换行分隔；显式空值表示全部禁用。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：仅在 sendNotify.js 不位于青龙标准目录时，填写该通知脚本所在目录。
- 填写格式：包含 sendNotify.js 的本地目录绝对路径。

## 多账号

WNFLB_COOKIE_LIST 中每个非空行代表一个账号；账号依次独立执行，任一账号失败时进程以非零状态退出。
