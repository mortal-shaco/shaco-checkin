## 脚本功能

- 每日签到，保留原始接口、POST 表单和 android-10011-102 参数
- 按行配置多账号，逐账号独立执行并汇总退出状态
- 可选签到事件上报，默认关闭非必要上报
- 可选 PushPlus HTTPS 统计通知及青龙通知发现、选择和总开关
- 完全断网预演、超时限制、禁用重定向、限制响应体大小与脱敏日志
- 明确签到成功或已签到消息校验；未知响应失败闭合
- 展示官方响应提供且可安全输出的非敏感账号身份
- 保留 main_handler 云函数入口，并返回同一业务退出码

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `WEWE_ACCOUNTS`

- 必填：是
- 敏感：是
- 获取或设置：在本人微微免费电话 App 中进行签到，通过本人授权的抓包工具查看发往 xconfig.uwewe.cn/sign/signvideoClient 的表单 userId。仅保存 userId，不复制整段请求；每行一个账号。上游未提供其他登录凭据或自动获取方式。
- 填写格式：每个非空行填写一个完整 userId；不使用 &、@ 或逗号分隔账号

### 可选参数

### `WEWE_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置；启用时不执行签到、事件上报、PushPlus 或青龙通知网络投递，只生成摘要。
- 填写格式：1 启用，0 关闭；默认 0

### `WEWE_ALLOW_INSECURE_HTTP`

- 必填：否
- 敏感：否
- 获取或设置：上游仅提供明文 HTTP 签到地址，可能暴露 userId；知悉风险后自行显式启用。默认阻止正式请求，不推测 HTTPS 接口。
- 填写格式：1 允许向原始 HTTP 地址提交，0 拒绝；默认 0

### `WEWE_REPORT_SIGNIN`

- 必填：否
- 敏感：否
- 获取或设置：自行设置；非必要事件上报默认关闭。启用后提交原始 event、place、time、type、typeEN、plat、version，不包含 userId。缺少上报业务响应契约，提交结果标为未核实并导致非零退出。
- 填写格式：1 启用事件上报，0 关闭；默认 0

### `WEWE_TIMEOUT`

- 必填：否
- 敏感：否
- 获取或设置：按运行环境自行设置网络超时。
- 填写格式：1 至 60 秒的数字；默认 15

### `PUSHPLUS_TOKEN`

- 必填：否
- 敏感：是
- 获取或设置：从本人 PushPlus 账户取得推送令牌，可选；使用 HTTPS 发送统计通知，不在通知中附带 userId 或接口原文。
- 填写格式：单个令牌，不用于账号分隔

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：在 auto 模式自行配置通知名单，支持目录编号 fa764c990d2fb7f6、文件名、脚本相对路径、文件名通配符；未设置时本任务在默认名单内，空字符串关闭全部。
- 填写格式：逗号、分号或空白分隔选择项；* 表示全部

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写青龙提供的 notify.py 或 sendNotify.js 所在目录。也依次发现可导入的 notify.send、/ql/data/scripts 和 /ql/scripts 中的通知模块；无需私有工作流仓库。
- 填写格式：通知模块所在目录的绝对路径
