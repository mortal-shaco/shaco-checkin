# 飞蚂蚁旧衣回收

- 管理状态：`待检查`（与本地脚本管理一致：待检查 / 已检查 / 上架）
- 脚本路径：`scripts/sudojia_flyant.js`
- 青龙命令：`node scripts/sudojia_flyant.js`
- 建议 Cron：`50 0 * * *`
- 发布哈希：`3dc5a4f1526f06c7cbf8e102b27fae96a159f8182b6e7db2bb16ef9bf25b7650`
- 许可证：`GPL-3.0`

## 脚本功能

- 每日签到
- 查询连续签到天数
- 查询累计获得、使用及剩余环保豆
- 按账号真实步数兑换一次
- 显式启用抽奖并展示奖品，验证余额后执行
- 显式启用早起打卡与报名
- 多账号独立执行与失败退出码
- 断网预演、时间轴日志和结构化汇总
- 青龙脱敏通知；预演仅本地预览

## 环境变量与参数

先配置必选参数再运行；缺少任一必选参数时任务会失败。敏感值不得写入脚本、订阅地址或公开日志。

### 必选参数

### `FLY_ANT_TOKEN`

- 必填：是
- 敏感：是
- 获取或设置：登录微信旧衣回收小程序，抓取 https://openapp.fmy90.com 的请求头 authorization，删除 bearer 前缀。每个账号独立获取；可在竖线后填写该账号当日真实且未兑换的步数。
- 填写格式：每个非空行一个账号：Token 或 Token|真实步数；仅按第一个竖线拆分，不支持 & 分隔账号。步数为正整数，每次执行仅兑换一次，避免当天重复运行兑换。

### 可选参数

### `FLY_ANT_DRAW`

- 必填：否
- 敏感：否
- 获取或设置：由用户自行设置；抽奖，可能消耗环保豆，余额验证且不少于 10 才执行
- 填写格式：0 或 1，默认 0

### `FLY_ANT_EARLY_SIGN`

- 必填：否
- 敏感：否
- 获取或设置：由用户自行设置；早起打卡，请先在小程序确认活动资格与时间
- 填写格式：0 或 1，默认 0

### `FLY_ANT_BET`

- 必填：否
- 敏感：否
- 获取或设置：由用户自行设置；早起报名，可能扣除环保豆，请先在小程序确认规则
- 填写格式：0 或 1，默认 0

### `FLY_ANT_DRY_RUN`

- 必填：否
- 敏感：否
- 获取或设置：由用户自行设置；完全断网预演，通知只输出本地脱敏预览
- 填写格式：0 或 1，默认 0

### `QINGLONG_NOTIFY`

- 必填：否
- 敏感：否
- 获取或设置：青龙通知总开关；未设置时仅上架脚本默认推送。显式设置后覆盖脚本选择策略。
- 填写格式：留空按上架状态；1、true、yes、on 全部开启；0、false、no、off 全部关闭。

### `QINGLONG_NOTIFY_DIR`

- 必填：否
- 敏感：否
- 获取或设置：可选，填写已有青龙 sendNotify.js 或 notify.py 所在目录；未设置则搜索青龙标准目录。
- 填写格式：本地目录绝对路径

### `QINGLONG_NOTIFY_SCRIPTS`

- 必填：否
- 敏感：否
- 获取或设置：可选脚本选择列表；设置后替代默认上架列表，只为匹配的脚本开启通知。
- 填写格式：用逗号、空格、分号或换行分隔 catalog ID、scripts/相对路径、文件名或文件名通配符；* 表示全部，空值表示全部关闭。

## 多账号

每个非空行一个账号；Token 与该账号可选真实步数用首个竖线分隔。账号依次独立执行，任一账号失败则整体非零退出。
